高压油管燃油喷射系统的压力控制问题。需要回答：(1)喷油嘴流量系数如何确定；(2)凸轮驱动的进油阀运动如何影响管内压力；(3)如何设计凸轮运动规律使压力波动最小；(4)不同工况下的压力稳定性。成功标准：四问均能从同一压力动态模型中读出，而非各自拼装独立说辞。

\section{模型假设}
\item 燃油近似不可压缩（体积弹性模量 E ≈ 常数）
\item 管内流动为准稳态（压力波传播时间 << 喷射周期）
\item 喷嘴流量遵循伯努利方程，流量系数 Cd 在工作范围内近似常数
\item 进油阀位移由凸轮型线决定，忽略阀弹簧动力学
\item 温度变化可忽略（短时喷射过程）

\section{模型建立与求解}
\subsection{压力动态（体积弹性）}
\begin{equation}
dP/dt = (E/V)·(Q_in - Q_out)
\end{equation}
其中，质量守恒+体积弹性模量定义。

\subsection{进油流量}
\begin{equation}
Q_in = Cd·A_in(x_valve)·√(2(P_in - P)/ρ)
\end{equation}
其中，伯努利方程，A_in 为阀门有效通流面积。

\subsection{喷嘴流量}
\begin{equation}
Q_out = Cd·A_out·√(2P/ρ)
\end{equation}
其中，伯努利方程。

\subsection{凸轮型线}
\begin{equation}
x_valve = f(cam_angle)
\end{equation}
其中，凸轮升程曲线，Q3 设计对象。


\subsection{约束条件}
\item 0 ≤ x_valve ≤ x_max（阀门行程有限）
\item P ≥ 0（物理非负）（压力非负）
\item Q_in ≥ 0, Q_out ≥ 0（流量方向约束）
\item 一个喷射周期内 ∫Q_out dt = V_inject（喷油量）（喷油量约束）

\subsection{目标函数}
\begin{equation}
min max|P(t) - P_target|（压力波动最小化）
\end{equation}
其中，Q3 凸轮优化目标。

\begin{equation}
标定 Cd 使模型压力曲线与实测匹配
\end{equation}
其中，Q1 参数标定。
