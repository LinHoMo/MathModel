\begin{abstract}
选定模型：二项抽样模型 批次大时二项近似足够 \end{abstract}

\section{模型假设}
\begin{itemize}
\item 产品不合格率 p 已知或可通过历史数据估计
\item 检验为破坏性或非破坏性均可，但有单位成本
\item 不合格品流出造成客户损失 c_def >> c_ins
\item 批次内产品独立同分布
\end{itemize}

\section{模型建立}
\item 0 ≤ n ≤ N（批次总量）
\subsection{漏检概率}
\begin{equation}
P(miss) = (1-p)^n ≈ e^{-np}（大批次）
\end{equation}

\subsection{总期望成本}
\begin{equation}
E[C] = c_ins·n + c_def·P(miss)·(N-n)
\end{equation}

\subsection{最优检验量}
\begin{equation}
n* = argmin E[C]，一阶条件: c_ins = c_def·(N-n)·(-∂P(miss)/∂n)
\end{equation}

\begin{equation}
min E[C_total] = c_ins·n + c_def·P(漏检)·(N-n)
\end{equation}

\section{候选模型对比}
\begin{itemize}
\item 二项抽样模型（选定）：优点 简单，缺点 假设放回抽样
\item 超几何抽样模型：优点 精确，缺点 计算复杂
\end{itemize}

选定模型：二项抽样模型
