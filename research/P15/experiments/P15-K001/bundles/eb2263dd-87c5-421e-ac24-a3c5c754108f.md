C 题 古代玻璃制品的成分分析与鉴别

丝绸之路是古代中西方文化交流的通道，其中玻璃是早期贸易往来的宝贵物证。早期的玻璃在西亚和埃及地区常被制作成珠形饰品传入我国，我国古代玻璃吸收其技术后在本土就地取材制作，因此与外来的玻璃制品外观相似，但化学成分却不相同。

玻璃的主要原料是石英砂，主要化学成分是二氧化硅（SiO2）。由于纯石英砂的熔点较高，为了降低熔化温度，在炼制时需要添加助熔剂。古代常用的助熔剂有草木灰、天然泡碱、硝石和铅矿石等，并添加石灰石作为稳定剂，石灰石煅烧以后转化为氧化钙（CaO）。添加的助熔剂不同，其主要化学成分也不同。例如，铅钡玻璃在烧制过程中加入铅矿石作为助熔剂，其氧化铅（PbO）、氧化钡（BaO）的含量较高，通常被认为是我国自己发明的玻璃品种，楚文化的玻璃就是以铅钡玻璃为主。钾玻璃是以含钾量高的物质如草木灰作为助熔剂烧制而成的，主要流行于我国岭南以及东南亚和印度等区域。

古代玻璃极易受埋藏环境的影响而风化。在风化过程中，内部元素与环境元素进行大量交换，导致其成分比例发生变化，从而影响对其类别的正确判断。如图 1 的文物标记为表面无风化，表面能明显看出文物的颜色、纹饰，但不排除局部有较浅的风化；图 2 的文物标记为表面风化，表面大面积灰黄色区域为风化层，是明显风化区域，紫色部分是一般风化表面。在部分风化的文物中，其表面也有未风化的区域。

### 2.2 建模结构案例

# 结构案例：古代玻璃制品的成分分析与鉴别 —— 从题面到模型的结构骨架

> 本案例**只提供建模结构骨架**，不含解答、不含数值结果、不含分类阈值。
> 作用是示范「如何把数据分析类题面拆成样本 / 特征 / 标签 / 判别规则」。

## 1. 结构识别路径

按下面五问逐条核对题面：

1. 是否有**样本集合**？—— 一批已知来源（或部分已知）的玻璃文物。
2. 是否有**多维特征**？—— 每种化学成分构成一个维度。
3. 是否有**已知的类别标签**？—— 部分样本的高钾/铅钡类型已知。
4. 是否需要**对未知样本归类**？—— 需要给出鉴别规则。
5. 是否需要**解释成因**？—— 风化、原料来源等会影响成分读数。

前三问命中 → 有监督分类；若标签只覆盖部分样本 → 半监督或先聚类再解释；
第五问命中 → 分类之外还要做归因分析。**分类与归因是两个独立任务，不能互相替代。**

## 2. 变量与参数的划分

| 类别 | 成员 | 说明 |
|---|---|---|
| 样本 | 每件文物（含其表面风化状态标记） | 观测单位 |
| 特征 | 各化学成分的含量比例 | 需注意是否为成分占比 |
| 标签 | 玻璃类型 | 仅部分样本可得 |
| 干扰变量 | 风化程度、取样部位 | 可能系统性偏移读数 |

**关键判断：特征是否是成分占比**。占比数据天然存在「总和为一」的约束，
各维度不独立，这会直接影响后续的距离度量与显著性检验。

## 3. 预处理骨架

按固定顺序处理，每一步都要说明依据：

1. **数据清洗**：识别缺失、异常、以及明显不符合物理约束的记录
2. **成分闭合效应处理**：占比数据需考虑是否做变换（如中心对数比变换）
3. **风化校正**：判断风化是否只是表层现象，是否需要单独建模或剔除
4. **量纲与尺度**：不同成分含量差异大，需决定是否标准化
5. **划分训练与检验集**：必须留出未参与建模的样本做独立检验

**顺序不可颠倒**：先做检验集划分，再做标准化与变换，
否则检验信息会泄漏进训练过程（这是数据分析类最常见的隐性错误）。

## 4. 建模骨架

- **无标签部分**：先做聚类或降维，观察自然分组结构
- **有标签部分**：训练判别模型，输出分类规则
- **规则可解释性**：优先给出可读的判别依据（哪些成分起决定作用）
- **结果稳健性**：用交叉验证或留出集评估，而不是只看训练误差

## 5. 候选机理与选择依据

| 候选机理 | 成立条件 | 本题适用性判断 |
|---|---|---|
| 聚类分析 | 无标签或先探索结构 | 用于观察自然分组 |
| 主成分/降维 | 维度高且相关性强 | 成分间高度相关时适用 |
| 判别分析 | 有标签，需线性判别边界 | 基线分类模型 |
| 决策树 | 需要可读的判别规则 | 可解释性优先时使用 |
| 回归分析 | 关注成分之间的定量关系 | 用于归因而非分类 |

选择依据：**有没有标签**、**要的是预测还是解释**、**成分占比是否做了变换**。
不要因为某个模型「准确率高」就跳过可解释性要求——鉴别规则本身是交付物之一。

## 6. 常见坑

- 把占比数据当成独立变量做常规统计 → 相关性被人为扭曲。
- 忽略风化对表面成分的系统性影响 → 分类边界被干扰变量主导。
- 检验集参与了标准化或特征选择 → 检验结果虚高。
- 用准确率单一指标评价不平衡数据 → 应同时报告各类别的查全与查准。
- 把聚类得到的分组直接当成「真实类别」而不做外部验证。

## 7. 验证骨架

1. **留出检验**：未参与建模的样本上评估，报告混淆矩阵。
2. **交叉验证**：多次划分取均值与标准差，报告稳定性。
3. **对照基线**：与「总是判为多数类」的朴素基线比较。
4. **灵敏度**：扰动关键成分的读数，观察分类是否翻转。
5. **专家/文献对照**：判别依据是否与已知的化学常识一致。
