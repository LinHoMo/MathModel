C 题 机场的出租车问题

大多数乘客下飞机后要去市区（或周边）的目的地，出租车是主要的交通工具之一。国内多数机场都是将送客（出发）与接客（到达）通道分开的。送客到机场的出租车司机都将会面临两个选择：
(A) 前往到达区排队等待载客返回市区。出租车必须到指定的"蓄车池"排队等候，依"先来后到"排队进场载客，等待时间长短取决于排队出租车和乘客的数量多少，需要付出一定的时间成本。
(B) 直接放空返回市区拉客。出租车司机会付出空载费用和可能损失潜在的载客收益。

在某时间段抵达的航班数量和"蓄车池"里已有的车辆数是司机可观测到的确定信息。通常司机的决策与其个人的经验判断有关，比如在某个季节与某时间段抵达航班的多少和可能乘客数量的多寡等。如果乘客在下飞机后想"打车"，就要到指定的"乘车区"排队，按先后顺序乘车。机场出租车管理人员负责"分批定量"放行出租车进入"乘车区"，同时安排一定数量的乘客上车。在实际中，还有很多影响出租车司机决策的确定和不确定因素，其关联关系各异，影响效果也不尽相同。

请你们团队结合实际情况，建立数学模型研究下列问题：

(1) 分析研究与出租车司机决策相关因素的影响机理，综合考虑机场乘客数量的变化规律和出租车司机的收益，建立出租车司机选择决策模型，并给出司机的选择策略。

(2) 收集国内某一机场及其所在城市出租车的相关数据，给出该机场出租车司机的选择方案，并分析模型的合理性和对相关因素的依赖性。

(3) 在某些时候，经常会出现出租车排队载客和乘客排队乘车的情况。某机场"乘车区"现有两条并行车道，管理部门应如何设置"上车点"，并合理安排出租车和乘客，在保证车辆和乘客安全的条件下，使得总的乘车效率最高。

(4) 机场的出租车载客收益与载客的行驶里程有关，乘客的目的地有远有近，出租车司机不能选择乘客和拒载，但允许出租车多次往返载客。管理部门拟对某些短途载客再次返回的出租车给予一定的"优先权"，使得这些出租车的收益尽量均衡，试给出一个可行的"优先"安排方案。

# 结构案例：机场的出租车问题 —— 从题面到模型的结构骨架

> 本案例**只提供建模结构骨架**，不含解答、不含数值结果、不含具体决策结论。
> 作用是示范「如何把服务系统类题面拆成到达过程 / 服务过程 / 决策收益」。

## 1. 结构识别路径

按下面五问逐条核对题面：

1. 是否存在**随机到达**？—— 航班与乘客到达存在随机性。
2. 是否存在**排队等待**？—— 司机在蓄车池按先来后到排队。
3. 是否存在**服务时间**？—— 上车、装载、驶离各占时间。
4. 是否存在**个体决策**？—— 司机在「排队等客」与「空车返回」之间选择。
5. 是否存在**管理方决策**？—— 机场可调整蓄车池规则或上车点安排。

前三条命中 → 排队服务系统；第四条命中 → 叠加个体收益决策；
第五条命中 → 叠加机制设计层。**三层要分开：先刻画系统，再刻画个体，最后才是规则设计。**

## 2. 变量与参数的划分

| 类别 | 成员 | 说明 |
|---|---|---|
| 系统状态 | 排队车辆数、等待中的乘客队列长度 | 随机的 |
| 到达参数 | 单位时间到达的航班数与乘客数 | 需给出分布假设并说明来源 |
| 服务参数 | 单次上车耗时、通行能力 | 决定服务率 |
| 收益参数 | 单次载客收益、空返成本、等待的时间成本 | 进入决策目标 |
| 决策变量 | 司机选择；管理方规则参数 | 分属不同主体 |

**易错点**：把「乘客到达率」与「司机到达率」当成同一个量。
两者是不同的随机过程，混用会让排队模型的输入口径全错。

## 3. 排队结构的骨架

- 明确**顾客**与**服务台**分别是什么（本题里二者需要仔细指定）
- 明确排队规则：先来后到、是否允许中途离开、容量是否有限
- 明确系统是否处于稳态：若到达率随航班时刻表剧烈波动，稳态模型不成立
- 写出状态转移：单位时间内队列长度的增减关系

**核对点**：服务率必须严格大于到达率，排队系统才可能稳定；
若题面数据给出的到达强度接近或超过通行能力，必须显式说明这一事实及其后果。

## 4. 决策层骨架（司机视角）

- 两条互斥选项各自的**期望净收益**：
  - 排队等待：收益 = 载客收入 − 等待时间成本
  - 空车返回：收益 = 市区载客期望收入 − 空返成本
- 决策规则：比较二者期望值
- 若引入司机之间的相互影响（越多司机排队，个体等待越久），
  则个体最优会随他人选择而变化，需转向均衡分析

**结构判断**：是否需要考虑均衡，取决于「个体收益是否依赖他人选择」。
若依赖，则不能只用单人决策模型。

## 5. 候选机理与选择依据

| 候选机理 | 成立条件 | 本题适用性判断 |
|---|---|---|
| 排队论稳态模型 | 到达与服务平稳、系统可达稳态 | 基线模型，用于刻画等待时间 |
| 时变（非稳态）排队 | 到达强度随时段剧烈变化 | 航班时刻表驱动时更贴近现实 |
| 蒙特卡洛仿真 | 分布复杂或规则细节多 | 适合校验解析结论 |
| 博弈/均衡分析 | 个体收益依赖他人选择 | 讨论司机群体行为时需要 |
| 决策分析 | 只关心单个主体的选择 | 管理方视角的规则比选 |

选择依据：**到达过程是否平稳**、**个体之间是否相互影响**。
先建立最简单的稳态模型作为基线，再按题面问法决定是否升级。

## 6. 常见坑

- 未说明到达分布的来源（是假设还是由数据拟合）→ 结论不可复核。
- 用日均到达率回答高峰时段的拥堵问题 → 口径错误，低估等待。
- 把等待时间成本与空返成本用不同量纲直接相加 → 需统一为时间价值或货币。
- 忽略蓄车池容量上限 → 队列长度被低估。
- 只给单一方案，缺少对照方案与灵敏度分析。

## 7. 验证骨架

1. **解析–仿真对照**：用仿真复现排队模型的等待时间，两者应同量级。
2. **极限检验**：到达率趋近零时等待时间应趋近零；趋近通行能力时应急剧上升。
3. **守恒检查**：长时段内进入系统的车辆数应与离开数加滞留数平衡。
4. **参数灵敏度**：扰动到达率与服务率，观察决策阈值是否翻转。
5. **对照方案**：至少给出一个现行规则作为比较基准。
