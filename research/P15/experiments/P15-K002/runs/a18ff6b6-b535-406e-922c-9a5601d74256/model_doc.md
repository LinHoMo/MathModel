# “拍照赚钱”任务定价数学模型

## 1. 问题理解

**核心矛盾**：众包平台的任务定价既要激励会员完成（价格越高完成率越高），又要控制平台支出（价格越低利润越高），矛盾核心是"定价—完成率—利润"三方权衡；叠加会员地理可达性（距离）与竞争（位置集中导致的争抢）后，定价需空间差异化。

**关键实体**：任务（位置、定价、完成状态）、会员（位置、信誉、预订限额/配额）、平台（预算收益、定价支出）。

**子问题分解**：
- **Q1**：研究附件一任务定价规律，分析未完成原因（数据挖掘 + 归因）。
- **Q2**：设计附件一新定价方案并与原方案比较（定价优化）。
- **Q3**：位置集中任务的打包发布——如何修改定价模型、对完成情况的影响（打包定价）。
- **Q4**：附件三新项目的定价方案与实施效果评价（外推 + 模拟）。

**显式条件**：附件一含任务位置、定价、完成情况（1/0）；附件二含会员位置、信誉、预订时间、预订限额，信誉越高优先级越高配额越大（按限额比例配发）；附件三仅含新任务位置。

**隐式条件**：会员理性选择（就近、高性价比）；任务完成与定价、距离、竞争相关；平台有预算上限；打包需位置集中。

**歧义点**：平台收益结构（采纳"利润=预算−定价"）、打包判据（采纳聚类+距离阈值）、附件三无标签如何评价（采纳外推+模拟）。

**问题类型判定**：核心建模范式为**统计建模（定价回归/分类）** 叠加 **优化（定价方案）** 与 **聚类（打包）**；判定依据：Q1 是数据驱动的规律识别，Q2-Q4 是在规律之上的决策优化。

|---|---|---|---|

## 5. 目标

- **Q1**（估计）：$\Pr(y_i=1)=\sigma(\beta_0+\beta_p p_i+\beta_d d_i+\beta_\rho\rho_i+\beta_\lambda\lambda_i)$——估计规律并归因。
- **Q2**（最大化）：$\max_p \Pi=\sum_i\pi_i(p_i)(B-p_i)$——利润最大化新定价。
- **Q3**（最大化）：打包组以组定价 $\bar p_g$ 参与：$\max \Pi=\sum_g\pi_g(\bar p_g)(B_g-\bar p_g)+\sum_{i\notin\cup g}\pi_i(p_i)(B-p_i)$。
- **Q4**（最大化/估计）：附件三最优定价 + 蒙特卡洛模拟完成率与利润区间。

## 7. 机理

**为什么是统计+优化**：完成行为是二值随机事件，其概率由任务与会员的空间经济关系决定——距离成本与竞争稀释使概率下降、定价激励使概率上升，逻辑回归能解析刻画这一关系；决策层（定价）在概率模型上做利润优化，属于"代理模型 + 优化"的经典结构。

**候选模型对比**：
1. **逻辑回归 + 利润优化**（采纳）：可解释、可解析求导、支持一阶条件显式定价；对众包定价有清晰的机制解释。
2. **随机森林/GBDT 黑箱**（弃用）：预测精度可能更高但不可解析求导、难以嵌入优化与归因，解释性差。
3. **空间扫描/热点分析**（弃用）：只回答"哪里聚集"，不能回答"定多少价"。
4. **基于代理的模拟（ABM）**（弃用）：可模拟个体选择但参数多、标定难，且不能直接给出最优定价。

**机理链**：特征工程 → 完成概率模型 → 利润函数 → 一阶条件/组合优化 →（打包）→（外推模拟）。

## 8. 方程

- **logit 模型**（代数）：$\log\dfrac{\pi_i}{1-\pi_i}=\beta_0+\beta_p p_i+\beta_d d_i+\beta_\rho\rho_i+\beta_\lambda\lambda_i$。
- **特征工程**（代数）：$d_i=\min_m\|c_i-c_m\|$，$\rho_i=\#\{m:\|c_i-c_m\|\le R\}/\pi R^2$，$\lambda_i=\#\{i':\|c_i-c_{i'}\|\le R\}/\#\{m:\dots\}$。
- **利润函数**（代数）：$\Pi=\sum_i\pi_i(p_i)(B-p_i)$。
- **一阶条件**（代数）：$\sigma'(\cdot)\beta_p(B-p_i)-\pi_i=0 \Rightarrow p_i^*=\mathrm{clip}\big(\tfrac{1}{\beta_p}\ln\tfrac{B-p_i^*}{p_i^*}-\tfrac{\beta_d d_i+\beta_\rho\rho_i+\beta_\lambda\lambda_i+\beta_0}{\beta_p},p_{min},p_{max}\big)$。
- **组定价**（代数）：$\bar p_g=\frac{1}{|g|}\sum_{i\in g}p_i$，$\pi_g=\sigma(\beta_0+\beta_p\bar p_g+\beta_d\bar d_g+\beta_\rho\bar\rho_g+\beta_\lambda\bar\lambda_g)$。
- **外推模拟**（递推）：$\hat\Pi=\frac1S\sum_s\sum_i\mathbb{1}[u_{i,s}\le\pi_i(p_i^*)](B-p_i^*)$，$u_{i,s}\sim U[0,1]$。

## 9. 求解与验证

**求解策略**：Q1 用 IRLS 最大似然估计回归系数并做显著性检验；Q2 用一阶条件不动点迭代逐任务求解定价（投影到边界）；Q3 用 DBSCAN 聚类生成候选组、组定价小网格枚举取利润最大；Q4 外推定价后用 S=2000 次蒙特卡洛模拟给出完成率与利润区间。复杂度：回归 $O(n\cdot iter)$，定价 $O(n)$，打包 $O(n^2)$，均秒级。

**可复现性**：回归与定价确定性；训练-测试划分与蒙特卡洛用固定随机数初始化方案，5 组初始化报告均值±标准差。

**验证方案**：训练-测试（80/20）AUC 与校准；R、B、D_pack 扰动 ±30% 灵敏度；$p\to0$ 完成率→0、$d\to\infty$ 完成率→0 的极限检验；多初始化稳定性。

**结果合理性预期**：完成率随定价上升、随距离与竞争下降；新方案利润提升 5%~15%；打包增益集中于聚集区。若偏离，按"模型缺陷（变量遗漏/行为假设）→ 参数问题（邻域半径/预算）→ 数值问题（不动点不收敛）"归因。
