# 智能 RGV 动态调度策略数学模型

## 1. 问题理解

**核心矛盾**：8 台 CNC 与 1 辆 RGV 构成柔性加工系统，RGV 同时承担上料、下料、清洗与转运，是系统的"单机瓶颈"。调度矛盾在于：RGV 服务序列如何安排，使班次产量最大、CNC 空闲等待最少，并在随机故障下保持稳健。

**关键实体**：8 台 CNC（1,3,5,7# 与 2,4,6,8# 上下料时间不同）、RGV（移动 1/2/3 单位时间、上下料、清洗）、直线轨道、上/下料传送带；物料（一道工序 / 两道工序）；班次 8 小时。

**子问题分解**：
- **Q1**：一道工序无故障——物料可在任意 CNC 完成，求最优调度与产量。
- **Q2**：两道工序无故障——第一、二道由不同 CNC 依次完成，求最优调度。
- **Q3**：故障情形——单台 CNC 加工故障概率约 1%，排除时间 10~20 分钟、未完成物料报废，分别考虑一道与两道工序。
- **Q4**：任务 2——用 3 组系统作业参数检验模型与算法，给出调度策略与系统作业效率，填入 EXCEL。

**显式条件**：表 1 的 3 组参数（移动时间、加工时间、上下料时间、清洗时间）；每班次 8 小时；故障概率 1%、排除 10~20 分钟；一道/两道工序规则；8 台 CNC。

**隐式条件**：RGV 单机互斥（一次一个动作）；CNC 加工完成后等待上下料期间被占用；两道工序缓冲可等待；故障报废未完成物料；产量口径为完成全部工序并清洗完毕。

**歧义点**：故障概率统计口径（采纳按加工分钟计）、两道工序同机问题（采纳必须异机）、产量口径（采纳完成+清洗）。

**问题类型判定**：核心建模范式为**调度优化（组合优化）**——确定性情形是单机运输服务排序问题；故障情形叠加**随机仿真**；Q4 是**参数敏感性评估**。

## 5. 目标

- **Q1**（最大化）：$\max Y=\sum_k\sum_j x_{k,j}\mathbb{1}[C_{k,j}\le T_s]$（一道工序）。
- **Q2**（最大化）：同上，两道工序以成对物料计数。
- **Q3**（最大化）：$\max \mathbb{E}_{\xi,\eta}[Y]$——故障下的期望产量。
- **Q4**（估计）：3 组参数分别计算 $Y^{(g)}$ 与系统效率 $\rho_g=Y^{(g)}/Y_{cap}^{(g)}$。

## 7. 机理

**为什么是调度优化**：系统时间全部确定，唯一决策自由度是 RGV 的服务顺序；一旦服务序列固定，所有完工时刻可由递推唯一确定，产量即递推末端计数——这是典型的组合调度（单机运输 + 并行机加工）问题。

**候选模型对比**：
1. **完工时间递推 + 贪心/邻域搜索**（采纳）：精确表达系统演化，复杂度低，支持 3 组参数快速求解；结合瓶颈产能公式指导策略方向。
2. **整数规划（MILP）**（弃用）：全班次时间索引变量规模爆炸（8 小时 × 秒级），求解时间不可接受，且无法处理故障随机性。
3. **排队论近似**（弃用）：闭合排队网络需指数分布假设，无法刻画确定时间与 RGV 强耦合，产量误差大。
4. **离散事件仿真**（Q3 采纳）：故障随机性下确定性最优不存在，仿真评估鲁棒策略期望产量。

**机理链**：服务序列 → 完工时间递推 → 产量计数；瓶颈产能 → 策略侧重；故障随机过程 → 仿真评估。

## 8. 方程

- **服务完成时刻**（递推）：$C_{k,j}=\max(C_{k-1,j'}+t_d(r_{k-1},j),\,A_j)+\tau_j+\tau_w$，其中 $A_j$ 为 CNC 就绪时刻；初始 $C_{0,\cdot}=0$。
- **产量计数**（代数）：$Y=\sum_k\sum_j x_{k,j}\mathbb{1}[C_{k,j}\le T_s]$。
- **瓶颈产能**（代数）：$\mu_{RGV}=\dfrac{1}{\bar t_d+\bar\tau+\tau_w}$，$\mu_{CNC}=\dfrac{m}{p}$，瓶颈 $=\min(\mu_{RGV},\mu_{CNC})$。
- **故障抽样**：$\xi_j\sim\mathrm{Bernoulli}(q)$ 每加工分钟，$\eta_j\sim U[600,1200]$。
- **期望产量**（递推）：$\hat Y=\frac1R\sum_r Y^{(r)}$，报告标准差与 95% 置信区间。
- **系统效率**（代数）：$\rho_g=Y^{(g)}/\lfloor T_s/\bar c_g\rfloor$，$\bar c_g$ 为瓶颈周期。

## 9. 求解与验证

**求解策略**：Q1/Q2 用最短就绪优先贪心（每步选 ETA 最小的可服务 CNC）+ 邻域搜索改进，复杂度 $O(Km)$（K 为服务次数）；Q3 用离散事件仿真（事件队列推进）+ 故障感知重指派规则，R=200 次独立样本估计期望产量与置信区间；Q4 对 3 组参数批量运行并计算效率。

**可复现性**：确定性调度逐位可复现；故障仿真用固定随机数初始化方案，5 组初始化取均值±标准差。

**验证方案**：单 CNC 平凡解析对照；移动/加工时间 ±20% 灵敏度；$q\to0$ 仿真收敛于确定性、$q\to1$ 产量趋 0 的极限检验；多初始化稳定性；加工时间 ±5% 不确定区间。

**结果合理性预期**：产量接近瓶颈产能、效率 $\rho$ 在 0.85~0.98；故障损失与停机时长成正比。若偏离，按"模型缺陷（工序/占用口径）→ 参数问题（参数表读取）→ 数值问题（贪心局部最优）"归因。
