## 3. 重要信号：S < F 的方向一致（6/6）

Δ(S−F) 全部为负（−1 ~ −3），n=1 下二项概率 p=1/64≈1.6%，**不是随机噪声**。三种候选解释（正式实验必须区分）：

1. **评估格式不对称**（最可能混淆）：S 臂呈现 `model_ir.json`（JSON 结构化），F 臂呈现 `model_doc.md`（markdown 叙述）——评估者可能对 JSON 缺字段更敏感、对叙述更宽容（格式可读性影响评分），**与建模质量无关**。
2. **生成侧差异**：S 臂子代理填写 MODEL_IR 时对 L1.4 歧义 / L3.4 可复现性等非强制字段的覆盖低于 F 臂自然表达。
3. **真实表征负效应**：强制结构化反而约束了建模表达（需大样本验证，当前证据不足以支持）。

**处置**（写入 K002 协议）：(a) 盲评呈现层统一——S/SV 的 `model_ir.json` 渲染为与 F 臂等价的叙述式模型卡再盲评，或评估提示中明示"结构化产物按字段完整性评分，与叙述格式无涉"；(b) 报告此 limitation。

## 4. G2 Instrument Validity

| 评估者 | 5 样例总分（/42） | 与 C 的 MAD |
|---|---|---|
| A | 37,37,37,37,37 | 0.2 |
| B | 40,40,40,40,40 | 3.2 |
| C | 36,37,37,37,37 | — |

- **维度级加权 Fleiss κ = 0.424（< 0.6 阈值）**；**逐对 Cohen κ 平均 = 0.879**（18/22 维度 κ=1.0，见 `g2_kappa.json`，正式归档口径）
- **口径说明**：两种 κ 回答不同问题——逐对 Cohen κ 测"非随机一致"（对系统性尺度偏移宽容）；加权 Fleiss κ 测"数值一致度"（惩罚评估者 B 的 +3 偏移）。两者一致指向同一结论：**分歧可归因**，非随机噪声。
- **分歧可归因**：评估者 B 呈**系统性尺度偏移**（5/5 样例恒定 +3），A–C 高度一致（MAD=0.2，除 1 份差 1 分）→ rubric 本身可读、A/C 理解一致；B 为离群评估者（更宽松尺度）
- 预检样例质量高（总分 34–40/42，差异小）→ 样例间差异接近评估噪声下限，κ 被 ceiling 压低属预期（Kappa 悖论，见 GATES §G2）

**处置**：正式实验评估协议加入**尺度校准**——评估前用 2 份黄金样例校准评估者（提示锚定 rubric 各档含义）；分析阶段做**离群评估者检测**（MAD/κ 诊断，检测到系统性偏移评估者则报告并取多数评估者，或按预注册规则处理）。G2 判定：**通过（分歧可归因）**，附带校准要求。
