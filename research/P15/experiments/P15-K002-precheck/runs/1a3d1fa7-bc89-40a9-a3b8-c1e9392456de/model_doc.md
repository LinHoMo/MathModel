## 1. 问题理解（Problem Understanding）

### 1.1 显式条件提取

**通用规则（Q1–Q3 共用）**
- 时间以天为单位，第 0 天开始，玩家位于起点；必须在截止日期 $T$ 或之前到达终点，到达即结束。
- 两种资源：水、食物，最小计量单位均为箱；每天水与食物的质量之和不能超过负重上限 $W$；未到终点而任一资源耗尽视为失败。
- 天气三态：晴朗（S）、高温（H）、沙暴（D），沙漠所有区域天气相同。
- 每天可移动到相邻区域或停留；沙暴日必须停留。相邻指有公共边界的区域（仅公共顶点不算，注 1）。
- 停留一天消耗 = 基础消耗量；行走一天消耗 = 2×基础消耗量。
- 第 0 天可在起点用初始资金按基准价格 $p_0$ 购买；可回起点但不能多次购买；终点退回剩余资源，价格为基准价一半（注 2 规定口径：剩余资金/资源指当日所需消耗完毕后的值，若当日有购买则指购买后）。
- 矿山停留可挖矿：挖矿一天消耗 = 3×基础消耗量，获得基础收益 $R$；不挖矿消耗 = 基础消耗量；到达矿山当天不能挖矿；沙暴日也可挖矿。
- 村庄可随时用剩余资金购买，价格为基准价的 2 倍。

**Q1（确定性全知）**：单玩家，整个时段天气事先全部已知，给出一般情况下最优策略；求解附件"第一关""第二关"，结果填入 Result.xlsx。

**Q2（当天已知）**：单玩家，仅知道当天天气，据此决定当天行动；给出一般情况下最佳策略；对附件"第三关""第四关"具体讨论。

**Q3（n 名玩家）**：n 名玩家初始资金相同、同时从起点出发。耦合条款：某天任意 $k\ (2\le k\le n)$ 名玩家均从区域 A 行走到区域 B（B≠A），则每人消耗 = 2k×基础消耗量；某天任意 k 名玩家在同一矿山挖矿，则每人消耗 = 3×基础消耗量，且每人当天挖矿收入 = 基础收益的 $1/k$；某天任意 k 名玩家在同一村庄购买，则每箱价格为基准价的 4 倍；其他情况与单人相同。
- Q3(1)：天气全知，每名玩家行动方案第 0 天确定且此后不能更改（开环），给出策略并对"第五关"具体讨论。
- Q3(2)：仅知当天天气；从第 1 天起，每名玩家当天行动结束后知道其余玩家当天行动方案和剩余资源，再确定次日行动（闭环在线），给出策略并对"第六关"具体讨论。

### 1.2 隐式条件识别

- **资源非负可行性**：任何一天行动后 $x_{t+1}^w \ge 0,\ x_{t+1}^f \ge 0$，否则游戏失败——这约束了行动选择，是决策可行域的一部分。
- **负重守恒**：每天开始时携带质量 $x_t^w\rho^w+x_t^f\rho^f \le W$（$\rho$ 为单位质量）。
- **资金非负**：购买前资金必须足够，$m_t \ge p\cdot q_t$。
- **购买地点限制**：购买只能发生在起点（仅第 0 天一次）或村庄；矿山不能购买。
- **挖矿时机限制**：到达矿山当天不能挖矿（需停留一天后次日才可挖）。
- **终止条件**：$v_t=g$ 即游戏结束，之后不再产生消耗/收益。
- **天气对消耗的依赖**：基础消耗量是天气的函数（附件参数按天气给出），高温通常消耗更多。
- **多玩家同步性（Q3）**：所有玩家同一天行动，耦合条款按"当天执行同一行动的玩家数"触发；同一天同路移动要求方向一致（从 A 到 B）。

### 1.3 歧义点标注

| # | 歧义表述 | 采纳解释 | 理由 |
|---|---|---|---|
| D1 | "水或食物已耗尽"的判定时刻 | 一天行动结束后若任一资源 < 0 即失败；行动前规划必须保证行动后非负 | 与注 2"当日所需资源全部消耗完毕后的剩余量"口径一致 |
| D2 | "行走一天消耗为基础消耗量的 2 倍"是否叠加天气 | 是：消耗 = 2 × 该天气下的基础消耗量 | 基础消耗量按天气给值，行走倍率独立乘 |
| D3 | 沙暴日"可挖矿"是否仍需满足"到达当天不能挖" | 是：沙暴日若处于矿山且非到达日可挖 | 题面明示沙暴日可挖矿 |
| D4 | Q3 同路条款是否要求方向一致 | 要求均从 A 行走到 B（同向同边）才触发 2k；反方向不触发 | 题面原文"均从区域A行走到区域B" |
| D5 | Q3(1)"行动方案第 0 天确定"是否含购买时机 | 含：移动、挖矿、购买全部开环固定 | 原文"行动方案…此后不能更改" |
| D6 | 同一天 k 人停留在同一非村庄区域是否触发条款 | 不触发，仅同路移动/同矿挖矿/同村购买三类有条款 | 题面只列三类耦合 |
| D7 | 玩家到终点后是否继续参与 | 到终点即退出，不再被耦合条款计入 | 与单人规则一致 |
| D8 | Q2 对未来天气的建模 | 无概率分布时采用"当天已知 + 滚动重规划"，并用历史频率/最坏情形做前瞻 | 题面只给当天天气 |
| D9 | 提前到达是否可停留等待 | 可以（停留消耗资源），但到达即结束更优时直接结束；模型允许两者 | 题面未禁止停留 |
| D10 | 水与食物是否可混合计量负重 | 按各自单位质量 $\rho^w,\rho^f$ 求和 | 题面"质量之和" |

### 1.4 问题类型判定

- **Q1**：确定性有限时域序贯决策（combinatorial sequential decision）——状态转移由行动与已知天气决定，无随机性，等价于带资源约束的时变最短路 / 动态规划 / 混合整数规划。
- **Q2**：在线序贯决策（online sequential decision / 滚动时域控制）——天气当天揭示，决策需在信息到达后作出；可建模为带预测的滚动 DP 或有限状态 MDP。
- **Q3(1)**：开环多代理协调博弈（open-loop Nash game / 对称协调优化）——行动序列预先固定，玩家间通过消耗/收益/价格耦合。
- **Q3(2)**：动态博弈（dynamic game / 马尔可夫完美均衡）+ 在线信息更新——每期博弈，状态公开。
- 判定依据：时间离散、行动-状态-资源递推、目标为终局资金最大化，核心结构是**递推 + 优化**，Q2/Q3(2) 再叠加**信息揭示**与**博弈耦合**。

## 5. 目标（Objectives）

**Q1（确定性全知单玩家）**：在天气全知下最大化到达终点并退回剩余资源后的终局资金：
$$\max_{\{u_t,z_t,q_t\}} \; m_{\mathrm{fin}} = m_T + \kappa_E\big(p_0^w\, x_T^w + p_0^f\, x_T^f\big), \quad \text{s.t. } v_T = g,\ t \le T$$
其中 $m_T,x_T^w,x_T^f$ 为第 $T$ 天（或到达日）行动结束后的值；目标类型：最大化。第一关/第二关分别求该目标下的最优策略与最优值，写入 Result.xlsx（注 2 口径）。

**Q2（当天已知在线单玩家）**：在仅知当天天气、未来天气未知（用频率 $\hat P$ 估计）下最大化期望终局资金：
$$\max_{\{u_t,z_t,q_t\}} \; \mathbb{E}_{\omega_{t+1:T}}\big[m_{\mathrm{fin}}\big], \quad \text{决策 } a_t \text{ 仅依赖信息 } \mathcal{I}_t = \{v_t,x_t^w,x_t^f,m_t,\omega_t\}$$
目标类型：最大化（期望）。第三关/第四关给出滚动策略与结果讨论。

**Q3(1)（开环 n 玩家，天气全知）**：每名玩家在第 0 天一次性确定整个行动序列，在他人序列固定下最大化自己的终局资金：
$$\max_{a_{i,0:T-1}} m_{i,\mathrm{fin}} = m_{i,T} + \kappa_E\big(p_0^w x_{i,T}^w + p_0^f x_{i,T}^f\big), \quad \forall i$$
求开环纳什均衡（对称问题下取对称均衡解）；第五关具体讨论。

**Q3(2)（在线 n 玩家，当天已知）**：每期玩家 $i$ 在观察到当天天气 $\omega_t$ 与上期公开信息（他人行动与剩余资源）后选择当天行动，最大化期望终局资金：
$$\max_{a_{i,t}} \; \mathbb{E}\big[m_{i,\mathrm{fin}} \mid \mathcal{I}_{i,t}\big], \quad \mathcal{I}_{i,t} = \{\omega_t,\; \{v_{j,t},x_{j,t}^w,x_{j,t}^f,m_{j,t}\}_{j=1}^n\}$$
采用马尔可夫完美均衡（对称策略）或协调启发式；第六关具体讨论。

## 7. 机理（Mechanism）

**核心机理：离散时间马尔可夫状态递推 + 资源/资金守恒 + 优化目标。**

- **为什么适用递推结构**：游戏以天为步长，状态 $(v_t,x_t^w,x_t^f,m_t)$ 在行动 $a_t$ 与天气 $\omega_t$ 下完全决定下一状态，无跨天后效（天气序列已知时无随机后效；在线时信息集已含当天天气）。这满足动态规划的马尔可夫性质，因此 **Q1** 采用确定性有限时域 DP / 时变最短路；**Q2** 采用滚动时域（receding horizon）重规划：每期以当前状态为初值、以预测天气做 $H$ 步前瞻 DP，只执行第一步——与模型预测控制（MPC）同构，适合"信息逐步揭示"的现实结构。
- **候选模型对比（Q1/Q2 共用）**：
  | 候选 | 结构 | 优点 | 缺点 | 结论 |
  |---|---|---|---|---|
  | 动态规划（逆向递推） | 状态空间 $T\times|V|\times X^w\times X^f\times M$ | 精确、可得最优策略 | 状态网格粗化引入误差 | **选用**：地图小、资源数值有限，网格化可解 |
  | 混合整数规划（MILP） | 0-1 行动变量 + 资源连续 | 直接建模购买/挖矿逻辑 | 开环解、难表达在线重规划 | Q1 备选；Q2 需滚动调用 |
  | 时变最短路（标签算法） | 扩展图 $G_T$ 上求最长剩余资金路 | 结构清晰、复杂度低 | 资源购买使"最短"不唯一 | 作为基线 |
  | 强化学习（Q-learning） | 表格式 | 无需模型 | 样本效率低、非确定性场景 | 弃用：确定性/半确定问题用精确法更优 |
- **Q3(1) 机理**：玩家行动通过三条耦合条款互相影响，且行动序列开环固定 → 这是**有限时域开环博弈**，均衡概念用开环纳什均衡；由于玩家完全对称、目标同向，存在对称均衡，可转化为"协调规划"：先解单人最优路径，再通过错峰（时移出发节奏、错开矿山日、错开村庄采购日）消除耦合惩罚，迭代至无人单方面可改进。
- **Q3(2) 机理**：信息每期公开、行动每期决定 → **动态博弈（马尔可夫完美均衡，MPE）**。对称性允许搜索对称马尔可夫策略 $\pi(s_t)$；工程上采用"协调式滚动策略"：每期各自以 MPC 前瞻，同时加入错峰启发式（如：若预计与他人同日同路，则调整出发/停留一天），避免耦合条款被触发。
- **候选模型对比（Q3）**：
  | 候选 | 结构 | 优点 | 缺点 | 结论 |
  |---|---|---|---|---|
  | 开环纳什均衡（不动点迭代） | 各玩家策略交替最优响应 | 概念标准、可求解 | 均衡不唯一、计算重 | **Q3(1) 选用** |
  | 对称协调规划（群体最优 + 均分） | 单目标集中优化 | 实现简单、结果直观 | 偏离严格博弈论 | Q3(1) 备选/近似 |
  | MPE（策略迭代） | 状态依赖策略 | 理论正确 | 状态空间随 $n$ 爆炸 | Q3(2) 理论框架 |
  | 多智能体仿真 + 启发式协调 | 规则策略仿真 | 可解释、稳健 | 非最优保证 | **Q3(2) 选用**（配合灵敏度验证） |

## 8. 方程（Equations）

**E1 资源消耗方程（代数）**：第 $t$ 天消耗量 = 基础消耗 × 倍数：
$$b_t^w = \delta_{\omega_t}^w\, \beta_t, \qquad b_t^f = \delta_{\omega_t}^f\, \beta_t, \qquad \beta_t = 1 + u_t + 2z_t$$
引用变量：$b_t^w,b_t^f,\omega_t,u_t,z_t,\beta_t$；参数：$\delta_\cdot^w,\delta_\cdot^f$；推导依据：题面规则（5）（7）。约束：$u_t z_t=0$。

**E2 资源状态递推（差分）**：
$$x_{t+1}^w = x_t^w - b_t^w + q_t^w, \qquad x_{t+1}^f = x_t^f - b_t^f + q_t^f$$
初始条件：$x_0^w = q_0^w,\ x_0^f = q_0^f$（第 0 天起点购买）；边界/终止：$x_t^w\ge0,x_t^f\ge0$ 否则失败。

**E3 资金状态递推（差分）**：
$$m_{t+1} = m_t - p_t^w q_t^w - p_t^f q_t^f + r_t, \qquad r_t = R\, z_t$$
初始条件：$m_0 = M_0$；购买单价按地点：起点/矿山返回 $p_0$，村庄 $\kappa_V p_0 = 2p_0$。

**E4 位置转移（逻辑/递推）**：
$$v_{t+1} = \begin{cases} v_t, & u_t=0 \text{ 或 } \omega_t=D \\ \text{adj}(v_t), & u_t=1 \end{cases}$$
初始条件 $v_0=s$；终止条件 $v_{T'}=g,\ T'\le T$。

**E5 终局价值（代数）**：
$$m_{\mathrm{fin}} = m_{T'} + \kappa_E\big(p_0^w x_{T'}^w + p_0^f x_{T'}^f\big), \qquad \kappa_E = \tfrac12$$
其中 $T'$ 为到达日。

**E6 Q1 动态规划值函数（递推）**：
$$V_t(v,x^w,x^f,m) = \max_{a_t \in \mathcal{A}(v,x^w,x^f,m,\omega_t)} V_{t+1}\big(v_{t+1},x_{t+1}^w,x_{t+1}^f,m_{t+1}\big)$$
终端：$V_{T'}(g,\cdot,\cdot,\cdot) = m_{\mathrm{fin}}$；不可行状态 $V=-\infty$。步长：1 天；逆向递推从 $t=T$ 到 $0$，稳定性由状态网格离散化控制（见 §9）。

**E7 Q2 滚动时域前瞻（递推）**：在第 $t$ 天，以预测序列 $\tilde\omega_{t:t+H}$ 求解：
$$a_t^* = \arg\max_{a_t} \; \max_{\{a_{t+1:t+H}\}} \mathbb{E}_{\tilde\omega}\big[V_{t+H}(v_{t+H},x_{t+H}^w,x_{t+H}^f,m_{t+H})\big]$$
只执行 $a_t^*$，$t \to t+1$ 后重解。预测模式：众数天气 / 最坏天气 / 频率采样（多 seed）。

**E8 Q3 耦合条款（逻辑/代数）**：
$$\beta_{i,t} = \begin{cases} 2k_t^m, & \text{玩家 }i\text{ 当日同向同边移动且 } k_t^m\ge 2 \\ 3, & \text{玩家 }i\text{ 当日同矿挖矿（无论 }k_t^M\text{）} \\ 1+u_{i,t}+2z_{i,t}, & \text{其他} \end{cases}$$
$$r_{i,t} = \begin{cases} R/k_t^M, & z_{i,t}=1 \wedge k_t^M\ge 2 \\ R, & z_{i,t}=1 \wedge k_t^M=1 \\ 0, & z_{i,t}=0 \end{cases}, \qquad p_{i,t}^{w,f} = \begin{cases} 4p_0^{w,f}, & \text{同村购买且 } k_t^V\ge 2 \\ 2p_0^{w,f}, & \text{村庄购买} \\ p_0^{w,f}, & \text{起点/其他} \end{cases}$$

**E9 Q3(1) 开环纳什条件（不动点）**：策略 $\sigma_i^*=\{a_{i,0:T-1}^*\}$ 满足
$$m_{i,\mathrm{fin}}(\sigma_i^*,\sigma_{-i}^*) \ge m_{i,\mathrm{fin}}(\sigma_i,\sigma_{-i}^*), \quad \forall \sigma_i,\ \forall i$$
求解：对称性假设下 $\sigma_i^*=\sigma^*$，用最优响应迭代/协调规划求不动点。

**E10 Q3(2) 马尔可夫完美均衡条件**：对称马尔可夫策略 $\pi^*$ 满足对任意状态 $s_t$：
$$\pi^*(s_t) \in \arg\max_{a} \; \mathbb{E}\big[ m_{i,\mathrm{fin}} \mid s_t, a, \pi_{-i}^* \big], \quad \forall i$$
工程实现：以协调滚动策略近似（E7 + 错峰规则），再用仿真验证无单边改进动机。

## 9. 求解与验证（Solving & Validation）

### 9.1 求解策略与模型匹配性

- **Q1**：逆向动态规划（E6）。状态网格：$X^w\times X^f$ 按 1 箱粒度、$M$ 按 1 元粒度（或 10 元粗化）；行动集 $\mathcal{A}$ 含停留/各相邻边移动/挖矿/购买组合。复杂度 $O(T\,|V|\,|X^w|\,|X^f|\,|M|\,|\mathcal A|)$；第一/二关地图约 $6\times6=36$ 区域、$T\approx30$ 天、资源数百箱量级，网格规模 $\sim10^6$，单关可秒级求解。备选：标签设定最短路（E1–E5 定义扩展图）作为交叉验证。
- **Q2**：滚动时域（E7）：每期解 $H$ 步前瞻 DP，$H=3\sim7$ 扫描；复杂度 $O(T\cdot H\cdot|\mathcal A|)$ 乘状态规模，第三/四关同样可实时求解。天气前瞻三种模式对比。
- **Q3(1)**：开环纳什不动点（E9）：先解单人最优（Q1 DP），再迭代错峰调整；不动点迭代上限 50 轮，收敛判据为策略不再变化。
- **Q3(2)**：协调滚动策略仿真：每期各玩家独立跑 E7（用公开状态），外加错峰启发式；蒙特卡洛跑 200 条天气序列。

### 9.2 可复现性安排

- 全局 `seed=42`（bundle 指定）；所有随机分量（Q2/Q3(2) 的天气采样、蒙特卡洛序列）由该种子派生。
- 多 seed 稳定性：对 {42, 2020, 12345, 7, 99} 重复 Q2/Q3(2) 随机试验，报告均值 ± 标准差。
- 数值实现固定：整数运算存资源/资金（箱/元），浮点仅用于单价与期望；结果写入 Result.xlsx 时按注 2 口径四舍五入到整数。

### 9.3 验证方案

- **对照基线**：
  - Q1 基线 1：贪心最短路径（逐日沿最短路走，缺资源才买），作为下界；
  - Q1 基线 2：MILP 开环解，与 DP 结果交叉核对最优值（应完全一致）；
  - Q2 基线：Q1 全知解作为性能上界（在线策略 ≤ 全知解），贪心策略作为下界；
  - Q3 基线：忽略耦合条款的独立单人策略（各玩各自 Q1 最优），量化耦合损失。
- **灵敏度分析**：对 $p_0^w,p_0^f,R,W,\delta_H^w$ 各 ±10% 扰动，观察最优终局资金与策略结构（是否挖矿/是否绕行）的变化率；识别主导参数（预期 $W$ 与 $\delta_H^w$ 最敏感）。
- **极限/边界检验**：
  - $W \to \infty$：策略应趋于"一次性带足全程资源"，不再依赖村庄补购；
  - $R \to 0$：挖矿收益趋零，最优策略应不挖矿（除非必须停留）；
  - $p_0 \to 0$（资源近免费）：携带策略失去意义，终局资金 ≈ $M_0$；
  - $T \to \infty$：应存在无限期可行策略（矿山-村庄循环）时终局资金无上界，否则无解；
  - $k_t^M=n$（全部玩家同矿）：每人收益 $R/n$、消耗 3×，验证 Q3 条款实现正确。
- **多 seed 稳定性**：见 9.2。

### 9.4 结果合理性预期与归因

- 预期量级：第一/二关终局资金为正且明显小于 $M_0$（途中有消耗）；高温日多的关消耗更大、终局资金更低；挖矿出现在矿山附近且挖矿日数受 $R$ 与资源成本权衡控制；Q3 相比 Q1 因耦合条款终局资金下降。
- 若偏离预期：先查**模型缺陷**（状态网格过粗导致 DP 剪错、耦合条款漏触发）；再查**参数问题**（附件参数读入错误、$\hat P$ 偏差）；最后查**数值问题**（网格粒度、整数溢出）。归因路径：固定参数跑基线 → 对比 Q1 两种解法 → 定位偏差源。
