# 解答案例：古代玻璃制品的成分分析与鉴别（2022_C）

> **本轮不注入**（仅建库，供后续 K+C+S 臂使用）。
> 凡涉及具体数值处标注 `待实算`，不填未经计算的数字。

## 1. 完整模型

### 1.1 数据模型

样本矩阵 `X`（行=文物，列=化学成分占比），标签 `y` 仅部分可得。
占比数据满足 `Σ_j X_ij = 1`，各列不独立。

### 1.2 预处理

```
闭合效应:  中心对数比变换 clr(x) = ln(x_j / g(x))
风化处理:  单独建模表层风化影响，或在主分析中对风化样本做敏感性分析
尺度:      标准化到零均值单位方差（在检验集划分之后做）
```

### 1.3 无标签部分（结构探索）

- 主成分分析：观察前若干个主成分是否把样本分成自然组
- 聚类：与已知标签比对，检验自然分组与类型的对应关系

### 1.4 有标签部分（判别）

- 判别分析作为基线（线性、可解释）
- 决策树给出可读规则
- 用留出集 + 交叉验证评估，报告混淆矩阵而非单一准确率

### 1.5 归因层

用回归分析成分之间的定量关系，解释风化与类型对读数的影响。

## 2. 求解步骤

1. 数据清洗（缺失、异常、违反物理约束的记录）
2. 先划分训练/检验集，再做变换与标准化
3. 无标签部分做降维与聚类，观察结构
4. 有标签部分训练判别模型，输出规则
5. 留出集评估 + 交叉验证
6. 归因分析

## 3. 校验

- 与「总是判为多数类」的朴素基线比较
- 交叉验证的均值与标准差（待实算）
- 关键成分扰动后分类是否翻转（待实算）
- 判别依据是否与已知化学常识一致

## 4. 待实算清单

- 主成分解释的方差比例
- 各判别模型的混淆矩阵与查全/查准
- 关键判别成分及其阈值
- 风化校正前后的分类差异
