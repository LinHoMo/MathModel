# 解答案例：机场的出租车问题（2019_C）

> **本轮不注入**（仅建库，供后续 K+C+S 臂使用）。
> 凡涉及具体数值处标注 `待实算`，不填未经计算的数字。

## 1. 完整模型

### 1.1 排队子系统

以蓄车池为服务系统：顾客为排队司机，服务台为放行上车点。

```
到达:  司机到达过程 λ(t)（随时段变化，需由时刻表估计）
服务:  单位时间放行能力 μ
队列:  L(t+Δt) = max(0, L(t)) + 到达 − 放行
等待:  W ≈ L / μ
```

### 1.2 司机决策（个体层）

```
方案 A（排队）: U_A = 载客收入 − 时间价值 × W
方案 B（空返）: U_B = 市区期望收入 − 空返成本
选择:  max(U_A, U_B)
```

### 1.3 均衡层（若考虑相互影响）

`U_A` 依赖 `L`，而 `L` 又依赖其他司机的选择 → 求不动点：
给定选择比例 → 得到队列 → 得到等待 → 更新选择比例，迭代至稳定。

### 1.4 管理方层

以规则参数（上车点数量、蓄车池容量、放行节奏）为决策变量，
以总等待时间或吞吐量为目标做比选。

## 2. 求解步骤

1. 由航班时刻表估计分时段到达强度（说明分布假设与数据来源）
2. 建立分时段排队模型，给出等待时间分布
3. 计算两种方案的期望净收益，给出决策阈值
4. 若引入相互影响，用不动点迭代求均衡
5. 蒙特卡洛仿真校验解析结论
6. 对管理方规则做对照比选

## 3. 校验

- 解析等待时间与仿真结果同量级（待实算）
- 极限检验：到达率趋零时等待趋零；趋近通行能力时急剧上升
- 长时段车辆数守恒（进入 == 离开 + 滞留）
- 参数扰动后决策阈值是否翻转（待实算）

## 4. 待实算清单

- 分时段到达强度的估计值与分布假设
- 平均等待时间与排队长度
- 两方案期望净收益与决策阈值
- 均衡状态下的排队司机比例
- 管理方各规则方案的对照指标
