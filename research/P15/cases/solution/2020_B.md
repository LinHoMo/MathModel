# 解答案例：穿越沙漠（2020_B）

> **本轮不注入**（仅建库，供后续 K+C+S 臂使用）。
> 完整性说明：以下给出完整建模路径、求解步骤与校验方式；
> 凡涉及具体数值处一律标注 `待实算`，**不填未经计算的数字**——
> 本仓库铁律为「所有数值可追溯到已验证的 Result Artifact」。

## 1. 完整模型

### 1.1 状态与决策

状态 `s = (节点, 剩余水, 剩余食物, 剩余资金, 天数, 天气)`，
决策 `a ∈ {停留, 行进至相邻节点, 挖矿, 购买资源}`。

### 1.2 状态转移

```
水/食物:   x' = x − 当日消耗(天气, 行动) + 补给量(行动)
资金:      m' = m − 购买支出 + 挖矿收入(若停留于矿山)
位置:      p' = 相邻节点 或 p
天数:      t' = t + 1
天气:      w' ~ P(w' | w)      # 题面给出的天气转移规则
```

### 1.3 递推方程

```
V_t(s) = max_a E_w[ 当期收益(s,a,w) + V_{t+1}(s') ]
终端:   V_T(s) = 资金(s) 若已到终点，否则 −∞（不可行）
```

天气随机时取期望；天气确定时退化为普通递推。

### 1.4 约束

- 负重：`水 + 食物 ≤ 负重上限`
- 生存：`水 ≥ 0, 食物 ≥ 0`（每阶段）
- 期限：到达终点的 `天数 ≤ 截止天数`
- 通行：只转移到相邻节点

## 2. 求解步骤

1. 读取地图，建立节点邻接表与地形属性
2. 离散化资源维度（先粗网格试算，再按精度与规模权衡加密）
3. 自底向上递推填表（或值迭代处理随机情形）
4. 回溯得到最优策略，输出逐日行动序列
5. 蒙特卡洛多次抽样天气，给出收益的期望与波动

## 3. 校验

- 天数极小时暴力枚举对照（待实算）
- 回溯策略的手动模拟累积收益 == 递推表值
- 松弛（去掉负重约束）给出上界，原解不劣于它

## 4. 待实算清单

- 最优策略的逐日行动序列
- 终点资金的最大值
- 不同天气分布下的策略稳定性
- 多玩家场景下的策略对比结论
