# 解答案例：高温作业专用服装设计（2018_A）

> **本轮不注入**（仅建库，供后续 K+C+S 臂使用）。
> 凡涉及具体数值处标注 `待实算`，不填未经计算的数字。

## 1. 完整模型

### 1.1 控制方程（逐层瞬态热传导）

对第 `i` 层（密度 `ρᵢ`、比热 `cᵢ`、导热系数 `kᵢ`）：

```
ρᵢ cᵢ ∂T/∂t = ∂/∂x ( kᵢ ∂T/∂x )
```

### 1.2 界面条件（层间，最易漏）

```
T|⁻ = T|⁺                     温度连续
kᵢ ∂T/∂x|⁻ = kᵢ₊₁ ∂T/∂x|⁺     热流连续
```

### 1.3 边界与初始条件

```
外边界（环境侧）: −k ∂T/∂x = h (T_env − T)
内边界（皮肤侧）: T = T_skin（恒定）
初始条件:        T(x, 0) = T₀
```

### 1.4 参数反演

```
min_θ  Σ_j ( T_model(x_skin, t_j; θ) − T_meas(t_j) )²
```

`θ` 为待反演的导热系数（或等效参数）；内层每给一组 `θ` 就完整求解一次正问题。

### 1.5 设计（优化）层

在温度约束下最小化厚度或成本，决策变量为各层厚度。

## 2. 求解步骤

1. 空间离散（有限差分或有限体积），在层界面处单独布点
2. 时间推进（隐式格式更稳，显式需满足稳定性条件）
3. 网格无关性检验后固定网格
4. 外层用最小二乘/优化器反演参数（内层调用正问题求解器）
5. 留一部分观测做独立检验
6. 在反演结果上做厚度优化

## 3. 校验

- 稳态解析对照（待实算）
- 能量守恒：进入热流 == 内能变化 + 流出热流
- 网格加密后观测量的变化趋于稳定（待实算）
- 留一检验：未参与反演的观测区间上的预测误差（待实算）

## 4. 待实算清单

- 反演得到的各层等效导热系数
- 皮肤外侧温度随时间的曲线
- 满足约束的最小厚度与各层配置
- 网格与步长的收敛阶
