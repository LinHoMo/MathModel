# 解答案例：板凳龙闹元宵（2024_A）

> **本轮不注入**（仅建库，供后续 K+C+S 臂使用）。
> 凡涉及具体数值处标注 `待实算`，不填未经计算的数字。

## 1. 完整模型

### 1.1 曲线参数化

盘入/盘出为等距螺线，以弧长参数 `s` 描述：

```
r = r₀ + (p / 2π) θ        阿基米德螺线（p 为螺距）
位置: ( r cos θ, r sin θ )
弧长-角度关系由积分给出，用于把「龙头弧长速度」换算为角速度
```

调头段：两段相切圆弧，半径满足题面比例关系，切点由相切条件解出。

### 1.2 链式递推

已知第 `k` 节前把手位置 `P_k`，第 `k+1` 节前把手在曲线上且满足

```
| P_{k+1} − P_k | = 板长（固定）
```

沿曲线向后回溯求解 `P_{k+1}`（每步一个一维方程求根）。

### 1.3 速度传播

```
v_k = (d s_k / d s_龙头) × v_龙头
```

几何因子由内外圈半径差决定 —— 内侧把手在转弯时速度可高于龙头。

### 1.4 碰撞判定

每节板凳抽象为线段（含板宽时用矩形近似），
逐时刻判定任意两条线段是否相交。

### 1.5 待定参数的优化

- 最小螺距：以「不碰撞」为约束，最小化螺距
- 最大速度：以「各把手速度 ≤ 上限」为约束，最大化龙头速度

## 2. 求解步骤

1. 建立螺线与调头段的参数化，核对切线连续性
2. 按时间步推进龙头位置
3. 逐节回溯求解全部把手位置
4. 计算各把手速度
5. 碰撞判定（全配对，不只相邻节）
6. 步长收敛检验后输出逐时刻位置/速度表

## 3. 校验

- 相邻把手间距恒等于板长（待实算）
- 调头段与螺线连接处切线连续（待实算）
- 步长减半后位置序列变化趋于稳定（待实算）
- 极限检验：螺距很大时退化为近似直线（待实算）

## 4. 待实算清单

- 各时刻全部把手的位置与速度表
- 盘入终止时刻与最小螺距
- 调头曲线的最优圆弧参数
- 满足速度约束的最大龙头速度
