# 结构案例：板凳龙闹元宵 —— 从题面到模型的结构骨架

> 本案例**只提供建模结构骨架**，不含解答、不含数值结果、不含具体曲线参数。
> 作用是示范「如何把几何运动类题面拆成参数化 / 运动学 / 约束 / 时序输出」。

## 1. 结构识别路径

按下面五问逐条核对题面：

1. 是否存在**明确的空间曲线**？—— 盘入与盘出沿螺线，调头段为相切圆弧。
2. 是否存在**刚体链式约束**？—— 各节板凳首尾相连，间距固定。
3. 是否存在**驱动与跟随关系**？—— 龙头速度给定，其余节被动跟随。
4. 是否存在**碰撞/不干涉约束**？—— 板凳之间不能相碰。
5. 是否要求**逐时刻的位置与速度序列**？—— 输出是时序表而非单个数值。

前三条命中 → 参数化曲线 + 链式刚体运动学；第四条命中 → 叠加几何干涉约束；
第五条命中 → 必须以时间步进的方式离散输出。**不要试图一步求出闭式解就交付。**

## 2. 变量与参数的划分

| 类别 | 成员 | 说明 |
|---|---|---|
| 几何参数 | 螺距、螺线圈数、各节板长与板宽、孔的相对位置 | 决定曲线与链长 |
| 运动参数 | 龙头前把手速度（或待求的最大速度） | 驱动量 |
| 状态变量 | 各节把手的位置与速度 | 随时间演化 |
| 导出的量 | 相邻节的间距、速度比 | 用于约束与判定 |

**易错点**：把「龙头速度」与「各把手速度」混为一谈。
链式约束下，内侧把手在转弯时的速度可以超过龙头速度，这一点必须在模型里体现。

## 3. 建模骨架

1. **曲线参数化**：用弧长参数描述盘入螺线与盘出螺线，明确螺距与圈数的定义口径
2. **调头段构造**：两段相切圆弧，半径之间满足题面给定的比例关系，
   相切条件给出圆弧圆心与切点的约束方程
3. **链式递推**：已知前一节把手位置，按固定板长反解后一节的位置（沿曲线回溯）
4. **速度传播**：由位置对时间求导得到各把手速度，或直接用弧长速度乘以几何因子
5. **碰撞判定**：把每节板凳抽象为线段（或含宽度的矩形），
   判定任意两条线段在每一时刻是否相交
6. **时间步进**：按固定时间步长推进，输出每个时刻的位置与速度

**顺序很重要**：先几何、再运动学、最后才是碰撞与优化。
反过来做会把几何误差带进速度，再放大到碰撞判定上。

## 4. 约束骨架

- 链式约束：相邻把手间距恒定（等于板长）
- 干涉约束：任意两节板凳在任意时刻不相交
- 速度约束：各把手速度不超过题目给出的上限
- 边界约束：调头空间为给定的圆形区域
- 时间范围：需覆盖题面要求的正负时刻区间

## 5. 候选机理与选择依据

| 候选机理 | 成立条件 | 本题适用性判断 |
|---|---|---|
| 纯几何螺线 + 弧长参数化 | 板凳链完全贴合曲线 | 基础模型，应最先建立 |
| 悬链线/柔性链近似 | 链不完全贴合、存在内侧松弛 | 用于修正内侧误差 |
| 多体动力学 | 需考虑受力与惯性 | 除非要求动力学，否则过重 |
| 数值优化 | 存在待定参数（螺距、半径、最大速度） | 与运动学嵌套使用 |

选择依据：**是否要求动力学**与**链是否严格贴合曲线**。
先用最简几何模型建立基线，再用柔性链模型评估基线误差，是更稳的顺序。

## 6. 常见坑

- 螺距定义口径不一致（沿轴向 vs 沿法向）→ 整条曲线系统性偏移。
- 用「龙头走过的弧长」代替「各把手所在圈层的弧长」→ 速度计算错误。
- 碰撞判定只检查相邻节 → 非相邻节在盘入密集处也可能相碰。
- 时间步长过大 → 碰撞被漏检；过小 → 输出规模失控，需做步长收敛检验。
- 把调头段的圆弧半径比例关系用反。

## 7. 验证骨架

1. **步长收敛**：缩小时间步长，位置与速度序列的变化应趋于稳定。
2. **守恒检查**：相邻把手间距在全过程应恒等于板长。
3. **极限检验**：令螺距趋于很大，盘入应退化为近似直线。
4. **几何对照**：调头段圆弧与螺线在连接处的切线方向应连续。
5. **独立复算**：用另一种参数化方式重算同一时刻的位置，比对差异。
