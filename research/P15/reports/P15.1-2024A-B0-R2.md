### 5.4 method_selection 详细分析

B0-R2 的 method_selection=0.0，原因值得分析：

- **选择的方法卡**: `mc-monte-carlo`（family=uncertainty_propagation）
- **参考方法家族**（来自 CUMCM-Bench-v2.json）: `kinematics`, `geometric_modeling`, `numerical_solution`
- **GT 方法**: `multibody_dynamics`, `numerical_optimization`, `differential_geometry`, `catenary_approximation`, `pure_geometric_spiral`
- **判定**: top1_family_hit=false, top3_hit=false, alternative_method=true

**根因**: 仓库现有方法卡（`core/knowledge/methods/cards/`）中没有运动学/几何建模家族的卡片。可用卡片集中在评价类（topsis/ahp/pca）、优化类（ga/pso/sa/nsga2）、时序类（arima/lstm）、统计类（ols/xgboost）等。mock executor 选择了 `mc-monte-carlo`（最接近仿真的卡片），但其家族 `uncertainty_propagation` 与运动学参考家族不匹配。

**这不是 mock executor 的错误，而是方法卡库的覆盖缺口**。真实 LLM 接入后，如果方法卡库不扩充运动学/几何建模卡片，method_selection 仍可能偏低。建议后续在 `core/knowledge/methods/cards/` 中新增 `mc-multibody-dynamics`、`mc-catenary`、`mc-spiral-geometry` 等卡片。

## 7. 测量仪器 Bug 修复

在 B0-R2 全链路验证过程中，发现并修复了 e2e_metrics.py 的一个运行时 bug：

### 7.1 writing_completeness key 不匹配

**Bug**: `e2e_metrics.py` 第 445 行，`_PAPER_DEFAULTS` 的 key 为 `min_figures/min_tables/min_equations/min_references`，但 `counts` 的 key 为 `figures/tables/equations/references`，导致 `_PAPER_DEFAULTS[k]` 抛出 `KeyError: 'figures'`。

**触发条件**: 项目存在 `paper/main.tex` 时。旧 B0 项目无 main.tex，此代码路径从未执行，bug 未被发现。

**修复**: 将 `_PAPER_DEFAULTS[k]` 改为 `_PAPER_DEFAULTS["min_" + k]`。

**影响**: 修复后 writing_completeness 指标可正常计算（B0-R2 = 16.2）。pytest 无回归（此代码路径无现有测试覆盖）。

## 8. 局限性

### 8.1 Mock Execution 不能证明 Agent 真实能力

- 所有 artifact 由确定性规则生成，非真实 LLM 输出
- `provenance.mock_execution = true` 明确标记
- Measurement Integrity = 0%（created_by 不以 "agent" 开头）
- EAG 中 latency/real_artifacts/execution_mode 三项 INVALID
- 数值结果（碰撞时间 187.5s、最小螺距 0.42m 等）为模拟值，不代表真实求解结果

### 8.2 method_selection 受方法卡库覆盖限制

- 仓库现有方法卡无运动学/几何建模家族
- mock 选择的 mc-monte-carlo 家族不匹配，得 0.0
- 真实 LLM 接入后若方法卡库不扩充，此指标仍可能偏低

### 8.3 model_correctness 语义评分缺失

- 结构检查 PASS（objective/constraints/variables 完整）
- 但语义正确性（模型是否真正解决了运动学问题）需外部 LLM 评分
- 当前为 n/a，不参与均值计算

### 8.4 decomposition_coverage 为退化口径

- 当前为 count_ratio（1 question artifact / 5 GT 子问题 = 20%）
- Q001 artifact 的 payload 实际包含 5 个子问题（Q1-Q5），但 e2e_metrics 按 question artifact 数量计数，不解析 payload.sub_questions
- 真实 LLM 接入后应使用语义对齐评分（decomposition_aligned）

### 8.5 writing_completeness 为 minimal mock paper

- main.tex 仅含 2 个 equation、1 个 table、1 个 figure、1 个 reference
- 远低于 env 阈值（min_figures=6, min_tables=4, min_equations=15, min_references=10）
- 得 16.2 是预期的低基线
