B 题 穿越沙漠

考虑如下的小游戏：玩家凭借一张地图，利用初始资金购买一定数量的水和食物（包括食品和其他日常用品），从起点出发，在沙漠中行走。途中会遇到不同的天气，也可在矿山、村庄补充资金或资源，目标是在规定时间内到达终点，并保留尽可能多的资金。

游戏的基本规则如下：
（1）以天为基本时间单位，游戏的开始时间为第0天，玩家位于起点。玩家必须在截止日期或之前到达终点，到达终点后该玩家的游戏结束。
（2）穿越沙漠需水和食物两种资源，它们的最小计量单位均为箱。每天玩家拥有的水和食物质量之和不能超过负重上限。若未到达终点而水或食物已耗尽，视为游戏失败。
（3）每天的天气为"晴朗"、"高温"、"沙暴"三种状况之一，沙漠中所有区域的天气相同。
（4）每天玩家可从地图中的某个区域到达与之相邻的另一个区域，也可在原地停留。沙暴日必须在原地停留。
（5）玩家在原地停留一天消耗的资源数量称为基础消耗量，行走一天消耗的资源数量为基础消耗量的2倍。
（6）玩家第0天可在起点处用初始资金以基准价格购买水和食物。玩家可在起点停留或回到起点，但不能多次在起点购买资源。玩家到达终点后可退回剩余的水和食物，每箱退回价格为基准价格的一半。
（7）玩家在矿山停留时，可通过挖矿获得资金，挖矿一天获得的资金量称为基础收益。如果挖矿，消耗的资源数量为基础消耗量的3倍；如果不挖矿，消耗的资源数量为基础消耗量。到达矿山当天不能挖矿。沙暴日也可挖矿。
（8）玩家经过或在村庄停留时可用剩余的初始资金或挖矿获得的资金随时购买水和食物，每箱价格为基准价格的2倍。

请根据游戏的不同设定，建立数学模型，解决以下问题。

1. 假设只有一名玩家，在整个游戏时段内每天天气状况事先全部已知，试给出一般情况下玩家的最优策略。求解附件中的"第一关"和"第二关"，并将相应结果分别填入Result.xlsx。

2. 假设只有一名玩家，玩家仅知道当天的天气状况，可据此决定当天的行动方案，试给出一般情况下玩家的最佳策略，并对附件中的"第三关"和"第四关"进行具体讨论。

3. 现有n名玩家，他们有相同的初始资金，且同时从起点出发。若某天其中的任意k(2<=k<=n)名玩家均从区域A行走到区域B(B不等于A)，则他们中的任一位消耗的资源数量均为基础消耗量的2k倍；若某天其中的任意k(2<=k<=n)名玩家在同一矿山挖矿，则他们中的任一位消耗的资源数量均为基础消耗量的3倍，且每名玩家一天可通过挖矿获得的资金是基础收益的1/k；若某天其中的任意k(2<=k<=n)名玩家在同一村庄购买资源，每箱价格均为基准价格的4倍。其他情况下消耗资源数量与资源价格与单人游戏相同。
（1）假设在整个游戏时段内每天天气状况事先全部已知，每名玩家的行动方案需在第0天确定且此后不能更改。试给出一般情况下玩家应采取的策略，并对附件中的"第五关"进行具体讨论。
（2）假设所有玩家仅知道当天的天气状况，从第1天起，每名玩家在当天行动结束后均知道其余玩家当天的行动方案和剩余的资源数量，随后确定各自第二天的行动方案。试给出一般情况下玩家应采取的策略，并对附件中的"第六关"进行具体讨论。

注1：附件所给地图中，有公共边界的两个区域称为相邻，仅有公共顶点而没有公共边界的两个区域不视作相邻。

# 穿越沙漠问题数学模型

## 1. 问题理解

**核心矛盾**：玩家需要在有限天数内，以有限初始资金购买水与食物两种资源，穿越由节点—边构成的地图，途中受天气（晴朗/高温/沙暴）影响消耗资源，可在矿山挖矿补充资金、在村庄以高价补充资源，目标是到达终点并最大化剩余资金。资源的"携带—消耗—补给"与"资金—时间"双重约束构成主要冲突。

**关键实体**：地图区域节点集 $V$、邻接边集 $E$、起点 $s$、终点 $e$、矿山节点集 $Q$、村庄节点集 $R$；资源（水、食物）；资金；天气过程；玩家（单人或 $n$ 人）。

**子问题分解**：
- **Q1**：单玩家、全程天气事先已知（确定性），求全局最优策略，并求解第一、二关。
- **Q2**：单玩家、仅知当天天气（不确定性），求最优策略，并讨论第三、四关。
- **Q3**：$n$ 名玩家同时出发，存在拥挤外部性（同行消耗 $2k$ 倍、同矿收益 $1/k$、同村价格 $4$ 倍）。(1) 天气全知且方案第 0 天固定；(2) 仅知当天天气且逐日公开行动与剩余资源。

**显式条件**：以天为单位；第 0 天在起点按基准价购买；行走消耗为基础量 2 倍；挖矿消耗 3 倍且到达矿山当天不能挖矿、沙暴日可挖矿；村庄价格为基准价 2 倍；终点退款为基准价一半；截止日前到达终点；沙暴日必须停留；每天水食物质量之和不超过负重上限；多人情形按 $k$ 修正消耗/收益/价格。Q1 需将结果填入 Result.xlsx。

**隐式条件**：资源耗尽即失败（非负约束）；若未在截止日到达终点也失败；购买行为与消耗行为的结算顺序（按注 2，剩余资金指当日资源全部消耗完毕后的资金，若有购买则指购买后）；地图邻接定义（有公共边才相邻）。

**歧义点及采纳**：(i) 天气生成机制未给出——Q2 采纳"经验频率/一阶马尔可夫转移"的投影假设；(ii) "同行"判定口径——采纳"移动边完全相同"；(iii) 沙暴日到达矿山当天能否挖矿——采纳"到达当天一律不能挖矿"。

**问题类型判定**：核心建模范式为**有限阶段序贯决策**（Q1 确定性动态规划、Q2 随机动态规划），Q3 升级为**博弈论**（静态纳什均衡 + 序贯博弈）。判定依据：状态转移逐日发生、行动逐日选择、后效性由状态完全捕捉。

## 5. 目标

- **Q1**（最大化）：$\max m_T$，约束 $t\le T$ 且 $i_T=e$。即给定天气序列，选择逐日行动使终局资金最大。
- **Q2**（最大化）：$\max \mathbb{E}_{\theta_{1:T}}[m_T]$，在仅知当天天气的信息结构下最大化期望终局资金。
- **Q3(1)**（最大化/均衡）：$m^{(j)}_T \to \max$，$j=1,\dots,n$，方案第 0 天固定，求纯策略纳什均衡下的均衡收益。
- **Q3(2)**（最大化）：在逐日信息集 $\mathcal{I}_t$ 下最大化 $\mathbb{E}[m^{(j)}_T]$，求序贯均衡。

## 7. 机理

**为什么是动态规划**：问题具有"阶段（天）—状态（位置、水、食物、资金）—行动"的序贯结构，且状态转移满足无后效性（未来只依赖当前状态与行动，不依赖历史路径），因此贝尔曼最优性原理成立，递推可精确求解。

**候选模型对比**：
1. **确定性/随机动态规划**（采纳）：状态空间有限、转移规则由题面完全给定，DP 可给出全局最优解且可证明最优性；Q1 用确定性递推，Q2 用期望递推。缺点：状态空间随关卡规模指数增长，需支配剪枝。
2. **整数规划（一次性 MILP）**（弃用）：能表达 Q1 的全局路径-购买-挖矿联合决策，但无法处理 Q2 的逐日信息到达与 Q3(2) 的序贯信息更新；解在信息未知前无法固定。
3. **离散事件仿真**（弃用）：仅能评估给定策略的性能，不能系统寻优；保留为验证工具。
4. **博弈论（静态/序贯均衡）**（Q3 采纳）：多人拥挤耦合天然是策略互动，纳什均衡与子博弈精炼均衡给出解概念；与 DP 结合（在均衡策略下做 MDP 求解）形成"均衡—寻优"双层框架。

**机理链**：规则→状态转移方程→贝尔曼方程→（Q3 叠加）均衡条件。

## 8. 方程

- **位置转移**（逻辑）：$i_{t+1} = j$ 若 $a_t=\text{move}(i_t\to j)$ 且 $j\in N(i_t)$，否则 $i_{t+1}=i_t$。初始 $i_0=s$。
- **资源消耗**（递推）：$w_{t+1}=w_t - c_w(\theta_t)\mu(a_t)$，$f_{t+1}=f_t - c_f(\theta_t)\mu(a_t)$。$\mu$ 见变量表；多人时 $\mu\leftarrow 2k$（同行）。边界：$w_0,f_0$ 为第 0 天购买量；非负约束强制失败条件。
- **资金更新**（递推）：$m_{t+1} = m_t + g_0 y_t - p_w q^w_t - p_f q^f_t + \alpha p_w \tilde w + \alpha p_f \tilde f$，退款仅终点发生。多人同矿 $g_0 \to g_0/k$，同村 $p\to 4p$。
- **负重约束**（代数）：$\rho_w w_t + \rho_f f_t \le W_{\max}$。
- **Q1 贝尔曼方程**（递推）：$V_t(i,w,f,m)=\max_{a_t} V_{t+1}(i',w',f',m')$，终端 $V_T(e,\cdot)=m_T$，$V_T(i\ne e,\cdot)=-\infty$。
- **Q2 随机贝尔曼方程**（递推）：$V_t(\cdot)=\max_{a_t}\sum_{\theta_{t+1}} p(\theta_{t+1}|\theta_t)V_{t+1}(\cdot)$。
- **Q3(1) 均衡条件**（逻辑）：$a^{(j)*}\in\arg\max m^{(j)}_T(a^{(j)},a^{(-j)*})$。
- **Q3(2) 序贯值函数**（递推）：$V^{(j)}_t(\mathcal I_t)=\max_{a^{(j)}_{t+1}}\mathbb E[V^{(j)}_{t+1}(\mathcal I_{t+1})|\mathcal I_t]$，$\mathcal I_t=\cup_j\{a^{(j)}_t,w^{(j)}_t,f^{(j)}_t\}$。

## 9. 求解与验证

**求解策略**：Q1/Q2 用状态压缩动态规划（按天后向递推），状态 $(i,w,f,m)$，行动集 $|A|\le 6$，复杂度 $O(T|V|W F M|A|)$，用支配剪枝（若状态 $A$ 在资金、水、食物、位置上全面不劣于状态 $B$ 则删 $B$）压缩状态空间；六关规模（节点数 ≤ 30、天数 ≤ 30）可在秒级求解。Q3(1) 用最优反应迭代（从对称策略出发，逐玩家求 DP 最优反应直至收敛），必要时用虚拟对局平滑；Q3(2) 用蒙特卡洛树搜索做近似序贯均衡。

**可复现性**：求解器为确定性算法（DP、最优反应迭代），同一输入逐位可复现；随机模拟（Q2 天气抽样、MCTS 探索）采用固定随机数初始化方案，并做 5 组初始化取均值±标准差。

**验证方案**：
- 基线对照：单玩家、天气恒定、无矿山村庄的平凡地图上手工枚举最优解，DP 输出应一致（误差 0）。
- 灵敏度：扰动基础消耗 $c_w,c_f$、天气转移 $p$、基础收益 $g_0$ 各 ±20%，观察终局资金与策略结构变化率。
- 极限检验：$W_{\max}\to\infty$ 约束松弛；$n\to1$ 多人退化为单人；$T\to0$ 无可行解。
- 多初始化稳定性：5 组随机初始化下模拟均值与标准差报告。

**结果合理性预期**：终局资金随初始资金与挖矿机会增加而增加；天气不确定性（Q2）的期望资金低于全知（Q1）情形；Q3 拥挤使均衡资金低于单人最优且随 $n$ 增大差距扩大。若偏离预期，按"模型缺陷（转移核/拥挤口径）→ 参数问题（附件数据读取）→ 数值问题（剪枝误删最优状态）"顺序归因。
