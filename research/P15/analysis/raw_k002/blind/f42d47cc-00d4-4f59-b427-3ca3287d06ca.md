C 题 机场的出租车问题

大多数乘客下飞机后要去市区（或周边）的目的地，出租车是主要的交通工具之一。国内多数机场都是将送客（出发）与接客（到达）通道分开的。送客到机场的出租车司机都将会面临两个选择：
(A) 前往到达区排队等待载客返回市区。出租车必须到指定的"蓄车池"排队等候，依"先来后到"排队进场载客，等待时间长短取决于排队出租车和乘客的数量多少，需要付出一定的时间成本。
(B) 直接放空返回市区拉客。出租车司机会付出空载费用和可能损失潜在的载客收益。

在某时间段抵达的航班数量和"蓄车池"里已有的车辆数是司机可观测到的确定信息。通常司机的决策与其个人的经验判断有关，比如在某个季节与某时间段抵达航班的多少和可能乘客数量的多寡等。如果乘客在下飞机后想"打车"，就要到指定的"乘车区"排队，按先后顺序乘车。机场出租车管理人员负责"分批定量"放行出租车进入"乘车区"，同时安排一定数量的乘客上车。在实际中，还有很多影响出租车司机决策的确定和不确定因素，其关联关系各异，影响效果也不尽相同。

请你们团队结合实际情况，建立数学模型研究下列问题：

(1) 分析研究与出租车司机决策相关因素的影响机理，综合考虑机场乘客数量的变化规律和出租车司机的收益，建立出租车司机选择决策模型，并给出司机的选择策略。

(2) 收集国内某一机场及其所在城市出租车的相关数据，给出该机场出租车司机的选择方案，并分析模型的合理性和对相关因素的依赖性。

(3) 在某些时候，经常会出现出租车排队载客和乘客排队乘车的情况。某机场"乘车区"现有两条并行车道，管理部门应如何设置"上车点"，并合理安排出租车和乘客，在保证车辆和乘客安全的条件下，使得总的乘车效率最高。

(4) 机场的出租车载客收益与载客的行驶里程有关，乘客的目的地有远有近，出租车司机不能选择乘客和拒载，但允许出租车多次往返载客。管理部门拟对某些短途载客再次返回的出租车给予一定的"优先权"，使得这些出租车的收益尽量均衡，试给出一个可行的"优先"安排方案。

## 模型产物（模型文档）

# 机场出租车运力调度与司机决策模型

## 1. 问题理解

**核心矛盾**：出租车司机在机场面临"排队等待载客（付出时间成本）"与"空载返回市区（付出油耗与接单不确定性）"的抉择；机场管理方要在**安全、效率、公平**之间设计乘车区与优先规则。

**关键实体**：出租车（到达机场形成队列）、乘客（按航班到达形成需求）、乘车区（车道、上车点）、司机（个体决策者）、机场管理方（规则制定者）。

**子问题分解**：
- Q1：司机"排队 vs 空返"的个体决策模型（收益 = 载客收入 − 等待/空返成本）；
- Q2：给定某机场数据（航班到港分布、打车需求），给出司机的具体选择方案并分析其依赖因素；
- Q3：两条并行车道乘车区的上车点数量与车辆/乘客安排，使总乘车效率最高（兼顾安全）；
- Q4："短途再返优先权"方案设计，使司机收益均衡（长短途公平）。

**显式条件**：司机到达机场后排队或空返；乘客乘出租车离开机场；两条并行车道乘车区；短途乘客返回快、再排一次队。

**隐式条件**：排队等待收益为负（时间机会成本）；空返有燃油成本与空驶里程；需求峰谷波动（航班时刻表驱动）。

**歧义点**：
1. "上车点数量"是否受车道长度限制：采纳受安全间距约束（每车占用长度 + 安全间隙）确定上界；
2. 司机收益口径：采纳"单次往返净收益 = 车费 − 燃油 − 时间成本"，排队只计时间成本，空返计燃油+接单不确定性；
3. "总乘车效率"：采纳为"单位时间载客离开的出租车数（吞吐量）"，安全性作为硬约束。

**问题类型判定**：核心范式为"排队论（生灭过程/队列模型）+ 决策分析（个体收益权衡）+ 优化（设施设计）"。

## 5. 目标

- Q1：**最大化**司机单次往返期望净收益：$\max_{d} \mathbb{E}[u(d)]$，排队与空返比较；
- Q2：**估计**给定机场数据下的最优选择边界（等待时间阈值）并分析依赖；
- Q3：**最大化**乘车效率：$\max_{n_p, \text{安排}} \eta$ s.t. 安全间距与车道容量；
- Q4：**最大化**长短途司机收益均衡：$\min |u_{long} - \bar u_{short}|$ 或最小化不公平指数。

## 6. 约束

|---|---|---|---|

| 排队不溢出（稳定条件）：$\lambda_c < n_p \mu$ | < | 排队论 | Q1–Q4 |

| 乘客等待上限（服务质量） | ≤ | 机场要求 | Q3 |
| 短途优先不使长途司机收益为负 | ≥ | 公平性 | Q4 |

## 7. 机理

问题包含三个耦合层：**司机个体决策层**（Q1/Q2，排队 vs 空返的期望收益比较，队列长度通过等待时间影响决策，形成"到达—决策—再到达"反馈）；**乘车区服务层**（Q3，多服务台排队系统，上车点=服务台，效率=吞吐量）；**机制设计层**（Q4，优先权规则改变排队次序，影响长短途收益分配）。

**候选模型对比**：
1. **排队论（M/M/c 与优先权队列）**——优：解析刻画等待时间与吞吐量，直接支撑 Q1/Q3/Q4；劣：到达/服务需指数假设。**选为最终框架**。
2. **决策分析（收益权衡 + 阈值决策）**——优：直接回答司机选择；劣：需要需求参数。作为 Q1/Q2 的决策层。
3. **仿真（离散事件仿真）**——优：可处理时变到达与复杂规则；劣：无解析闭式。作为验证与参数检验层。
4. **博弈论（司机间竞争）**——劣：司机个体决策近似为独立，排队均衡可用排队论近似。排除为主方法。

## 8. 方程

**等待时间（M/M/c）**：
$$W_q = \frac{C(c, \rho_c)}{\mu c - \lambda_c}, \quad \rho_c = \frac{\lambda_c}{\mu c}$$
其中 $C(c,\rho)$ 为 Erlang C 概率。

**司机决策**（Q1）：
$$\mathbb{E}[u(\text{queue})] = \bar r - c_t W_q - c_f r_{in},\qquad \mathbb{E}[u(\text{empty})] = \mathbb{E}[\bar r - c_f(r_{in}+r_e)] - \epsilon$$
选择排队当且仅当 $\bar r - c_t W_q \ge \mathbb{E}[\bar r] - c_f r_e$，即等待时间阈值 $W_q \le W^* = c_f r_e / c_t$。

**乘车效率**（Q3）：
$$\eta = \min(\lambda_c, n_p \mu) \cdot \mathbb{1}[\text{稳定}], \quad n_p \le \lfloor D_{lane}/l_s \rfloor$$

**优先权收益分配**（Q4）：短途再返司机权重 $\rho$，调整等效服务率
$$\mu_{short} = \mu / (1-\rho), \quad \text{公平指数 } I = \frac{u_{long}}{u_{long}+u_{short}} \in [0.45, 0.55]$$

## 9. 求解与验证

**求解策略**：Q1 用阈值决策解析；Q2 用机场数据分段估计 $\lambda_c, \mu, W_q$ 并给出分时段选择方案；Q3 用排队论吞吐量公式 + 整数枚举上车点数；Q4 用优先权队列仿真扫描 $\rho$ 找到公平区间。复杂度：解析 O(1)，仿真 O(事件数)。

**可复现性**：仿真固定种子 42 并多 seed（42/123/456/789/1024）报告均值±标准差；数据估计给出置信区间。

**验证方案**：
1. 基线对照：M/M/1 闭式解 vs 模型特例；
2. 灵敏度：$c_f, c_t, \lambda_p$ 各 ±20% 对等待阈值 $W^*$ 影响；
3. 极限：$\lambda_c \to 0$ 时排队等待趋 0、司机全排队；$\lambda_c \to c\mu$ 时等待发散、司机全空返；
4. 仿真-解析交叉：仿真等待时间与 Erlang C 公式偏差 <10%；
5. 公平性：$\rho$ 扫描下 $I$ 落入目标区间。

**结果合理性预期**：Q1 阈值 $W^*$ 量级为 30–60 分钟；Q2 高峰时段排队、低谷空返；Q3 上车点 6–10 个量级；Q4 短途优先权重适中使收益均衡。若偏离，按"参数标定→队列模型→规则设计"归因。
