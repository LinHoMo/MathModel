### 2.3 低一致性维度（κ < 0.6）及归因

| 维度 | κ | 归因 |
|---|---|---|
| L1.2 | 0.333 | 隐式条件识别主观性强，不同 evaluator 识别的隐式约束条目不同 |
| L1.3 | 0.167 | 交付要求识别边界模糊（部分包未明确列出子问题交付物） |
| L1.4 | 0.333 | **格式中立边界**：结构化 MODEL_IR 无独立 ambiguity 段 vs 叙述式 model_doc 用中文段落标注歧义，同一歧义内容因格式差异得 0 或 1 |
| L2.1 | 0.333 | 变量声明"完备度"阈值主观（未声明符号占比 10% vs 20% 的判分边界） |
| L2.2 | 0.445 | 参数声明同上，含取值/来源的判定边界 |
| L2.4 | 0.333 | 目标函数正确性判定需理解建模意图，主观性较强 |
| L2.5 | 0.333 | 约束完备性判定同上 |
| L3.1 | 0.333 | 求解策略与模型匹配度判定主观 |
| L3.2 | 0.0 | **系统性分歧**：多数盲评包无实际代码执行日志，evaluator 对"代码存在=1"还是"无执行=0"判定不一致 |
| L3.3 | 0.279 | 结果收敛性判定需数值证据，多数包无实际数值 |
| L3.4 | 0.145 | 可复现性判定（种子/步数/统计）主观性强 |
| L3.5 | 0.095 | **rubric 口径歧义**：汇总表权重 1（满分 1）vs 细则 0-2 三档并存，evaluator 间口径不统一 |
| L4.1 | 0.333 | 基线对比判定主观（退化基线/随机基线/文献基线的认定边界） |
| L4.2 | 0.333 | 灵敏度分析判定（是否报告弹性系数/临界值）边界模糊 |
| L4.3 | 0.333 | **rubric 口径歧义**：同 L3.5，v1.1 细化"≥2 类检验+结果-主张关联才 2 分"但汇总表权重 1 |
| L4.4 | 0.333 | 验证方案覆盖度判定主观 |
| L4.5 | 0.095 | claim-evidence 映射判定：叙述式 model_doc 无结构化 claim map 时保守给 1，结构化 MODEL_IR 有 supported/refuted 时给 2，格式差异导致分歧 |

### 2.4 裁决
κ 整体 0.4345 未达 0.6 阈值，但**分歧可归因**（见上表）：
1. **客观维度（5/22）κ=1.0**，说明 evaluator 对 rubric 核心条款理解一致
2. **低 κ 维度集中在主观判定 + rubric 口径歧义（L3.5/L4.3）+ 无执行日志的系统性低分（L3.2）**
3. 小样本（5 份校准）放大了 κ 噪声

按任务规则"κ≥0.6 或分歧可归因→进入正式评分"，**本实验满足分歧可归因条件，正式评分有效**。低 κ 维度的分数在后续按臂汇总时应标注为"高方差维度"。
