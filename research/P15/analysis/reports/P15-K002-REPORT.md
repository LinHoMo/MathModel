## 2. 方法（严格按预注册）

- **规模**：主检验 6 题（2020_B/2018_A/2019_C/2018_B/2017_B/2011_B）× 3 臂 × 5 rep = 90；泛化 2 题（2022_C/2024_A）× 3 臂 × 3 rep = 18；共 **108 runs**。
- **臂**：F（自由文本 model_doc.md）/ S（MODEL_IR 18 字段）/ SV（S + Validation Plan 强制字段）。
- **主终点**：MCQ_primary = (L2+L3+L4)/(15+9+9)×100（rubric v1.1）；VAL_primary = L4/9×100。
- **检验**：block 级配对差（block=题，N=6），效应量 + bootstrap 95% CI（100k 次，种子 42），决策门 = CI 下界 > 0 → positive（与 K001 同门）。
- **盲评**：3 独立 evaluator（互不可见），5 份共享样例校准（κ=0.4345，5/22 维度 ≥0.6，分歧可归因：主观维度 + L3.5/L4.3 口径歧义 + L3.2 无执行日志系统性低分 + L4.5 无 claim map），后分片 36×3 全量评分；Generator 与 Evaluator 完全隔离。
- **COVERAGE gate**：S/SV 臂 problem_binding 子问题覆盖（36/36 complete=True，0 FAIL）；**F 臂 gate N/A**（自由文本无 MODEL_IR problem_binding，测量局限如实记录——生成侧未为 F 臂填 coverage 字段）。

## 4. 测量边界与归因

1. **L3 层格式不对称（负效应主因）**：S 臂 JSON 的结构化字段（solvers/experiments/validations 声明）在盲评中被更严格审视——无执行日志即低分；F 臂自由文本可叙述性声称执行/验证。rubric v1.1 的"格式中立"条款（§0.4）未能消除该不对称（L3 维度的证据形式天然偏向叙述）。
2. **执行级终点 N/A**：K002 生成侧产物（MODEL_IR/model_doc）不含真实代码执行；预注册定义的 execution_success_rate/model_fidelity 等执行级终点在本实验无法测量（产物级不可执行）。这是**架构分工**：执行由 P1 harness runtime 承担（VS-001/M3/M4 已实现真实执行闭环），K002 测量的是构造产物质量。**结论：K002 的 L3 层需要真实执行产物才能有意义测量——这是本次实验暴露的核心测量缺口**。
3. **κ=0.4345**：5/22 维度 ≥0.6（L1.1/L1.5/L2.3/L2.6/L2.7 全 1.0）；低 κ 维度为主观判定（L1.2/L1.4/L2.1/L2.4/L2.5）、rubric 口径歧义（L3.5/L4.3）、无执行日志系统性（L3.2）、无 claim map（L4.5）。已在敏感性 B 中剔除处理。
4. **F 臂 coverage N/A**：自由文本无机械子问题覆盖判定（生成侧未填），如实记录，不豁免 S/SV 的 gate。
5. **泛化方向反转**：2 题小样本，不解释为效应反转；提示主检验负效应可能非全局。
6. **数据修正说明**：初版分析后核对发现 5 份评分文件（11ce5dd2/444ea7c8/6c6fa611/fec21bbe/aaf91531）曾被预检残留评估者（E02）文件污染（工作区版本）；已恢复为盲评提交版（eval_A/B/C）后重算。**本报告全部数字为修正后版本**；结论方向与初版一致（RQ1 NEGATIVE / RQ2 inclusive / SV−F(VAL) POSITIVE），幅度微调（RQ1 Δ −4.95→−4.85）。修正经 `k002_analysis.py` 复跑确认。

## 5. 与 K001 对比

| | K001 | K002 |
|---|---|---|
| 设计 | 2×2×rep（K/Sham×F/S） | 3 臂（F/S/SV）×6 题×5 rep |
| 主效应 | Δ_K=+2.14 CI=[+0.00,+6.41] | Δ_S−F=−4.85 CI=[−7.98,−2.22] |
| 决策 | CI 跨 0 → 不达门 | CI 上界<0 → 显著负 |
| 测量教训 | 词表错位（measurement failure ≠ capability failure） | L3 格式不对称 + 执行层产物级不可测 |

**两个实验均未提供"结构化表示提升建模构造能力"的 positive 证据**（K001 无显著、K002 显著负）。方向一致指向：**表示层的收益不在"产物文本质量"（MCQ 盲评），而在"可执行/可验证性"（harness 侧，P1 已证明 M1→FAIL→M2→PASS 闭环）**。

## 6. 决策与建议

1. **RQ1 未达 positive 决策门 → 不进 P15.2**（与 K001 同路径；P15.2 的"结构化表示增益"命题两次未获正面证据）。
2. **K002 暴露的核心测量缺口**：L3/L4 需要真实执行产物（execution_result/validation_report 一等 artifact）才能公平测量"模型构造质量"——**下一实验（若做）必须是构造+执行一体化**（生成侧产出 MODEL_IR → harness 真执行 → 盲评执行证据），而非产物文本盲评。
3. **S+V 强制验证字段的相对收益**（敏感性 A：SV−S MCQ=+5.15 POSITIVE；补充 SV−F VAL=+3.70 POSITIVE）——验证计划的强制字段化在结构化臂内部有建设性效果，值得保留（K002 三臂设计的信息没有白费）。
4. **Rubric 口径修复**：L3.5/L4.3 汇总表权重与细则档位矛盾（盲评发现），v1.2 需统一；低 κ 主观维度需更机械的判据。
5. 状态机推进：RUNNING → VALIDATION → **ANALYSIS**（本报告）→ CLOSED（数据已归档）。
