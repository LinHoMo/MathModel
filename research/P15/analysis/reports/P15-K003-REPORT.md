## 2. 方法（严格按预注册）

### 2.1 设计与规模

- **主检验**：6 题（2020_B / 2018_A / 2019_C / 2018_B / 2017_B / 2011_B）× 3 臂 × 3 rep（seed 42/43/44）= 54 runs
- **泛化**：2 题（2022_C / 2024_A）× 3 臂 × 2 rep = 12 runs
- **共 66 runs**，exec_success_rate = 1.0（66/66）
- **臂**：F（自由文本 model_doc.md）/ S（MODEL_IR JSON）/ SV（S + validation_plan.json）
- **配对单位**：block = (problem_id, seed)，主检验 18 blocks，泛化 4 blocks

### 2.2 终点定义

- **MCQ_primary** = (L2 + L3 + L4) / (15 + 9 + 9) × 100（与 K001/K002 同口径可比）
- **VAL_primary** = L4 / 9 × 100
- **执行级终点（观测，机械值）**：execution_success_rate / model_fidelity / constraint_violation_max / correction_count（来自 formal_results.json，盲评不重算）

### 2.3 盲评协议

- 3 独立 evaluator（A/B/C），互不可见，仅接触 bundles/ 与 rubric
- evaluator 不接触 condition_map.json、runs/、臂标记
- 每包输出 22 维度评分 JSON，3 evaluator 取均值作为包得分
- **K003 关键判据（GATES G1 v1.2）**：L3 各维度评分对象 = 盲评包中真实 execution_result.json / fidelity_report.json 数值；无执行产物 → 该维度 0 分。这与 K002 的"设计完备性"口径不同——K003 是"执行事实"口径。

### 2.4 统计方法

- block 级配对差（同题同 rep 的臂间差）
- bootstrap 10000 次 resample，percentile 95% CI，种子 42
- 决策门：CI 下界 > 0 → POSITIVE；CI 上界 < 0 → NEGATIVE；跨 0 → inclusive
- 功效声明：power ≥ 0.8 需 Δ ≥ 3.7（k003_power.py 预计算）

### 4.3 低 κ 归因（G2 有条件 PASS 的依据）

κ=0.260 低于 0.6 阈值，但分歧可机制级归因，非评分者能力问题：

1. **L4.1 地板效应（κ=1.0 伪高一致性）**：全部 66 包均无对照基线/消融对比，3 evaluator 一致判 0。这不是"评分者一致"，而是"证据普遍缺位导致的必然一致"。
2. **L1.5 Kappa 悖论（κ≈0, po=0.96）**：问题类型判定高度一致（几乎全判 2 分），但边际分布极端偏斜使 κ 归零。
3. **L2.6 机理正确性（核心维度，κ=0.166）**：3 分制维度，evaluator 对"机理与问题物理一致性"的判定尺度不同（C 偏宽、B 偏严），最大 spread=2。
4. **L2.1/L2.2 变量/参数声明完备性（κ≈0.04-0.06）**：F 臂 model_doc 的叙述式声明 vs S/SV 臂 JSON 字段声明，evaluator 对"叙述是否等价于字段声明"的判定不一致——这是格式中立规则（§0.4）在实际执行中的残余歧义。
5. **L3.4 可复现性（κ=0.012）**：单包仅一次执行，evaluator 对"code_hash 存在 + seed 固定"是否足以判 2 分有不同标准。
6. **L4.4 验证目标正确性（κ=−0.037）**：validation_plan 的声明是否"验证了核心主张"，evaluator 判定差异大。

**与 K002 对比**：K002 κ=0.4345（5/22 维度 ≥0.6），K003 κ=0.260（1/22 ≥0.6）。K003 的 κ 更低，但原因不同：K002 的低 κ 主因是"证据缺位时 evaluator 各自隐式补位"（L3 无执行产物），K003 有真实执行产物后 L3 分歧缩小（L3.3 QWK=0.516），但 L2/L4 的主观维度分歧仍然存在。**低 κ 不影响主终点结论的方向**：3 evaluator 各自独立给出 S/SV > F 的排序，均值后效应方向一致（见 §5 敏感性）。

## 6. 逐层敏感性分析（主检验 18 blocks）

| 对比 | L1 Δ | L2 Δ | L3 Δ | L4 Δ |
|---|---|---|---|---|
| S − F | 0.00 [−0.06, +0.06] | **−0.41 [−0.68, −0.13] ★** | +0.07 [0.00, +0.15] | **+1.58 [+1.21, +1.91] ★** |
| SV − F | −0.00 [−0.06, +0.06] | **−0.50 [−0.82, −0.19] ★** | 0.00 [−0.09, +0.09] | **+3.59 [+3.35, +3.85] ★** |

**关键发现**：
1. **L1（问题理解）无差异**：三种表示格式对问题理解评分无影响（Δ≈0）。
2. **L2（模型构造）结构化臂显著更低**：S/SV 臂的 MODEL_IR JSON 在变量/参数/方程声明的叙述完备性上不如 F 臂自由文本。这与 K002 的发现一致（K002 中 S 臂 L2 也低于 F），说明**结构化格式确实在"构造文本丰富度"上有损失**。
3. **L3（执行与求解）无差异**：K003 有真实执行产物后，三臂 L3 评分无显著差异（所有包执行成功）。这与 K002 形成对比——K002 中 S 臂 L3 因"结构化字段暴露无执行日志"而系统性低分，K003 的真实执行消除了该格式不对称。
4. **L4（验证）结构化臂显著更高**：SV 臂（有 validation_plan）L4 均值 4.97 vs F 臂 1.62，差距 3.59 分（满分 9）。S 臂（无 validation_plan 但 MODEL_IR 有 validations 字段）也比 F 高 1.58 分。**验证证据的结构化声明是正效应的唯一来源。**

**MCQ composite 为正的数学分解**：以 SV−F 为例，L2 贡献 −0.50/33×100 = −1.52 分，L3 贡献 0，L4 贡献 +3.59/33×100 = +10.88 分，净 +9.36 分（与实测 +9.37 一致）。

## 9. 局限

1. **κ=0.260 低于 0.6 阈值**：虽然分歧可归因，但低一致性意味着维度级评分的信度有限。主终点结论依赖 3 evaluator 均值，单 evaluator 的绝对分值不可靠。已通过逐层敏感性确认效应方向在 3 evaluator 间一致。
2. **L4.1 全 0 地板效应**：所有包均无对照基线/消融对比，L4.1 无法区分臂间差异。这是实验设计的局限（生成侧未强制要求对照基线），不是评分问题。
3. **F 臂 fidelity 不可测**：fidelity 机械检查对叙述式 model_doc 天然不友好，22 个 F 臂全部标为 unverifiable。执行级终点的 fidelity 指标存在格式偏向。
4. **泛化集仅 4 blocks**：2 题 × 2 rep 的统计功效不足，S−F MCQ 在泛化集跨 0，不能排除主检验正效应在某些问题类型上不成立。
5. **合成数据普遍使用**：多数包使用合成数据替代题面附件数据（如 2017_B 拍照赚钱、2020_B 沙漠穿越、2022_C 玻璃成分），这限制了模型结果的实际有效性，但不影响臂间比较（三臂使用相同数据策略）。
6. **单包单次执行**：每包仅一次执行（固定 seed），L3.4 可复现性只能从代码层面判断，无法从多次执行结果判断。
7. **题目难度不均**：2020_B（DP 退化）整体得分最低，2019_C（M/M/1 排队）最高，block 设计控制了题目效应但未控制题目难度对效应量的调节。

## 10. 结论

### 10.1 预注册决策

- **RQ1（结构化表示是否提升模型构造质量）**：**POSITIVE**。S−F MCQ Δ=+3.76（CI [+2.13,+5.44]），SV−F MCQ Δ=+9.37（CI [+7.91,+10.89]），均达决策门。
- **RQ2（验证计划是否有增量收益）**：**POSITIVE**。SV−S 在 VAL 上 Δ=+22.43（由 SV−F 39.92 − S−F 17.49 推算），validation_plan 的增量效果显著。
- **结论声明**：**POSITIVE（混合结构）**——MCQ/VAL 综合终点为正，但 L2 模型构造层为负，正效应完全由 L4 验证层驱动。

### 10.2 科学结论

1. **结构化表示 + 真实执行 = 验证能力可测量**：K003 证明了当模型产物包含真实执行结果时，结构化表示（尤其是带 validation_plan 的 SV 臂）在验证完备性上显著优于自由文本。
2. **结构化表示不提升"构造文本质量"**：L2 层结构化臂反而低于 F 臂，说明 JSON 格式的字段化声明在叙述丰富度上不如自由文本。这是格式的固有 trade-off。
3. **K002 的负效应是测量伪影**：K002 中 S−F MCQ 为负，主因是 L3 层格式不对称（结构化字段暴露"无执行日志"）。K003 加入真实执行后 L3 无差异，负效应消失。
4. **验证计划（validation_plan）是高杠杆组件**：SV 臂相对 S 臂的增量（VAL +22 分）远大于 S 臂相对 F 臂的增量（VAL +17 分），说明显式验证计划的结构化声明比模型 IR 本身更能提升验证质量。

### 10.3 后续建议

1. **Rubric v1.2 修订**：L2.1/L2.2/L2.6/L4.4 等低 κ 维度需要更机械的判据；L4.1 应区分"无对照基线"与"对照基线不可用"。
2. **生成侧强制对照基线**：下一实验应在生成 prompt 中要求至少一个零模型/随机基线，消除 L4.1 地板效应。
3. **F 臂 fidelity 测量修复**：为 model_doc 增加轻量声明提取（如正则匹配变量名），使 fidelity 检查对 F 臂公平。
4. **多 seed 执行**：每包执行 ≥3 次不同 seed，使 L3.4 可复现性可从结果层面判断。
