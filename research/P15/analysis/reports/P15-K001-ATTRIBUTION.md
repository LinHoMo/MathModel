# P15-K001 深度归因 — Negative Result 的机制分析

> 定位：P15-K001（2×2 预注册实验）正式报告的补充证据文档。
> 回答的问题：**为什么注入高质量 Modeling Knowledge 卡没有显著提升 Model Construction Quality？**
> 数据来源：`research/P15/experiments/P15-K001/runs/<sid>/knowledge_trace.json` × 55、`model_ir.json` × 55、盲评 55 份。
> 状态：基于已冻结实验数据的分析，不改变任何冻结结论。

---

## 1. 知识利用机制的真实数据（55 runs 全量）

| 指标 | 数量 | 比率 | 说明 |
|---|---|---|---|
| trace 文件 | 55/55 | 100% | 每 run 均有 knowledge_trace |
| 空 trace（无知识注入，A 臂） | 11 | 20% | 与 A 臂 run 数一致 ✅ |
| retrieved 条目 | 55 | — | 33 知识卡 + 22 结构案例 |
| **used（采纳）** | **44** | **80%** | 被检索条目中有 80% 进入建模 |
| **adapted（改编后使用）** | **32** | **58%** | 多数知识被"改编"而非机械套用 |
| **rejected（拒绝）** | **11** | **20%** | 全部为机理不匹配的错位注入 |

### 1.1 rejected 的 11 条——全部是 Sham 错位卡的正确拒绝

| 被拒条目 | 被拒于哪题 | 拒绝理由（摘录） | 判定 |
|---|---|---|---|
| mc-numerical-pde ×3 | 2019_C（机场出租车） | "面向数值求解偏微分方程的通用方法，与本问题的机场出租车蓄车排队与司机决策对象和机理不匹配" | ✅ 正确拒绝 |
| mc-dp ×3 | 2018_A（热传导） | "题面不存在离散决策阶段、状态转移与跨阶段累积收益结构，温度场演化…" | ✅ 正确拒绝 |
| mc-queuing-theory ×3 | 2020_B（沙漠穿越） | "题面不存在随机到达事件流、服务台容量与等待指标，强行套用会丢失资源与资金的逐日耦合" | ✅ 正确拒绝 |
| mc-fuzzy-evaluation ×1 | 2022_C（玻璃文物） | "类型标签来自考古工作者…非模糊综合评价" | ✅ 正确拒绝 |
| mc-ols ×1 | 2024_A（板凳龙） | "确定性运动学系统…不存在待拟合的随机关系" | ✅ 正确拒绝 |

**关键结论 A**：生成侧外部 Agent 具备**真实的知识适用性判断能力**——对与题目机理不匹配的卡（实验设计中的 Sham 负对照），11/11 全部识别并拒绝，且拒绝理由基于机理分析（"是否存在离散决策阶段/随机到达流/待拟合关系"），不是模板话术。这本身是测量系统的正面信号：**知识注入机制没有产生"注入即盲从"**。

**关键结论 B**：这意味着 P15-K001 中 E 臂（Sham）测的其实是"**Agent 能否识别错位知识**"——而它 100% 识别了。Sham 臂未显示惩罚效应（Δ_Sham=+3.42 反而为正），说明错位卡在被拒绝后并未污染建模，且"额外上下文+结构化方法候选"本身有轻微正向处理效应。

### 1.2 adapted 58%——知识作为约束而非支配

正确匹配的卡（如 mc-dp→2020_B）被检索 9 次（B/D 臂 6 次 + E 臂 Sham 3 次错位被拒），其中正确臂的 6 次全部 used，其中 2 次 adapted（"改编"）。例如 2020_B 的模型族主标签为 `discrete_recurrence`（而非直接写 `dynamic_programming`），描述为"以天为阶段推进的资源—资金演化模型"——Agent 吸收了 DP 的序贯决策机理，但按题目资源/资金耦合做了具体化。

**这符合项目哲学"Knowledge constrains and informs construction, not dictates it"**，但同时也暴露测量粒度问题：trace 只记录 used/adapted 标记，**不记录"改编后是否保留了卡的核心机理约束"**（如最优子结构、无后效性检验是否真的执行）。

## 2. Negative Result 的四层归因

预注册结论：Δ_K = +2.14，95% CI [+0.00, +6.41]，下界触 0 → negative result。以下按证据强度排序解释：

### 2.1 信息增益 ceiling（最可能的主导因素）
LLM 作为建模主体本身已内化大量建模知识（DP/PDE/Queueing 的基本机理、适用条件）。知识卡作为"先验文本注入"，提供的是**已经存在于 LLM 参数中的知识的显式化**。当无知识臂（A/C）的 Agent 已经能构造出结构完整的 MODEL_IR 时，知识臂的边际信息增量趋近于零。
**证据**：A 臂（无知识无案例）的条件均值与其他臂几乎无差异（overall A=37.7/42，其他臂 37.8–38.3）；不是知识臂更好，而是**基线臂已经够好**。

### 2.2 测量粒度：L2 混测结构完备与内容正确，但不测过程与 L3/L4（确定的测量限制）
- L2 composite 的 7 维（MODEL_CONSTRUCTION_RUBRIC v1.0）**混合**两类：结构完备（L2.1 变量/2.2 参数/2.5 约束/2.7 方程结构，锚定 CUMCM-Bench key_variables/key_constraints）与内容正确（L2.4 目标正确性、L2.6 机理正确性——权重 3 为全维度最高）。
- 因此 K001 主终点并非纯"结构完备"测量：**机理正确性（权重最高）已被计入**。但 L2 仍然不测量：① L3 Solving 与 L4 Validation 的正确性（盲评 22 维已评但不在主终点）；② **建模过程推理质量**（是否执行了最优子结构验证、边界条件检查等知识卡 requires/validation 中的行为）。
- 知识卡真正可能产生差异的部分（验证行为、风险规避）若体现在过程而非产物结构/目标/机理描述中，L2 主终点**看不到**。
- trace 的 used/adapted 是自报标记，无强制证据要求"改编保留了核心机理"（adapted=21 的具体内容未做机理保真检查）。

### 2.3 注入剂量不足
每题注入 1 张匹配卡（+ 可选 1 份案例）。对主检验三题（2020_B/2018_A/2019_C），匹配卡分别只有 mc-dp/mc-numerical-pde/mc-queuing-theory 一张。剂量维度未做梯度（1 卡 vs 3 卡 vs 5 卡），无法排除"剂量不足"解释。

### 2.4 统计功效（已预注册声明）
block=3（每臂 11 runs）下最小可检 p=0.25，CI 宽（[+0.00, +6.41]）。效应量 Δ_K=+2.14 是**方向正确但精度不足**的观测——不能排除真实效应存在但未达可检水平。

## 3. Sham > K 为什么是重要信号

Δ_Sham = +3.42 > Δ_K = +2.14（CI 均跨 0，但点估计 Sham 更大）：

| 解释候选 | 证据 | 判定 |
|---|---|---|
| 更多上下文/更多处理资源的普适效应 | Sham 卡即使错位也被拒绝，但"额外阅读+结构化候选"可能触发 Agent 更深入的机理思考 | **最可能** |
| Sham 卡附带的方法族候选触发联想 | 错位卡仍列出候选方法族，可能激活 Agent 对正确方法的检索 | 部分支持 |
| 知识卡本身有负效应 | 正确卡被 adapted 后可能"框住"了 Agent 的自由建模 | 无直接证据，adapted 内容未做机理保真检查 |

**设计启示**：下一轮必须引入**上下文量匹配对照**（Sham 与真卡文本长度、结构完全一致，仅内容错位），才能把"知识内容效应"与"更多上下文处理效应"分离。P15-K001 的 Sham 卡长度差 0.8%–9.7%，已接近匹配，但分析上仍应以"处理资源"为最保守解释。

---

## 3.1 按题效应分解——题目区分度是隐藏变量（补充证据）

`analysis_result.json` 的 per_block 分解揭示效应**集中在一道题**：

| 题 | Δ_K | Δ_Sham | 各条件 MCQ 均值 | 判定 |
|---|---|---|---|---|
| 2020_B | **+6.41** | +12.82 | A/E=87.18，B/C/D=100 | 知识/案例在 DP 题上有效应（方向一致） |
| 2018_A | 0.0 / −2.56 | −2.56 | A/D/E=87.18，B/C=84.62 | 弱负效应（PDE 卡未提升，可能干扰） |
| 2019_C | **0.0** | 0.0 | **全臂恒定 87.18** | **零区分度**（所有条件同分） |

**关键发现**：
1. **2019_C 全臂恒定 87.18**——该题在 5 臂 × 3 rep 下所有 run 得分完全相同。要么评分在天花板/地板饱和，要么该题所有条件产物质量无差异。**该题对效应估计贡献为零信息**（delta 恒 0），实际有效 block 只有 2（2020_B、2018_A）。
2. 效应方向全部由 2020_B 提供（+6.41）：mc-dp 卡与 2020_B 序贯决策结构的匹配带来真实提升；而 2018_A 的 PDE 卡反而 −2.56（可能"卡文本引导"干扰了 Agent 的自由建模，或噪声）。
3. **对实验设计的直接含义**：K001 的"3 题主检验"实际只有 2 题有区分度——**主检验题集必须预检区分度**（每题各条件均值方差），全同分题标记为无区分度 block，不进入效应估计（或单列报告）。

**对归因的修正**：Δ_K=+2.14 不是"均匀小效应"，而是"2020_B 上 +6.41、2018_A 上 −2.56、2019_C 上 0"的混合。知识卡效应**高度依赖题目与卡的结构匹配深度**：DP 卡的机理（最优子结构/状态压缩）在 2020_B 上提供了 LLM 可能未显式执行的显式检查；PDE/Queueing 卡未产生同等待增益（ceiling 或干扰）。

## 3.2 2020_B 效应的精确定位——知识卡防止子问题漏覆盖（补充证据）

逐 run 修正计分（L2.6 满分即 3，不乘权重）后 2020_B 全貌：

| 臂 | run MCQ | 均值 | 备注 |
|---|---|---|---|
| A（无知识） | 61.5 / 100 / 100 | 87.2 | **1 个 Q1-only FAIL**（06cb0fb3，claude batch0） |
| B（知识） | 100 ×3 | 100 | 0 FAIL |
| C（案例） | 100 ×3 | 100 | 0 FAIL |
| D（知识+案例） | 100 ×3 | 100 | 0 FAIL |
| E（Sham 错位） | 61.5 / 100 / 100 | 87.2 | **1 个 Q1-only FAIL**（37f8a88b，claude batch0） |

**精确结论**：2020_B 上 Δ_K=+6.41 的**全部来源是"无知识臂各 1 个 Q1-only 失败（61.5），知识/案例臂 0 个失败"**——即 1 个稀有事件在臂间的 0/1 差异，统计上极弱（这正是 CI 下界触 0 的本质）。

**机制解释**：mc-dp 卡的 `good_for`/`structure_signals` 明确列出"2020_B 型：每日一决策、资源跨期消耗、状态（位置/资源/天数）有限离散"并指向 Q1–Q3 结构；真卡臂（B/D）的 Agent 看到卡即知需覆盖全部子问题。而 2020_B 恰是 3 问结构（最大资金/最优路线/风险分析），漏覆盖 Q2/Q3 直接导致 61.5。**知识卡的"结构信号"帮助了子问题覆盖**——这是知识卡真实（但微弱且基于 n=1）的机制效应。

**验证排除**：2019_C 各臂产物哈希全部不同（非机械复制），但评分按 rep 完全同模式（92.3/92.3/76.9）→ 该题无臂差异源于题目/评分层面，非生成侧造假。

**对 K002 的强化**：子问题覆盖不是"评分项"，而是**必须机械强制的前置 gate**（K002 已设计）；同时知识卡效应若只在"防止漏覆盖"上体现，K002 的知识维度测试应关注覆盖相关指标。

## 4. 2 个 FAIL run 的真实信号（能力维度）

- `06cb0fb3`（arm A，claude 生成）与 `37f8a88b`（arm E，claude 生成）：均 2020_B，`problem_binding.sub_question_id = "Q1"`——**只构造了 Q1 的模型**，未覆盖 Q2/Q3。
- 结构字段均非空（assumptions=5, variables=12, objectives=1, constraints=5, equations=6, mechanisms=3, experiments=1, validations=2），说明**不是空壳，而是覆盖不全**。
- **判定**：这是**真实的 capability/coverage 信号**（非测量问题）：外部 Agent 在单次 run 中可能只处理题目第一问就停止。盲评正确判 FAIL。

**对测量体系的意义**：子问题覆盖度（sub-question coverage）是当前评分中**最能区分 Agent 的维度之一**，应升级为强制 gate（Q1–Qn 全覆盖才进入质量评分），而不是仅作为评分项。

## 5. 对下一轮实验设计的直接启示

在审计报告（三仓库对比）回来后定稿，但本归因已确立四个必选项：

1. **上下文量匹配对照**：Sham 与真卡长度/结构完全一致，分离"知识内容效应"与"处理资源效应"。
2. **过程级测量**：trace 增加"机理保真检查"字段（改编后是否保留卡的核心 requires/validation 行为），或引入 critc 审查过程记录。
3. **子问题覆盖强制 gate**：Q1–Qn 全覆盖才进入评分（P15-K001 2 个 FAIL 已证明该维度区分力最强）。
4. **剂量梯度**：知识注入 0 / 1 卡 / 3 卡 三档，检验剂量效应。

**候选主效应**（优先级排序，待审计报告确认后定稿）：
- Representation effect：强制结构化 MODEL_IR（18 字段 schema 约束）vs 自由文本建模——检验"标准化表达"本身是否提升质量
- Evidence requirement effect：强制 Claim→Evidence→Result→Experiment 链 vs 无要求
- Critic effect：独立批判者审查 vs 无审查
- Knowledge effect 第二版：修正剂量+过程测量后的再检验

## 6. 结论（一句话）

P15-K001 的 negative result 最可能的解释是**信息增益 ceiling（LLM 已内化建模知识）+ 测量粒度不足（只测产物不测过程）+ 功效有限**，而非"知识卡无效"；同时实验证明了**知识注入机制不会产生盲从（Sham 11/11 正确拒绝）**，并暴露了**子问题覆盖度是最强区分维度**这一可执行改进点。
