# 投稿前检查清单

> 适用于所有竞赛模板（cumcm / mcm / diangong / huawei / huashu）。
> 提交前逐项核对，全部通过后方可提交。
> 自动化检查：`python core/tools/validate.py`（或 `validate_project.py <项目>`）。

---

## 一、格式与排版（L1）

| # | 检查项 | 自动 | 标准 |
|---|--------|------|------|
| 1.1 | `paper/main.tex` 存在且可编译 | ✅ | XeLaTeX 编译无 error |
| 1.2 | `paper/references.bib` 存在 | ✅ | 非空、格式正确 |
| 1.3 | 页数在范围内 | ✅ | min_pages ≤ 页数 ≤ max_pages |
| 1.4 | 正文字数达标 | ✅ | ≥ min_words（默认 18000） |
| 1.5 | 图表数量达标 | ✅ | 图 ≥ min_figures（6），表 ≥ min_tables（4） |
| 1.6 | 公式数量达标 | ✅ | ≥ min_equations（15） |
| 1.7 | 参考文献数量达标 | ✅ | ≥ min_references（10） |
| 1.8 | 近 5 年文献占比 | ✅ | ≥ recent_ref_ratio（60%） |
| 1.9 | 摘要字数 | ✅ | abstract_min_words ≤ 摘要 ≤ abstract_max_words |
| 1.10 | 封面/承诺书 | 🔲 | 按当届模板填写，无遗漏字段 |

## 二、内容与结构（L2）

| # | 检查项 | 自动 | 标准 |
|---|--------|------|------|
| 2.1 | 论文结构完整 | ✅ | 摘要→问题重述→问题分析→假设→符号→建模求解→灵敏度→评价→参考文献→附录 |
| 2.2 | 章节编号连续 | ✅ | 无跳号、无重复 |
| 2.3 | 图表编号与正文引用一致 | ✅ | 每个 `\ref{}` 有对应 `\label{}` |
| 2.4 | 公式编号连续 | ✅ | 无跳号 |
| 2.5 | 目录与正文标题一致 | 🔲 | 人工核对（如有目录页） |
| 2.6 | 摘要覆盖所有子问题 | 🔲 | 每个子问题在摘要中有一句话结论 |
| 2.7 | 关键词 3-5 个 | 🔲 | 分号分隔，覆盖核心方法 |

| # | 检查项 | 自动 | 标准 |

| 3.2 | 四舍五入口径一致 | ✅ | 论文与 JSON 小数位数一致 |

## 四、代码与复现（L3）

| # | 检查项 | 自动 | 标准 |
|---|--------|------|------|
| 4.1 | `code/main.py` 存在 | ✅ | 文件大小 ≥ min_main_py_bytes |
| 4.2 | 随机种子固定 | ✅ | `np.random.seed(42)` 或等效 |
| 4.3 | 启发式算法多次运行 | ✅ | ≥ multi_run_count（5）次，报告均值±标准差 |
| 4.4 | 支撑材料完整 | ✅ | 总大小 ≥ min_deliverables_bytes |
| 4.5 | 代码可独立运行 | 🔲 | `python code/main.py` 无报错，输出结果与论文一致 |
| 4.6 | 依赖清单 | 🔲 | `requirements.txt` 或 `environment.yml` 列出所有第三方包 |

## 快速执行

```bash
# 1. 自动化检查（覆盖所有 ✅ 项）
python core/tools/validate_project.py <项目名>

# 2. 全链路门禁
python core/tools/gate.py <项目名> all

# 3. 编译 PDF（如有 LaTeX 环境）
cd projects/<项目名>/paper && xelatex main.tex && bibtex main && xelatex main.tex && xelatex main.tex

# 4. 人工核对 🔲 项（对照上方清单逐条确认）
```

全部通过后，方可打包提交。
