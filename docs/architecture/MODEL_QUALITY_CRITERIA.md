# MODEL_QUALITY_CRITERIA — 模型质量与创新性的可操作判据（草案）

> Version: v0.1-draft ｜ Status: **DRAFT（待评审，未冻结）** ｜ Updated: 2026-09-11
> 目的：给「模型好不好、有没有创新」立一套**独立于 harness 自身打分**的可操作判据，
> 使"能力"命题可被证伪。本文不修改任何运行时代码，仅为判据草案。

---

## 0. 为什么需要这份文档

当前"能力提升"的主张缺乏独立标尺，四处证据都指向同一断层：

| 证据 | 事实 | 暴露的问题 |
|---|---|---|
| K001 | 知识注入 Δ=+2.14，置信区间触 0，p=1.0 | 负结果，但"能力"命题未被判死 |
| K002 | 纯表示 S−F(MCQ)=−4.85，显著负 | 结构化表示不产生建模价值 |
| K003 | S−F=+3.76 全来自 L4；L2 构造层为负 | 正效应来源被限定，且 L4 被判为循环论证 |
| 盲评 κ | K002 κ=0.4345 / K003 κ=0.260，均 <0.6 | 测量工具本身不可靠 |
| STRATEGIC_VERDICT §4-Round2 攻击 5 | "要求产出 validation_plan → rubric 评这些字段存在 → 得分高" | 自我打分循环 |

**结论**：在没有独立判据之前，任何"模型更好/更有创新"的声称都无法与"自己给自己打分"
区分。本文即为此立靶。

## 1. 判据本身必须满足的四条设计原则

1. **独立性**：判据的输入不得包含 harness 自己的评分或 LLM 盲评结论（否则是循环）。
2. **可证伪**：每条判据必须配一个**反例**——什么样的结果会推翻"模型 X 更好"。
3. **机械优先**：能用程序判定的，不用人评；人评只用于机械判据无法覆盖的最后一层。
4. **可复现**：给定（模型定义 + 数据 + 随机种子），判定结果确定且可重算。

> 判据若违反任一条，不得进入"能力"结论，只能进"观察"。

## 2. 判据（三级）

### 2.1 结构判据（可机械判定，无外部依赖）

| 编号 | 判据 | 可操作定义 | 反例（证伪条件） |
|---|---|---|---|
| S1 | **假设最小性** | 对同一现象的两个模型，比较计入 MODEL_IR `assumptions` 且**实际用于推导**的假设数；更少者优 | 若更少假设的模型在 S2/S3 全劣，则"最小性"不构成优势 |
| S2 | **验证覆盖** | 模型 `claims` 中**可被机械验证**（L3 可判：量纲/边界/守恒/约束）的条数占比 | 若两模型覆盖相同却结论相反，覆盖不构成优势 |
| S3 | **不变量满足** | 守恒律（质量/能量/干物质）、边界条件、量纲一致性逐条机械检查，全部通过 | 任一不变量被数值解违反且未在文档声明 → 模型无效 |
| S4 | **可追溯完备性** | 模型描述文档中的数值，可追溯到结果台账/题面的比例（现有 `check_numeric_traceability`） | 存在无法溯源且非题面给出的数字 → 不通过 |

### 2.2 经验判据（需数据 / 参考解）

| 编号 | 判据 | 可操作定义 | 反例 |
|---|---|---|---|
| E1 | **样本外预测** | 在留出数据/未参与标定的情形上计算误差 | 若留出误差不优于平凡基线（如均值/线性外推），则模型无预测力 |
| E2 | **基线 delta** | 相对"最简可用 baseline"（如常物性 / 无移动边界 / 均匀假设）的改进量 | delta 的置信区间含 0 → 改进不成立（沿用 K001 判法） |
| E3 | **未标定参数稳健性** | 对题面**未给定、由建模者设定**的参数做区间扫描，结论（如烘干时长、清除比例）的漂移幅度 | 结论随该参数跨过可用窗口 → 必须作为标定量如实披露，不得当作结论 |

> 现状缺口：A 题的恒温目标温度 50 °C、B 题的名义接收半径 1250 m 均属 E3 范畴，
> 已如实披露，但**未被门禁强制**。E3 应升级为机械检查项。

### 2.3 表述判据（人可读，最后一道）

| 编号 | 判据 | 可操作定义 |
|---|---|---|
| P1 | **可复现性** | 第三方按文档命令能重跑并得到同结果（seed 固定） |
| P2 | **推导可追溯** | 每个断言的数字/公式都能在 MODEL_IR 或结果台账找到落点 |

## 3. 反模式清单（什么**不算**创新）

1. **盲评高分但无机械验证** —— 分数来自人/LLM 的主观印象。
2. **循环论证** —— 判据的评价对象恰好是判据自身要求的产物（K003 L4 的教训）。
3. **复杂度堆砌换分** —— 假设/参数越多分越高，而非越少越好。
4. **未标定常数调出的好看** —— 用反标定的工艺参数（温度/半径）凑出"落在 2–3 天窗口"。
5. **表示层冒充建模层** —— 结构化 JSON 的完备性被当作建模能力（K002 已否证）。
6. **基础设施冒充能力** —— 新增门禁/契约条数被当作进步（本题已有的自省）。

## 4. 与现有门禁的关系

| 现有机制 | 覆盖 | 本文新增 |
|---|---|---|
| L2 Fidelity | MODEL_IR ↔ 代码语义对齐 | 保留，不重复 |
| L3 数值判定 | 约束/目标/域有限、非负 | **S3** 补齐守恒律/量纲/边界 |
| L4 盲评 | 主观质量 | **降级为辅助**；主判据交 S1–S4 + E1–E2 |
| `check_numeric_traceability` | 数值溯源 | 直接作为 **S4** |
| Evidence Gate E1–E9 | 证据完备性 | 保留，不重复 |

**κ 的处置**：κ < 0.6 的盲评维度不再作为主判据输入；若保留，须在结论中注明
"该维度仅方向性参考"。

## 5. 判据自身的证伪条件

本文的判据集若出现以下情况，须重新设计：

- **无增量**：在三个交付实例上，按 S1–S4 + E1–E2 排名与盲评排名**完全一致**
  → 判据未提供盲评之外的信息。
- **不可判**：多数实例在 S2/S3/E1 上返回"不可算"（如无参考解、无留出数据）
  → 判据在真实语料上不可用，须放宽或换判据。
- **可game**：存在"只提升 S1–S4 分数而 E1/E2 不变差"的平凡构造
  → 判据被规避。
