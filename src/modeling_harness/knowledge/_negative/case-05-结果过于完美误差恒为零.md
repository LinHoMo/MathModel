# 负样本：结果过于完美（误差恒为 0）

> 对应反模式：antipatterns.md #16「结果过于完美——误差恒为 0、相关系数恒为 1，却无解释」

## 问题切片

某赛题涉及用模型反演/重建若干观测数据。正文"结果验证"一节这样写：

> 为验证模型准确性，本文将模型输出与真实值进行对比。经计算，模型输出与
> 真值的相对误差为 0.00%，决定系数 R² = 1.000，相关系数达到 1，说明模型
> 完全精确地再现了全部观测数据。

表 3 逐条列出 20 个样本的"真值 vs 输出"，两列数字**逐位完全相同**，误差列填满了
`0.00%`。全文没有一处解释"为什么能零误差"，也没有说明数据是不是带噪声、模型是否
直接拟合了目标（而非预测）。

## 失分归因

1. **命中 #16 原文"误差恒为 0、相关系数恒为 1，却无解释"**：这是最刺眼的"结果过于完美"。
   真实数据必有噪声，0.00% 全零误差意味着两种可能——要么模型**把目标值当输入/直接复制**
   （数据泄漏式过拟合），要么数据是凭空生成/反向填充的。无论哪种，都需要解释，本例
   只字未提。——严重度 `major`（若被判定为"数据/结果造假"倾向，可升 `blocking`）。
2. **命中 #15「只给单一指标」**：只报了一个 R²/相关系数，没有残差分布、没有换集验证、
   没有不确定度，0.00% 一眼假。
3. 与 `numeric-edge-cases#1`（标准化泄漏）同源的可疑信号：任何"验证得分 1.0 / 误差 0"
   的结果，都应优先怀疑**测试集泄漏 / 目标泄漏**，而不是"模型完美"。
4. 结论导向错误：误差为 0 恰是**需要解释的异常**，正文却当作"模型好"的正面证据，
   属于评审视角的扣分。

## 正确做法

| 错误 | 修正 |
|---|---|
| "相对误差 0.00%、R²=1.000"当成绩 | 检查是否存在目标泄漏 / 数据复制；在模型规格里声明"本模型为拟合型（非外推预测型），误差为 0 是因为对训练集内点做精确插值" |
| 表 3 全填 0.00% | 若确为插值型模型，改报告"模型在样本点上的拟合残差为 0（因采用精确通过所有样本点的插值），其泛化能力需另用留一交叉验证评估"，补留一法结果 |
| 无解释 | 加一段"为什么会出现零误差"的机制说明：是插值构造使然，还是数据确无噪声；并给出**换一套样本/留一法**下真实非零误差 |
| 只报一个指标 | 补残差箱线图、MAE/RMSE/sMAPE 多指标、留一交叉验证误差，展示"训练点内 0、留一点即非 0"的诚实结果 |

可转成 revision-planner 验收标准：论文中不得出现"误差 0.00% 且无任何解释"的表述；
若保持零误差结论，必须附对应机制说明 + 留一交叉验证的非零误差（`all_results.json`
须含 `loo_cv` 字段）。

## 涉及阶段

- **产生环节**：
  - Programmer 手 `result-verifier`（L4 数值验证时未对"零误差"启动可疑性检查，未做
    留一法/换集验证）；
  - Modeler 手 `model-builder`（若模型被设计成"直接复现目标"，则是选型/建模缺陷）。
- **检出环节**：
  - Writer 手 `consistency-checker`（L4 应在论文-代码一致时发现"0.00% 无解释"）；
  - Reviewer 手 `weakness-hunter`（扫描命中 `antipatterns#16`、`#15`，严重度 major+）。
- **回退建议**：先由 `result-verifier` 复跑并补留一验证/残差分布；若是模型设计问题，
  回 `model-builder`；若仅缺"为什么零误差"的解释，回 `section-writer` 补一段说明即可。
