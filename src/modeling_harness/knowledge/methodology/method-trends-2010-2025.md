## 二、方法-问题类型映射

### 2.1 A题核心方法组合（连续优化/物理建模）

**题目特征**：连续变量、物理/工程背景、需要数学建模推导

**核心方法组合**：ODE/PDE建模 → 数值求解 → 参数优化 → 敏感性分析

| 方法组合 | 适用场景 | 典型题目 |
|---------|---------|---------|
| ODE + Runge-Kutta + 参数拟合 | 动态系统、传染病模型 | 流感传播、人口增长 |
| PDE + 有限差分/有限元 | 扩散/波动问题 | 污染扩散、热传导 |
| 几何分析 + 数值搜索 | 几何优化问题 | 2025年A题典型 |
| 微分方程 + 蒙特卡洛 | 随机扰动系统 | 竞技体育建模 |

**最佳示例**：2024年A题（ODE+数值求解+多目标优化）、2025年A题（几何分析+数值搜索）

### 2.2 B题核心方法组合（离散优化/组合优化）

**题目特征**：离散变量、NP-hard问题、约束复杂

**核心方法组合**：问题建模 → 整数规划/启发式算法 → 精度验证

| 方法组合 | 适用场景 | 典型题目 |
|---------|---------|---------|
| 整数规划 + 分支定界 | 小规模精确解 | 装箱、分配 |
| GA + 局部搜索（混合GA） | 中大规模优化 | 调度、路径规划 |
| 模拟退火 + 约束处理 | 高约束问题 | 资源分配 |
| 禁忌搜索 + 邻域设计 | 序列优化 | 排序、组卷 |

**最佳示例**：2024年B题（GA+精确解验证+灵敏度分析）

### 2.3 C题核心方法组合（数据驱动/统计建模）

**题目特征**：数据量大、需要挖掘规律、预测/分类/评价

**核心方法组合**：数据清洗 → 特征工程 → 聚类/分类/回归 → 模型验证

| 方法组合 | 适用场景 | 典型题目 |
|---------|---------|---------|
| XGBoost + SHAP + 交叉验证 | 分类/预测 | 欺诈检测、销量预测 |
| PCA + K-means + 综合评价 | 评价/排名 | 企业评价、地区排名 |
| LSTM/GRU + 时间序列 | 时序预测 | 股价预测、流量预测 |
| 回归分析 + 特征选择 | 回归问题 | 影响因素分析 |

**最佳示例**：2024年C题（XGBoost+SHAP+多模型对比）

### 2.4 D题核心方法组合（多目标优化）

**题目特征**：多个目标冲突、需要权衡、实际工程/管理背景

**核心方法组合**：多目标建模 → Pareto优化 → 决策分析 → 仿真验证

| 方法组合 | 适用场景 | 典型题目 |
|---------|---------|---------|
| NSGA-II + TOPSIS决策 | 工程优化 | 设计优化、调度 |
| 多目标线性规划 + 敏感性分析 | 资源分配 | 供应链、物流 |
| 双层优化 + 鲁棒优化 | 不确定性多目标 | 投资、定价策略 |

**最佳示例**：2024年D题（NSGA-II+双层优化+仿真）

### 2.5 E题核心方法组合（交叉学科/综合应用）

**题目特征**：跨学科、需要多种方法融合、开放性问题

**核心方法组合**：问题分解 → 数据挖掘 + 领域知识 → 多方法融合

| 方法组合 | 适用场景 | 典型题目 |
|---------|---------|---------|
| 文本挖掘 + 网络分析 + 仿真 | 社会网络 | 舆情传播、社交网络 |
| 机器学习 + 因果推断 + 政策分析 | 公共政策 | 教育、医疗政策 |
| 图神经网络 + 优化 + 仿真 | 图结构数据 | 交通网络、推荐系统 |

**最佳示例**：2024年E题（多方法融合+交叉验证+可视化）

- **混合整数规划 + 分支定界**：适用于小规模精确优化，使用CPLEX/Gurobi求解

**C题组合详解**：
- **XGBoost + SHAP + 交叉验证**：适用于表格数据预测/分类，需足够样本量
- **PCA + 聚类 + 综合评价**：适用于多指标评价/排名，需合理选择聚类数

**D题组合详解**：
- **NSGA-II + TOPSIS + 仿真验证**：适用于多目标工程优化，计算开销较大
- **双层优化 + 鲁棒优化**：适用于不确定性多目标，模型复杂度高

**E题组合详解**：
- **多方法融合 + 交叉验证**：适用于交叉学科/开放问题，需平衡方法复杂度与可解释性
- **数据挖掘 + 因果推断**：适用于社会/经济政策分析，需要领域知识

## 四、2025年最新趋势

### 4.1 分层次优化

将复杂问题分解为多个层次，逐层求解：上层（宏观决策）→ 中层（策略优化）→ 下层（执行细节）

**典型应用**：物流网络设计（选址-分配-路径）、供应链优化（采购-生产-配送）、城市规划（宏观-中观-微观）

### 4.2 多算法验证

使用多种算法求解同一问题，交叉验证结果：算法1求解 → 算法2求解 → 结果对比 → 一致性分析

**常用组合**：GA + SA + 禁忌搜索；整数规划 + 启发式算法；精确解 + 近似解

**优势**：提高结果可信度、发现算法局限性、提供多方案选择

### 4.3 几何分析 + 数值搜索

先用几何/解析方法缩小搜索范围，再用数值方法精确求解：几何建模 → 解析推导 → 可行域分析 → 数值搜索

**优势**：减少计算量、提高求解效率、增强理论深度

**2025年A题典型应用**：优化问题的几何约束分析、可行域的解析刻画、数值搜索的初始点选择

### 4.4 预测拦截点

在预测模型基础上，设计拦截/干预策略：预测模型 → 拦截点识别 → 干预策略设计 → 效果评估

**典型应用**：传染病防控（预测传播→识别关键节点→设计干预策略）、网络安全（预测攻击→识别脆弱点→设计防御策略）

### 4.5 其他新兴趋势

| 趋势 | 描述 | 应用场景 |
|------|------|---------|
| 图神经网络（GNN） | 处理图结构数据 | 社交网络、交通网络 |
| 因果推断 | 从相关到因果 | 政策评估、A/B测试 |
| 可解释AI（XAI） | 提高模型可解释性 | 医疗、金融、政策 |
| 迁移学习 | 跨领域知识迁移 | 数据稀缺场景 |

## 五、方法选择决策树

### 5.1 决策树总览

```
题型判断
├── A题（连续优化/物理建模）
│   ├── 物理/工程背景 → ODE/PDE → 数值求解 → 参数优化
│   ├── 几何优化 → 几何分析 → 数值搜索
│   └── 随机系统 → 微分方程 → 蒙特卡洛
│
├── B题（离散优化/组合优化）
│   ├── 小规模（<100变量）→ 整数规划 → 分支定界
│   ├── 中大规模（>100变量）→ GA/PSO/SA → 局部搜索
│   └── 高约束 → 约束规划 → 启发式修正
│
├── C题（数据驱动/统计建模）
│   ├── 分类问题 → XGBoost/RF → SHAP → 交叉验证
│   ├── 预测问题 → LSTM/GRU → Transformer
│   ├── 聚类/评价 → PCA → K-means → 综合评价
│   └── 回归问题 → 回归分析 → 特征选择
│
├── D题（多目标优化）
│   ├── 双层优化 → NSGA-II → TOPSIS
│   ├── 不确定性 → 鲁棒优化 → 蒙特卡洛仿真
│   └── 约束多目标 → NSGA-II → 仿真验证
│
└── E题（交叉学科）
    ├── 社会网络 → 网络分析 + 仿真 + 政策建议
    ├── 经济管理 → 数据挖掘 + 因果推断 + 经济模型
    └── 其他 → 问题分解 → 多方法融合 → 交叉验证
```

## 六、方法使用注意事项

### 6.1 常见错误

| 错误类型 | 描述 | 正确做法 |
|---------|------|---------|
| 方法堆砌 | 堆砌多种方法但无逻辑 | 选择2-3种核心方法，形成完整逻辑链 |
| 忽略验证 | 只用一种方法求解 | 多方法对比或精确解验证 |
| 过度复杂 | 方法选择过于复杂 | 根据问题规模选择合适复杂度 |
| 忽略可解释性 | 模型黑箱化 | 添加XAI方法（SHAP等） |
| 缺少敏感性分析 | 结果稳定性不明 | 添加参数/模型敏感性分析 |

### 6.2 不同题型常见失误

**A题常见失误**：
- 微分方程建模后缺乏数值验证
- 参数估计缺乏物理意义解释
- 忽略初始条件和边界条件

**B题常见失误**：
- 启发式算法缺乏收敛性分析
- 小规模问题未尝试精确解
- 约束处理不严谨

**C题常见失误**：
- 数据清洗不充分
- 特征工程缺乏领域知识
- 过拟合未做交叉验证

**D题常见失误**：
- 多目标权重设置缺乏依据
- Pareto前沿未做可视化
- 决策方法选择不当

**E题常见失误**：
- 方法融合缺乏逻辑
- 跨学科知识不足
- 政策建议缺乏数据支撑
