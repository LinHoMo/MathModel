# 数学推导规范与模板

> 本文档定义数学建模竞赛中公式推导的标准流程和模板，确保推导过程的完整性和严谨性。

---

## 一、推导链路标准

### 1.1 核心原则

**完整性原则**：从基本原理到最终模型，每一步都要有数学依据。

**可追溯性原则**：每个公式都要能追溯到经典教材或文献。

**一致性原则**：符号、单位、量纲在全文中保持一致。

### 1.2 推导链路结构

```
基本定律/原理 → 数学模型 → 边界条件 → 求解方法 → 验证方法
```

## 二、A题物理建模推导模板

### 2.1 标准推导链路

```
物理定律 → 力/能量分析 → 运动方程/控制方程 → 边界条件 → 数值/解析解 → 验证
```

### 2.2 力学问题推导模板

#### 步骤1：物理定律选择

| 问题类型 | 适用定律 | 典型公式 |
|---------|---------|---------|
| 质点运动 | 牛顿第二定律 | F = ma |
| 刚体转动 | 转动定律 | M = Iα |
| 流体流动 | 纳维-斯托克斯方程 | ρ(∂v/∂t + v·∇v) = -∇p + μ∇²v |
| 热传导 | 傅里叶定律 | q = -k∇T |
| 电磁场 | 麦克斯韦方程组 | ∇×E = -∂B/∂t |

#### 步骤2：力/能量分析

**力学系统分析模板**：

```
1. 识别研究对象：[对象名称]
2. 建立坐标系：[坐标系类型，如直角坐标、极坐标]
3. 分析受力：
   - 重力：G = mg，方向[向下]
   - 弹性力：F_spring = -kx，方向[与位移相反]
   - 阻尼力：F_damping = -cv，方向[与速度相反]
   - 外力：F_external = [具体表达式]
4. 合力表达式：F_total = ΣF_i
```

#### 步骤3：建立运动方程

**标准形式**：

```
m·x'' + c·x' + k·x = F(t)
```

其中：
- m：质量 [kg]
- c：阻尼系数 [N·s/m]
- k：弹簧刚度 [N/m]
- F(t)：外力 [N]

#### 步骤4：边界条件

| 边界条件类型 | 数学表达 | 物理意义 |
|-------------|---------|---------|
| 初始位移 | x(0) = x₀ | t=0时的位置 |
| 初始速度 | x'(0) = v₀ | t=0时的速度 |
| 固定边界 | x(L) = 0 | 端点固定 |
| 自由边界 | x'(L) = 0 | 端点自由 |

#### 步骤5：求解方法选择

| 问题类型 | 推荐方法 | 适用条件 |
|---------|---------|---------|
| 线性常微分方程 | 解析法 | 低维、简单边界 |
| 非线性常微分方程 | 数值法（Runge-Kutta） | 高维、复杂边界 |
| 偏微分方程 | 有限差分/有限元 | 连续介质 |
| 优化问题 | 启发式算法 | NP难问题 |

#### 步骤6：验证方法

| 验证类型 | 方法 | 判断标准 |
|---------|------|---------|
| 量纲验证 | 检查公式两边量纲 | 量纲一致 |
| 极限验证 | 令参数为0或∞ | 退化为已知情况 |
| 能量验证 | 检查能量守恒 | 相对误差<1% |
| 解析对比 | 与解析解对比 | 误差<容忍阈值 |

### 2.3 示例：波浪能装置推导

**问题描述**：设计振荡浮子式波浪能装置，使输出功率最大化。

**推导过程**：

```
1. 物理定律：牛顿第二定律 F = ma

2. 力分析：
   - 重力：G = mg（向下）
   - 浮力：F_buoyancy = ρgV_displaced（向上）
   - 阻尼力：F_damping = -cv（与速度相反）
   - 弹簧力：F_spring = -kx（与位移相反）
   - 波浪激励力：F_wave = F₀cos(ωt)（周期性）

3. 运动方程：
   m·x'' = G + F_buoyancy + F_damping + F_spring + F_wave
   m·x'' + c·x' + k·x = F₀cos(ωt) + (ρgV₀ - mg)

4. 边界条件：
   x(0) = 0（初始位置）
   x'(0) = 0（初始速度）

5. 稳态解：
   x(t) = X·cos(ωt - φ)
   其中：X = F₀/√((k-mω²)² + (cω)²)
         φ = arctan(cω/(k-mω²))

6. 输出功率：
   P = c·(x')² = c·ω²·X²·sin²(ωt - φ)
   平均功率：P_avg = 0.5·c·ω²·X²
```

## 三、B题实验设计推导模板

### 3.1 标准推导链路

```
因素识别 → 实验设计 → 数据收集 → 统计分析 → 模型建立 → 优化
```

### 3.2 回归分析推导模板

#### 步骤1：因素识别

| 因素类型 | 示例 | 处理方法 |
|---------|------|---------|
| 连续因素 | 温度、压力 | 直接使用 |
| 离散因素 | 催化剂类型 | 编码处理 |
| 分类因素 | 原料来源 | 虚拟变量 |

#### 步骤2：实验设计

| 设计方法 | 适用场景 | 优点 |
|---------|---------|------|
| 全因子设计 | 因素少（≤4） | 信息完整 |
| 部分因子设计 | 因素多 | 减少实验次数 |
| 中心复合设计 | 响应面法 | 二次模型 |
| Box-Behnken设计 | 三水平 | 效率高 |

#### 步骤3：回归模型建立

**多元线性回归**：

```
Y = β₀ + β₁X₁ + β₂X₂ + ... + βₖXₖ + ε
```

**参数估计**（最小二乘法）：

```
β̂ = (X'X)⁻¹X'Y
```

**模型检验**：

| 检验类型 | 统计量 | 判断标准 |
|---------|--------|---------|
| 拟合优度 | R² | R² > 0.8 |
| 显著性检验 | F统计量 | p < 0.05 |
| 系数检验 | t统计量 | p < 0.05 |
| 残差分析 | DW统计量 | 1.5 < DW < 2.5 |

#### 步骤4：优化求解

**目标函数**：

```
max Y = β₀ + β₁X₁ + ... + βₖXₖ
s.t. X_min ≤ X ≤ X_max
```

**求解方法**：线性规划/非线性规划


### 4.2 机器学习建模模板

#### 步骤1：数据理解

| 分析类型 | 方法 | 目的 |
|---------|------|------|
| 描述统计 | 均值、方差、分布 | 了解数据特征 |
| 相关分析 | 相关系数矩阵 | 识别特征关系 |

| 技术 | 方法 | 适用场景 |

| 标准化 | Z-score | 不同量纲特征 |

| 降维 | PCA | 高维数据 |

#### 步骤3：模型选择

| 任务类型 | 推荐模型 | 优点 |
|---------|---------|------|

| 回归 | XGBoost | 精度高 |

## 五、符号管理规范

### 5.1 符号定义表格式

| 符号 | 含义 | 单位 | 首次出现位置 |
|------|------|------|-------------|
| m | 质量 | kg | 公式(1) |
| c | 阻尼系数 | N·s/m | 公式(2) |
| k | 弹簧刚度 | N/m | 公式(3) |

### 5.2 符号使用规则

1. **唯一性**：一个符号只表示一个物理量
2. **一致性**：全文使用同一符号
3. **规范性**：使用国际通用符号
4. **完整性**：所有符号都要在符号表中定义

### 5.3 单位一致性检查

**量纲分析方法**：

```
公式两边的量纲必须一致。

示例：F = ma
- F的量纲：[M][L][T]⁻²（力）
- m的量纲：[M]（质量）
- a的量纲：[L][T]⁻²（加速度）
- 验证：[M][L][T]⁻² = [M] × [L][T]⁻² ✓
```

## 六、常见错误与避免

### 6.1 推导过程错误

| 错误类型 | 示例 | 正确做法 |
|---------|------|---------|
| 跳步推导 | 直接写出最终公式 | 每步都要有依据 |
| 符号混乱 | 同一符号多义 | 使用符号表管理 |
| 单位不一致 | 混用国际单位和工程单位 | 统一使用国际单位 |
| 边界条件缺失 | 忽略初始条件 | 明确所有边界条件 |

### 6.2 验证方法错误

| 错误类型 | 示例 | 正确做法 |
|---------|------|---------|
| 过度验证 | 做过多不必要的验证 | 选择关键验证点 |
| 验证不足 | 只做一种验证 | 多维度验证 |
| 判断标准模糊 | "结果合理" | 给出具体阈值 |
