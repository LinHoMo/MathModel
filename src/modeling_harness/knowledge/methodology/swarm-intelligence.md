# 群智能优化算法

> 适用：复杂优化、组合优化、NP-hard 问题、无解析梯度的黑箱目标函数。
> 本篇补足 `genetic-algorithms.md` 之外的主流群智能方法：粒子群、蚁群、模拟退火、免疫算法。

## 一、先问：真的需要启发式算法吗

**启发式算法是最后手段，不是首选。** 用之前先确认：

| 问题特征 | 该用什么 |
|---|---|
| 目标与约束都是线性的 | 线性规划（单纯形 / 内点），**不要**用启发式 |
| 凸优化、有解析梯度 | `scipy.optimize` / `cvxpy` |
| 整数/混合整数规划 | 分支定界（PuLP / OR-Tools / Gurobi） |
| 小规模组合优化（n ≤ 20） | 穷举或动态规划 |
| 非线性、非凸、不可微、规模大 | **才考虑**群智能 |

用启发式算法解一个线性规划，是**明确的失分点**——评委一眼看出你在用复杂方法掩盖建模能力的不足。

## 二、四条铁律

1. **绝不能宣称全局最优**。除非有数学证明、精确解对照，或足够可信的多起点稳定性验证。正确表述是"在给定参数与迭代预算下求得的最优解"。
2. **必须多次独立运行**。env 要求 `code.multi_run_count ≥ 5`，取统计结果（均值、标准差、最优、最差），变异系数 `CV = σ/μ` 应 ≤ 0.10。
3. **必须做多起点 / 多种子稳定性检查**（`modeling.multi_start_check`）。非凸问题上单次运行的"最优解"很可能是局部最优。
4. **必须给出对照基线**。贪心构造、随机搜索、或已知精确解——没有对照就无法说明你的算法好在哪。

## 三、粒子群算法 PSO

### 3.1 原理

每个粒子记住自身历史最优 $p_i$ 与群体历史最优 $g$，按速度—位置更新：

$$v_i^{t+1}=\omega v_i^{t}+c_1r_1(p_i^{t}-x_i^{t})+c_2r_2(g^{t}-x_i^{t})$$

$$x_i^{t+1}=x_i^{t}+v_i^{t+1}$$

三项含义：惯性（保持运动趋势）、认知项（回到自身最优）、社会项（趋向群体最优）。

### 3.2 参数

| 参数 | 典型值 | 说明 |
|---|---|---|
| 惯性权重 $\omega$ | 0.9 → 0.4 线性递减 | 大利于全局搜索，小利于局部精细 |
| 学习因子 $c_1,c_2$ | 1.5 ~ 2.0 | 通常取 $c_1=c_2=2$ |
| 种群规模 | 20 ~ 50 | 维度高时适当增大 |
| 速度上限 $v_{\max}$ | 解空间的 10%~20% | 防止粒子飞出搜索域 |

### 3.3 适用与陷阱

- **适用**：连续变量优化、维数适中（<100）。
- **陷阱**：
  - 早熟收敛（所有粒子挤到一个点）→ 用递减 $\omega$ 或引入变异
  - 边界处理不当（粒子飞出后直接截断会损失多样性）→ 用反射或随机重置
  - 离散/组合问题直接用 PSO 会得到无效解 → 需改用二进制 PSO 或离散编码

## 四、蚁群算法 ACO

### 4.1 原理

信息素正反馈：路径越短，信息素浓度越高，后续蚂蚁越倾向选择。

$$\tau_{ij}\leftarrow(1-\rho)\tau_{ij}+\sum_k\Delta\tau_{ij}^k,\qquad
\Delta\tau_{ij}^k=\begin{cases}Q/L_k,&\text{蚂蚁 }k\text{ 经过 }ij\\0,&\text{否则}\end{cases}$$

状态转移概率：

$$p_{ij}^k=\frac{\tau_{ij}^{\alpha}\eta_{ij}^{\beta}}{\sum_{s\in N_k}\tau_{is}^{\alpha}\eta_{is}^{\beta}}$$

其中 $\eta_{ij}=1/d_{ij}$ 为启发式信息（贪心偏好）。

### 4.2 参数

| 参数 | 典型值 | 含义 |
|---|---|---|
| 信息素重要度 $\alpha$ | 1 ~ 2 | 过小退化为贪心，过大早熟 |
| 启发式重要度 $\beta$ | 2 ~ 5 | 越大越依赖距离信息 |
| 挥发系数 $\rho$ | 0.1 ~ 0.5 | 太小易停滞，太大遗忘过快 |
| 信息素强度 $Q$ | 1 ~ 100 | 与 $L_k$ 量级匹配 |

### 4.3 适用与陷阱

- **适用**：**离散组合优化**——TSP、VRP、路径规划、调度、网络路由。
- **陷阱**：
  - 参数对结果极敏感，必须做参数扫描，不能照抄默认值
  - 收敛慢、计算量大（每轮所有蚂蚁都要走完整路径）
  - 连续优化问题不适合（蚁群天然是离散的）
  - 忘记精英策略（精英蚁系统）会让收敛明显变慢

## 五、模拟退火 SA

### 5.1 原理

源于固体退火。以 Metropolis 准则**概率性接受劣解**，从而跳出局部最优：

$$P(\text{接受劣解})=\exp\left(-\frac{\Delta f}{T}\right)$$

温度 $T$ 按冷却表递减：$T_{k+1}=\alpha T_k$（$\alpha\in[0.8,0.99]$）。

### 5.2 为什么它最重要

**SA 是所有启发式算法里最容易被正确实现的**，而且：

- 有理论保证：温度趋零足够慢时以概率 1 收敛到全局最优
- 局部搜索算子易设计（交换、插入、反转）
- 单次运行快，适合做 5 次独立运行的统计

**推荐做法**：把 SA 作为基线对照。如果精心设计的 PSO / ACO 跑不过 SA，说明你的算法实现或参数有问题。

### 5.3 关键要素

| 要素 | 常见选择 |
|---|---|
| 初始温度 | 使初始接受概率约 0.8 |
| 降温方式 | 指数降温 $T\leftarrow\alpha T$ 最常用 |
| 内循环次数 | 每个温度下迭代 $L$ 次（与邻域规模相当） |
| 终止条件 | $T<T_{\min}$ 或若干轮无改进 |
| 邻域算子 | TSP 用 2-opt / Or-opt；调度用交换 / 插入 |

## 六、免疫算法 IA

模拟生物免疫系统：抗体 = 候选解，抗原 = 目标函数，亲和度 = 适应度。

核心算子：**克隆选择**（高亲和度抗体大量克隆）+ **亲和度成熟**（克隆体高频变异）+ **浓度抑制**（抑制相似抗体，维持多样性）。

- **优势**：浓度抑制机制天然维持种群多样性，多峰优化表现好
- **劣势**：实现复杂、参数多、竞赛中相对小众
- **建议**：仅在**多峰函数 / 多模态优化**且其他算法早熟严重时考虑，别为了新奇而用

## 七、选型与对比

| 算法 | 变量类型 | 擅长 | 收敛速度 | 实现难度 |
|---|---|---|---|---|
| 遗传算法 GA | 连续 / 离散 / 混合 | 通用，编码灵活 | 中 | 中 |
| 粒子群 PSO | 连续 | 连续优化、参数寻优 | **快** | 低 |
| 蚁群 ACO | 离散 | **TSP / VRP / 路径** | 慢 | 高 |
| 模拟退火 SA | 连续 / 离散 | 通用基线、局部搜索 | 中 | **低** |
| 免疫算法 IA | 连续 / 离散 | 多峰、维持多样性 | 中 | 高 |

## 八、结果怎么汇报才站得住

**必须报这几项**，缺一项都会被追问：

1. **多次运行的统计**：最优、最差、均值、标准差、变异系数 CV
2. **收敛曲线**：横轴迭代次数、纵轴最优值，多条曲线（多次运行）叠加
3. **参数表与参数敏感性**：关键参数扫描结果，说明为什么取这个值
4. **与基线对照**：贪心 / 随机 / SA / 精确解（小规模时）
5. **与精确解对照**：小规模实例用 Gurobi 求精确解，验证启发式解的质量差距（gap）

**只报"最优值 = xxx"而不报上面这些，等于没有验证。**

## 九、数值陷阱

- **随机种子**：必须固定所有随机源（numpy / random / 数据加载顺序），否则不可复现
- **只跑一次**：单次运行的"最优"没有统计意义，至少 5 次
- **早熟误判为收敛**：种群多样性趋零但仍在迭代，实际已停滞
- **参数照抄默认值**：不同问题量级不同，默认值几乎必然不合适
- **目标函数量级未归一化**：多目标加权时量纲差异会主导搜索方向
- **边界处理**：截断法会堆积在边界，反射或随机重置更好

## 十、代码骨架（PSO + 多次运行统计）

```python
import numpy as np

def pso(objective, bounds, n_particles=40, iters=200,
        w=(0.9, 0.4), c1=2.0, c2=2.0, seed=42):
    """粒子群优化。bounds: (n_dim, 2) 数组，每行为 [lo, hi]。"""
    rng = np.random.default_rng(seed)      # 固定随机源，保证可复现
    lo, hi = bounds[:, 0], bounds[:, 1]
    span = hi - lo
    v_max = 0.15 * span

    X = lo + rng.random((n_particles, len(lo))) * span
    V = rng.uniform(-v_max, v_max, X.shape)

    pbest_x, pbest_f = X.copy(), objective(X)
    gbest_i = int(np.argmin(pbest_f))
    gbest_x, gbest_f = pbest_x[gbest_i].copy(), pbest_f[gbest_i]
    curve = [gbest_f]

    for t in range(iters):
        w_t = w[0] + (w[1] - w[0]) * t / max(1, iters - 1)   # 线性递减惯性
        r1, r2 = rng.random(X.shape), rng.random(X.shape)
        V = (w_t * V
             + c1 * r1 * (pbest_x - X)
             + c2 * r2 * (gbest_x - X))
        V = np.clip(V, -v_max, v_max)
        X = np.clip(X + V, lo, hi)          # 边界截断（量级差异大时改用反射）

        f = objective(X)
        improved = f < pbest_f
        pbest_x[improved] = X[improved]
        pbest_f[improved] = f[improved]

        i = int(np.argmin(pbest_f))
        if pbest_f[i] < gbest_f:
            gbest_x, gbest_f = pbest_x[i].copy(), pbest_f[i]
        curve.append(gbest_f)

    return gbest_x, gbest_f, np.array(curve)


def multi_run(objective, bounds, runs=5, **kw):
    """多次独立运行并给出统计——启发式算法的必备汇报项。"""
    bests, curves = [], []
    for k in range(runs):
        _, f, c = pso(objective, bounds, seed=kw.pop("seed", 42) + k, **kw)
        bests.append(f)
        curves.append(c)
    bests = np.asarray(bests)
    cv = bests.std() / abs(bests.mean()) if bests.mean() != 0 else np.inf
    return {
        "best": bests.min(), "worst": bests.max(),
        "mean": bests.mean(), "std": bests.std(),
        "cv": cv,                       # 应 <= 0.10（env: code.cv_threshold）
        "curves": curves,
    }
```

## 十一、常见扣分点

1. 宣称"全局最优"而无证明或精确解对照
2. 只跑一次就报结果
3. 不报变异系数，无法判断稳定性
4. 无收敛曲线
5. 参数照抄默认值且不说明
6. 没有对照基线（贪心 / 随机 / 精确解）
7. 随机种子未固定，结果不可复现
8. 能用线性规划/整数规划求解器，却硬用启发式
9. 多目标未归一化直接加权求和
10. 目标函数计算了重复内容，导致迭代极慢却未优化
