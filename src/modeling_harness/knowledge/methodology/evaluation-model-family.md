# 评价模型族

> 适用题型：C 题（评价/决策类）、D 题（综合类）、以及绝大多数竞赛题的"方案比选"环节。
> 这是国赛出现频率最高的模型族之一，也是最容易写成"套公式"的地方。

## 一、评价问题的通用结构

所有评价问题都可以拆成同一副骨架：

```
评价对象 × 评价指标 × 指标权重 × 合成规则 → 排序 / 分级
```

因此选模型的实质是回答四个问题：

1. **指标怎么定**——有没有客观标准？还是只能主观构造？
2. **权重从哪来**——主观经验、数据本身、还是两者结合？
3. **怎么合成**——线性加权、理想点距离、还是模糊隶属？
4. **结果怎么用**——排序、分级、还是找非有效单元？

**最常见的错误是跳过前三问，直接挑一个看起来高级的方法。** 评委追问"权重为什么这么取""为什么用这个方法而不是那个"时答不上来，比方法本身简单更致命。

## 二、权重生成：主观赋权

### 2.1 层次分析法 AHP

- **原理**：把指标两两比较构造判断矩阵 $A=(a_{ij})$，求最大特征根对应的特征向量作为权重。
- **适用**：指标难以量化、依赖专家经验、且指标数不宜过多（建议 ≤9）。
- **必须做一致性检验**：

$$CI=\frac{\lambda_{\max}-n}{n-1},\qquad CR=\frac{CI}{RI}$$

$CR<0.1$ 才认为判断矩阵可接受。**不做一致性检验的 AHP 是无效模型**——这是最高频的扣分点。

- **陷阱**：
  - 判断矩阵不满足互反性（$a_{ij}\neq 1/a_{ji}$）
  - 标度使用随意（1–9 标度不能混用 0–1 标度）
  - 指标过多导致判断矩阵阶数高、一致性难通过

### 2.2 德尔菲法 Delphi

多轮专家匿名打分、反馈、收敛。适合缺乏历史数据的全新问题，但**耗时长、主观性强**，竞赛中通常作为 AHP 的补充而非主力。

### 2.3 最小平方法与特征向量法

判断矩阵不一致时的权重估计替代方案，竞赛中较少单独使用。

## 三、权重生成：客观赋权

### 3.1 熵权法

- **原理**：指标值差异越大，信息熵越小，权重越大。

$$p_{ij}=\frac{x_{ij}}{\sum_{i=1}^{m}x_{ij}},\quad
e_j=-\frac{1}{\ln m}\sum_{i=1}^{m}p_{ij}\ln p_{ij},\quad
w_j=\frac{1-e_j}{\sum_k(1-e_k)}$$

- **适用**：有实际数据、希望权重由数据本身决定。
- **致命陷阱**：
  - **常数列**：某指标所有样本取值相同 → $p_{ij}$ 出现 $0/0$，熵值算不出（NaN）。
    建模前必须检查每列标准差，为 0 的列直接剔除或单独说明。
  - **负值**：熵权法要求 $x_{ij}\ge 0$，负值需先平移或改用其他方法。
  - **零值**：$p_{ij}=0$ 时 $\ln p_{ij}\to-\infty$。需加极小量平滑或改用改进熵权。

### 3.2 CRITIC 法

同时考虑**对比强度**（标准差）与**冲突性**（指标间相关系数）：

$$C_j=\sigma_j\sum_{k=1}^{n}(1-|r_{jk}|),\qquad w_j=\frac{C_j}{\sum_k C_k}$$

比熵权法更稳健：它惩罚了与其他指标高度相关的冗余指标。适合指标间存在相关性的情形。

### 3.3 主成分分析 PCA / 因子分析

用方差贡献率确定权重，本质是降维。适合指标多且相关，**但主成分含义往往难以解释**，在需要"每个指标都有明确权重"的场合不适用。

### 3.4 标准差法与变异系数法

最简单的客观赋权：变异系数 $CV_j=\sigma_j/\bar{x}_j$ 归一化后作权重。
适合作为快速基线，但单独使用显得单薄，通常与其他方法组合。

## 四、组合赋权（推荐）

主观与客观各有偏颇，**组合赋权是更稳妥的选择**，也是拉开差距的地方：

| 方法 | 公式 | 特点 |
|---|---|---|
| 线性组合 | $w=\alpha w^{\text{主}}+(1-\alpha)w^{\text{客}}$ | 最常用；$\alpha$ 需说明取值依据 |
| 乘法合成 | $w_j=\dfrac{w_j^{\text{主}}w_j^{\text{客}}}{\sum_k w_k^{\text{主}}w_k^{\text{客}}}$ | 放大两者一致的部分 |
| 博弈论组合 | 极小化组合权重与各单一权重的偏差 | 理论基础更强，推导可写满半页 |

**关键**：无论用哪种，都必须在论文里**说明权重来源与依据**，并给出组合前后权重的对比表。不说明的组合等于拍脑袋。

## 五、综合评价：从权重到排序

### 5.1 TOPSIS（优劣解距离法）

- **步骤**：正向化 → 标准化 → 加权 → 计算到正/负理想解距离 → 相对贴近度排序。

$$D_i^{+}=\sqrt{\sum_j w_j(v_{ij}-v_j^{+})^2},\quad
C_i=\frac{D_i^{-}}{D_i^{+}+D_i^{-}}$$

- **适用**：有明确数据、需要排序的通用场合。
- **陷阱**：
  - **指标未正向化**：成本型指标混入效益型指标，结果完全错误。
  - 标准化方式不统一（有的用极差、有的用 z-score）
  - 欧氏距离假设指标正交，指标高度相关时应改用马氏距离或先降维

### 5.2 模糊综合评价

- **适用**：评价指标本身模糊（"满意度高""风险大"）、难以精确量化。
- **步骤**：确定因素集与评语集 → 构造隶属度矩阵 $R$ → 权重 $A$ 合成 $B=A\circ R$。
- **陷阱**：隶属度函数构造随意；合成算子（取大取小 / 加权平均）选择未说明。
  取大取小会丢失大量信息，**建议用加权平均型算子**。

### 5.3 秩和比法 RSR

- **原理**：把指标值编秩，计算秩和比，再回归分档。
- **适用**：样本量不大、需要**分级**而非排序（如把区域分成高/中/低风险三档）。
- **陷阱**：编秩时未处理相同值（应取平均秩）。

### 5.4 数据包络分析 DEA

- **适用**：**多输入多输出**的效率评价（如学校、医院、银行的投入产出效率）。
- **模型**：CCR（规模报酬不变）、BCC（规模报酬可变）、SBM（考虑松弛变量）。
- **陷阱**：
  - 决策单元数应不少于投入+产出指标数之和的 2–3 倍，否则大量单元效率为 1，区分度为零
  - 输入输出指标选择不当
  - 未说明用的是投入导向还是产出导向

### 5.5 灰色关联分析

按序列曲线几何形状的相似程度排序，适合**小样本、贫信息**。详见 `grey-system.md`。

## 六、选型决策树

```
有明确客观数据？
├─ 否 → AHP / Delphi（主观赋权），必须做一致性检验
└─ 是 → 指标间是否高度相关？
        ├─ 是 → CRITIC 或 PCA 降维后赋权
        └─ 否 → 熵权法（注意常数列与负值）
                 ↓
        需要排序还是分级？
        ├─ 排序 → TOPSIS（数据明确）/ 模糊综合评价（指标模糊）/ 灰色关联（小样本）
        ├─ 分级 → RSR
        └─ 多输入多输出效率 → DEA
```

## 七、结果稳健性（最容易漏的一环）

评价类模型的结论高度依赖权重，**必须做敏感性分析**：

1. **权重扰动**：主客观权重组合系数 $\alpha$ 在 0–1 间扫描，看排序是否翻转
2. **方法交叉验证**：TOPSIS 与灰色关联、RSR 分别算一遍，看结论是否一致
3. **指标增删**：去掉一个权重最大的指标，看结果是否稳健

**三种方法给出同一排序，结论才站得住。** 只用一种方法、只给一组权重，评委一句"换个权重结论会不会变"就能问倒。

## 八、数值要点

- 指标**正向化**在标准化之前完成（极小型、中间型、区间型分别处理）
- 标准化方式：极差法保留原始分布信息，z-score 适合后续需要统计推断的场合
- 熵权法前检查常数列与负值（见 `pitfalls/numeric-edge-cases.md` 第 3 条）
- AHP 判断矩阵必须做一致性检验 $CR<0.1$
- 组合赋权的 $\alpha$ 要么给出依据，要么做 $\alpha$ 敏感性扫描

## 九、常见扣分点

1. AHP 不做一致性检验
2. 熵权法遇常数列直接产出 NaN，未检查
3. 成本型指标未正向化就进 TOPSIS
4. 权重来源不说明，直接给一组数字
5. 只用一种方法、不交叉验证
6. 不做权重敏感性分析
7. DEA 决策单元过少，所有单元效率都是 1
8. 模糊综合评价的合成算子不说明，用取大取小丢失信息
9. 无量纲化前后混用不同标准化方法
10. 结论只给排序，不解释"为什么这个排第一"

## 十、代码骨架

```python
import numpy as np

def entropy_weight(X):
    """熵权法。X: (m 样本, n 指标)，要求 X >= 0 且无常数列。"""
    X = np.asarray(X, dtype=float)
    # 常数列检查（漏了这步会产出 NaN）
    std = X.std(axis=0)
    if np.any(std == 0):
        raise ValueError("存在常数列，熵权法不适用，请先剔除或单独说明")
    P = X / X.sum(axis=0, keepdims=True)
    with np.errstate(divide="ignore", invalid="ignore"):
        logp = np.where(P > 0, np.log(P), 0.0)
    e = -(P * logp).sum(axis=0) / np.log(len(X))
    return (1 - e) / (1 - e).sum()


def topsis(X, w, benefit=None):
    """TOPSIS。benefit: 布尔数组，True 表示效益型（越大越好）。"""
    X = np.asarray(X, dtype=float)
    if benefit is None:
        benefit = np.ones(X.shape[1], dtype=bool)
    # 正向化：成本型取极差反转
    Xn = X.copy()
    for j, b in enumerate(benefit):
        if not b:
            Xn[:, j] = X[:, j].max() - X[:, j]
    # 极差标准化
    rng = Xn.max(axis=0) - Xn.min(axis=0)
    rng[rng == 0] = 1.0
    Z = (Xn - Xn.min(axis=0)) / rng
    V = Z * w
    pos, neg = V.max(axis=0), V.min(axis=0)
    d_pos = np.linalg.norm(V - pos, axis=1)
    d_neg = np.linalg.norm(V - neg, axis=1)
    return d_neg / (d_pos + d_neg)
```
