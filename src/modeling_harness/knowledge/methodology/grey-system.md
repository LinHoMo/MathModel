# 灰色系统理论

> 适用：小样本、贫信息的预测与关联分析问题。
> 国赛高频考点，尤其 C 题（数据少但要做预测/评价时）。

## 一、什么时候用灰色系统

灰色系统处理"部分信息已知、部分信息未知"的问题。典型场景：

| 场景 | 为什么灰色系统合适 |
|---|---|
| 样本量极少（4–15 个） | 统计方法需要大样本，灰色系统 4 个数据点就能建模 |
| 数据不完整、有缺失 | 累加生成能弱化随机性 |
| 规律不明显但整体有趋势 | 一阶累加后近似指数规律 |
| 指标间的关联难以用相关系数刻画 | 灰色关联按曲线几何相似度衡量 |

**反面**：样本充足（>30）且规律复杂时，ARIMA、机器学习通常更好。
**不要为了用灰色系统而放弃更合适的方法**——论文里必须说明为什么选它。

## 二、GM(1,1) 模型

### 2.1 建模步骤

设原始序列 $X^{(0)}=(x^{(0)}(1),\dots,x^{(0)}(n))$。

**第 1 步：级比检验（可行性前提，不能跳过）**

$$\sigma(k)=\frac{x^{(0)}(k-1)}{x^{(0)}(k)},\quad k=2,\dots,n$$

要求 $\sigma(k)\in\left(e^{-\frac{2}{n+1}},\,e^{\frac{2}{n+1}}\right)$。

不满足时应对数据做平移变换 $y^{(0)}(k)=x^{(0)}(k)+c$，再检验。
**若反复平移仍不满足，说明数据不适合 GM(1,1)，应换模型**——硬套出来的结果是发散的，解释了一堆其实全是错的。

**第 2 步：一阶累加生成（1-AGO）**

$$x^{(1)}(k)=\sum_{i=1}^{k}x^{(0)}(i)$$

累加使非负摆动序列转化为单调增序列，弱化随机性。

**第 3 步：构造紧邻均值序列**

$$z^{(1)}(k)=0.5\,x^{(1)}(k)+0.5\,x^{(1)}(k-1),\quad k=2,\dots,n$$

**第 4 步：灰微分方程与参数估计**

$$x^{(0)}(k)+a\,z^{(1)}(k)=b$$

最小二乘估计：

$$\hat{u}=[a,b]^{T}=(B^{T}B)^{-1}B^{T}Y$$

其中

$$B=\begin{bmatrix}-z^{(1)}(2)&1\\ \vdots&\vdots\\ -z^{(1)}(n)&1\end{bmatrix},
\quad Y=\begin{bmatrix}x^{(0)}(2)\\ \vdots\\ x^{(0)}(n)\end{bmatrix}$$

**第 5 步：白化方程与响应时间式**

$$\frac{dx^{(1)}}{dt}+a\,x^{(1)}=b
\;\Longrightarrow\;
\hat{x}^{(1)}(k+1)=\left(x^{(0)}(1)-\frac{b}{a}\right)e^{-ak}+\frac{b}{a}$$

**第 6 步：累减还原**

$$\hat{x}^{(0)}(k+1)=\hat{x}^{(1)}(k+1)-\hat{x}^{(1)}(k)$$

### 2.2 发展系数的适用边界

$-a$ 称为发展系数。**GM(1,1) 只在 $|a|<2$ 时有意义**：

| $|a|$ 范围 | 适用性 |
|---|---|
| $a\le -2$ | 无意义 |
| $-2<a\le 0$ | 不适合（增长过快） |
| $0<a<0.3$ | **适合中长期预测** |
| $0.3\le a<0.5$ | 适合短期预测，中长期慎用 |
| $0.5\le a<1$ | 慎用，建议改用 DGM 或新陈代谢模型 |
| $a\ge 2$ | 无意义 |

**这是最容易被忽略的陷阱**：模型跑出了数，但 $a$ 越界，预测值发散到荒谬量级。
建模后必须检查 $a$ 的取值并在论文中报告。

### 2.3 精度检验

**后验差检验**：

$$C=\frac{S_2}{S_1},\qquad
p=P\left(\left|\varepsilon(k)-\bar{\varepsilon}\right|<0.6745\,S_1\right)$$

| 等级 | $C$ | $p$ |
|---|---|---|
| 一级（好） | $<0.35$ | $>0.95$ |
| 二级（合格） | $<0.50$ | $>0.80$ |
| 三级（勉强） | $<0.65$ | $>0.70$ |
| 四级（不合格） | $\ge0.65$ | $\le0.70$ |

**只报预测值不报精度检验，等于没做模型。** 相对残差、后验差比、小误差概率至少报一项。

## 三、改进模型

| 模型 | 解决什么问题 | 何时用 |
|---|---|---|
| **DGM(1,1)** | 离散形式，避免白化方程的离散化误差 | 对精度要求高时优先 |
| **新陈代谢 GM** | 每预测一步就加入新信息、去掉最老数据 | 中长期预测，跟踪时变规律 |
| **Verhulst** | 处理饱和增长（S 形） | 有增长上限的情形（如人口、渗透率） |
| **GM(1,N)** | 多变量 | 有多个相关因素驱动时 |
| **残差修正 GM** | 用残差序列再建 GM 修正 | 原模型精度不足时 |

## 四、灰色关联分析

### 4.1 邓氏关联度

$$\gamma_i=\frac{1}{n}\sum_{k=1}^{n}
\frac{\min_i\min_k|x_0(k)-x_i(k)|+\rho\max_i\max_k|x_0(k)-x_i(k)|}
{|x_0(k)-x_i(k)|+\rho\max_i\max_k|x_0(k)-x_i(k)|}$$

$\rho\in(0,1)$ 为分辨系数，**通常取 0.5**。$\rho$ 越大，区分度越低。

### 4.2 三种关联度

| 类型 | 衡量对象 | 适用 |
|---|---|---|
| 绝对关联度 | 曲线间的几何相似（与位置无关） | 只看形状 |
| 相对关联度 | 相对于起点的变化速率 | 看增长节奏 |
| 综合关联度 | $\theta\cdot$绝对 $+(1-\theta)\cdot$相对 | 综合判断，$\theta$ 常取 0.5 |

### 4.3 陷阱

- **未做无量纲化**：量纲差异大的序列直接算关联度，结果被量纲主导
- 分辨系数 $\rho$ 取值未说明
- 关联度排序后不解释"为什么这个因素关联最强"
- 用关联度当因果——关联不等于因果，论文表述要谨慎

## 五、灰色预测 vs 其他预测方法

| 方法 | 样本需求 | 适用规律 | 优势 | 劣势 |
|---|---|---|---|---|
| GM(1,1) | 4–15 | 近似指数 | 小样本可用 | 只适合单调趋势 |
| ARIMA | ≥30 | 平稳/可差分平稳 | 理论成熟 | 需大样本、需平稳检验 |
| 指数平滑 | ≥10 | 短期趋势 | 简单快速 | 中长期差 |
| 回归 | ≥20 | 有明确驱动变量 | 可解释 | 需要自变量 |
| LSTM | ≥数百 | 复杂非线性 | 表达力强 | 小样本必过拟合 |

**小样本硬上神经网络是最典型的失分点**（见 `pitfalls/antipatterns.md` 第 1 条）。
样本 <20 时，GM(1,1) 通常比深度学习更合适，也更经得起追问。

## 六、代码骨架

```python
import numpy as np

def gm11(x0, forecast=0):
    """GM(1,1)。返回 (a, b, 拟合序列, 预测序列, 级比检验是否通过)。"""
    x0 = np.asarray(x0, dtype=float)
    n = len(x0)

    # 级比检验——不做这步，模型可能根本不适用
    sigma = x0[:-1] / x0[1:]
    lo, hi = np.exp(-2 / (n + 1)), np.exp(2 / (n + 1))
    feasible = bool(np.all((sigma > lo) & (sigma < hi)))

    x1 = np.cumsum(x0)
    z1 = 0.5 * (x1[1:] + x1[:-1])
    B = np.column_stack([-z1, np.ones(n - 1)])
    Y = x0[1:]
    a, b = np.linalg.lstsq(B, Y, rcond=None)[0]

    # 发展系数越界检查（漏掉会产出荒谬的发散预测）
    if abs(a) >= 2:
        raise ValueError(f"发展系数 a={a:.4f} 越界(|a|>=2)，GM(1,1) 不适用")

    def x1_hat(k):
        return (x0[0] - b / a) * np.exp(-a * k) + b / a

    fitted = np.array([x1_hat(k) - x1_hat(k - 1) for k in range(1, n)])
    fitted = np.r_[x0[0], fitted]

    pred = np.array([x1_hat(k) - x1_hat(k - 1)
                     for k in range(n, n + forecast)]) if forecast else np.array([])
    return a, b, fitted, pred, feasible


def accuracy_check(x0, fitted):
    """后验差检验：返回 (C, p, 等级)。"""
    resid = x0 - fitted
    S1, S2 = x0.std(ddof=1), resid.std(ddof=1)
    C = S2 / S1
    p = np.mean(np.abs(resid - resid.mean()) < 0.6745 * S1)
    if C < 0.35 and p > 0.95:
        grade = "一级(好)"
    elif C < 0.50 and p > 0.80:
        grade = "二级(合格)"
    elif C < 0.65 and p > 0.70:
        grade = "三级(勉强)"
    else:
        grade = "四级(不合格)"
    return C, p, grade
```

## 七、常见扣分点

1. **不做级比检验**直接建模
2. **不检查发展系数** $a$，预测值发散还照常报告
3. **不报精度检验**（后验差比 $C$、小误差概率 $p$）
4. 样本充足却硬用 GM(1,1)，不说明理由
5. 中长期预测不做新陈代谢改进，误差累积严重
6. 灰色关联前未做无量纲化
7. 分辨系数 $\rho$ 取值未说明
8. 把关联度当成因果关系表述
9. 预测步数超过建模样本数的一半（外推过远）
10. 数据有明显的周期或季节成分，却用单调趋势模型硬套
