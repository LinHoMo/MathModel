# 差分方程与元胞自动机

> 适用：离散时间演化、种群动态、交通流、传播扩散、自组织现象、微观仿真。
> 与 `ode-pde.md`（连续）、`simulation.md`（蒙特卡洛）互补。

## 一、什么时候用离散模型

| 情形 | 该用 |
|---|---|
| 系统本质上按代/步演化（种群、库存、迭代算法） | **差分方程** |
| 个体行为简单、局部相互作用产生宏观模式 | **元胞自动机** |
| 状态连续、变化平滑 | 微分方程（见 `ode-pde.md`） |
| 随机性强、需统计平均 | 蒙特卡洛（见 `simulation.md` / `monte-carlo.md`） |

**别把连续系统硬离散化**，也别把离散代际过程硬写成微分方程。选择依据是研究对象本身的时间结构。

## 二、差分方程

### 2.1 一阶线性

$$x_{t+1}=a x_t+b$$

通解：$x_t=a^t x_0+b\dfrac{1-a^t}{1-a}$（$a\neq1$）。

不动点 $x^*=\dfrac{b}{1-a}$。**稳定性判据：$|a|<1$ 收敛，$|a|>1$ 发散。**

$a<-1$ 时振荡发散，$a=-1$ 时周期为 2 的振荡——这类"看起来还在算、实际已经失去意义"的结果必须识别出来。

### 2.2 二阶线性与特征根

$$x_{t+2}+p\,x_{t+1}+q\,x_t=0$$

特征方程 $\lambda^2+p\lambda+q=0$。

- 两根实根：$x_t=C_1\lambda_1^t+C_2\lambda_2^t$
- 复根 $\lambda=re^{\pm i\theta}$：振荡，$r=\sqrt{q}$
- **稳定性**：$|\lambda_{1,2}|<1$，等价于 $1+p+q>0,\ 1-p+q>0,\ 1-q>0$

**建模后必须报告特征根**——这是判断长期行为（收敛/振荡/发散）的依据，不报就等于没分析。

### 2.3 非线性与混沌

Logistic 映射：

$$x_{t+1}=r\,x_t(1-x_t)$$

| $r$ | 行为 |
|---|---|
| $0<r<1$ | 趋于 0 |
| $1<r<3$ | 收敛到不动点 |
| $3<r<3.449$ | 周期 2 |
| $3.449<r<3.544$ | 周期 4 |
| $r>3.5699$ | **混沌** |

**启示**：即使完全确定性的简单模型，也可能产生不可长期预测的行为。
做长期预测前必须检查参数是否落在混沌区——否则预测毫无意义，论文里的"2050 年预测值"是自欺欺人。

### 2.4 Leslie 矩阵（年龄结构种群）

$$\mathbf{n}_{t+1}=L\,\mathbf{n}_t,\quad
L=\begin{bmatrix}
f_1&f_2&\cdots&f_m\\
s_1&0&\cdots&0\\
0&s_2&\cdots&0\\
\vdots&&\ddots&\vdots
\end{bmatrix}$$

$f_i$ 为繁殖率，$s_i$ 为存活率。

- 长期增长率 = 主特征值 $\lambda_1$
- 稳定年龄结构 = 对应特征向量
- **报告 $\lambda_1$ 与稳定年龄分布**，这是 Leslie 模型的结论核心

## 三、元胞自动机 CA

### 3.1 定义

四要素：**元胞空间**（网格）+ **状态集**（有限）+ **邻域**（von Neumann / Moore）+ **演化规则**（局部、同步更新）。

核心特征：**时间、空间、状态都离散**；下一时刻状态只由自身与邻域决定。

### 3.2 Wolfram 分类（一维）

| 类别 | 行为 | 例子 |
|---|---|---|
| I | 趋于均匀稳定态 | 规则 0、32 |
| II | 趋于周期结构 | 规则 4、108 |
| III | 混沌随机 | 规则 30、90 |
| IV | **复杂局域结构，边缘混沌** | 规则 110（通用计算） |

**第四类最有建模价值**——能产生持续、非周期的复杂结构，适合模拟真实系统的自组织。

### 3.3 经典模型

| 模型 | 规则 | 应用 |
|---|---|---|
| 生命游戏 | 存活：邻居 2–3；诞生：邻居 3 | 自组织、复杂性 |
| 森林火灾 | 树→燃烧（邻居有火）→空地→以概率 p 长树 | 临界现象、灾害传播 |
| 交通流 NS 模型 | 加速 / 减速 / 随机慢化 / 位置更新 | 拥堵形成、幽灵堵塞 |
| 传染病 CA | 易感 / 感染 / 康复 + 邻域传染概率 | 空间传播 |
| 沙堆模型 | 高度差超阈值则倒塌 | 自组织临界 |
| 舆论传播 | 邻居多数决定 / Sznajd 模型 | 观点动力学 |

### 3.4 建模步骤（论文里要写清）

1. 网格与边界条件（周期 / 反射 / 固定）——**边界条件必须写明**
2. 状态集定义与初始分布
3. 邻域类型
4. 更新规则（同步 or 异步；异步需说明更新顺序）
5. 演化步数与终止条件
6. **多次独立运行的统计**（初始分布随机时必须做）

## 四、结果分析（CA 最容易缺的部分）

跑出漂亮的图只是开始，必须有量化分析：

| 分析 | 做法 |
|---|---|
| 宏观量时间序列 | 感染密度、车辆平均速度、森林覆盖率随时间变化 |
| 参数敏感性 | 关键概率（传染率 p、慢化概率、生长率）扫描 |
| 临界现象 | 找相变点（如森林火灾的树木密度阈值） |
| 多次运行统计 | 不同随机初始下的均值 ± 标准差 |
| 与解析/平均场对比 | 若有 ODE 近似，比较两者差异并解释 |

**只有一张演化图、没有量化分析，是 CA 建模最常见的失分点。**

## 五、数值陷阱

- **边界条件未写明**：周期边界与固定边界结果差异巨大
- **同步 vs 异步更新**：混淆会导致完全不同的动力学
- **网格效应**：结果依赖网格分辨率，应做分辨率敏感性检查
- **只跑一次**：随机初始分布下必须多次运行取统计
- **长期预测落在混沌区**：不检查参数就直接外推
- **初始分布未说明**：随机均匀分布还是特定结构，直接影响结论
- **伪随机数**：必须固定种子

## 六、代码骨架

```python
import numpy as np

def logistic_map(r, x0, n, seed=None):
    """Logistic 映射。返回序列与最后是否处于混沌区的提示。"""
    x = np.empty(n)
    x[0] = x0
    for t in range(1, n):
        x[t] = r * x[t - 1] * (1 - x[t - 1])
    chaotic = r > 3.5699
    return x, chaotic


def leslie_growth(L, n0, steps):
    """Leslie 矩阵种群演化。返回 (各步向量, 主特征值, 稳定年龄结构)。"""
    eigvals, eigvecs = np.linalg.eig(L)
    k = int(np.argmax(eigvals.real))
    lam = eigvals[k].real
    stable = np.abs(eigvecs[:, k].real)
    stable = stable / stable.sum()
    traj = [n0]
    for _ in range(steps):
        traj.append(L @ traj[-1])
    return np.array(traj), lam, stable


def forest_fire(size=100, p_grow=0.01, p_lightning=0.001, steps=300, seed=42):
    """森林火灾元胞自动机。状态：0 空地 / 1 有树 / 2 燃烧。
    采用周期边界；返回每步的树木密度与燃烧密度序列。"""
    rng = np.random.default_rng(seed)
    grid = rng.choice([0, 1], size=(size, size), p=[0.4, 0.6])
    tree_hist, fire_hist = [], []

    for _ in range(steps):
        new = grid.copy()
        # Moore 邻域中是否有火（周期边界）
        burning = (grid == 2)
        neighbor_fire = np.zeros_like(burning)
        for di in (-1, 0, 1):
            for dj in (-1, 0, 1):
                if di == 0 and dj == 0:
                    continue
                neighbor_fire |= np.roll(np.roll(burning, di, 0), dj, 1)

        new[(grid == 1) & neighbor_fire] = 2          # 引燃
        new[grid == 2] = 0                            # 烧毁
        empty = (grid == 0)
        new[empty & (rng.random((size, size)) < p_grow)] = 1   # 生长
        strike = (grid == 1) & (rng.random((size, size)) < p_lightning)
        new[strike] = 2                               # 雷击

        grid = new
        tree_hist.append((grid == 1).mean())
        fire_hist.append((grid == 2).mean())

    return np.array(tree_hist), np.array(fire_hist)
```

## 七、常见扣分点

1. 边界条件不写
2. 同步 / 异步更新不说明
3. 只有演化图，没有宏观量的量化分析
4. 随机初始下只跑一次
5. 差分方程不报告特征根或稳定性
6. 长期外推却不检查是否处于混沌区
7. 网格分辨率只取一种，不做敏感性检查
8. 元胞规则描述含糊，无法复现
9. 随机种子未固定
10. 离散模型与连续模型的选型理由不说明
