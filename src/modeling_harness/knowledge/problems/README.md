# 赛题库（problems）

> 历史赛题索引骨架。本目录是 `type-classifier`（题型识别）与 `method-matcher`（方法匹配）两个 agent 的**检索参照**，用于「赛题 → 题型 → 方法方向」的快速匹配。

---

## 一、目录用途

本目录收录历年 CUMCM（高教社杯 / 全国大学生数学建模竞赛）真题的**结构化索引**，为以下两类 agent 提供检索依据：

- **type-classifier（题型识别）**：当拿到一道新赛题时，先按（a）赛题背景、（b）变量性质、（c）目标数量四个维度判断其题型（A/B/C/D/E），再从本目录检索**近似的历史赛题**，用「历史题型 + 方法方向」交叉印证分类结果，避免误判。
- **method-matcher（方法匹配）**：分类确定后，从近似历史赛题的方法方向出发，到 `core/knowledge/methodology/` 挑选候选模型，形成 ≥2 个候选模型以供对比。

---

## 二、索引维度

每条赛题记录包含以下维度：

| 维度 | 取值 / 说明 |
|---|---|
| 题型 | A 物理/连续优化；B 离散/组合优化；C 数据驱动/统计；D 多目标优化/工程；E 交叉学科/开放 |
| 年份 | 赛题年份（本目录当前覆盖 2015–2025） |
| 难度 | 易 / 中 / 难（主观标注，仅供参考） |
| 核心关键词 / 方法方向 | 供 type-classifier 做语义近似匹配、method-matcher 做模型候选 |

> **注意**：CUMCM 官方「题号」（A/B/C 本科组，D/E 专科组）与本库「题型分类」的字母基本对齐，但**不完全等同**——例如官方 B 题可能是数据统计类（库内归 C）。匹配时以 **库内题型归类** 为准（见 `INDEX.md` 备注列），官方题号仅作定位用。

---

## 三、使用方式

1. **按题型检出**：`INDEX.md` 按年份分节、每题标注「题型」列，按 A/B/C/D/E 过滤即可得到该类历史赛题集合。
2. **按关键词检出**：将新赛题的核心名词（如「定日镜」「热传导」「无人机编队」「信贷」）与「核心关键词」列做语义/字面匹配，取出相近题目。
3. **按难度参考**：「难度」列辅助判断选题工作量，不作为分类依据。
4. **辅助选型**：命中近似题后，读取该题的「方法方向」，再到 `core/knowledge/methodology/` 中定位对应方法文档（如 `ode-pde`、`dynamic-programming`、`machine-learning`、`multi-objective` 等），据此构建候选模型列表供 method-matcher 对比。

**检出示例**：新赛题「镜场聚光效率优化」→ 关键词「定日镜」→ 命中 2023 A 定日镜场 → 方法方向「几何建模 + 数值优化 + 仿真」→ 候选：几何分析、数值优化、monte-carlo。

## 四、与 paper-cases 的关系

| | `problems/` | `paper-cases/` |
|---|---|---|
| 定位 | **赛题索引** | **获奖论文拆解** |
| 粒度 | 一条赛题 = 一行记录（年/题型/名称/方法方向/难度） | 一篇论文 = 一个完整拆解文档（8 段式） |
| 用途 | 题型识别 + 方法选型的**前置检索** | 学习建模思路、创新点与写作的**深度参考** |
| 关联 | `INDEX.md` 的「年份 + 题型」可定位到同题对应的获奖论文 | `paper-cases/` 的 A-topic / B-topic / C-topic 即按题号归档 |

即：**先查 problems 定题型、选方向，再翻 paper-cases 看同类题怎么写、学创新点。**

## 五、题型分类口径（A/B/C/D/E）

与本库 `core/knowledge/methodology/method-trends-2010-2025.md` 一致：

| 题型 | 特征 | 首选方法组合 |
|---|---|---|
| A | 物理/工程背景、连续变量、需数学推导 | ODE/PDE 建模 + 数值求解 + 参数优化；几何分析 + 数值搜索 |
| B | 离散变量、NP-hard、约束复杂 | 整数规划 + 分支定界；GA/PSO/SA + 局部搜索 |
| C | 数据量大、预测/分类/评价 | XGBoost/RF + SHAP + 交叉验证；聚类 + 综合评价 |
| D | 多目标冲突、需权衡 | NSGA-II + TOPSIS + 仿真；双层/鲁棒优化 |
| E | 跨学科、开放性 | 问题分解 + 多方法融合 + 交叉验证 |

## 六、收录范围与维护

- **当前覆盖 2015–2025 年 CUMCM 真题**，每年 A/B/C 为主，D/E（专科组）仅收录已核实年份；2018/2019 年题名与库内案例卡交叉印证，2015–2017 年题名据公开汇总资料整理（与 2018/2019 库内口径互洽）。
- **真实性约束**（铁律）：题目名称必须基于真实真题，不确定者以「（待补）」标注，宁可少写不造假。新录入时沿用相同口径。
