## 六、标签使用指南

### 6.1 如何选择创新点

1. **分析问题特点**
   - 物理建模类（A题）：优先考虑"物理+优化"、"解析+数值"组合
   - 实验优化类（B题）：优先考虑"统计+机器学习"、"仿真+优化"组合
   - 数据分析类（C题）：优先考虑"预测+优化"、"运筹+AI"组合

2. **匹配已有标签**
   - 查看同类论文的创新点标签
   - 找出高频使用的标签组合
   - 识别尚未被充分覆盖的标签

3. **选择适合的创新方向**
   - 方法创新：改进现有算法或引入新方法
   - 应用创新：将方法应用到新场景或考虑新约束
   - 组合创新：融合多种方法或跨领域融合

### 6.2 如何创造新标签

1. **识别未覆盖的创新类型**
   - 分析117篇论文中未出现的创新模式
   - 关注跨学科交叉领域的空白
   - 考虑新兴技术（如大模型、强化学习）的应用

2. **定义新标签**
   - 标签名称：简洁明确，4-8字
   - 标签定义：清晰描述创新内涵
   - 代表论文：选择典型论文作为示例

3. **更新索引表**
   - 在对应类别下添加新标签
   - 更新论文-标签映射表
   - 重新计算标签统计

### 6.3 创新点提炼公式

```
创新点 = 方法改进/组合 + 应用场景 + 效果验证
```

**示例**：
- A092：GA-SA混合算法（方法改进）+ 定日镜场布局（应用场景）+ 避免早熟收敛（效果验证）
- C050：动态定价+库存联合优化（方法组合）+ 蔬菜易腐品（应用场景）+ 利润提升（效果验证）
- B159：动态规划+贝叶斯估计（方法组合）+ 生产决策（应用场景）+ 不确定性处理（效果验证）
