# C4烯烃制备分析与试验设计

## 基本信息
- 论文编号: B007
- 题型: B题
- 主题: 乙醇催化偶合制备C4烯烃的实验数据分析与优化
- 获奖等级: 一等奖

## 一、问题理解
### 1.1 核心问题
基于乙醇催化偶合制备C4烯烃的实验数据，分析催化剂组合和温度对乙醇转化率、C4烯烃选择性的影响，建立优化模型求解最大收率条件，并设计补充实验方案。

### 1.2 子问题分解
- 子问题1: 分析不同催化剂组合下乙醇转化率、C4烯烃选择性与温度的关系；分析给定条件下随时间变化的趋势
- 子问题2: 研究不同催化剂组合和温度对乙醇转化率和C4烯烃选择性的影响程度
- 子问题3: 求解使得C4烯烃收率最高的催化剂组合与温度，以及温度低于350℃时的最优解
- 子问题4: 设计5次补充实验以更充分地探索变量关系

### 1.3 输入输出
- 输入: 附件1（不同催化剂组合在不同温度下的实验数据）、附件2（350℃下不同时间的实验数据）
- 输出: 变量关系分析、影响因素量化、最大收率条件、实验设计方案

## 二、建模假设
### 2.1 假设列表
| 假设编号 | 假设内容 | 理由 | 影响 |
|---------|---------|------|------|
| H1 | 乙醇催化偶合制备C4烯烃的过程中，除给定催化剂组合以及温度和反应时间外，其它条件对实验结果的影响可忽略不计 | 控制变量法的基本假设，简化问题复杂度 | 使模型聚焦于核心变量 |
| H2 | 在反应进行时，实验室内环境温度和气压不会对反应造成影响 | 实验在标准实验室条件下进行 | 排除环境干扰因素 |
| H3 | 实验设备完好且在实验过程中不会出现漏气、破损等情况导致实验失败或数据出现差错 | 保证数据的可靠性 | 确保数据质量 |

### 2.2 关键假设
假设H1是核心假设，它将问题简化为研究催化剂组合、温度和时间三个主要变量对实验结果的影响，为后续建模奠定了基础。

## 三、模型构建
### 3.1 影响因素
- 催化剂组合因素：Co/SiO₂质量、Co负载量、HAP质量、乙醇浓度
- 温度因素：反应温度（250℃-450℃）
- 时间因素：反应时间（附件2数据）
- 副产物因素：乙烯、乙醛、脂肪醇等副产物选择性

### 3.2 数学模型
1. **皮尔逊相关系数分析**：计算温度与乙醇转化率、C4烯烃选择性的相关性
   $$P_{x,y} = \frac{cov(x,y)}{\sigma_x\sigma_y} = \frac{E[(x-x_i)(y-y_i)]}{\sigma_x\sigma_y}$$

2. **非线性回归拟合**：建立二次函数关系
   $$U_1 = \alpha_{11}t^2 + \alpha_{12}t + \alpha_{13}$$
   $$U_2 = \alpha_{21}t^2 + \alpha_{22}t + \alpha_{23}$$

3. **多元线性回归模型**：
   $$y_1 = -80.509 - 0.034x_1 + 0.134x_2 + 0.141x_3 - 8.765x_4 + 0.333x_5$$
   $$y_2 = -48.732 + 0.003x_1 - 3.164x_2 + 0.086x_3 + 2.673x_4 + 0.181x_5$$

4. **偏最小二乘回归模型**：改进多元线性回归，分析多因变量间的相互影响

5. **C4烯烃收率优化模型**：
   $$\max \rho = y_1 \times y_2$$
   $$s.t. \begin{cases} \sum_{i=1}^{5} y_i = 100 \\ Xl_i \leq x_i \leq Xl_r \end{cases}$$

### 3.3 约束条件
- 所有生成物选择性之和等于100%
- 各自变量取值范围在实验设计的最小值和最大值之间
- 温度约束：正常实验条件250℃-450℃，特殊情况≤350℃

## 四、求解方法
### 4.1 算法选择
1. **皮尔逊相关系数**：用于判断变量间的相关性强弱
2. **非线性回归**：用于拟合温度与指标的二次函数关系
3. **聚类分析**：用于对副产物进行降维处理
4. **多元线性回归**：用于分析多个自变量对因变量的影响
5. **偏最小二乘回归**：用于改进多元线性回归，处理多因变量问题
6. **方差分析**：用于分析变量间的交互作用
7. **均匀设计实验法**：用于设计5次补充实验

### 4.2 算法流程
1. 数据预处理：聚类分析降维，剔除无关变量（石英砂）
2. 相关性分析：计算皮尔逊相关系数
3. 曲线拟合：非线性回归建立温度与指标的关系
4. 回归建模：多元线性回归和偏最小二乘回归
5. 优化求解：建立单目标优化模型，加入方差分析改进
6. 实验设计：均匀设计法安排5次补充实验

### 4.3 参数设置
- 皮尔逊相关系数阈值：0.9（判断强相关）
- 非线性回归类型：二次曲线（R²均值>95%）
- 回归模型显著性水平：α=0.05
- 均匀设计实验次数：5次

## 五、结果验证
### 5.1 验证方法
1. **拟合优度检验**：R²值均在0.7以上，部分达到0.98以上
2. **残差分析**：标准化残差满足正态分布，误差较小
3. **方差齐次检验**：显著性大于0.05，方差齐性
4. **模型对比**：多元线性回归与偏最小二乘回归结果相近

### 5.2 灵敏度分析
- 温度对乙醇转化率和C4烯烃选择性影响最大
- Co负载量对C4烯烃选择性有较强负相关影响
- 乙醇浓度对乙醇转化率有负相关影响
- 装料比的影响相对较小

### 5.3 对比实验
- 多元线性回归与偏最小二乘回归对比：残差平方和相差很小，R²差值也很小
- 不同拟合方式对比：二次曲线拟合优于线性和S型曲线
- 装料方式对比：方式Ⅱ总体优于方式Ⅰ
