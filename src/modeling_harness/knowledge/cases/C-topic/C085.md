# 基于双层和随机规划的原材料订购与运输问题

## 基本信息
- 论文编号: C085
- 题型: C题
- 主题: 原材料订购与运输优化
- 获奖等级: 推测为一等奖或以上

## 一、问题理解
### 1.1 核心问题
在不确定环境下，如何建立双层规划模型优化原材料订购和运输决策，实现供应链整体最优。

### 1.2 子问题分解
- 子问题1: 建立双层规划模型（上层-企业决策，下层-供应商响应）
- 子问题2: 引入随机规划处理需求/价格不确定性
- 子问题3: 设计高效算法求解双层随机规划问题

### 1.3 输入输出
- 输入: 供应商网络、需求分布、成本参数、不确定性参数
- 输出: 最优订购策略、运输方案、风险评估

## 二、建模假设
### 2.1 假设列表
| 假设编号 | 假设内容 | 理由 | 影响 |
|---------|---------|------|------|
| H1 | 供应链存在层级结构 | 实际供应链特点 | 双层规划基础 |
| H2 | 需求服从已知概率分布 | 历史数据拟合 | 随机规划基础 |
| H3 | 供应商理性决策 | 博弈论假设 | 下层问题可解 |
| H4 | 信息部分不对称 | 实际情况 | 增加模型复杂度 |

### 2.2 关键假设
H1和H2是核心假设，决定了双层随机规划的模型框架。

## 三、模型构建
### 3.1 影响因素
- 结构因素：供应链层级、供应商数量、运输网络
- 决策因素：订购量、运输量、库存水平
- 不确定因素：需求波动、价格变化、运输时间
- 博弈因素：企业与供应商的决策交互

### 3.2 数学模型
上层问题（企业决策）：
$$\min_{x} C_1(x, y^*(x)) = \sum_{i,j} c_{ij} x_{ij} + E_{\xi}[h(y^*(x), \xi)]$$

下层问题（供应商响应）：
$$\max_{y} C_2(x, y) = \sum_{i} p_i y_i - \sum_{i} s_i y_i^2$$

随机规划形式：
$$\min_{x} E_{\xi}[f(x, \xi)] = \sum_{k=1}^{K} p_k f(x, \xi_k)$$

### 3.3 约束条件
- 上层约束：供应能力、资金、运输容量
- 下层约束：生产能力、库存限制、需求满足
- 耦合约束：上下层变量的关联关系
- 非负约束：所有决策变量非负

## 四、求解方法
### 4.1 算法选择
- 双层规划：KKT条件转化、遗传算法
- 随机规划：场景分析、样本平均近似
- 组合算法：双层+随机的联合求解

### 4.2 算法流程
1. 场景生成：基于概率分布生成需求场景
2. 问题转化：将双层问题转化为单层问题
3. 求解算法：设计合适的求解器
4. 策略生成：得到各场景下的策略
5. 策略选择：确定鲁棒性策略

### 4.3 参数设置
- 场景数量：100-1000
- 收敛精度：$10^{-4}$
- 最大迭代次数：500
- 鲁棒性参数：根据风险偏好设置
