## 一、方法-题型匹配矩阵

### 1.1 优化方法

| 方法 | A题适用 | B题适用 | C题适用 | 最佳场景 | 论文案例 |
|------|---------|---------|---------|---------|----------|
| 遗传算法(GA) | ✅ | ✅ | ✅ | 组合优化、多约束问题 | C038(种植策略)、B159(生产决策) |
| 粒子群(PSO) | ✅ | ✅ | ✅ | 连续参数优化 | B226(测线布设)、A092(定日镜) |
| 模拟退火(SA) | ✅ | ✅ | ✅ | 大规模组合优化 | B203(RGV调度)、B078(穿越沙漠) |
| 差分进化(DE) | ✅ | ✅ | ✅ | 多目标优化、非线性 | C038(差分遗传)、C063(种植优化) |
| 蚁群算法(ACO) | ⚠️ | ✅ | ✅ | 路径规划、调度问题 | B159(生产决策)、B217(调度优化) |
| 序列二次规划(SQP) | ✅ | ⚠️ | ⚠️ | 连续光滑优化 | A001(波浪能)、A092(定日镜) |
| 网格粗扫+单纯形精化 | ✅ | ✅ | ✅ | 低维非光滑参数优化 | A244(高压油管)、B479(同心鼓) |

**选择规律**：
- A题：物理系统优化优先SQP，组合优化用GA/DE，低维机构参数用两级粗扫+精化
- B题：实验优化用GA+方差分析，调度问题用ACO/SA
- C题：资源分配用DE/GA，多目标用NSGA-II

**历年经典线补充（近年扩充卡）**：
- 事件驱动仿真 + 两级优化：A244(高压油管)、B480(RGV调度)、C285(机场出租车)
- 0-1/整数规划求精确上界 + 启发式求可行解：B480(RGV调度)、B478(AGV调度)
- 不动点迭代逆推阈值：C285(机场出租车)、C286(城市出租车)

## 二、题型-方法推荐流程

### 2.1 A题方法选择流程

```
物理机理明确？
├── 是 → 机理建模
│   ├── 流体问题 → 流体力学方程 + 数值模拟(FDM/FVM)
│   │   └── 案例：A001(波浪能)、A023(高压油管)
│   ├── 光学问题 → 几何光学 + 聚光效率计算
│   │   └── 案例：A092(定日镜)、A127(场优化)
│   ├── 运动问题 → 运动学方程 + 路径规划
│   │   └── 案例：A053(板凳龙)、A163(轨迹优化)
│   ├── 力学平衡问题 → 多体静力学 + 悬链线模型
│   │   └── 案例：A247(系泊系统)
│   └── 热传导问题 → 传热方程 + 有限元
│       └── 案例：A070(炉温曲线)、A229(高温防护服)
└── 否 → 数据驱动？
    ├── 是 → 参数反演 + 灵敏度分析
    │   └── 案例：A115(FAST反射面)、A246(CT几何标定)
    └── 否 → 启发式算法 + 蒙特卡洛
        └── 案例：A242(复杂系统优化)
```

**A题方法优先级**：
1. 机理建模（必须）
2. 数值模拟（核心）
3. 多目标优化（NSGA-II/加权法）
4. 灵敏度分析（验证）
5. 蒙特卡洛（鲁棒性）

### 2.2 B题方法选择流程

```
实验数据？
├── 是 → 数据分析
│   ├── 单因素实验 → 方差分析 + 回归分析
│   │   └── 案例：B007(C4烯烃)
│   ├── 多因素实验 → 正交设计 + 响应面法
│   │   └── 案例：B050(工艺优化)
│   └── 时序实验 → 趋势分析 + 神经网络
│       └── 案例：B026(催化实验)
└── 否 → 优化问题？
    ├── 是 → 启发式算法
    │   ├── 组合优化 → GA/ACO
    │   │   └── 案例：B159(生产决策)
    │   └── 调度问题 → 动态规划 + SA
    │       └── 案例：B203(RGV调度)
    └── 否 → 几何/定位问题？
        ├── 是 → 计算几何 + 启发式搜索
        │   └── 案例：B030(无人机定位)
        └── 否 → 统计分析 + 机器学习
            └── 案例：B226(测线布设)
```

**B题方法优先级**：
1. 统计分析（基础）
2. 回归建模（核心）
3. 方差分析（因素筛选）
4. 启发式算法（优化）
5. 蒙特卡洛（不确定性）

### 2.3 C题方法选择流程

```
数据类型？
├── 结构化数据 → 传统机器学习
│   ├── 分类问题 → 随机森林/XGBoost/SVM
│   │   └── 案例：C166(分类模型)
│   ├── 回归问题 → XGBoost/神经网络
│   │   └── 案例：C201(预测模型)
│   └── 聚类问题 → K-means/层次聚类
│       └── 案例：C051(环境监测)
├── 时序数据 → 时间序列分析
│   ├── 短期预测 → ARIMA/指数平滑
│   │   └── 案例：C138(交通预测)
│   ├── 长期预测 → LSTM/Transformer
│       └── 案例：C143(需求预测)
│   └── 剩余时间预测 → 经验规律回归+在线滚动修正
│       └── 案例：C289(电池放电预测)
└── 优化问题 → 优化算法
    ├── 资源分配 → 差分遗传/随机规划
    │   └── 案例：C038(种植策略)
    ├── 定价问题 → 动态规划/博弈论
    │   └── 案例：C050(蔬菜定价)
    └── 订购问题 → 双层规划/贪心算法
        └── 案例：C066(原料订购)
```

**C题方法优先级**：
1. 数据预处理（必须）
2. 统计分析（探索）
3. 机器学习（建模）
4. 优化算法（决策）
5. 多目标优化（权衡）

## 四、方法选择检查清单

### 4.1 选择前检查

- [ ] **问题类型明确**
  - A题：物理建模问题？机理是否清楚？
  - B题：实验/优化问题？数据是否充足？
  - C题：数据分析问题？预测还是决策？

- [ ] **数据条件评估**
  - 数据量：小样本(<100)还是大样本(>1000)？
  - 数据类型：结构化、时序、图像？
  - 数据质量：缺失值、异常值情况？

- [ ] **约束条件梳理**
  - 物理约束：A题必须考虑
  - 资源约束：B/C题常见
  - 时间约束：所有题型

- [ ] **目标函数确定**
  - 单目标 vs 多目标？
  - 最大化 vs 最小化？
  - 可微 vs 不可微？

### 4.2 选择中检查

- [ ] **方法适用性**
  - A题：机理建模优先，避免纯数据驱动
  - B题：统计方法优先，机器学习辅助
  - C题：机器学习优先，优化算法决策

- [ ] **论文支持性**
  - 该方法是否有成功案例？
  - 是否有改进空间？
  - 是否有理论支撑？

- [ ] **代码可行性**
  - MATLAB/Python实现？
  - 是否有现成工具箱？
  - 计算复杂度是否可接受？

- [ ] **创新性评估**
  - 方法组合是否有新意？

## 六、常见错误与避坑指南

### 6.1 A题常见错误

1. **跳过机理建模**：直接用优化算法，缺乏理论基础
2. **忽略物理约束**：结果不符合物理规律
3. **过度简化假设**：丢失关键物理过程
4. **数值模拟不稳定**：网格/步长选择不当

### 6.2 B题常见错误

1. **统计方法缺失**：直接建模，缺乏探索性分析
2. **实验设计不合理**：样本量不足或代表性差
3. **模型过拟合**：训练集表现好，测试集差
4. **因素交互忽略**：只考虑主效应，忽略交互作用

### 6.3 C题常见错误

1. **数据预处理不足**：缺失值、异常值未处理
2. **特征工程薄弱**：直接用原始数据建模
3. **模型选择盲目**：不考虑数据特点
4. **结果解释牵强**：缺乏经济/业务意义
