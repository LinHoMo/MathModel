# 性能优化结果报告模板

本模板用于阶段 4 的正式结案报告。
报告不是过程流水账，而是对 `performance-plan.md` 的结案摘要。

```text

## 1. 任务摘要
- 项目/模块：
- 报告日期：
- 编写人：
- 文档路径：
- 对应计划文档：
- 优化对象（入口函数/脚本）：
- 工作负载与验收口径：
- 最终结论（达成 / 未达成 / 临时验收）：

## 2. 建立计划摘要
- 目标定义结论：
- 脚本依赖分析结论：
- 关键优化项防漏初检结论：
- 初始基线数据（耗时 / 分配 / 基准层级）：
- 初始主导瓶颈证据：
- 计划中的关键逐脚本函数化条目：

## 3. 逐脚本性能优化结果
- 每个本地脚本（包括入口脚本）的最终状态（`✅ done` / `⛔ blocked` / `N/A` / `✖ dropped`）：
- 关键脚本的前后对比（耗时 / 分配 / 证据）：
- 逐脚本辅助脚本函数化结果摘要：
- 若某些脚本为 `N/A`，原因是什么：
- 若某些脚本为 `⛔ blocked`，阻塞点是什么：

## 4. 整体性能优化结论
- 整体复测数据（耗时 / 分配 / 基准层级）：
- 共享缓存、重复初始化、重复 I/O、重复 plan 创建、公共缓冲区复用的整体结论：
- 是否确认局部优化未把瓶颈转移到别处：
- 外部调用方式、输入输出路径和关键副作用顺序是否保持不变：
- 多线程评估 / 实施结果（线程配置、单线程/多线程对比、是否获得扩展收益）：
- 是否仍有待补的 `full` 验证：

## 5. 结论与后续
- 收益主要来源：
- 当前剩余瓶颈：
- 已知风险或行为变化：
- 尚未处理或明确后置的事项：
- 是否建议结案或继续后续独立优化任务：
```
