# MODEL_SPEC — MCM/ICM 2000 C 大象避孕飞镖种群控制

> 基线校准跑（P13.0）真实求解产物。代码 `code/main.py`（seed=42）；
> 全部数值结果 `figures/all_results.json`。本文件自洽可读，不依赖对话上下文。

## 1. 问题

公园维持约 11,000 头大象，过去 20 年靠每年捕杀/搬迁 600–800 头控制数量；
现评估改用避孕飞镖（darting，永久绝育母象）的可行性。数据为近两年被迁出
大象的年龄–性别分布（data1/data2，合并 2,664 头，雌性占比 46.4%）。

## 2. 符号

| 符号 | 含义 | 取值/来源 |
|---|---|---|
| $S_a$ | a 岁存活到 a+1 岁的年生存率 | 数据估计（分段回归） |
| $b_0$ | 每育龄母象每年产雌犊数 | 数据粗估 / 校准 |
| $\lambda_0$ | 无控制 Leslie 主特征值 | 特征值计算 |
| $L$ | 雌性 Leslie 矩阵（0–70 岁，71 组） | 本模型 |
| $p$ | 每年对未绝育育龄母象的注射份额 | 决策变量 |
| $p^*$ | 使 60 年期末头数回到 11,000 的 $p$ | 二分求解 |
| $N^*$ | 目标头数 | 11,000 |

## 3. 假设

- **A1（投影假设）**：迁出样本的年龄分布 ≈ 稳态年龄分布的随机投影
  （捕杀按家庭群整群移除，近似与年龄无关的选择）。
- **A2（数据修复）**：两份 CSV 中 40 岁均误标为 49（夹在 39 与 41 之间），
  按 40 归位。
- **A3（生育窗口）**：雌象 10–60 岁生育（文献常识）。
- **A4（校准锚）**：幼象在迁出样本中系统性低估 → 直接估计的
  $\lambda_0=1.0031$ 与捕杀记录矛盾（隐含年剩余仅 0.31% vs 实际 6%）；
  以捕杀记录反推 $\lambda_0 = 1 + 700/11000 \approx 1.0636$ 校准生育率
  （乘子 m=4.42）。
- **A5（避孕机制）**：飞镖为永久绝育；已绝育个体随种群存活老化，不生育；
  每年从**未绝育**育龄母象中按份额 $p$ 注射。
- **A6（搬迁机制）**：搬迁每年整头移除 $r$ 个个体，各年龄均匀。

## 4. 模型

**Q1 生存率/年龄结构**：稳态下 $\ln N(a) = \ln N(0) + \sum_{i<a}\ln S_i$，
对 $\ln N(a)$ 分段线性回归（0–2 / 2–50 / 50–70）：
$S_{juv}=0.8346,\ S_{adult}=0.9811,\ S_{sen}=0.8555$。
当前年龄结构 = 校准口径稳定分布归一 $N^*$。

**Q2 避孕配额**：雌性 Leslie 矩阵
$L_{a+1,a}=S_a,\ L_{0,a}=b_0\,(10\le a\le 60)$。
避孕使有效生育率乘 $(1-s_t)$，$s_t$ = 已绝育占育龄母象份额（状态变量，
随模拟演化）。$p^*$ 由 60 年模拟 + 二分求得；不确定性用
5 独立批 × 200 次年龄计数的非参数 bootstrap（seed 42，scenario B 口径）。

**Q3 灾难恢复**：$t=0$ 瞬时移除 30/50/70%，立即停止避孕（满生育），
投影至总头数 $\ge N^*$ 的年数。

**Q4 泛化**：公园规模 {300, 2000, 5000, 11000, 25000} × 生存率缩放
$\{S^{0.9}, S, S^{1.1}\}$（健康/基准/退化），每档按 A4 重新校准后求 $p^*$。

## 5. 关键结果（详见 all_results.json）

| 量 | 情景 A（数据直接） | 情景 B（捕杀校准，推荐） |
|---|---|---|
| $\lambda_0$ | 1.0031 | 1.0636（锚定） |
| 年度飞镖母牛数 | 25.4 | **115.1**（bootstrap 95%CI 108.1–119.6，5 批 std 0.2） |
| 搬迁均衡额（头/年） | 34.2 | **700.0**（与题面 600–800 一致：内部一致性校验） |
| 50% 灾难恢复 | 224 年 | **12 年** |

- **避孕 vs 搬迁**（Task3 尾项）：避孕年度操作量约为搬迁的 1/6，但使幼龄
  份额从 61.2% 降至 17.8%（60 年）——种群显著老龄化，影响观赏价值；
  搬迁立竿见影但操作量与动物应激大。
- **不确定性影响**（Task2 要求）：A/B 两情景的一切结论差异均源自幼象
  计数偏低这一数据缺陷——Q3 恢复时间 224 年 vs 12 年是最敏感的结论。

## 6. 边界与局限

1. 稳态投影假设（A1）忽略捕杀的年龄选择性偏差方向；
2. 校准锚把捕杀记录当作无误差常数（实际 600–800 区间 → λ0 ∈ 1.055–1.073，
   对应飞镖数区间约 ±15%）；
3. 交配系统（雄象影响）、密度制约、环境随机性未建模；
4. 校准后幼龄份额 61% 偏高，提示校准口径下幼体死亡可能被低估；
5. 生育率 m=4.42 的校准放大了 b0 的测量误差，bootstrap 仅覆盖抽样误差，
   不覆盖机制误差。
