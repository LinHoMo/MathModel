\section{问题重述}
生产质量检验的成本权衡问题。建模思路：检验成本与不合格品流出损失之间存在权衡，建立二项抽样模型求解最优检验量。

\section{模型假设}
\item 产品合格率已知或可估计
\item 检验本身有成本，不合格品流出有损失

\section{模型建立与求解}
\subsection{漏检概率}
\begin{equation}
P(miss) = 1 - (1-p)^n
\end{equation}
其中，二项分布。

\subsection{总成本}
\begin{equation}
E[C] = c_ins·n + c_def·P(miss)·(N-n)
\end{equation}
其中，期望成本。


\subsection{约束条件}
\item 0 ≤ n ≤ N（批次总量）（检验量不超过批次）

\subsection{目标函数}
\begin{equation}
min E[C_total] = c_ins·n + c_def·P(漏检)·(N-n)
\end{equation}
其中，总期望成本最小。

\item 超几何抽样模型：优点 精确，缺点 计算复杂

\subsection{选定模型}
选定模型：二项抽样模型

选择理由：批次大时二项近似足够
