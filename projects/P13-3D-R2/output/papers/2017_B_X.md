\section{问题重述}
众包平台'拍照赚钱'任务定价问题。建模思路：用户选择任务基于报酬-距离权衡，完成率服从 logistic 函数。优化目标是找到使总期望收益最大的定价策略，考虑区域差异和时段效应。

\section{模型假设}
\item 用户选择任务基于报酬与距离的权衡
\item 任务完成率与价格正相关

\section{模型建立与求解}
\subsection{完成率模型}
\begin{equation}
P(complete) = σ(β·price - α·distance + γ·region + b)
\end{equation}
其中，多因素 logistic 回归。


\subsection{约束条件}
\item 0 ≤ completion_rate ≤ 1（概率有界）

\subsection{目标函数}
\begin{equation}
max E[收益] = Σ price_i · completion_rate_i
\end{equation}
其中，总期望收益最大。
