\section{问题重述}
有限耕地下的多作物种植策略优化。建模思路：线性收益+面积约束构成 LP 问题，可扩展为多目标优化考虑风险。

\section{模型假设}
\item 耕地面积固定，作物间可轮作
\item 市场需求和价格可预测

\section{模型建立与求解}
\subsection{收益模型}
\begin{equation}
R = Σ r_i · x_i
\end{equation}
其中，线性收益。

\subsection{面积约束}
\begin{equation}
Σ x_i ≤ A
\end{equation}
其中，耕地约束。


\subsection{约束条件}
\item Σx_i ≤ A（耕地面积约束）
\item x_i ≥ 0（非负约束）

\subsection{目标函数}
\begin{equation}
max R = Σ r_i · x_i
\end{equation}
其中，总收益最大。


\section{模型评价与讨论}

\subsection{候选模型对比}

\item 随机规划：优点 考虑价格波动，缺点 需要分布信息

\subsection{选定模型}
选定模型：线性规划
