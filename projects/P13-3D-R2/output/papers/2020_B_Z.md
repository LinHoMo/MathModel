\begin{abstract}
本文针对穿越沙漠问题，建立了数学模型并进行了求解。
沙漠穿越的随机序贯决策优化问题。需要回答：(1)环境模型的建立（地形、天气、资源消耗）；(2)最优决策策略的求解（MDP/DP）；(3)不确定性下的鲁棒策略；(4)不同策略的风险-收益权衡。成功标准：策略在随机天气下显著优于贪心策略。
\end{abstract}

\section{模型假设}
\item 天气状态服从马尔可夫链（晴/阴/雨），转移概率已知
\item 资源消耗率与速度和天气相关
\item 绿洲位置和补给量已知
\item 队伍速度可连续调节
\item 目标为最小化期望到达时间或最大化安全概率

\section{模型建立与求解}
\subsection{位置动态}
\begin{equation}
s(t+1) = s(t) + v(t)·Δt
\end{equation}
其中，确定性前进。

\subsection{资源消耗}
\begin{equation}
r(t+1) = r(t) - c(v, weather)·Δt
\end{equation}
其中，消耗率依赖速度和天气。

\subsection{天气转移}
\begin{equation}
P(w'=j | w=i) = T_ij
\end{equation}
其中，马尔可夫转移矩阵。

\subsection{Bellman 方程}
\begin{equation}
V(s,w) = min_a [cost(s,w,a) + γ·Σ_w' T(w,w')·V(s',w')]
\end{equation}
其中，MDP 值迭代。


\subsection{约束条件}
\item r(t) ≥ 0 ∀t（资源非负）

\subsection{目标函数}
\begin{equation}
min E[总时间] 或 max P(安全到达)
\end{equation}
其中，时间最优或安全最优。
