\begin{abstract}
本文针对生产过程中的决策问题问题，建立了数学模型并进行了求解。
生产质量检验的成本-风险权衡优化问题。需要回答：(1)质量检验的概率模型；(2)检验成本与不合格品损失的权衡；(3)最优检验频率和抽样方案；(4)不同质量水平下的最优策略。成功标准：最优策略显著降低总期望成本。
\end{abstract}

\section{问题重述}
生产质量检验的成本-风险权衡优化问题。需要回答：(1)质量检验的概率模型；(2)检验成本与不合格品损失的权衡；(3)最优检验频率和抽样方案；(4)不同质量水平下的最优策略。成功标准：最优策略显著降低总期望成本。

\section{模型假设}
\item 产品不合格率 p 已知或可通过历史数据估计
\item 检验为破坏性或非破坏性均可，但有单位成本
\item 不合格品流出造成客户损失 c_def >> c_ins
\item 批次内产品独立同分布

\section{模型建立与求解}
\subsection{漏检概率}
\begin{equation}
P(miss) = (1-p)^n ≈ e^{-np}（大批次）
\end{equation}
其中，二项分布/泊松近似。

\subsection{总期望成本}
\begin{equation}
E[C] = c_ins·n + c_def·P(miss)·(N-n)
\end{equation}
其中，检验成本+期望损失。

\subsection{最优检验量}
\begin{equation}
n* = argmin E[C]，一阶条件: c_ins = c_def·(N-n)·(-∂P(miss)/∂n)
\end{equation}
其中，边际成本=边际收益。


\subsection{约束条件}
\item 0 ≤ n ≤ N（批次总量）（检验量不超过批次）

\subsection{目标函数}
\begin{equation}
min E[C_total] = c_ins·n + c_def·P(漏检)·(N-n)
\end{equation}
其中，总期望成本最小。
