## 建模骨架（先看这段再读代码）

1. **结构识别**：题面属几何运动 / 运动学结构，题卡允许的建模结构包含运动学、纯几何螺线、
   微分几何、数值优化、多体动力学；本实现取「运动学 + 微分几何 + 数值优化」三者的组合。
2. **关键决断 —— 弦长约束，不是弧长约束**：同一条板凳是刚体，两孔中心距固定
   （龙头 2.86 m、龙身/龙尾 1.65 m，由板长 3.41 / 2.20 m 减去两侧各 0.275 m 得到）。
   因此约束是 **|P(k+1) − P(k)| = L(k)**（弦长），而**不是**"相邻把手弧长间距恒为 L"的常见近似。
3. **路径统一为弧长参数化**：螺线段与圆弧段共享同一个弧长坐标，所以 Q1–Q5 复用同一个递推器。
   盘出螺线是盘入螺线关于中心的中心对称像，且两者在对应参数处的**行进切向相同**——
   这是 Q4 全部解析结论的起点。
4. **构型递推**：由龙头弧长坐标向后逐个解连杆的弧长间隔（Newton，以上一连杆解为热启动；
   失败回退网格扫描 + 二分）。
5. **速度**：v(k) = (dσ(k)/dσ(0)) · v_head · T(σ(k))，实现上用中心差分（步长 1e-3 s）。
   链路不可伸长但**弧长**间隔随曲率变化，所以后方把手速率并不等于龙头速率。
6. **碰撞判定**：板体含把手外 0.275 m 伸出，视为宽 0.30 m 的矩形；
   只检查 |i−j| ≥ 2 的板对（相邻板共用把手铰接，必然重叠）；
   线段最小距离取「内部驻点 + 4 条边钳制驻点」的最小者，对凸二次函数在矩形域上是**精确解**。

## 三个结构性发现（本实例最有价值的部分）

**发现一：最小板距随时间非单调振荡，终止时刻必须细扫。**
链是**内接于螺线的离散多边形**而非光滑曲线，板体相对相位周期性变化，振幅约 板长²/(8r)。
实测最小板距序列在 0.315 → 0.326 之间来回跳（不同秒的临界板对在 (0,11)/(0,13) 之间切换）。
⇒ 若像常见做法那样"假定单调后二分"，会得到错误的终止时刻。
本实现用 1 s 粗扫 + 0.05 s 细扫定位首次接触，再用「相邻帧龙头位移 = v·Δt」做连续性校验，
确认没有求根跳支（实测相邻帧位移恰为 0.05 m）。

**发现二：整链构型只由（螺距, 龙头弧长）决定，与盘入历史无关。**
⇒ Q3 可化为**单点判定**：越往内曲率越大，最危险构型必在龙头半径最小处，即 r = 4.5 m（调头空间边界）。
已在 7 个龙头半径（4.5 → 20 m）上扫描验证：边界处 0.300001 m 最小，往外单调放宽到 0.412262 m。
⇒ 因此「从远处盘入」与「从第 16 圈盘入」两种解读给出同一临界构型，结论鲁棒。

**发现三：调头曲线长度对半径分配是不变量 —— 所以不能靠调半径把它调短。**
两端切向相同 ⇒ 两段弧转角必须相等（ψ1 = ψ2 = ψ），位移合并后只含半径**和**：

    D = B − A = (R1 + R2) · (sinψ·u − (1−cosψ)·n)
    ⇒ tan(ψ/2) = −(D·n)/(D·u),  R1 + R2 = (D·u)/sinψ
    ⇒ L = (R1 + R2)·ψ 与 R1:R2 的分配无关

数值验证：半径分配取 1:1、1.5:1、2:1、3:1、5:1、10:1 六种，L 全部等于 13.621245 m。
⇒ 题面「前一段圆弧半径是后一段的 2 倍」并不特殊，也**无法**通过调整圆弧使调头曲线变短。
若进一步允许出螺线切点沿螺线内移，S 曲线形式上可短到 3.18 m，但第二段弧半径退化到约 10³ m
（已是一条直线，不再是 S 形），且把出螺线在圆内的那一段计入后，圆内完整调头路径由 13.62 m
涨到不小于 18.70 m —— 不构成真正的缩短。

## 踩坑清单（后续 Agent 优先读这段）

1. **纯 Python 循环递推会慢到不可用**。原始网格扫描 + 二分实现要 32 s / 301 帧；
   改成 Newton 迭代（F(δ) = |Γ(σ−δ) − Γ(σ)|² − L²，F′ = −2·w·Γ′）并以**上一连杆的解热启动**后，
   降到 4.7 s 且精度不变（弦长残差 3.29e-13）。网格 + 二分保留为兜底分支，不要删。
2. **弧长反演返回的是数组**（内部 `atleast_1d`），标量场景必须取 ravel 后再转 float，
   否则报 "only 0-dimensional arrays can be converted to Python scalars"。
3. **交付物必须放项目根**：模型定义、模型描述（含 Mermaid）、结果聚合文件三者都在根目录，
   赛题原文规范名为 `inputs/problem.txt`。放进 `model/` 子目录会被项目级校验判为缺失。
4. **数值追溯是把双刃剑**：模型描述里出现的**每一个**数字都要能在结果聚合文件中找到
   （相对容差 0.5%、绝对 0.01，阈值 90%）。实测踩过的陷阱：
   章节编号会被当成物理量；LaTeX 里乘号与系数之间若不留空格，小数会被正则从中间切开；
   上标形式的指数会被切成两个整数；`py -3.12` 里的版本号同样会被计入。
   对策：给章节起名字而不是编号、乘号后加空格、指数改用 e-notation，并在结果文件里补齐
   运行环境、运行时、扫描表、流程计数等**真实**元数据（不要为了过检而编数字）。
5. **交付文档里禁止出现内部实现字符串**：脚本后缀、结果聚合文件的全名、仓库协议文件的全名、
   内部工作目录名等，都会被判为"内部路径泄漏"（完整名单见项目级校验器的内部路径模式表）。
   复现命令请统一用 `py -3.12 -m <模块名>` 形式，不要写脚本后缀；引用文件时写角色名而非全名。
6. **速度差分的收敛性必须自证**：h 取 1 / 0.5 / 0.25 s 三档，尾端速率收敛到同一位数，
   才能声称"把手速率差于龙头"是真实物理而不是数值误差。
7. **离散多边形的相位效应**：任何"最小间距 / 最近距离随时间"的曲线在本题都**不是单调的**。
   做极值或首次穿越定位时，宁可多扫一层细网格。
8. **刚性链的可跟随性硬约束**：圆弧半径必须不小于最长连杆的一半（2.86 / 2 = 1.43 m），
   否则 2.86 m 的龙头连杆无法在弧上安置。本解 R2 = 1.502709 m，裕度只有 0.0727 m，
   是本题几何的紧约束点——做敏感性分析时优先看这里。

## 局限与未决（如实声明）

1. **共路径假设的外推**：题面只在问题 1 明示"各把手中心均在螺线上"。Q2–Q5 沿用了这一假定
   （把手位于龙头走过的组合路径上）。严格建模需要拖曳链的刚体-铰链动力学，而题面未给摩擦与驱动信息。
   影响量级不超过板宽，且集中在调头段。
2. **碰撞判据是保守的**：用"线段 + 0.15 m 半径"的胶囊近似矩形，会在极近距离处略微偏早报碰（安全方向）。
   若要严格按矩形判碰，需换成分离轴定理，属于可提升项。
3. **Q3 的龙头半径扫描取 7 个离散点**（4.5 → 20 m），不是连续扫描；
   结论依赖"构型-历史无关性"与已核验的单调性。
4. **未与官方参考答案比对**：题卡的参考结果字段为空，按仓库铁律不凭记忆伪造对照值。
   若后续拿到官方答案，应新增一条验证项而不是修改现有结论。
5. **A04 假设的敏感性未量化**：尚未做"若把手不严格共路径，结果偏移多少"的定量实验。
