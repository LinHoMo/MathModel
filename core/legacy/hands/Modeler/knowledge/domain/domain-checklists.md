# 领域检查清单

> 使用说明：在建模前，根据题型选择对应清单，逐项确认，避免遗漏关键因素。

---

## 一、A题（物理建模）通用检查清单

### 1.1 问题理解
- [ ] 明确物理现象的本质（波动？扩散？振动？）
- [ ] 识别关键物理量（能量、动量、质量守恒）
- [ ] 确定系统边界（封闭/开放、线性/非线性）

### 1.2 建模假设
- [ ] 假设是否合理（能否被物理定律支持？）
- [ ] 假设是否简化了问题（但不能过度简化）
- [ ] 假设是否明确列出（论文中必须单独成节）

### 1.3 物理方程
- [ ] 控制方程是否正确（Navier-Stokes？波动方程？）
- [ ] 边界条件是否完整（初始条件、边界条件）
- [ ] 参数单位是否统一（SI单位制）

### 1.4 数值求解
- [ ] 网格划分是否合理（精度 vs 计算量）
- [ ] 数值方法是否适合（有限元？有限差分？）
- [ ] 收敛性是否验证（残差曲线、网格独立性）

### 1.5 结果验证
- [ ] 量纲是否正确（通过量纲分析验证）
- [ ] 极限情况是否合理（参数趋于0或∞时）
- [ ] 与实际/文献是否一致

## 二、B题（实验/优化）通用检查清单

### 2.1 实验设计
- [ ] 因素筛选是否充分（全因子/部分因子/Plackett-Burman）
- [ ] 水平设置是否合理（基于预实验/文献）
- [ ] 重复次数是否足够（至少3次）
- [ ] 随机化是否执行（避免系统误差）

### 2.2 数据分析
- [ ] 正态性检验（Shapiro-Wilk）
- [ ] 方差齐性检验（Levene）
- [ ] 异常值处理（3σ原则/箱线图）

### 2.3 响应面/回归
- [ ] 模型选择是否合适（线性/二次/交互）
- [ ] R²和调整R²是否可接受（>0.8）
- [ ] 残差是否随机（无模式）
- [ ] 多重共线性检查（VIF<10）

### 2.4 优化求解
- [ ] 优化目标是否明确（最大化/最小化）
- [ ] 约束条件是否完整
- [ ] 最优解是否验证（是否局部最优）
- [ ] 灵敏度分析是否执行

### 2.5 模型评估
- [ ] 交叉验证（留一法/K折）
- [ ] 预测误差（RMSE、MAE）
- [ ] 模型鲁棒性（参数扰动）

---

## 三、C题（数据分析）通用检查清单

### 3.1 数据理解
- [ ] 字段含义是否清楚
- [ ] 数据来源是否可靠
- [ ] 样本量是否足够
- [ ] 时间范围是否明确

### 3.2 数据质量
- [ ] 缺失值处理（删除/填充/插值）
- [ ] 异常值检测（IQR/Z-score）
- [ ] 重复值处理
- [ ] 数据一致性检查

### 3.3 特征工程
- [ ] 特征构造（组合、交叉、变换）
- [ ] 特征选择（过滤/包裹/嵌入）
- [ ] 标准化/归一化
- [ ] 编码处理（类别变量）

### 3.4 模型选择
- [ ] 基线模型（简单模型作为对比）
- [ ] 多模型对比（至少3种）
- [ ] 评估指标选择（准确率/AUC/RMSE）
- [ ] 过拟合控制（正则化/早停/特征选择）

### 3.5 结果解释
- [ ] 特征重要性分析
- [ ] 模型可解释性（SHAP/LIME）
- [ ] 业务含义解读
- [ ] 局限性说明

## 四、特定领域检查清单

### 4.1 波浪能装置
- [ ] 水深条件（浅水/深水）
- [ ] 波浪类型（规则波/不规则波）
- [ ] 能量转换效率
- [ ] 装置类型（振荡浮子/振荡水柱）
- [ ] 阻尼系数设置

### 4.2 定日镜场/FAST
- [ ] 太阳位置计算（时角、赤纬）
- [ ] 镜面反射模型
- [ ] 阴影遮挡计算
- [ ] 边缘效应
- [ ] 热损失

### 4.3 化学实验
- [ ] 催化剂选择
- [ ] 温度范围
- [ ] 压力条件
- [ ] 反应时间
- [ ] 产率/选择性

### 4.4 调度问题
- [ ] 任务约束（时间窗、优先级）
- [ ] 资源约束（设备、人员）
- [ ] 目标函数（Makespan/延迟/成本）
- [ ] 不确定性处理

### 4.5 定价/库存
- [ ] 需求弹性
- [ ] 保质期约束
- [ ] 损耗率
- [ ] 季节性因素
- [ ] 竞争对手行为

### 4.6 信贷决策
- [ ] 样本不平衡处理
- [ ] 特征工程（WOE/IV）
- [ ] 模型稳定性（PSI）
- [ ] 可解释性要求
- [ ] 监管合规

## 五、通用质量检查

### 5.1 模型层面
- [ ] 假设是否明确列出
- [ ] 模型是否有理论支撑
- [ ] 参数是否有物理意义
- [ ] 结果是否可重复

### 5.2 论文层面
- [ ] 问题重述是否准确
- [ ] 模型假设是否合理
- [ ] 符号说明是否完整
- [ ] 结果分析是否深入
- [ ] 灵敏度分析是否执行
- [ ] 优缺点是否讨论

### 5.3 图表层面
- [ ] 坐标轴标签是否完整
- [ ] 单位是否标注
- [ ] 图例是否清晰
- [ ] 分辨率是否足够
