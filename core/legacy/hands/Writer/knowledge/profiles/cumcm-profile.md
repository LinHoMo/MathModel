# CUMCM竞赛配置文件

## 基本信息
- **竞赛全称**：全国大学生数学建模竞赛
- **主办方**：中国工业与应用数学学会
- **比赛时间**：每年9月中旬，比赛时长72小时（3天）
- **队伍要求**：3人/队，全国赛事
- **语言要求**：中文为主，英文摘要必须
- **页数限制**：20页（正文部分）

## 题型分类与特征

### A题：连续型问题
**问题特征**：涉及物理过程、生物过程、化学动力学等连续变化系统
**典型方法**：
- 常微分方程（ODE）建模
- 偏微分方程（PDE）建模
- 数值积分（龙格-库塔法、有限差分法）
- 参数估计与敏感性分析

**论文结构建议**：
1. 问题分析与假设
2. 数学模型建立（从第一性原理推导）
3. 数值求解方法
4. 结果展示与分析
5. 敏感性分析

**评分要点**：
- 公式推导严谨性（≥30个公式）
- 物理意义解释
- 数值解稳定性
- 参数敏感性分析

**常见陷阱**：
- 公式推导跳步
- 物理意义解释不足
- 未进行数值验证
- 敏感性分析缺失

### B题：离散型问题
**问题特征**：涉及图论、组合优化、离散事件模拟等
**典型方法**：
- 图论算法（Dijkstra、Floyd、最大流）
- 组合优化（TSP、VRP、调度问题）
- 整数规划（MILP）
- 离散事件模拟

**论文结构建议**：
1. 问题抽象与图模型构建
2. 算法选择与设计
3. 算法复杂度分析
4. 结果展示与对比
5. 算法优化与改进

**评分要点**：
- 图模型定义清晰（节点、边、权重）
- 算法选择合理性
- 计算复杂度分析
- 与基准方法对比

**常见陷阱**：
- 未定义清楚图模型
- 算法复杂度分析缺失
- 未与简单方法对比
- 结果未验证

### C题：数据分析问题
**问题特征**：涉及大规模真实数据集、统计分析、机器学习
**典型方法**：
- 探索性数据分析（EDA）
- 统计建模（回归、时间序列）
- 机器学习（分类、聚类、回归）
- 数据可视化

**论文结构建议**：
1. 数据理解与预处理
2. 探索性数据分析
3. 特征工程与选择
4. 模型建立与训练
5. 模型评估与解释

**评分要点**：
- 数据处理完整性
- 模型选择合理性
- 结果可解释性
- 业务洞察深度

**常见陷阱**：
- 数据预处理不充分
- 过拟合问题
- 未进行特征选择
- 结果解释不足
