# 图表规范增强指南（基于真题案例分析）

> 本文档基于历年数学建模竞赛获奖论文的图表特征总结而成，覆盖 A/B/C/D/E 五类赛题的图表选型、制作规范、常见错误与修正方案。

---

## 一、图表类型选择指南（基于真题案例）

### 1.1 A 题：物理过程与机理建模

A 题通常涉及物理过程建模，图表应突出物理量之间的关系与时空演化规律。

| 典型赛题年份 | 推荐图表类型 | 说明 |
|---|---|---|
| 2023A（定日镜场） | 轨迹图、温度场热力图 | 展示光线反射路径与温度分布 |
| 2022A（波浪能装置） | 力分析图、位移-时间曲线 | 表达受力平衡与运动轨迹 |
| 2021A（FAST 调节） | 三维曲面图、参数敏感性图 | 展示多参数耦合关系 |
| 通用场景 | 相图、相空间轨迹图 | 展示系统动力学行为 |

**核心原则**：A 题图表必须体现物理意义，避免纯数据堆砌。力分析图需标注坐标系与矢量方向。

### 1.2 B 题：运筹优化与调度

B 题涉及资源分配、路径规划、调度排产等，图表应直观展示方案可行性。

| 典型赛题年份 | 推荐图表类型 | 说明 |
|---|---|---|
| 2023B（慢性病管理） | 流程图、决策树图 | 展示筛查与诊断路径 |
| 2022B（快递包裹问题） | 甘特图、网络拓扑图 | 展示车辆调度与路径分配 |
| 2021B（煤炭运输） | 有向图、网络流图 | 表达运输网络与流量分配 |
| 通用场景 | 收敛曲线、目标函数迭代图 | 展示算法求解过程 |

**核心原则**：B 题图表应突出"方案可行性"与"资源利用率"，甘特图和流程图是评委最易理解的表达方式。

### 1.3 C 题：数据分析与统计建模

C 题以数据驱动为主，图表应突出统计规律与模型效果。

| 典型赛题年份 | 推荐图表类型 | 说明 |
|---|---|---|
| 2023C（古文物断代） | 散点矩阵、相关性热力图 | 展示特征间关系 |
| 2022C（中小微企业信贷） | ROC 曲线、混淆矩阵 | 评估分类模型性能 |
| 2021C（农作物种植） | 箱线图、小提琴图 | 展示数据分布特征 |
| 通用场景 | 残差图、QQ 图、降维投影图 | 诊断模型假设与效果 |

**核心原则**：C 题图表数量较多，但每张图必须有对应的分析文字。避免"堆图"而不解读。

### 1.4 D 题：综合评价与决策

D 题涉及多属性评价、政策分析等，图表应突出对比与权衡。

| 典型赛题年份 | 推荐图表类型 | 说明 |
|---|---|---|
| 2023D（传统技艺保护） | 雷达图、层次结构图 | 展示多维评价结果 |
| 2022D（高校夏令营） | 优化结果对比柱状图 | 对比不同方案优劣 |
| 通用场景 | 帕累托前沿图、权重敏感性图 | 展示多目标权衡关系 |

**核心原则**：D 题图表应体现"对比性"，帕累托前沿图是多目标优化问题的必备图表。

### 1.5 E 题：系统动力学与政策仿真

E 题涉及社会经济系统建模，图表应突出系统结构与动态演化。

| 典型赛题年份 | 推荐图表类型 | 说明 |
|---|---|---|
| 2023E（碳中和路径） | 因果回路图、存量流量图 | 展示系统反馈结构 |
| 2022E（生态旅游） | 系统动力学仿真曲线 | 展示政策干预效果 |
| 通用场景 | 阶梯图、多情景对比曲线 | 展示不同政策下的演化路径 |

**核心原则**：E 题图表应突出"因果关系"与"时间演化"，因果回路图是论文亮点。

## 二、图表规范详细要求

### 2.1 命名规范

图表命名应遵循"图序 + 图题"格式，要求简洁、准确、自解释。

| 规范项 | 正确示例 | 错误示例 |
|---|---|---|
| 中文命名 | 图 1　定日镜场布局优化结果 | 图 1. 下面是优化后的结果 |
| 编号连续 | 图 1、图 2、图 3 | 图 1.1、图 1、图 a |
| 避免过长 | 图 5　三种模型预测效果对比 | 图 5　在不同参数设置下三种模型对训练集和测试集的预测效果对比图 |
| 表格同理 | 表 1　各方案综合评价结果 | 表 1　Evaluation Results |

**注意**：数学建模竞赛论文中图表编号必须全文连续，不能按章节分段编号。

### 2.2 引用规范

论文正文中必须在首次使用图表时进行引用，格式为"如图 X 所示"。

| 规范项 | 正确示例 | 错误示例 |
|---|---|---|
| 引用位置 | 优化结果如图 1 所示。 | 如下图所示。 |
| 引用时机 | 图表在首次提及时引用 | 图表出现在引用之前 |
| 多次引用 | 如图 1、图 2 所示，… | 如图所示，如上图所示 |

### 2.3 格式要求

| 要求项 | 规范 |
|---|---|
| 文件格式 | 矢量图优先（SVG、PDF、EPS）；若为位图，分辨率不低于 300dpi |
| 字体嵌入 | 中文使用宋体/黑体，英文使用 Times New Roman 或 Arial；导出时必须嵌入字体 |
| 图片尺寸 | 单栏宽度 8cm，通栏宽度 16cm；高度一般不超过 12cm |
| 背景 | 白色背景，无多余边框；避免使用灰色或彩色背景 |
| 线条 | 线宽 0.5-1.5pt，实线/虚线/点线区分不同曲线；避免使用超过 5 种线型 |

### 2.4 颜色规范

| 要求项 | 规范 |
|---|---|
| 色盲友好 | 避免红-绿对比；使用蓝-橙、蓝-红等色盲安全配色 |
| 配色方案 | 推荐使用 ColorBrewer、Nature Methods 配色方案 |
| 颜色数量 | 单张图不超过 6 种颜色；超过时使用颜色梯度 |
| 灰度兼容 | 确保黑白打印时仍可区分不同数据系列 |
| 对比度 | 前景与背景对比度至少 4.5:1 |

**推荐色盲安全配色方案**（Nature Methods 风格）：
- 蓝色：#0072B2
- 橙色：#E69F00
- 绿色：#009E73
- 黄色：#F0E442
- 天蓝：#56B4E9
- 红色：#D55E00
- 紫色：#CC79A7
- 黑色：#000000

## 三、每种图表类型的制作规范

### 3.1 折线图

折线图适用于展示连续变量的变化趋势，是数学建模中使用频率最高的图表类型。

**制作规范**：
- 坐标轴标签必须标注物理量名称与单位，格式为"变量名（单位）"
- Y 轴起始值应根据数据范围合理设置，避免截断导致视觉误导
- 网格线使用浅灰色细线（#CCCCCC），仅保留主网格线
- 图例置于图表内部（右上角或右下角），避免遮挡数据曲线
- 多条曲线使用不同颜色+不同线型（实线/虚线/点线）双重区分

**标注要素**：
- 关键数据点（极值点、拐点、交点）应标注具体数值
- 曲线超过 5 条时，考虑分面绘制（faceting）

### 3.2 散点图

散点图适用于展示两个变量之间的关系，常用于相关性分析与聚类可视化。

**制作规范**：
- 标记大小（markersize）设为 20-50，避免过大导致重叠
- 透明度（alpha）设为 0.3-0.7，用于展示数据密度
- 存在明显趋势时，添加回归线（实线）与置信区间（阴影区域）
- 聚类结果使用不同颜色标记，并在图例中标注类别名称

**高级技巧**：
- 数据点超过 1000 个时，考虑使用 hexbin 或 KDE 图替代
- 三维数据可使用气泡图（marker size 表示第三维）

### 3.3 柱状图

柱状图适用于展示分类变量的数值对比，常用于方案比较与结果展示。

**制作规范**：
- 分组柱状图中，组内间距小于组间间距（组内间距 0.2，组间间距 0.8）
- 误差线（errorbar）标注标准差或置信区间，使用 T 型误差线
- 柱子宽度一般为 0.6-0.8
- 数值差异较大时，考虑使用对数坐标轴

**标注要素**：
- 柱顶标注具体数值（保留 2-3 位有效数字）
- 显著性差异使用星号标注（* p<0.05, ** p<0.01, *** p<0.001）

### 3.4 热力图

热力图适用于展示矩阵数据或二维分布，常用于相关性分析、混淆矩阵、空间分布等。

**制作规范**：
- 颜色映射（colormap）推荐使用：
  - 发散型数据：RdBu_r（红蓝反转）
  - 顺序型数据：YlOrRd（黄橙红）、Blues（蓝色渐变）
- 数值标注：在每个单元格中标注具体数值，字号小于坐标轴标签
- 颜色条（colorbar）标注物理量名称与单位

**标注要素**：
- 单元格文字颜色根据背景亮度自动切换（深背景用白字，浅背景用黑字）
- 矩阵超过 20×20 时，考虑简化标注或使用分块热力图

### 3.5 流程图

流程图适用于展示算法逻辑、决策过程、系统架构等，是 B 题和 E 题的必备图表。

**制作规范**：
- 节点形状规范：
  - 圆角矩形：起止节点（开始/结束）
  - 矩形：处理步骤
  - 菱形：判断/决策
  - 平行四边形：输入/输出
  - 椭圆：连接节点
- 连接线使用直角折线，避免斜线交叉
- 层次布局采用自上而下或自左而右
- 节点内文字居中，字号 10-12pt

**工具推荐**：
- draw.io（免费在线工具）
- Visio（专业工具）
- Python graphviz 库（可编程生成）

### 3.6 箱线图

箱线图适用于展示数据分布特征，常用于数据预处理与模型诊断。

**制作规范**：
- 箱体宽度一般为 0.5-0.8
- 异常值使用单独的点标记（diamond 或 circle）
- 中位数使用加粗线或不同颜色标注
- 分组箱线图中，组内间距小于组间间距

### 3.7 雷达图

雷达图适用于展示多维评价结果，常用于 D 题综合评价。

**制作规范**：
- 维度数一般为 5-8，过多会导致图形拥挤
- 每个维度的取值范围应归一化到 [0, 1] 或 [0, 100]
- 多个方案使用不同颜色的填充区域，透明度 0.2-0.3
- 外圈标注维度名称与刻度

### 3.8 帕累托前沿图

帕累托前沿图适用于展示多目标优化的权衡关系，是 D 题的亮点图表。

**制作规范**：
- X 轴和 Y 轴分别表示两个目标函数
- 帕累托最优解用实心点标注，非支配解用空心点标注
- 前沿曲线使用平滑拟合线连接
- 理想点和最差点用特殊标记标注

## 四、评委视角

### 4.1 评委偏好的图表类型

根据历年获奖论文分析，评委最认可的图表类型排序：

1. **流程图**：逻辑清晰，一目了然，评委最易理解
2. **折线图**：趋势明确，数据故事性强
3. **热力图**：信息密度高，视觉冲击力强
4. **对比柱状图**：方案比较直观，结论明确
5. **帕累托前沿**：体现多目标优化思想，学术性强

**评委最反感的图表类型**：
- 截断坐标轴的折线图（误导视觉）
- 无分析文字的堆砌图表
- 颜色过多的彩虹图
- 无坐标轴标签的图表

### 4.2 图表数量建议

| 论文类型 | 建议图表数量 | 说明 |
|---|---|---|
| A 题（物理建模） | 8-15 张 | 机理分析图、仿真结果图、对比图 |
| B 题（运筹优化） | 6-12 张 | 流程图、甘特图、收敛曲线、方案对比 |
| C 题（数据分析） | 10-18 张 | 探索性分析图、模型效果图、诊断图 |
| D 题（综合评价） | 8-12 张 | 评价结果图、敏感性分析图、对比图 |
| E 题（系统仿真） | 6-10 张 | 因果回路图、仿真曲线、政策对比图 |

### 4.3 图表与文字的比例

- 图表占论文页面的 30%-40%
- 每张图表后必须有 2-4 行分析文字
- 图表不能替代文字描述，文字不能完全复述图表内容
- 关键数据应在文字和图表中同时体现

**黄金比例**：每 1000 字论文，对应 2-3 张图表。

## 五、常见错误与修正

### 5.1 错误：图表无分析文字

**错误表现**：图表直接放在论文中，无任何文字解读。

**修正方案**：
```
优化结果如图 1 所示。从图中可以看出，随着迭代次数增加，
目标函数值在第 50 代后趋于稳定，最终收敛于最优值 23.67。
这表明所设计的遗传算法具有良好的收敛性能。
```

**规范**：每张图表后至少包含 3 个要素——图表描述、趋势分析、结论提炼。

### 5.2 错误：连续两张图无过渡

**错误表现**：图 1 之后直接是图 2，无任何过渡文字。

**修正方案**：
```
图 1 展示了各方案的成本对比。进一步分析各方案的效率指标，
结果如图 2 所示。综合成本与效率两个维度，方案 B 在保证效率
的前提下实现了成本最优。
```

**规范**：相邻图表之间必须有过渡文字，说明图表之间的逻辑关系。

### 5.3 错误：颜色不可区分

**错误表现**：使用红-绿对比，或颜色过于接近，黑白打印后无法区分。

**修正方案**：
- 将红-绿对比改为蓝-橙对比
- 每种颜色搭配不同线型（实线/虚线/点线）
- 添加数据标记（circle/square/triangle）进行双重区分

**自检方法**：将图表转换为灰度模式，检查是否仍可区分。

### 5.4 错误：标签不清晰

**错误表现**：坐标轴无单位、图例缺失、字号过小。

**修正方案**：
- 坐标轴标签格式："变量名（单位）"，字号不小于 10pt
- 图例必须包含所有数据系列，字号 9-10pt
- 图表标题字号 12pt，坐标轴标签 10pt，刻度标签 8-9pt
- 导出图片后，放大到 200% 检查文字是否清晰

### 5.5 其他常见错误

| 错误 | 表现 | 修正 |
|---|---|---|
| 格式不统一 | 字体、颜色、线宽不一致 | 建立统一模板，全文套用 |
| 截断数据 | Y 轴不从 0 开始，夸大差异 | Y 轴从 0 开始，截断需标注 |
| 图表过多/过少 | 堆砌 20+ 张或仅 3-4 张 | 8-15 张为宜，相似图表合并 |
| 无编号引用 | 正文未引用图表 | 首次使用标注"如图 X 所示" |

## 七、图表质量自检清单

完成论文后，逐项检查以下清单：

- [ ] 所有图表编号连续，无跳号或重复
- [ ] 正文中每张图表均有引用（"如图 X 所示"）
- [ ] 坐标轴标签包含变量名和单位
- [ ] 图例清晰，覆盖所有数据系列
- [ ] 每张图表后有 2-4 行分析文字
- [ ] 相邻图表之间有过渡文字
- [ ] 颜色方案色盲友好，黑白可区分
- [ ] 字体统一，嵌入无缺失
- [ ] 图片分辨率不低于 300dpi
- [ ] 图表风格全文统一
- [ ] Y 轴截断有明确标注
- [ ] 关键数据点有标注
- [ ] 流程图节点形状符合规范
- [ ] 热力图有颜色条和数值标注
