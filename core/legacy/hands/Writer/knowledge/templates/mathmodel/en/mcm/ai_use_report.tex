\section{Use Context}

For each AI-generated output used in the paper, describe how it was
incorporated (verbatim, paraphrased, adapted, or as inspiration only)
and any post-processing applied.

\subsection{Verbatim Use}
\textit{None.} We did not include any AI-generated text verbatim in
the final submission.

\subsection{Paraphrased Use}
\begin{itemize}
    \item \textbf{Section 3.1 (Model Selection):} ChatGPT's list of
    population models (Q001) was paraphrased into a comparison table
    in our own words. We added model equations and references not
    provided by the AI.
    \item \textbf{Section 3.2 (Parameter Estimation):} Claude's
    summary of estimation techniques was paraphrased and integrated
    with our own derivation.
\end{itemize}

\subsection{Adapted Use}
\begin{itemize}
    \item \textbf{Appendix A.3 (Code):} ChatGPT's bug fix (Q002) was
    adapted to fit our variable naming convention. We added comments
    and type hints.
    \item \textbf{Figure 4:} GitHub Copilot auto-completion was
    adapted with custom labels and color scheme.
\end{itemize}

\subsection{Inspiration Only}
\begin{itemize}
    \item \textbf{Section 4 (Results):} ChatGPT's suggestions for
    visualization inspired our final plot design, but the figure was
    generated entirely from our own code.
\end{itemize}

\subsection{Translation}
\begin{itemize}
    \item \textbf{Throughout the paper:} DeepL was used to translate
    initial Chinese drafts into English. All translations were
    post-edited for technical accuracy by team members.
\end{itemize}
