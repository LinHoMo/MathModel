## 6. 校验结果

### 6.1 数值一致性

- [ ] 论文中每个数字能追溯到 all_results.json
- [ ] 摘要和正文数值一致

### 6.2 引用完整性

- [ ] \cite{} 的每个 key 在 references.bib 中存在
- [ ] 没有捏造的引用
- [ ] 引用格式正确

### 6.3 图表引用

- [ ] \includegraphics{} 引用的图片文件存在
- [ ] \ref{} 引用的 \label{} 存在

- [ ] 无 TODO/FIXME/TBD 残留
- [ ] 无内部文件名、脚本名
- [ ] 无临时目录路径

- [ ] 无AI痕迹词汇
