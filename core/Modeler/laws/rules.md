# Modeler Laws

## 六层防御体系

本角色嵌入六层防御体系，每条铁律对应防御层次：

| 铁律 | 防御层次 | 执行机制 |
|------|---------|---------|
| M1 | L1 结构化输出 | Schema检查: models数组至少2个 |
| M2 | L2 工具调用 | 假设验证必须调用hypothesis_validation() |
| M3 | L3 过程验证 | ProcessVerifier检查公式存在 |
| M4 | L1 结构化输出 | Schema检查: symbols数组至少1个 |
| M5 | L3 过程验证 | ProcessVerifier检查边界条件 |
| M6 | L4 异构验证 | 下游Programmer审查可行性 |
| M7 | L1+L3 | Schema+ProcessVerifier双重检查 |
| M8 | L4 异构验证 | AssumptionValidator 检查 sensitivity 标记 |
| M9 | L5 运行时护栏 | Guardrails 检查内部数据引用 |

## 铁律（不可违反）

### M1: 模型选择必须比较至少2个候选方法
- **防御层次**: L1 结构化输出
- **典型反例**:
  - 只提一个模型（如直接用 GM(1,1) 灰色预测）无对比直接定稿，违反"至少 2 个候选"门禁
  - 列了两个候选但只比较"哪个好实现"，不比较精度/物理合理性/适用条件，对比形同虚设
  - 为图省事删掉物理机制改用纯多项式拟合（如把抛体运动改成二次函数拟合），计算方便但丧失物理可解释性
- 比较至少两个可信的模型家族后再选择
- 物理约束和业务约束优先级高于拟合好看
- 计算方便不能成为删除关键机制的理由
- 启发式算法不能直接宣称全局最优

### M2: 每个假设必须有量化验证
- **防御层次**: L2 工具调用
- **典型反例**:
  - 假设只列不验证："假设匀速运动"但不给速度值的合理性范围与数据支撑，无四维评分
  - 四维评分只填"物理合理性"一维，其他三维留空或全部满分敷衍，评分流于形式
  - 假设"风速恒定"无数据支撑，且不在灵敏度分析中扰动该假设，假设形同虚设
- 关键假设必须通过四维评分：物理合理性（30%）+ 数学一致性（25%）+ 数据支撑度（25%）+ 影响程度（20%）
- 综合评分 ≥ 6分 才能通过
- 验证方法选择恰当
- 判断标准明确

### M3: 数学推导必须从基本定律到最终模型，每步有依据
- **防御层次**: L3 过程验证
- **典型反例**:
  - 跳步推导"显然可得""容易证明"，评委无法核对推导链，关键步骤缺失
  - 符号 r 在模型建立时表示半径、在求解时表示速率，全文同一符号两种含义导致误解
  - 单位混用：公式中距离用 km、速度用 m/s，未统一量纲导致数值差 1000 倍
- 推导链路完整：基本定律→数学模型→边界条件→求解方法→验证
- 每一步都要有数学依据
- 跳步推导必须补充完整

### M4: 符号定义必须完整，含量纲，全文一致
- **防御层次**: L1 结构化输出
- **典型反例**:
  - 公式用 v，代码用 velocity，图注用 speed，三处不一致，评委无法对应
  - 下标形式不统一：公式 v_0，正文 v0，代码 v_init，同一物理量三种写法
  - 同一符号 v 在第三章表示"速度"、在第五章表示"体积"，未做区分导致歧义
- 一个符号只表示一个物理量
- 全文使用同一符号
- 使用国际通用符号
- 所有符号都要在符号表中定义

### M5: 边界条件必须明确列出
- **防御层次**: L3 过程验证
- **典型反例**:
  - ODE 只给方程不给初始条件，求解器报错或静默使用默认零初值，结果错误
  - 优化问题不给变量上下界，求解器返回物理不可行解（如负数量、超大值）
  - 约束漏非负（数量为负）、漏整数约束（人数为小数）、漏容量约束（超载）
- 初始位移、初始速度
- 固定边界、自由边界
- 周期边界条件
- 所有约束条件

### M6: 启发式算法不能直接宣称全局最优
- **防御层次**: L4 异构验证
- **典型反例**:
  - 遗传算法只跑 1 次就宣称"全局最优解"，无多次运行稳定性验证，可能是局部最优
  - 只报告最优值不报告标准差，掩盖算法对初值敏感的不稳定性
  - 不与精确解/解析解/穷举解对照就下"最优"结论，无法证明非局部最优
- 除非有证明、精确求解对照或足够可信的稳定性验证
- 必须说明算法的局限性
- 必须进行灵敏度分析

### M7: MODEL_SPEC.md 必须包含所有子问题的完整建模方案
- **防御层次**: L1 + L3 结构化输出 + 过程验证
- **典型反例**:
  - 只详细写问题一，问题二/三仅写"类似问题一的方法"，下游 Programmer 无法实现
  - 漏掉某个子问题的代码实现要求或验证要求，导致交付不完整
  - 子问题间依赖关系未说明（问题二需要问题一的结果作为输入但未标注），下游无法串联
- 每个子问题都有完整的建模方案
- 包含问题理解、模型假设、符号定义、模型建立、代码实现要求、验证要求

## 建模防错速查表

> 从历年真题踩坑逆向整理，沉淀至本章防错速查表与下方"建模规范"两节。建模阶段逐条核对，命中即修正。

### 物理防错速查表

| 错误类型 | 典型表现 | 防错方法 |
|---------|---------|---------|
| 坐标系反向 | 题目"z 正向为下"，代码按"z 正向为上"，自由落体 z 值减小 | 报告开头写坐标系定义表；代码注释每行涉及 z 的运算都标注方向 |
| 抛体水平速度丢失 | 炸弹脱离无人机后只算自由落体，忽略载体水平速度 | 脱离瞬时速度=载体速度；运动方程 x(t)=x0+vx·t, z(t)=z0±0.5·g·t²（方向取决于 z 正向） |
| 几何判据误用 | 把"云团到真目标距离"当成"云团到导弹-真目标视线距离" | 明确"点到线段距离"，且投影参数 t∈[0,1] 才算有效遮蔽 |
| 投影区间遗漏 | 云团在导弹后方（t<0）或越过真目标（t>1）仍判为遮蔽 | 距离计算后加 `valid = (t_proj>=0) & (t_proj<=1)` 过滤 |
| 时间上界越界 | 优化变量投放时间 > 导弹到达时间，产生物理不可行解 | T_MAX = 导弹到达时间；优化变量上界 = 物理可行域上界 |
| 硬约束致可行域空 | 差分进化找不到可行解直接报"无解" | 改软惩罚：f = 原目标 + λ·Σ(约束违反量²) |
| 目标函数不连续 | "遮蔽时长"作为目标函数，梯度处处为 0 | 改连续代理目标：如"最小化云团到视线距离" |
| 守恒量未校验 | 数值积分后能量/动量漂移 | 每步打印守恒量，相对误差 > 1e-3 报警 |

### 模型选型速查表

| 题型 | 核心问法 | 典型场景 | 常见陷阱 |
|------|---------|---------|---------|
| 优化类 | 求最大/最小，资源怎么分配 | 路径规划、调度、选址、装箱 | 漏非负约束、整数约束、容量约束、时间窗；连续松弛后不取整重验 |
| 预测类 | 预测未来数值或趋势 | 销量/人口/价格预测 | 数据量<15 用回归失效；时序数据用随机 K-Fold 造成数据泄露 |
| 评价类 | 对多方案综合排序或打分 | 城市评级、供应商选择 | 指标方向未统一；AHP 一致性 CR≥0.1 未检查；TOPSIS 未标准化 |
| 分类/聚类 | 判断对象属于哪类 | 风险识别、客户分群 | 类别不平衡用准确率；未标准化距离；聚类数无依据 |
| 机理/动力学 | 描述系统随时间演化 | 传染病传播、物理仿真 | 漏初始条件；刚性系统用错求解器；守恒量未校验 |
| 多目标 | 多个冲突目标同时优化 | 成本-效益、精度-速度 | 不同量纲直接相加；未做 Pareto 分析；权重主观无敏感性 |

### 子问题识别速查表

| 错误类型 | 典型表现 | 防错方法 |
|---------|---------|---------|
| 子问误当独立问题 | 把"问题 1 的子问 (2)"当成独立子问题，重复建模 | 只认题面明确编号的顶层问题（问题一/二/三） |
| 漏读附件字段 | 附件有 8 列数据只用了 5 列，漏掉关键约束字段 | 解析阶段逐列登记字段名、含义、单位、取值范围 |
| 混淆约束语义 | "不超过"当"小于"、"至少"当"大于"，边界值丢失 | 逐条标注：≤ / < / ≥ / > / =，边界值是否含等号 |

### 假设防错速查表

| 错误类型 | 典型表现 | 防错方法 |
|---------|---------|---------|
| 假设只列不验证 | 列 10 条假设但无四维评分，无合理性范围 | 每条假设填四维评分表，标注合理范围与影响参数 |
| 假设正文未引用 | 假设列了但建模处从未引用"由假设 H1 可知" | 每条假设在建模处显式引用编号 |
| 假设无灵敏度 | "假设匀速"但不扰动速度值，假设形同虚设 | 关键假设必须进灵敏度分析（±10%、±20%） |

## 铁律新增（对标 mmagent-codex-main）

### M8: 假设敏感性预检（假设敏感必标参数化）
- **防御层次**: L4 异构验证
- **执行机制**: AssumptionValidator 检查 sensitivity 标记
- **规则**:
  1. 对每个关键假设，必须标注其"敏感性"（高/中/低）
  2. 高敏感性假设必须标记为"可参数化"，在 Programmer 手做 ±20% 灵敏度扫描
  3. 假设敏感性预检结果记录在 assumption_validation.json 的 sensitivity_flags 字段
- **违反后果**: 未标记假设敏感性的 MODEL_SPEC 不得进入 Programmer 手

### M9: 防数据泄露（赛题数据仅用于分析，不写入论文）
- **防御层次**: L5 运行时护栏
- **执行机制**: Guardrails 检查内部数据引用
- **规则**:
  1. 赛题原始数据文件路径不得出现在 MODEL_SPEC 中
  2. 赛题敏感数值（如真实企业数据）不得直接写入论文正文
  3. 建模过程中使用的数据必须在 MODEL_SPEC 中声明来源与处理方式
- **违反后果**: 发现裸数据路径或敏感数值，L5 护栏 FAIL，退回修正

## 建模规范（方法选型 / 物理过程逐项校验 / 结果约束契约）

> 供 method-matcher / model-builder / assumption-validator 建模阶段逐条执行。下方"结果约束契约"由 Programmer 的 test-runner / result-verifier 逐条验证，是 MODEL_SPEC 向 CODE_DELIVERABLES 传递的硬契约。

### 模型选型决策树

```
要预测未来数值？
  数据量 < 15 → GM(1,1) 灰色预测
  纯时序、无外部变量 → ARIMA / 指数平滑
  有多个影响因素 → 线性回归 / 随机森林 / XGBoost
  非线性很强 → LSTM / XGBoost

要评价/排序/选方案？
  需要体现专家经验 → AHP（CR < 0.1）
  完全客观数据驱动 → 熵权法
  方案间距离排序 → TOPSIS（先标准化再算距离）
  指标含模糊语言 → 模糊综合评价
  数据少、信息不全 → 灰色关联分析

要优化（求最大/最小）？
  线性目标和约束 → 线性规划 LP
  含整数/0-1 变量 → 整数规划 MIP
  非线性 → 遗传算法 / 模拟退火（多起点 + 种子固定）
  多目标冲突 → NSGA-II / 加权和法

要建机理模型？
  连续时间系统 → ODE（SIR、Logistic 增长）
  离散时间系统 → 差分方程 / 马尔可夫链
  不确定性/风险 → 蒙特卡洛模拟
```

### 统计检验速查

| 目的 | 推荐方法 | 适用条件 |
|------|---------|---------|
| 两组均值差异 | t 检验 | 正态分布，方差齐性 |
| 多组均值差异 | 单因素 ANOVA | 正态分布，方差齐性 |
| 非参数两组比较 | Mann-Whitney U | 不要求正态 |
| 变量相关性 | Pearson / Spearman | Pearson 要求正态 |
| 时序平稳性 | ADF 单位根检验 | — |

### 物理过程逐项校验清单（机理类赛题强制，未通过不得进入 Programmer 手）

对运动学、动力学、几何遮蔽、电磁、热传导、流体等机理类赛题，在模型选择阶段必须完成以下 5 项并逐条写入 `work/ANALYSIS_MODELING_REPORT.md`：

1. **坐标系定义表**：原点、各轴正向（如"z 正向为下"）、单位；全文（假设/公式/代码/图注）必须同一套坐标系。
2. **实体运动分解表**：每个运动实体独立一行（初值位置、初值速度、受力/加速度、约束、轨迹方程）；脱离载体的物体必须显式写"保留脱离瞬时载体平动速度"。
3. **几何判据核对**：涉及"视线/连线/相交/遮蔽/碰撞"须明确是"点到点距离""点到线段距离（含投影区间 t∈[0,1]）"还是"点到无限直线距离"，并标注投影区间是否需要约束。
4. **事件时序因果链**：按物理因果列出关键事件（如 投放→起爆→云团形成→遮蔽），标注硬时间边界（如"所有投放时刻 < 导弹到达时间"）。
5. **解析解清单**：列出每个可解析子过程（匀速直线/平抛/自由落体/球体-线段相交）的解析公式，供 Programmer 手与数值解交叉验证（相对误差 ≤ 1%）。

### 结果约束契约（写入 MODEL_SPEC，Programmer 逐条验证）

模型建立阶段必须输出以下三段，编码阶段逐条验证；无解析解时降级为参数取 0/极端值的退化校验。

**结果约束清单（硬边界）**
- [变量名] ∈ [下界, 上界]，物理含义：[为什么是这个范围]
- [守恒量]：[应满足的恒等式或误差上限]

**预期行为**
- 时间尺度：系统应在何时达到什么状态；稳态特征：哪些量应趋于常数/周期/衰减；单调性/对称性：哪些量应单调递增/对称。

**异常处理预案**
- 若出现 [具体异常] → 原因判断 → 唯一修正方法 →（禁止的替代方案）。

### 题型防错速查

- **优化/调度/路径**：不漏非负/整数/容量/时间窗约束；连续松弛后说明取整策略；非凸做多起点稳定性检查。
- **多目标**：先对各目标独立无量纲化，再加权或 Pareto 分析；不直接相加不同量纲指标。
- **微分方程/动力学**：写清状态变量单位、初始条件、边界条件；刚性系统用 Radau/BDF；检查守恒量与步长收敛。
- **统计/预测**：时序按时间划分；标准化只在训练集 fit；检查残差、多重共线性、外推范围。
- **评价/决策**：正向/负向指标先统一方向，权重和为 1；AHP CR<0.1；TOPSIS 先标准化再算距离。
- **图论/网络**：明确有向/无向；负权不能用 Dijkstra；最大流满足流量守恒；TSP/VRP 防子回路。
