### 工程优化铁律（编程手必须遵守）

- 每个优化变量必须有**物理上界和下界**。模型是桌面缩尺（高几百 mm），结果出现数米构件即为物理不可行。
- 连续松弛解的取整必须明确策略（上取整 / 就近取整 + 修复），不能四舍五入后不管可行性。
- 求解器 `success` 不等于最优：必须回代所有约束，输出每条约束的值 / 边界 / 松弛量 / 是否活跃。
- 非凸 / 启发式算法必须多起点（≥5 次）或多种子稳定性检查，报告均值 ± 标准差，不能只给最好一次结果。
- `scipy.optimize.minimize` 只做最小化；最大化利润 / 覆盖率时目标函数必须取负，结果记录还原真实值。
- `scipy` 约束方向是 `fun(x) >= 0`；容量约束、下界约束最易写反，写完必须代入边界点验证符号。
