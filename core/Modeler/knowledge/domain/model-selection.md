# 模型选择决策树

> 使用说明：根据问题类型、数据特征、计算资源，自动匹配最优模型。

---

## 一、总体决策流程

```
问题类型 → 数据特征 → 模型候选 → 评估指标 → 最优选择
```

---

## 二、问题类型判断

### 2.1 第一层：监督/非监督

```
有标签？
├── 是 → 监督学习
└── 否 → 非监督学习
    ├── 有聚类需求 → 聚类
    ├── 有降维需求 → 降维
    └── 有异常检测需求 → 异常检测
```

### 2.2 第二层：分类/回归

```
目标变量类型？
├── 类别变量 → 分类问题
│   ├── 二分类 → 二分类模型
│   └── 多分类 → 多分类模型
└── 数值变量 → 回归问题
    ├── 单输出 → 单输出回归
    └── 多输出 → 多输出回归
```

### 2.3 第三层：时间序列/静态

```
数据有时间顺序？
├── 是 → 时间序列问题
│   ├── 单变量 → 单变量预测
│   └── 多变量 → 多变量预测
└── 否 → 静态数据问题
```

## 三、分类问题决策树

### 3.1 二分类

```

├── < 100 → 简单模型

### 3.2 多分类

## 四、回归问题决策树

### 4.1 线性关系判断

```
散点图/相关系数？
├── 强线性关系 (|r| > 0.7) → 线性模型
│   ├── 线性回归
│   ├── 岭回归
│   └── LASSO
├── 弱线性关系 (0.3 < |r| < 0.7) → 混合模型
│   ├── 多项式回归
│   ├── 决策树
│   └── 随机森林
└── 非线性关系 (|r| < 0.3) → 非线性模型
    ├── 神经网络
    ├── XGBoost
    └── 核回归
```

### 4.2 样本量与维度

```
样本量/特征数？
├── 样本 > 10倍特征 → 标准方法
│   ├── 随机森林
│   ├── XGBoost
│   └── 神经网络
├── 样本 ≈ 特征 → 正则化方法
│   ├── 岭回归
│   ├── LASSO
│   └── ElasticNet
└── 样本 < 特征 → 高维方法
    ├── PCA回归
    ├── 岭回归
    └── 稀疏模型
```

### 4.3 特殊回归

```
目标变量特征？
├── 正值连续 → Gamma回归
├── 计数数据 → Poisson回归
├── 有序类别 → 有序回归
└── 生存数据 → Cox回归
```

## 五、时间序列决策树

### 5.1 平稳性判断

```
ADF检验p值？
├── < 0.05 (平稳) → 平稳模型
│   ├── ARMA
│   ├── ARIMA(p,0,q)
│   └── 指数平滑
└── > 0.05 (非平稳) → 差分后建模
    ├── 一阶差分 → ARIMA(p,1,q)
    └── 二阶差分 → ARIMA(p,2,q)
```

### 5.2 季节性判断

```
有季节性？

│   ├── SARIMA
│   ├── 季节指数平滑
│   └── Prophet
└── 否 → 非季节模型
    ├── ARIMA
    ├── 简单指数平滑
    └── 神经网络
```

### 5.3 预测步长

```
预测步长？
├── 短期 (< 10步) → 统计模型
│   ├── ARIMA
│   ├── 指数平滑
│   └── 线性回归
├── 中期 (10-50步) → 混合模型
│   ├── ARIMA + 神经网络
│   ├── Prophet
│   └── 状态空间模型
└── 长期 (> 50步) → 深度学习

## 七、模型评估指标

### 7.1 分类指标

| 指标 | 适用场景 | 计算公式 |
|------|---------|---------|
| 准确率 | 类别平衡 | (TP+TN)/(TP+TN+FP+FN) |
| 精确率 | 关注假阳性 | TP/(TP+FP) |
| 召回率 | 关注假阴性 | TP/(TP+FN) |
| F1 | 平衡精确召回 | 2*P*R/(P+R) |
| AUC | 不平衡数据 | ROC曲线下面积 |
| KS | 信用评分 | max(TPR-FPR) |

### 7.2 回归指标

| 指标 | 适用场景 | 特点 |
|------|---------|------|
| MSE | 通用 | 对大误差敏感 |
| RMSE | 通用 | 与目标同单位 |
| MAE | 异常值多 | 更鲁棒 |
| MAPE | 比较不同量级 | 百分比误差 |
| R² | 解释方差 | 0-1之间 |

## 十、使用方法

### 10.1 决策流程

1. **确定问题类型**: 分类/回归/聚类
2. **分析数据特征**: 样本量、维度、分布
3. **考虑资源约束**: 时间、内存
4. **选择候选模型**: 2-3个
5. **交叉验证对比**: 选择最优
6. **调优参数**: 微调性能

### 10.2 注意事项

- **没有免费午餐**: 没有模型在所有问题上都最好
- **简单优先**: 能用简单模型解决就不要复杂
- **集成方法**: 不确定时用集成学习
- **业务理解**: 模型选择要考虑业务需求

## 十一、优化问题的物理可行性铁律（必读，高频失分点）

> 来源：MathModelAgent modeler.py（竞争分析 A-2）。优化类赛题最容易被扣分的地方不是模型精度，而是解在物理上根本不可行。

**核心铁律**：优化绝不能只追求数学极值，必须考虑物理可行性。

- **每个优化变量必须有物理上界和下界**。典型错误：题目是缩尺桌面模型（构件高度仅几百 mm），优化结果却给出数米长的构件——物理上根本放不下。
- **在方案 / 论文中显式写出「约束化」过程**：先报告无约束解，再说明它违反哪条物理限制，最后给出加约束后的解。格式：

```
无约束最优解为 X* = ...，但其对应构件长度 L = ... 超出题目装配空间上限
L_max = ...，物理上不可行。故引入约束 L ≤ L_max，重解得约束最优解
X' = ...，对应 L' ≤ L_max，满足物理可行性。
```

- **约束来源清单**：尺寸 / 质量 / 载荷 / 时间 / 成本 / 材料可制造性，尤其是题目给出的确界（如 `H=200mm`、`m=3kg` 这类确定物理常量）。

**校验项**（建模完成后自查）：
1. 每个决策变量的取值范围是否都已显式给定上下界？
2. 上下界是否来自题目条件 / 物理定律，而非拍脑袋？
3. 无约束解若越界，是否已在结果中明确"引入约束 YY ≤ YY_max"？

## 十二、EDA 方案要求（区分机理题 vs 数据题，反套路）

> 来源：MathModelAgent modeler.py（竞争分析 A-3）。机理题套数据分析模板是评委一眼识破的硬伤。

**先判断题目参数的性质**，再决定是否做描述性统计：

| 题目类型 | 参数性质 | EDA 正确做法 | 禁止 |
|---|---|---|---|
| 物理 / 力学机理题（如 `H=200mm`、`m=3kg`，参数是题目给定的**确定物理常量**） | 物理常量，无分布 | 几何关系推导、参数物理一致性验证、量纲检查 | **不写描述性统计**、不画直方图 / 箱线图、不提"异常值清洗"（评委会判定你在套数据分析模板） |
| 数据驱动题（**大量样本、有分布**） | 数据集，有分布 | 完整 EDA：分布、相关性、缺失值、异常值、归一化 | （无） |

**判别口诀**：题目给的是"一个数"还是"一堆数"？一个数 → 机理题，走推导；一堆数 → 数据题，走 EDA。

**机理题 EDA 应聚焦**：
- 几何关系与坐标系的推导
- 参数物理一致性与量纲检查（如单位是否自洽）
- 边界条件与初始条件的合理性

不聚焦于此而去做描述性统计，会被判定为"背模板写作"。
