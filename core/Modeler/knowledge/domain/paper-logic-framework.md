# 论文逻辑框架

> 使用说明：在写作前，用此框架组织论文逻辑，确保论证清晰、主线明确。

---

## 一、整体逻辑结构

### 1.1 黄金圈法则
```
Why: 为什么要做这个问题？（问题背景、意义）
How: 怎么解决的？（方法、模型）
What: 得到了什么结果？（结论、贡献）
```

### 1.2 论文主线
```
问题提出 → 问题分析 → 模型建立 → 模型求解 → 结果验证 → 结论总结
    ↓           ↓           ↓           ↓           ↓           ↓
  背景意义    影响因素    数值方法    算法实现    灵敏度分析   创新点
  文献综述    假设条件    目标函数    参数设置    对比实验     局限性
```

---

## 二、章节逻辑设计

### 2.1 问题重述（1-2页）
**逻辑**: 从原题到建模问题的转化

```
原题 → 问题分解 → 建模任务 → 输入输出
```

**必须回答**:
- 题目要求什么？
- 需要解决哪些子问题？
- 最终输出是什么？

### 2.2 问题分析（2-3页）
**逻辑**: 展示你对问题的理解深度

```
影响因素分析 → 因素间关系 → 简化假设 → 建模思路
```

**必须包含**:
- 因素识别（头脑风暴）
- 因素关系图（流程图/关系图）
- 关键假设（带理由）
- 整体建模框架（技术路线图）

### 2.3 模型假设（1页）
**逻辑**: 为后续建模奠定基础

```
假设1: [内容] → 理由: [解释] → 影响: [说明]
假设2: [内容] → 理由: [解释] → 影响: [说明]
...
```

**原则**:
- 每个假设必须有理由
- 明确假设带来的影响
- 不能隐藏关键假设

### 2.4 符号说明（0.5页）
**逻辑**: 统一符号，便于阅读

```
| 符号 | 含义 | 单位 |
|------|------|------|
| x    | 决策变量 | m   |
| f    | 目标函数 | W   |
```

### 2.5 模型建立（5-10页）
**逻辑**: 从假设到数学表达

```
分析 → 建模 → 公式推导 → 约束条件 → 完整模型
```

**每个子模型**:
1. 问题描述（文字）
2. 数学表达（公式）
3. 参数说明（表格）
4. 模型解释（为什么这样建）

### 2.6 模型求解（5-10页）
**逻辑**: 从模型到算法

```
求解策略 → 算法设计 → 参数设置 → 伪代码 → 实现
```

**必须包含**:
- 为什么选这个算法
- 算法流程图
- 关键参数设置
- 收敛性分析

### 2.7 结果分析（3-5页）
**逻辑**: 从数据到结论

```
结果展示 → 结果解释 → 灵敏度分析 → 对比实验 → 稳健性
```

**必须包含**:
- 多角度展示（表格+图）
- 结果解释（为什么这样）
- 灵敏度分析（参数影响）
- 对比实验（和基线/其他方法）
- 稳健性分析（结论是否稳定）

### 2.8 模型评价（2-3页）
**逻辑**: 展示批判性思维

```
优点 → 缺点 → 改进方向
```

**必须诚实**:
- 优点要具体（不能泛泛而谈）
- 缺点要真实（不能回避）
- 改进要可行（不能空谈）

## 三、论证逻辑模板

### 3.1 方法选择论证
```
"针对XX问题，现有方法包括A、B、C。
A方法的优点是XX，缺点是XX；
B方法的优点是XX，缺点是XX；
C方法的优点是XX，缺点是XX。
综合考虑，本文选择XX方法，因为：
1. [理由1]
2. [理由2]
3. [理由3]"
```

### 3.2 创新点论证
```
"与现有方法相比，本文的创新点包括：
1. 创新点1: [描述] → 优势: [解释] → 验证: [实验]
2. 创新点2: [描述] → 优势: [解释] → 验证: [实验]
..."
```

### 3.3 结果解释论证
```
"从图X可以看出，[现象描述]。
这是因为[原因分析]。
这一结果与[文献/理论]一致/不同，说明[结论]。"
```

## 四、过渡句模板

### 4.1 章节过渡
```
"在上一章中，我们建立了XX模型。
本章将介绍如何求解该模型。"
```

### 4.2 小节过渡
```
"基于上述分析，我们接下来将...
首先，...
其次，...
最后，..."
```

### 4.3 段落过渡
```
"除了XX因素外，YY因素也会影响...
此外，ZZ因素同样重要..."
```

## 五、总结与讨论逻辑

### 5.1 结论总结
```
"本文针对XX问题，建立了YY模型。
主要贡献包括：
1. [贡献1]
2. [贡献2]
3. [贡献3]

通过XX验证，结果表明...
"
```

### 5.2 局限性讨论
```
"本文的局限性包括：
1. [局限1] → 可能影响: [说明] → 改进方向: [建议]
2. [局限2] → 可能影响: [说明] → 改进方向: [建议]
..."
```

### 5.3 未来工作
```
"未来可以从以下方向改进：
1. [方向1]
2. [方向2]
..."
```

## 六、常见逻辑错误

### 6.1 跳步
❌ 错误: "我们使用遗传算法，结果如图X所示"
✅ 正确: "我们选择遗传算法，因为...，算法流程如图X所示，参数设置如表Y所示"

### 6.2 循环论证
❌ 错误: "因为我们假设X成立，所以模型有效"
✅ 正确: "假设X的合理性在于...，验证表明..."

### 6.3 过度推广
❌ 错误: "本文方法可以解决所有XX问题"
✅ 正确: "本文方法适用于XX条件下的YY问题"

### 6.4 因果混淆
❌ 错误: "A和B相关，所以A导致B"
✅ 正确: "A和B存在相关性，可能的原因包括..."

## 七、检查清单

### 7.1 逻辑检查
- [ ] 每个结论是否有依据
- [ ] 每个假设是否有理由
- [ ] 每个创新点是否有验证
- [ ] 是否有跳步或循环论证

### 7.2 完整性检查
- [ ] 问题分析是否充分
- [ ] 模型建立是否完整
- [ ] 结果分析是否深入
- [ ] 评价是否诚实

### 7.3 流畅性检查
- [ ] 章节之间是否有过渡
- [ ] 段落之间是否有衔接
- [ ] 读者能否跟上你的思路
