# 写作范式库

> 从获奖论文中提取的写作模式、句式、过渡方式，提升论文表达质量。

---

## 一、开头范式

### 1.1 问题背景引入
```
"随着...的发展，...问题日益突出。
...在...领域具有重要意义。
然而，现有方法存在...的不足。"
```

### 1.2 问题重述
```
"本文针对...问题，研究如何...。
具体而言，需要解决以下子问题：
（1）...；（2）...；（3）...。"
```

### 1.3 贡献声明
```
"本文的主要贡献包括：
（1）提出了...方法，解决了...问题；
（2）建立了...模型，实现了...；
（3）通过...验证，证明了...。"
```

---

## 二、方法描述范式

### 2.1 方法选择
```
"针对...问题的特点，本文选择...方法。
相比于...方法，...方法具有以下优势：
（1）...；（2）...；（3）...。"
```

### 2.2 模型建立
```
"基于上述分析，本文建立如下数学模型：
...
其中，式（1）表示...，式（2）表示...。"
```

### 2.3 算法描述
```
"本文采用...算法求解上述模型，算法流程如下：
步骤1：...；
步骤2：...；
步骤3：...。
算法的时间复杂度为O(...)。"
```

---

## 三、结果分析范式

### 3.1 结果展示
```
"图X展示了...的结果。
从图中可以看出...。
具体而言，当...时，...；当...时，...。"
```

### 3.2 结果解释
```
"上述结果的原因是...。
这与...的理论/实验结果一致/不同。
可能的解释是...。"
```

### 3.3 灵敏度分析
```
"为分析参数...对结果的影响，本文进行了灵敏度分析。
如图X所示，当...从...变化到...时，...变化了...%。
结果表明，...对...的影响较大/较小。"
```

---

## 四、过渡范式

### 4.1 章节过渡
```
"在上一章中，我们建立了...模型。
本章将介绍如何求解该模型。
首先，...；其次，...；最后，...。"
```

### 4.2 段落过渡
```
"除了上述因素外，...也是影响...的重要因素。
本文进一步考虑...，建立...。
此外，...也会对...产生影响，因此...。"
```

### 4.3 方法对比过渡
```
"为验证本文方法的有效性，本文将其与...方法进行对比。
对比指标包括...。
实验结果如表X所示。"
```

## 五、讨论范式

### 5.1 优点讨论
```
"本文方法具有以下优点：
（1）...，可以...；
（2）...，有助于...；
（3）...，提高了...。"
```

### 5.2 缺点讨论
```
"本文方法也存在以下局限性：
（1）...，可能导致...；
（2）...，限制了...；
（3）...，影响了...。"
```

### 5.3 改进方向
```
"未来可以从以下方向改进：
（1）引入...，以解决...问题；
（2）采用...，以提高...；
（3）结合...，以增强...。"
```

## 七、常用句式库

### 7.1 因果关系
```
"由于...，因此..."
"因为...，所以..."
"...导致了..."
"...使得..."
"这主要是因为..."
```

### 7.2 对比关系
```
"与...相比，..."
"不同于...，..."
"...而..."
"相比之下..."
"一方面...，另一方面..."
```

### 7.3 递进关系
```
"此外..."
"进一步..."
"更重要的是..."
"不仅如此..."
"在此基础上..."
```

### 7.4 转折关系
```
"然而..."
"但是..."
"不过..."
"尽管如此..."
"虽然...，但是..."
```

```

```

### 8.2 表标题
```
"表X ...的结果对比
注：...表示...，...表示..."
```

### 8.3 坐标轴
```
横轴: "..." (单位)
纵轴: "..." (单位)
图例: .../.../...
```

## 九、学术表达规范

### 9.1 避免的表达
```
❌ "我认为..."
✅ "本文认为..."

❌ "这个方法很好..."
✅ "该方法具有...优势"

❌ "结果显示..."
✅ "实验结果表明..."

❌ "可能是因为..."
✅ "可能的原因是..."
```

### 9.2 精确表达
```
❌ "提高了..."
✅ "提高了...%"

❌ "相关性较高..."
✅ "相关系数为0.85"

❌ "误差较小..."
✅ "均方根误差为0.02"
```

### 9.3 客观表达
```
❌ "显然..."
✅ "结果表明..."

❌ "毫无疑问..."
✅ "可以认为..."

❌ "毫无疑问..."
✅ "实验验证了..."
```

## 十、检查清单

### 10.1 表达检查
- [ ] 是否使用了学术表达
- [ ] 是否避免了口语化
- [ ] 是否保持了客观性
- [ ] 是否使用了精确数字

### 10.2 逻辑检查
- [ ] 章节之间是否有过渡
- [ ] 段落之间是否有衔接
- [ ] 因果关系是否清晰
- [ ] 对比是否公平

### 10.3 完整性检查
- [ ] 问题背景是否介绍
- [ ] 方法选择是否说明
- [ ] 结果分析是否深入
- [ ] 结论是否总结
