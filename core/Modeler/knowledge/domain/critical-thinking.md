# 批判性思维检查清单

> 使用说明：在论文定稿前，逐项检查，强制反思创新点和逻辑漏洞。

---

## 一、创新点检查

### 1.1 创新性自问
- [ ] **我的方法和别人有什么不同？**（如果答案是"没有"，需要重新思考）
- [ ] **这个创新点是"真正的创新"还是"换个说法"？**
- [ ] **创新点是否有理论/实践支撑？**（不能凭空想象）
- [ ] **创新点是否可验证/可复现？**

### 1.2 创新点分级
| 级别 | 描述 | 示例 |
|------|------|------|
| A级 | 方法创新 | 提出新算法/新模型 |
| B级 | 应用创新 | 将已有方法应用到新领域 |
| C级 | 组合创新 | 将多个方法有机结合 |
| D级 | 参数改进 | 调整参数提高性能 |
| E级 | 无创新 | 直接套用现有方法 |

**目标**: 至少达到C级

### 1.3 创新点表述
```
好的表述: "针对传统遗传算法易陷入局部最优的问题，本文提出了一种基于自适应变异率的改进遗传算法..."
差的表述: "本文使用遗传算法求解..."
```

---

## 二、逻辑漏洞检查

### 2.1 前提假设
- [ ] **假设是否合理？**（能否用物理/经济/常识解释）
- [ ] **假设是否过于理想化？**（现实中是否成立）
- [ ] **假设是否明确说明？**（不能隐藏假设）

### 2.2 因果关系
- [ ] **相关性≠因果性**（是否混淆了两者）
- [ ] **是否遗漏了混淆变量？**
- [ ] **时间顺序是否正确？**（因在前，果在后）

### 2.3 推理过程
- [ ] **每一步推理是否有依据？**
- [ ] **是否跳步了？**（读者能否跟上）
- [ ] **结论是否过度推广？**（从特例到一般的合理性）

---

## 三、替代方案检查

### 3.1 方法对比
- [ ] **为什么选这个方法而不是其他？**（必须回答）
- [ ] **是否尝试了多种方法？**（至少3种）
- [ ] **对比结果是否支持你的选择？**

### 3.2 替代解释
- [ ] **结果是否有其他解释？**
- [ ] **是否排除了其他可能性？**
- [ ] **结论是否唯一？**

### 3.3 敏感性分析
- [ ] **参数变化对结果影响大吗？**
- [ ] **结论是否稳健？**
- [ ] **边界条件是否测试？**

---

## 四、局限性检查

### 4.1 模型局限
- [ ] **模型的适用范围是什么？**
- [ ] **哪些情况下模型会失效？**
- [ ] **简化假设带来了什么误差？**

### 4.2 数据局限
- [ ] **数据量是否足够？**
- [ ] **数据质量如何？**
- [ ] **样本是否有代表性？**

### 4.3 计算局限
- [ ] **计算复杂度如何？**
- [ ] **是否可以扩展到更大规模？**
- [ ] **运行时间是否可接受？**

---

## 五、写作质量检查

### 5.1 逻辑流畅性
- [ ] **章节之间是否有过渡？**
- [ ] **论证是否有主线？**
- [ ] **读者能否理解你的思路？**

### 5.2 表达准确性
- [ ] **术语使用是否一致？**
- [ ] **公式符号是否定义？**
- [ ] **图表是否清晰？**

### 5.3 完整性
- [ ] **问题背景是否介绍清楚？**
- [ ] **相关工作是否综述？**
- [ ] **结论是否总结到位？**

---

## 六、同行评审模拟

### 6.1 评审问题清单
假设你是审稿人，会问什么问题？

1. **"为什么选择这个方法？"**
2. **"你的创新点是什么？"**
3. **"结果是否可复现？"**
4. **"有没有考虑XX情况？"**
5. **"和现有方法比有什么优势？"**

### 6.2 防御性回答
对每个问题准备回答：
- 如果能回答 → 说明论文完整
- 如果不能回答 → 需要补充内容

---

## 七、最终检查

### 7.1 一句话总结
用一句话概括你的贡献：
```
"本文提出了____方法，解决了____问题，相比现有方法____优势。"
```

### 7.2 价值评估
- [ ] **这篇论文对竞赛有什么价值？**
- [ ] **如果我是评委，会给这篇论文什么奖？**
- [ ] **这篇论文有什么实际应用价值？**

---

## 使用方法

1. **建模前**: 阅读创新点检查，明确目标
2. **建模中**: 随时检查逻辑漏洞
3. **定稿前**: 完整走一遍所有检查项
4. **提交前**: 模拟同行评审

**核心原则**: 如果某个检查项无法通过，说明需要修改，而不是跳过。
