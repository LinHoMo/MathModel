# 基于计算几何与带阈值启发式搜索的无人机无源定位模型

## 基本信息
- 论文编号: B035
- 题型: B题
- 主题: 无人机纯方位无源定位与位置调整
- 获奖等级: 一等奖

## 一、问题理解
### 1.1 核心问题
研究无人机在编队飞行中通过纯方位无源定位进行位置调整的问题，建立定位模型和调整方案，实现无人机有效定位和位置校正。

### 1.2 子问题分解
- 子问题1: 基于圆形编队，建立三架无人机发射信号时的被动接收无人机定位模型
- 子问题2: 探究除FY00和FY01外，还需几架无人机发射信号才能实现有效定位
- 子问题3: 设计无人机位置调整方案，使所有无人机在理想位置
- 子问题4: 扩展到锥形编队，设计相应的调整方案

### 1.3 输入输出
- 输入: 无人机初始位置信息、圆形/锥形编队要求、信号发射规则
- 输出: 定位模型、位置调整方案、调整后坐标、误差分析

## 二、建模假设
### 2.1 假设列表
| 假设编号 | 假设内容 | 理由 | 影响 |
|---------|---------|------|------|
| H1 | 待测位置的无人机只是相对于预期位置有微小的偏移量 | 实际编队飞行中位置偏差通常较小 | 简化定位问题 |
| H2 | 每架无人机知道自己的编号，可以通过自己的编号进行分析计算 | 无人机编队的基本要求 | 使定位成为可能 |
| H3 | 假设地面完全掌握每一架无人机的任意时刻的位置信息，并可以向无人机发送指令 | 地面控制站的功能 | 便于统一调度 |
| H4 | 无人机对自身位置进行定位时，总是假定发射信号的无人机位置是无偏的 | 简化定位计算 | 可能引入误差 |
| H5 | 无人机总能按照自己计算出来的行进矢量进行运动，不会有机械层面的误差 | 理想化假设 | 简化调整过程 |

### 2.2 关键假设
假设H1和H2是核心假设，它们使得问题在可解范围内，同时保证了定位计算的可行性。

## 三、模型构建
### 3.1 影响因素
- 无人机位置因素：极坐标下的极径ρ和极角θ
- 信号角度因素：无人机接收到的角度信息α_XY
- 编队几何因素：圆形编队半径、无人机间距
- 误差因素：位置偏差、角度测量误差

### 3.2 数学模型
1. **基于正弦定理的定位模型**：
   $$d = \frac{r}{\sin\alpha_{0S_1}} \cdot \sin(\alpha_{0S_1} + \theta - \theta_{S_1})$$
   $$\theta = \arctan\left(\frac{\sin\alpha_{0S_1} \sin(\alpha_{0S_2} + \theta_{S_2}) - \sin\alpha_{0S_2} \sin(\alpha_{0S_1} - \theta_{S_1})}{\sin\alpha_{0S_2} \cos(\alpha_{0S_1} - \theta_{S_1}) + \sin\alpha_{0S_1} \cos(\alpha_{0S_2} + \theta_{S_2})}\right)$$

2. **基于计算几何的定位模型**：
   - 圆心坐标确定：通过旋转向量和叉积确定圆心位置
   - 两圆交点求解：利用对称性避开联立方程
   $$x_R = 2\frac{(y_{0S_1} - y_{0S_2})(x_{0S_2}y_{0S_1} - x_{0S_1}y_{0S_2})}{(x_{0S_1} - x_{0S_2})^2 + (y_{0S_1} - y_{0S_2})^2}$$
   $$y_R = 2\frac{(x_{0S_1} - x_{0S_2})(x_{0S_1}y_{0S_2} - x_{0S_2}y_{0S_1})}{(x_{0S_1} - x_{0S_2})^2 + (y_{0S_1} - y_{0S_2})^2}$$

3. **带阈值的启发式搜索算法**：
   - 估价函数：L2loss函数
   $$L = \sum_{i=1}^{9} d_i^2$$
   - 搜索策略：带阈值的启发式搜索，避免贪心算法的短视性

### 3.3 约束条件
- 无人机位置约束：极角误差≤1°，极径相对误差≤15%
- 信号发射约束：每次至多4架无人机发射信号
- 调整精度约束：阈值ε=10^-4 m

## 四、求解方法
### 4.1 算法选择
1. **正弦定理法**：用于极坐标系下的定位求解
2. **计算几何法**：用于直角坐标系下的定位求解
3. **带阈值的启发式搜索**：用于位置调整方案的优化
4. **仿真模拟**：用于验证定位模型的有效性

### 4.2 算法流程
1. 定位模型建立：采用两种方法（正弦定理法和计算几何法）
2. 无人机最小需求分析：根据误差范围分类讨论
3. 位置调整策略：设计带阈值的启发式搜索算法
4. 锥形编队扩展：采用预先设定信号发射顺序的方案

### 4.3 参数设置
- 圆形编队半径：100m
- 无人机数量：10架（1架圆心，9架圆周）
- 误差范围：极角误差≤1°，极径相对误差≤15%
- 调整精度：阈值ε=10^-4 m
- 搜索阈值：最大搜索层数N

## 五、结果验证
### 5.1 验证方法
1. **两种方法对比**：正弦定理法和计算几何法的结果对比
2. **误差分析**：对极径误差和极角误差进行详细分析
3. **收敛性分析**：分析不同算法的收敛速度
4. **仿真验证**：对锥形编队进行10000次测试验证

### 5.2 灵敏度分析
- 位置偏差对定位精度的影响：偏差越小，定位越准确
- 信号角度误差对定位的影响：误差范围在±1°内可接受
- 搜索阈值对收敛速度的影响：阈值越大，收敛越快但精度可能降低

### 5.3 对比实验
- 不同算法对比：随机选择、贪心算法、带阈值启发式搜索
- 不同定位方法对比：三架无人机定位和四架无人机定位
- 圆形与锥形编队对比：锥形编队需要更复杂的调整策略
