# （A246）CT 系统参数标定及成像

## 基本信息
- 论文编号: A246
- 题型: A题（2017 年 CUMCM A 题教学示例）
- 主题: CT 几何标定与滤波反投影重建
- 获奖等级: 教学示例卡（综合典型写法，非真实论文引用）

## 一、问题理解
### 1.1 核心问题
已知标定模板内若干已知半径、已知相对位置的圆形（球形）介质，利用其在不同旋转角下的投影信息，反演 CT 系统的几何参数（旋转中心、光源-样品距离、探测器方位），进而对待测未知样品实现稳定成像。

### 1.2 子问题分解
- 子问题1: 建立锥束/扇束投影几何模型，推导圆心与投影椭圆质心的关系
- 子问题2: 基于多个投影角的椭圆轮廓数据，标定系统几何参数
- 子问题3: 利用标定结果对待测样品做滤波反投影重建并评估质量

### 1.3 输入输出
- 输入: 标定模板各投影角下的椭圆轮廓（半长轴、半短轴、质心坐标）；待测样品投影数据
- 输出: 几何参数估计（旋转中心坐标、光源距离、探测器倾角）；重建图像（灰度矩阵）

## 二、建模假设
### 2.1 假设列表
| 假设编号 | 假设内容 | 理由 | 影响 |
|---------|---------|------|------|
| H1 | X 射线为直线传播、忽略散射 | 标定模型可解析推导 | 投影几何成立 |
| H2 | 射线强度衰减服从 Beer-Lambert 定律 | 投影值为线积分 | 重建理论前提 |
| H3 | 标定圆为理想圆且参数精确已知 | 反演的基准 | 误差只来自几何参数 |
| H4 | 转台匀速旋转、角位置精确已知 | 角度无需标定 | 减少未知量 |
| H5 | 探测器像素尺寸一致 | 坐标换算线性 | 像素-物理坐标换算 |

### 2.2 关键假设
关键假设为 H1（直线传播）与 H3（标定体参数已知），它们决定了几何反演问题的可解性；H1 失效（散射严重）时须引入散射校正，超出本卡范围。

## 三、模型构建
### 3.1 影响因素
- 光源位置与光源-旋转中心距离 D
- 旋转中心在探测器坐标系中的投影坐标 (u0, v0)
- 探测器平面方位（倾角）
- 标定圆半径与空间位置
- 投影角数目与角度覆盖范围

### 3.2 数学模型
1. 投影几何（锥束）：点光源 S，样品点 P，探测器点 Q 共线：
   Q = S + t·(P - S)，t = D_sd / D_sp
   圆平面（垂直于转轴）在斜投影下的像为椭圆；**椭圆质心 ≠ 圆心的投影**（透视偏心效应），必须用解析式修正：
   偏移量与圆的半径、圆心到光轴距离、D 有关。

2. 标定反演：设待标定参数向量 θ = (u0, v0, D, α)（α 为探测器倾角），对每个投影角 k、每个标定圆 i，理论质心坐标
   q̂_k,i(θ) 由几何模型给出；非线性最小二乘：
   min_θ Σ_k Σ_i ‖q_k,i − q̂_k,i(θ)‖²
   Gauss-Newton / LM 迭代，多起点防局部最优。

3. 重建：滤波反投影（FBP）：
   f(x,y) = ∫_0^π [ p_θ(s) * h(s) ]|_{s = x cosθ + y sinθ} dθ
   其中 h 为 Ram-Lak 滤波器；离散实现为卷积后按几何参数反投影到重建网格。

### 3.3 约束条件
- 几何参数物理可行域：D > 0，|α| < 10°，(u0, v0) 位于探测器范围内
- 角度覆盖：标定须至少覆盖半周（0–180°）
- 标定圆投影不越界、不相互重叠遮挡

## 四、求解方法
### 4.1 算法选择
标定用「多起点非线性最小二乘」（LM 迭代，起点 ≥ 10 组网格+随机扰动），重建用 FBP 为主、SIRT（同时迭代重建）为对照，因为 FBP 解析快速、SIRT 可检验几何参数的敏感性。

### 4.2 算法流程
1. 从投影数据提取各角度椭圆轮廓（边缘检测 + 椭圆拟合）
2. 网格粗扫（D、u0 各 10 点）确定初值邻域
3. LM 多起点精标定，取目标函数最小的解
4. 代入几何参数执行 FBP 重建
5. 用仿真模体验证标定与重建流程，再处理实测数据

### 4.3 参数设置
- 随机种子固定 42（铁律）；标定多起点 ≥ 10，报告 ≥5 次运行的均值±标准差
- 角度采样：0–180°，步长 1°（180 个投影）
- 重建网格 256×256；Ram-Lak 滤波器，截止频率 = 奈奎斯特
- SIRT 对照：迭代 50 次，松弛因子 0.3
- 标定收敛判据：参数相对变化 < 1e-6 或目标函数下降 < 1e-9
- 噪声鲁棒性：对投影加高斯噪声（σ 取投影值均值的 1%/2%/5% 三档），每档蒙特卡洛 ≥ 200 次

## 五、结果验证
### 5.1 验证方法
- 仿真模体（Shepp-Logan 类）全流程闭环：已知几何 → 生成投影 → 标定回收参数 → 重建对比原图（RMSE、SSIM）
- 标定残差分析：各投影角质心残差应无系统性角度趋势
- 重建图像伪影目检 + 定量指标（边缘锐度、均匀区标准差）

### 5.2 灵敏度分析
- 单参数扰动：D、u0、v0、α 各在 ±2%（角度 ±0.5°）扰动，观察重建 RMSE 变化，排序参数敏感度（通常旋转中心坐标最敏感）
- 标定圆个数与位置的影响：减少标定圆或集中于视野中心时标定精度退化

### 5.3 对比实验
- 偏心修正前后标定误差对比（不修正时旋转中心估计系统性偏移）
- FBP vs SIRT 重建质量对比（低噪声下 FBP 足够；高噪声下 SIRT 略优但计算量高一个量级）
- 标定参数误差注入实验：人为注入 ±1% 几何误差，量化其对重建的放大倍数

## 六、创新点提炼
### 6.1 方法创新
- 显式推导并修正投影椭圆质心的透视偏心效应，避免直接把质心当圆心投影的常见错误
- 多起点非线性最小二乘标定流程，粗扫+精化两段式保证全局性

### 6.2 应用创新
- 将几何标定与图像重建串成统一闭环：标定精度直接量化为重建质量损失
- 给出「标定体布局建议」：标定圆应偏离视野中心且半径有差异，以增强参数可辨识性

### 6.3 组合创新
- 解析几何推导 + 数值反演 + 图像重建三层次融合
- 仿真模体闭环验证 + 实测数据应用 + 蒙特卡洛噪声压力测试的组合验证体系

## 七、可借鉴点
### 7.1 写作技巧
- 先讲清「为什么质心≠圆心投影」（配几何示意图），再给公式，评审易懂且认可深度
- 标定结果以「参数估计值 + 95% 置信区间」表格呈现（由多次运行的均值±标准差换算）
- 重建结果用「标定前/标定后」对照图展示增益

### 7.2 建模技巧
- 未知量最小化：角度已知就不标定角度，降低反演病态程度
- 用仿真闭环先行验证全流程，再上实测数据，错误可定位
- 几何参数可行域约束写进优化，避免非物理解

### 7.3 表达技巧
- 流程图：投影提取 → 粗扫 → 精标定 → 重建 → 验证
- 灵敏度龙卷风图展示各几何参数对重建误差的影响排序
- 重建图像统一色标与像素尺寸，保证跨图可比
