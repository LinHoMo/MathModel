# 数据预处理与特征工程（Data Preprocessing）领域知识

## 一、核心概念

### 1.1 定位
- C 题与一切数据驱动建模的**第一道工序**：原始数据不处理直接建模是评审最常见的扣分源。
- 论文必须单列「数据准备」一节：来源、清洗规则、统计描述——这部分质量直接影响可信度。

### 1.2 处理对象
缺失值 / 异常值 / 重复与口径不一 / 量纲差异 / 类别编码 / 时序对齐 / 文本字段。

## 二、基本方法

### 2.1 缺失值处理（决策树）

```text
缺失比例 > 60% 的列 → 考虑删除（须论证信息可替代）
随机缺失（MCAR/MAR）→ 均值/中位数/众数填补，或插值（时序用线性/样条）
非随机缺失（MNAR）→ 不得静默填补：做缺失指示变量 + 敏感性分析
```

```python
import numpy as np

def fill_missing(col: np.ndarray, strategy: str = "median") -> tuple[np.ndarray, int]:
    mask = np.isnan(col)
    n_miss = int(mask.sum())
    if strategy == "median":
        v = np.nanmedian(col)
    elif strategy == "mean":
        v = np.nanmean(col)
    else:
        raise ValueError(strategy)
    col = col.copy(); col[mask] = v
    return col, n_miss
```

### 2.2 异常值检测
- **统计法**: 3σ 原则（正态假设时）；IQR 法：`[Q1-1.5·IQR, Q3+1.5·IQR]` 外为候选异常。
- **领域法**: 物理边界（负的质量、>100% 的比例）优先于统计法。
- **处理必须留痕**: 论文报告「检测数 / 处理方式（剔除、截断、保留）/ 前后结论变化」；异常值剔除后须做敏感性对照（含/不含异常值各跑一遍）。

### 2.3 标准化与归一化
| 方法 | 公式 | 适用 |
|---|---|---|
| Min-Max | (x-min)/(max-min) | 有界、无极端值（TOPSIS/综合评价） |
| Z-score | (x-μ)/σ | 含异常值、回归/聚类 |
| 向量归一化 | x/‖x‖ | 比值型指标 |

**评价类必考**: 正向/负向指标方向统一（负向取倒数或 1-x）；标准化参数用训练集统计量，测试集只套用（防泄漏）。

### 2.4 时序与面板对齐
- 频率不一（年/月/日）须插值或聚合，并注明口径。
- 面板数据标注个体-时间索引；平衡面板检查缺失组合。

### 2.5 特征工程清单（监督学习前）
1. 单变量：分布偏态（log/Box-Cox 变换）
2. 交叉：比率、差值、滞后项（时序）
3. 目标编码/独热编码（类别变量）
4. 相关性筛查：|r|>0.95 的冗余对去其一（防多重共线性）

## 四、常见错误

1. **静默删除异常值**: 不报告剔除量与敏感性，评审视为数据造假嫌疑。
2. **标准化参数泄漏**: 用全集统计量标准化再切分训练/测试。
3. **缺失填补后当真实值**: 填补值必须标注，结论需对填补方式做敏感性。
4. **忽略指标方向**: 负向指标未处理直接进 TOPSIS，排序反转。
5. **口径混用**: 年数据与月数据直接拼接。
