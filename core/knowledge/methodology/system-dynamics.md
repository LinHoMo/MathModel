# 系统动力学方法论

> 本文件提供系统动力学（System Dynamics, SD）的建模方法论：存量-流量图、反馈回路、一阶/二阶线性系统微分方程与定性分析，并以传染病 SIR 模型为典型范例，用 Python 等价表达 Vensim 建模思维。系统动力学偏重**结构**与**长期行为模式**，而非精确点预测。

## 一、方法选择决策树

```
系统问题建模
├── 关注时间动态 + 反馈（因果回路）？
│   ├── 需刻画累积量（存量）及其变化率（流量）→ 存量-流量图
│   ├── 变量间互为因果、随时间迭代 → 微分/差分方程组
│   │   ├── 单存量 → 一阶系统
│   │   ├── 双存量耦合 → 二阶系统（可振荡）
│   │   └── 多个存量/年龄结构 → 方程组 + 数值积分
│   ├── 传染病传播 → SIR / SEIR / SIS 模型
│   └── 人口/资源/经济长期演化 → Logistic / 捕食者-猎物
├── 只看静态相关 / 短周期精确预测？
│   ├── 静态结构 → 回归 / SEM，不用系统动力学
│   └── 高精度逐点预测 → 时间序列/机器学习优先
└── 优化/路径规划？
    └── 优化类问题 → 运筹学，不在 SD 范畴
```

## 二、基本原理：存量-流量图与反馈回路

### 2.1 基本概念

| 图元 | 符号 | 含义 | 示例 |
|------|------|------|------|
| 存量（Stock） | 矩形 | 累积量，随时间的积分 | 感染人数 I、资本存量 K |
| 流量（Flow） | 带阀门的箭头 | 流入/流出速率，改变存量 | 新增感染、出生/死亡 |
| 辅助变量 | 圆/无框字 | 计算中间量 | 感染率 β |
| 因果链 | 实线箭头（+/-） | 变量间同向/反向影响 | 人口↑→接触↑ |
| 反馈回路 | 闭合链路 | 增强（R）或抑制（B）回路 | 传染自我强化 |

**存量方程**（微分形式）：

```
d(Stock)/dt = Inflow - Outflow
Stock(t) = Stock(0) + ∫₀ᵗ (Inflow - Outflow) dt
```

### 2.2 正/负反馈回路

- **正反馈（增强回路 R）**：变化被放大，导致指数增长或崩溃。例：感染人数↑ → 接触传播↑ → 感染人数↑（自我强化）；复利：存款↑ → 利息↑ → 存款↑。
- **负反馈（调节回路 B）**：变化被抑制，趋于稳定或振荡。例：易感者↓ → 新感染↓ → 感染增速↓；温控：温度偏离↑ → 加热/制冷↑ → 偏离↓。

**定性判断**：数回路中「-」号的个数，偶数个负链 = 正反馈，奇数个负链 = 负反馈。

### 2.3 适用条件

| 条件 | 说明 |
|------|------|
| 关注长期行为模式 | 增长/衰减/振荡/超调，而非逐点精确值 |
| 存在反馈与累积 | 变量随时间累积且互为因果 |
| 结构清晰可界定 | 存量的流入流出可被定义与量化 |
| 参数无精确数据也可 | 可做灵敏度/情景分析，看结构敏感性 |

## 三、一阶/二阶线性系统微分方程

### 3.1 一阶线性系统

```
dx/dt = a - b·x,   x(0) = x₀
```

- 解析解：`x(t) = a/b + (x₀ - a/b)·e^(-bt)`，稳定平衡点 `x* = a/b`
- **定性行为**：当 b>0 单调收敛到平衡点（时间常数 τ = 1/b）；b<0 发散
- 典型实例：单室药物代谢、蓄水池进出、Newton 冷却定律

### 3.2 二阶线性系统

```
m·d²x/dt² + c·dx/dt + k·x = F(t)
```

或写作状态空间形式（两个一阶方程）：

```
dx/dt = v
dv/dt = (F - c·v - k·x) / m
```

- 判别式 `Δ = c² - 4mk`：
  - 过阻尼（Δ>0）：单调收敛
  - 临界阻尼（Δ=0）：最快无振荡收敛
  - 欠阻尼（Δ<0）：**衰减振荡**（振荡行为来源）
  - c=0：无阻尼等幅振荡（周期 T = 2π√(m/k)）

**定性分析要点**：二阶系统出现振荡的根本原因是「两个存量之间的延迟反馈」（如弹簧的位移与速度互为因果）。

### 3.3 代码要点（数值积分）

```python
import numpy as np
from scipy.integrate import solve_ivp

def first_order(t, x, a, b):
    return a - b * x

def second_order(t, state, m, c, k, F=0.0):
    x, v = state
    return [v, (F - c * v - k * x) / m]

# 一阶系统
sol1 = solve_ivp(first_order, [0, 10], [0.0], args=(5.0, 1.0),
                 t_eval=np.linspace(0, 10, 200))

# 二阶系统（欠阻尼：c 小）
sol2 = solve_ivp(second_order, [0, 20], [1.0, 0.0], args=(1.0, 0.5, 4.0),
                 t_eval=np.linspace(0, 20, 400))
```

## 四、传染病 SIR 模型（典型范例）

### 4.1 模型方程

SIR 模型将人群分为易感者 S、感染者 I、恢复者（移除）R 三个存量：

```
dS/dt = -β·S·I/N
dI/dt =  β·S·I/N - γ·I
dR/dt =  γ·I
N = S + I + R（常数）
```

- β：单位时间有效接触传染率
- γ：恢复率（1/γ = 平均感染期）
- **基本再生数 R₀ = β/γ**：>1 时疫情爆发，<1 时自然消退
- 结构含一个正反馈（S·I 传染）与一个负反馈（γ·I 移除）

### 4.2 定性分析

- 传播阈值定理：当 `S(0) > γ/β`（即 `β/γ · S(0)/N > 1`），I 先增后减（疫情曲线）；否则单调下降
- 峰值感染：`I_max = N + (γ/β)(ln(γ/β) - ln(S(0)) - 1)`，用 Lambert-W 或求根可得
- 长期：`I(∞) → 0`，`S(∞)` 为超越方程 `ln(S(∞)/S(0)) = -(β/γ)(N-S(∞))/N` 之解

### 4.3 代码要点

```python
import numpy as np
from scipy.integrate import solve_ivp

def sir(t, y, beta, gamma, N):
    S, I, R = y
    dS = -beta * S * I / N
    dI = beta * S * I / N - gamma * I
    dR = gamma * I
    return [dS, dI, dR]

def run_sir(N=1e6, I0=100, beta=0.3, gamma=0.1, days=200):
    R0 = beta / gamma
    S0 = N - I0
    sol = solve_ivp(sir, [0, days], [S0, I0, 0.0],
                    args=(beta, gamma, N), t_eval=np.linspace(0, days, 500))
    S, I, R = sol.y
    peak = I.max()
    print(f"R0 = {R0:.2f}, 峰值感染人数 = {peak:.0f} "
          f"({peak/N*100:.1f}%), 峰值时刻 = {sol.t[I.argmax()]:.0f} 天")
    return sol, R0, peak
```

### 4.4 Vensim 思维的 Python 等价

| Vensim 表达 | Python 等价 |
|------------|-------------|
| 存量（Level）= INTEG(rate, initial) | `solve_ivp` 积分 | 
| 流量 Rate = f(...) | 微分方程右端函数 |
| 时间步 DT | `solve_ivp` 自适应步长 / `t_eval` 网格 |
| 因果回路图 | 手绘/`networkx` 有向图 |
| 灵敏度分析（Monte Carlo） | 对 β/γ 抽样循环跑 `run_sir` |

```python
def sensitivity_analysis(N=1e6, I0=100, runs=5, seed=42):
    """对 beta/gamma 做多次抽样，报告峰值均值与标准差（铁律 P6）"""
    rng = np.random.default_rng(seed)
    betas = rng.uniform(0.2, 0.4, runs)
    gammas = rng.uniform(0.08, 0.15, runs)
    peaks = []
    for b, g in zip(betas, gammas):
        _, _, pk = run_sir(N, I0, beta=b, gamma=g, days=300)
        peaks.append(pk)
    print(f"峰值均值: {np.mean(peaks):.0f}, 标准差: {np.std(peaks):.0f}")
    return np.array(peaks)
```

## 五、建模步骤

```
1. 界定系统边界与时间范围（长期行为 vs 短期预测）
2. 识别存量大集合（累积量）
3. 画出因果回路图，标注正/负反馈回路
4. 绘制存量-流量图，写出微分方程
5. 估计参数（可来自数据拟合或文献）
6. 数值求解（solve_ivp / odeint）
7. 验证：与历史数据对比 + 灵敏度/情景分析
8. 定性结论：行为模式（增长/振荡/门槛）+ 政策启示
```

## 七、常见陷阱与解决方案

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 把 SD 当精确预测 | SD 关注行为模式与结构 | 强调定性结论 + 情景分析，不给逐点精确值 |
| 存量/流量混淆 | 把变化率当存量 | 检查量纲：存量是「量」，流量是「量/时间」 |
| 忽略时间步与数值稳定 | 步长过大 | solve_ivp 自适应步长，或用固定小步长验证 |
| 参数无依据 | 拍脑袋定参 | 数据拟合（curve_fit / least_squares）或文献取值 + 灵敏度 |
| 反馈符号判错 | 少数了负链 | 逐一数「-」个数，偶数=正反馈 |
| 过度复杂 | 状态变量过多不可解释 | 从最小可行模型开始，逐层加复杂度 |
| 忘记报告灵敏度 | 只给单点结果 | 蒙特卡洛抽样（seed=42）报告均值与标准差 |
