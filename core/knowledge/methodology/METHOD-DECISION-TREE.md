# 方法选型决策树（METHOD-DECISION-TREE）

> 供 method-matcher（L2）使用的**结构化选型路径**：先按特征分支收敛到方法族，再在族内对比候选。
> 机器可读版本：`core/knowledge/methodology/METHOD-DECISION-TREE.json`。
> 本文件解决「拍脑袋选模型」：选型必须走完决策树并在产物中记录路径（`decision_path`）。

## 使用流程（method-matcher 执行）

1. 从 `work/type_classification.json` 读取 `topic_type`（A/B/C/D/E）与子问题特征。
2. 对**每个子问题**，从根节点出发回答分支问题，走到叶节点得到方法族。
3. 在叶节点的方法族内选 ≥ `get("modeling.min_candidate_models")` 个实质不同候选。
4. 把走过的分支序列写入候选的 `decision_path` 字段（如 `["数据驱动:是","时序结构:是","样本量:<200"]`）。

## 分支问题定义

| 编号 | 问题 | 判据 |
|---|---|---|
| Q1 | 机理是否主导？ | 题目给出/可推出物理、化学、动力学定律（守恒律、传导、动力学方程） |
| Q2 | 是否有题给数据？ | 附件提供观测/实验/统计数据 |
| Q3 | 决策变量是否离散/含整数约束？ | 选址、指派、调度、开关量、路径 |
| Q4 | 是否含时间演化？ | 状态随时间推进（序列预测、过程仿真、传染病传播） |
| Q5 | 是否为多目标/带权衡？ | 多个互相冲突的目标或成本-收益权衡 |
| Q6 | 样本量与噪声水平？ | 大样本(≥1000)/中样本(200–1000)/小样本(<200)；噪声高低 |
| Q7 | 是否含不确定性？ | 参数随机、场景未知、鲁棒性要求 |
| Q8 | 是否为空间/网络结构？ | 地理分布、图结构、网络流 |

## 主干分支（按题型入口）

### A 题入口（物理/连续机理）

```
Q1=是
├─ 空间场（温度/浓度/形变随位置变化）→ 【PDE/场模型族】
│    候选：有限差分、有限元、解析解+数值校验
├─ 仅时间演化（集总参数）→ 【ODE 动力学族】
│    候选：常微分方程组、离散时间递推、能量/守恒律模型
└─ 机理含参数需拟合 → 【机理+数据混合族】
     候选：参数辨识（最小二乘/贝叶斯）、机理模型+残差修正
```

### B 题入口（离散/组合/决策）

```
Q3=是
├─ Q8=是（网络/路径）→ 【图论与网络优化族】
│    候选：最短路/最小生成树/网络流、启发式（GA/模拟退火）
├─ 规模小（变量<1000）→ 【精确优化族】
│    候选：整数/混合整数规划、动态规划
└─ 规模大或非凸 → 【元启发式族】
     候选：遗传算法、粒子群、模拟退火（须多起点+多种子验证）
Q3=否 且 Q7=是 → 【不确定决策族】
     候选：随机规划、鲁棒优化、蒙特卡洛+期望准则、MDP
```

### C 题入口（数据/统计）

```
Q2=是
├─ Q4=是（时序）
│    ├─ Q6=小样本(<200) → 【经典时序族】
│    │    候选：ARIMA/指数平滑、灰色模型、Holt-Winters
│    └─ Q6=中大样本 → 【时序学习族】
│         候选：LSTM/GRU、树模型滚动预测、ARIMA+机器学习组合
├─ 目标为分类/回归（截面数据）→ 【监督学习族】
│    候选：线性/逻辑回归+树模型（RF/XGBoost/LightGBM）、SVM
│    强制：交叉验证 + 多指标（不只看 R²/准确率）
├─ 无目标变量 → 【无监督族】
│    候选：KMeans/层次聚类、PCA/因子分析
└─ 目标为排名/等级 → 【综合评价族】
     候选：熵权法+TOPSIS、主成分综合评价、组合赋权（AHP+客观权重）
     强制：至少两种赋权口径做灵敏度
```

### D 题入口（多目标/工程系统）

```
Q5=是
├─ 目标可量化 → 【多目标优化族】
│    候选：NSGA-II/NSGA-III、加权法/ε-约束法、理想点法
└─ 目标含主观判断 → 【决策分析族】
     候选：AHP/ANP、模糊综合评价、VIKOR
Q1=是（含工程机理）→ 回到 A 题入口建机理层，外层套优化/决策
```

### E 题入口（交叉/开放）

```
Q2=有数据 → 按 C 题入口选数据方法
Q2=无数据 → 【机理+假设驱动族】
     候选：机理简化模型、Agent-Based 仿真、系统动力学
Q7=是 → 叠加 【不确定性分析】：蒙特卡洛传播、情景分析、灵敏度全局法（Sobol）
```

## 通用叠加层（任何叶节点可附加）

| 叠加层 | 何时加 | 方法 |
|---|---|---|
| 灵敏度分析 | 所有模型（铁律要求） | 单参数扫描、Morris、Sobol |
| 不确定性量化 | 参数/数据有噪声 | Bootstrap、蒙特卡洛、置信区间 |
| 模型验证 | 所有模型 | 交叉验证、留一法、物理量守恒检查 |
| 可解释性 | 机器学习模型用于论文陈述 | 特征重要性、SHAP、偏依赖 |

## 铁律联动

- 决策树**不豁免**候选对比：叶节点只是缩小候选空间，仍须 ≥2 个候选并写对比（M1）。
- 分支答案必须来自 `work/question_spec.json` / `type_classification.json` 的事实，不得臆断；信息不足时分支记 `"unknown"` 并列入假设。
- 物理/业务约束优先级高于拟合优度（M1）：机理可行的弱拟合方案 优于 机理违背的强拟合方案。

## 与既有知识的分工

- `paper-cases/METHOD-MAPPING.md`：方法-题型匹配证据（历史论文怎么用）。
- `paper-cases/INNOVATION-TAGS.md`：在选定族上可叠加的创新点。
- `methodology/INDEX.md`：各方法的详细文档。
- **本文件**：从问题特征到方法族的**收敛路径**，是选型的入口，不是方法细节。
