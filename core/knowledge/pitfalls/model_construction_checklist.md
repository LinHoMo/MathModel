# Model Construction Checklist — 数学建模合理性预检（P13-3B 干预清单）

> 来源：P13-3 首测暴露的三个 failure mode（mathematical 55 的扣分明细）。
> 用法：建模手（model-builder / agent 会话）在模型成型后、实验前逐条自检；
> 每条未过 = 潜在 math_deduction。本清单属 Brain/Knowledge 层，可随失败
> 模式库演进而扩充（每条新增须对应一个真实赛题上的实锤失败）。

## 1. 校准合理性（calibration plausibility）

- [ ] 校准/拟合产生的**每一个**派生量都要做现实合理性检查（年龄结构、
      区间、量级、比例）——"公式能运行"≠"模型正确"。
- [ ] 双参数校准原则：**有生物学/物理/文献锚的参数锚定在合理值**；
      **不可观测的参数**（如幼体存活）才允许吸收校准缺口。
- [ ] 单参数强行吸收缺口导致其他派生量不合理的，视为校准失败
      （实锤：P13-0 2000C m=4.42 → 幼龄份额 61%）。

## 2. 约束完备性（missing constraints）

- [ ] 题面隐含的现实约束逐条排查：容量/承载力、作业能力上限、非负性、
      可行性、守恒/边界。
- [ ] 无法精确定量的约束，**作为情景显式建模并给敏感性**，不得静默省略。
      （实锤：密度制约缺失；搬迁 600-800 头/年的作业上限未入模。）

## 3. 不确定性传播（uncertainty propagation）

- [ ] 前端校准/估计的每一个不确定源必须传播到**所有**下游结论：
      parameter uncertainty → model uncertainty → prediction uncertainty
      → decision uncertainty。
- [ ] 校准后"区间消失"（下游只报点估计）= 结构性缺陷
      （实锤：λ 锚定区间未传入泛化方案表）。

## 4. 口径一致性（consistency）

- [ ] 同一派生量（稳定分布、校准参数、指标口径）全链路使用同一版本，
      并在文档中交叉引用；口径切换必须显式声明并说明理由。

## 5. 声明完备性（P13-3C 盲评实锤新增）

- [ ] **机制方程中引用的每一个参数/系数必须全部列入 parameters 声明**
      （自然死亡率、功能反应系数、回归系数、基准水平——实锤：v1 盲评
      抓到 μ/ω/η/δ/φ/R0 未声明）。
- [ ] **随机过程的实现必须与变量域一致**：无界高斯噪声要有下界保护或
      换成有界过程，否则与变量 domain/约束矛盾（实锤：ε~N(0,σ²) 可产生
      R<0，与 R≥0 及密度因子为正的约束冲突）。
- [ ] **每个对齐点（题目子问）必须能指认模型中承载它的变量/方程**——
      文字表态而模型中无承载通道 = 对齐失败（实锤：MMA 臂 Q1 生态冲击
      通道在模型变量中不存在）。

## 6. 数值口径与符号（P13-3C 第二轮盲评实锤新增）

- [ ] **情景方程的时间量纲必须与滚动步长一致**：年率参数在月步长网格上
      不得按期复利（实锤：年率 g 在月网格按 (1+g)^t 复利）。
- [ ] **松弛/短缺变量的符号不得放松约束**：短缺进入上界时方向必须使约束
      更紧而非更松（实锤：q_t ≤ x_M + s_e——短缺越大上界越松）。
- [ ] **每轮新增 failure mode 必须回写本清单**（本轮：量纲换算 ×1、
      符号方向 ×1、参数未声明 ×3——累计三轮七项）。

## 7. 主张-支持配对（P13-3C Round 4 消融实锤新增——最高优先级）

> 消融发现：对齐干预单独施加时 Mathematical **下降**（65→45、85→20）、
> major 缺陷反超基线——因为对齐映射扩大主张面而支持纪律缺位。

- [ ] **新增的每一个估计量必须有生成通道**：模型动力学能实际产生该量
      （确定性模型不得声称"灭绝概率/方差"类随机量；实锤：确定性无死亡
      模型承诺灭绝概率对比）。
- [ ] **新增耦合必须有饱和/反馈封闭**：单向正反馈（γ·N·P 无饱和、无
      宿主反馈）会发散，物理不可能（实锤：dP/dt = γ_p·N·P − δ_P·P）。
- [ ] **对齐扩张与约束纪律必须同批施加**：只扩主张面不扩支持面 =
      中间态比基线更差（消融实锤：B1-A composite 缺陷多于 B0）。
- [ ] 每个新机制方程的**量纲必须与参数声明一致**（实锤：γ_p 单位 1/yr
      用于质量作用项 γ_p·N·P，需 1/(ind·yr)）。
