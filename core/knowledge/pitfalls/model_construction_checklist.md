# Model Construction Checklist — 数学建模合理性预检（P13-3B 干预清单）

> 来源：P13-3 首测暴露的三个 failure mode（mathematical 55 的扣分明细）。
> 用法：建模手（model-builder / agent 会话）在模型成型后、实验前逐条自检；
> 每条未过 = 潜在 math_deduction。本清单属 Brain/Knowledge 层，可随失败
> 模式库演进而扩充（每条新增须对应一个真实赛题上的实锤失败）。

## 1. 校准合理性（calibration plausibility）

- [ ] 校准/拟合产生的**每一个**派生量都要做现实合理性检查（年龄结构、
      区间、量级、比例）——"公式能运行"≠"模型正确"。
- [ ] 双参数校准原则：**有生物学/物理/文献锚的参数锚定在合理值**；
      **不可观测的参数**（如幼体存活）才允许吸收校准缺口。
- [ ] 单参数强行吸收缺口导致其他派生量不合理的，视为校准失败
      （实锤：P13-0 2000C m=4.42 → 幼龄份额 61%）。

## 2. 约束完备性（missing constraints）

- [ ] 题面隐含的现实约束逐条排查：容量/承载力、作业能力上限、非负性、
      可行性、守恒/边界。
- [ ] 无法精确定量的约束，**作为情景显式建模并给敏感性**，不得静默省略。
      （实锤：密度制约缺失；搬迁 600-800 头/年的作业上限未入模。）

## 3. 不确定性传播（uncertainty propagation）

- [ ] 前端校准/估计的每一个不确定源必须传播到**所有**下游结论：
      parameter uncertainty → model uncertainty → prediction uncertainty
      → decision uncertainty。
- [ ] 校准后"区间消失"（下游只报点估计）= 结构性缺陷
      （实锤：λ 锚定区间未传入泛化方案表）。

## 4. 口径一致性（consistency）

- [ ] 同一派生量（稳定分布、校准参数、指标口径）全链路使用同一版本，
      并在文档中交叉引用；口径切换必须显式声明并说明理由。
