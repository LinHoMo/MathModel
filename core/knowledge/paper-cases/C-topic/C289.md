# （C289）电池剩余放电时间预测

## 基本信息
- 论文编号: C289
- 题型: C题（2016 年 CUMCM C 题；教学示例）
- 主题: 电池满放电时间关系建模与剩余放电时间在线预测
- 获奖等级: 教学示例卡（综合典型写法，非真实论文引用）

## 一、问题理解
### 1.1 核心问题
某电池的满放电时间随放电电流与环境温度变化。需先建立满放电时间与电流、温度的定量关系模型并对新工况做预测；再根据实时运行数据（电流、电压、温度随时间的序列）在线预测电池还能继续放电多长时间，并给出预测误差评估。

### 1.2 子问题分解
- 子问题1: 满放电时间 t_full 与放电电流 I、环境温度 T 的关系建模，预测未测工况下的满放电时间
- 子问题2: 基于实时序列（I(t)、V(t)、T(t)）预测剩余放电时间，支持随放电进程滚动更新
- 子问题3: 模型误差分析与适用边界讨论（何时可信、何时失效）

### 1.3 输入输出
- 输入: 各工况下的放电电流、环境温度、满放电时间实验数据；实时采样序列（电流、电压、温度、时间戳）
- 输出: t_full=f(I,T) 关系式与预测区间；任意时刻的剩余放电时间估计 t_rem 及其置信区间；误差指标

## 二、建模假设
### 2.1 假设列表
| 假设编号 | 假设内容 | 理由 | 影响 |
|---------|---------|------|------|
| H1 | 电池可用容量只随温度缓变，电流的影响经 Peukert 效应进入时间 | 电化学经验规律 | 模型可分离为容量项与指数项 |
| H2 | 采样间隔内电流近似恒定 | 采样频率远高于电流变化频率 | 库仑积分可用分段求和 |
| H3 | 放电至截止电压前无充电恢复现象 | 工况数据为单调放电 | 库仑计数单调递减 |
| H4 | 温度对容量的修正可用线性系数刻画 | 工作温区窄 | 避免过参数化 |
| H5 | 测量噪声独立零均值 | 标准回归前提 | 最小二乘估计有效 |

### 2.2 关键假设
关键假设为 H1（容量-电流分离）与 H3（无恢复效应）：H1 失效表现为残差随电流系统性偏斜，须引入电流-容量交互项；H3 失效（间歇放电恢复）则库仑计数系统性低估剩余容量，须切换为电压法主导。

## 三、模型构建
### 3.1 满放电时间关系模型（Peukert + 温度修正）
1. Peukert 定律：I^n · t_full = C_p(T)，n 为 Peukert 指数（常取 1.05–1.35）。
2. 温度修正：C_p(T) = C_0 · (1 + α(T − T_ref))，T_ref = 25°C。
3. 对数线性化后最小二乘：
   ln t_full = ln C_0 + ln(1 + α(T − T_ref)) − n·ln I
   由回归系数同时估计 n、C_0、α，并给出参数协方差与预测区间。

### 3.2 剩余放电时间模型
1. 库仑计数：Q_rem(t) = Q(T) − ∫₀ᵗ I(s)ds，Q(T) 由 3.1 的容量项换算。
2. 恒流近似：t_rem = Q_rem / I_now；变电流时以近窗电流外推（窗口均值或一阶自回归）后数值积分求耗尽时刻。
3. 电压修正：放电末期电压陡降，用放电曲线 V→SOC 映射把当前电压折算为剩余容量，得 t_rem^V。
4. 阶段加权融合：t_rem = w·t_rem^A + (1−w)·t_rem^V，平坦段（电压变化率小）w=0.8 库仑主导，末期（电压变化率超阈值）w=0.3 电压主导。

### 3.3 约束与边界
- 预测值非负且不超过当前工况满放电时间
- 截止电压为放电终止判据
- 外推工况（I、T 超出数据范围）须显式标注并放宽区间

## 四、求解方法
### 4.1 算法选择
满放电关系用对数线性回归（可解释、参数少），剩余时间用库仑计数+电压映射双轨融合，因为库仑计数在平坦段稳、电压法在末期稳，单轨都有系统偏差区间。

### 4.2 算法流程
1. 数据预处理：剔除异常采样、对齐时间戳、按工况分组
2. 拟合 Peukert-温度模型：对数线性最小二乘 + 非线性最小二乘（Levenberg–Marquardt）多起点（≥10 起点）复核全局性
3. 留一工况交叉验证：逐一留出工况预测满放电时间
4. 实时预测：梯形法库仑积分（按实际采样间隔）→ 电压映射修正 → 阶段加权融合
5. 不确定性：参数协方差传播 + 自助法（≥200 次）给出 t_rem 的 95% 预测区间
6. 滚动回放：用全程数据逐时刻回放，统计预测误差随放电深度的变化

### 4.3 参数设置
- 随机种子固定 42（铁律）；自助与划分报告 ≥5 次独立运行均值±标准差
- Peukert 指数 n 搜索范围 1.05–1.35；温度系数 α 初值范围 −0.01–0.01/°C；T_ref = 25°C
- 电流外推窗口：30–60 采样点起步，灵敏度 15–120
- 电压映射曲线：按电流分档拟合，每档 ≥3 条完整放电曲线平均
- 阶段切换阈值：|dV/dt| 超过平坦段中位数的 3 倍判定进入末期

## 五、结果验证
### 5.1 验证方法
- 满放电时间：留一工况交叉验证的 MAPE、RMSE；回归残差图按电流/温度分层检查系统性
- 剩余时间：全程回放，对比 30%/50%/80% 放电深度时刻的预测值与真实剩余时间
- 双轨对照：库仑单轨、电压单轨、融合轨的误差曲线对比，验证融合的必要性

### 5.2 灵敏度分析
- n、α、Q 分别扰动 ±5%、±10% 对 t_rem 的影响（龙卷风图）
- 电流外推窗口宽度 15/30/60/120 的稳定性
- 温度外推（高于/低于实验温区 5°C）时预测区间的膨胀幅度

### 5.3 对比实验
- 恒流近似（直接用当前电流除）对照：说明变电流外推的增益
- 无温度修正对照：说明低温工况误差来源
- 多起点 LM 与对数线性解的参数一致性（差异应 <2%，否则检查数据或初值）

## 六、创新点提炼
### 6.1 方法创新
- Peukert 定律与线性温度修正合成单一对数线性模型，参数可估、区间可给
- 库仑计数与电压映射双轨按放电阶段加权融合，避开各自系统偏差区

### 6.2 应用创新
- 滚动回放评估：把离线数据当在线流回放，误差随放电深度的变化曲线是剩余时间类问题的标准验证范式
- 预测区间随放电深度收窄的呈现方式，直接回答「何时估计可信」

### 6.3 组合创新
- 机理经验式（Peukert）+ 数据驱动（电压映射）+ 统计推断（自助区间）三层结合
- 离线关系建模与在线滚动预测共享同一参数体系，口径一致

## 七、可借鉴点
### 7.1 写作技巧
- 关系模型章节给出「参数表 + 置信区间 + 残差分层图」三件套
- 剩余时间结果用「预测值 ± 区间带 + 真实轨迹」叠图，随放电深度展示区间收窄
- 适用边界单独成节：明确写出模型在什么电流/温度/放电深度范围内可信

### 7.2 建模技巧
- 先验证 H1（残差是否随电流系统偏斜）再决定是否加交互项，避免默认模型成立
- 双轨融合权重按阶段切换而非全局固定，是剩余时间/剩余寿命类问题的通用技巧
- 留一工况交叉验证比随机划分更贴合「预测新工况」的实际任务

### 7.3 表达技巧
- 技术路线图体现「关系建模 → 参数标定 → 在线滚动预测 → 回放评估」四步
- 误差表按放电深度分层（前 30%/中段/末期），不用单一全局均值掩盖末期失准
- 外推工况的预测用区间而非点值呈现，并显式标注外推标记
