# 百货商场会员画像的 RFMT 建模与聚类细分

## 基本信息
- 论文编号: C287
- 题型: C题
- 主题: 基于 RFMT 的会员价值评价、聚类细分与精准营销策略（会员画像历年经典）
- 获奖等级: 教学示例卡（综合典型写法，非真实论文引用）

## 一、问题理解
### 1.1 核心问题
百货商场拥有会员交易流水，需要把无差别的会员名单转成可运营的细分群体：量化每位会员的价值与偏好（画像），聚合成少数可解释的群体，并为每类群体给出差异化营销策略。

### 1.2 子问题分解
- 子问题1: 数据清洗与交易特征工程（异常、缺失、时间窗口）
- 子问题2: RFMT 指标体系构建与权重确定
- 子问题3: 会员聚类细分与簇数选择
- 子问题4: 群体画像解读与营销策略设计

### 1.3 输入输出
- 输入: 会员交易流水（时间、金额、品类、门店）、会员注册信息
- 输出: 会员级评分、K 个细分群体及画像、分群营销策略与评估口径

## 二、建模假设
### 2.1 假设列表
| 假设编号 | 假设内容 | 理由 | 影响 |
|---------|---------|------|------|
| H1 | 分析窗口内行为可代表会员倾向 | 画像建模前提 | 窗口取 12 个月 |
| H2 | 高频小额与低频大额同等需要权重区分 | 价值维度不同 | RFMT 四维而非三维 |
| H3 | 品类多样性反映忠诚度而非偶发 | T 维定义基础 | T 用 Shannon 熵 |
| H4 | 会员群体在特征空间可分 | 聚类可行性 | K-means/层次聚类 |
| H5 | 缺失交易记录为随机缺失 | 无缺失机制数据 | 删除或均值填补 |

### 2.2 关键假设
H2 决定用 RFMT 而非 RFM：百货场景下消费类型多样性（T）对复购有独立解释力，须在特征重要性对比中验证（加入/去掉 T 维的轮廓系数变化）。H1 的时间窗口须做稳健性检验（6/12/18 个月）。

## 三、模型构建
### 3.1 影响因素
- R（Recency）: 最近一次消费距今天数（越近越好）
- F（Frequency）: 窗口内消费次数
- M（Monetary）: 窗口内消费总额（或利润）
- T（Type）: 消费品类多样性（Shannon 熵）
- 辅助: 客单价、品类偏好集中度、消费时段规律

### 3.2 数学模型
指标标准化：Z-score 后方向对齐（R 取负向转正向）。

权重确定：主观（AHP 两两比较+一致性检验）与客观（熵权法）组合：
$$w_i = \gamma w_i^{AHP} + (1-\gamma) w_i^{entropy}$$
综合评分 $Score = \sum_i w_i x_i$。

聚类：K-means（多起点）+ 层次聚类交叉验证；
簇数选择：肘部法则（SSE 拐点）+ 轮廓系数峰值双重判据。

群体画像：以簇心特征 + 雷达图 + 与全体会员的分位数对比刻画。

### 3.3 约束条件
- 数据质量：缺失率超阈值的会员剔除并报告比例
- 标准化：量纲统一，防 M 维主导
- 可解释性：簇数控制在 4–6，每簇须能命名
- 策略可执行：每类群体给出明确的触达渠道与权益

## 四、求解方法
### 4.1 算法选择
特征工程与评分用确定性计算；聚类用 K-means（多起点 ≥10）并以层次聚类复核；权重用 AHP+熵权组合；稳定性用自助重抽样。

### 4.2 算法流程
1. 清洗：去重、异常金额截尾（1%/99% 分位）、缺失处理
2. 计算 R/F/M/T 四维指标并标准化
3. AHP 一致性检验 + 熵权法 → 组合权重 → 会员评分
4. 肘部+轮廓系数定 K，K-means 多起点聚类，层次聚类复核一致率
5. 每簇画像命名（如高价值忠诚客/沉睡大额客/高频低额客/新客）
6. 按画像输出差异化策略与 KPI 口径

### 4.3 参数设置
- 窗口 12 个月；K 候选 3–8
- K-means 起点 ≥10；`np.random.seed(42)`；自助重抽样 ≥200 次
- AHP 一致性比率阈值 CR < 0.1；组合系数 γ = 0.5 作基线、0.3/0.7 做灵敏度
- 独立运行 ≥5 次报告均值±标准差

## 五、结果验证
### 5.1 验证方法
- 轮廓系数、Calinski-Harabasz 指数报告（簇数选择留痕）
- 两种聚类算法的会员归属一致率（≥90% 视为稳定）
- 业务校验：每簇的 R/F/M/T 分位排序符合命名直觉

### 5.2 灵敏度分析
- 时间窗口 6/12/18 个月下簇结构稳定性（调整兰德指数）
- 权重 γ 从 0.3 到 0.7 的评分排序相关（Spearman）
- T 维加入/去掉对轮廓系数与簇数的影响（验证 RFMT 相对 RFM 的增益）

### 5.3 对比实验
- RFMT vs RFM vs 单指标分层的轮廓系数与业务可解释性对照
- K-means vs 层次聚类 vs 高斯混合模型的指标对比
- 策略效果的评估设计：分群营销与无差别营销的 A/B 口径（转化率、复购率）

## 六、创新点提炼
### 6.1 方法创新
- AHP+熵权组合赋权，兼顾业务先验与数据信息，且做一致性留痕
- 双聚类算法交叉验证 + 自助重抽样，把"聚类不稳定"这一常见质疑正面回应

### 6.2 应用创新
- 每类群体输出"触达渠道 + 权益 + KPI"三件套，策略不止于分群
- 用 A/B 口径预设验证方案，使营销结论可复核

### 6.3 组合创新
- 特征工程 + 组合赋权 + 多算法聚类 + 画像解读四级串联
- 定量分群与业务命名双向校验，避免"数字簇"无法落地

## 七、可借鉴点
### 7.1 写作技巧
- 簇画像用雷达图 + 分位数表双呈现，一眼看出各群差异
- 权重确定过程完整留痕（判断矩阵、CR 值、熵权），评委可复算

### 7.2 建模技巧
- 聚类题必报稳定性证据（一致率/重抽样），否则结论易被质疑
- 维度增益要用实验证明（RFMT vs RFM 对比），不靠口头主张

### 7.3 表达技巧
- 营销策略按"群体 → 目标 → 渠道 → 权益 → KPI"列表化
- 数据质量问题（缺失率、截尾比例）如实报告，增强可信度
