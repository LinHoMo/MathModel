# 赛题索引（2015–2025 CUMCM 真题）

> 按年份分节的赛题索引，每年列出 A/B/C 三题（本科组），D/E（专科组）仅收录已核实年份。
> 题目名称基于真实真题，不确定者以「（待补）」标注；2025 年题名据公开复盘资料整理，具体以组委会公布为准。
> 2018/2019 年题名与库内案例卡交叉印证（见各行备注）；2015–2017 年题名据公开汇总资料整理，与 2018/2019 库内口径互洽。

- **题型列** = 官方题号（A/B/C 本科组，D/E 专科组）。
- **备注列**中的「库内归类」为本库 A/B/C/D/E 题型分类口径（A 物理/连续、B 离散/组合、C 数据/统计、D 多目标/工程、E 交叉/开放），与官方题号不完全一致时**以库内归类为准**。
