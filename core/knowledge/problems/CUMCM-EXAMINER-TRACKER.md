## 二、赛题家族（同命题方向下的历年真题集合）

> type-classifier Step 2.6 使用：将当前赛题映射到家族，用家族方法演进规律推荐方法。

### 2.1 「定日镜/聚光」家族

- **家族成员**：2021 A FAST 反射面 + 2023 A 定日镜场 + 2025 A 烟幕干扰弹（光学遮蔽部分）
- **命题趋势**：从纯几何光学 → 几何+效率优化 → 几何+遮蔽+协同（难度递增）
- **基础方法**（必须）：空间解析几何 + 反射定律 + 数值搜索优化
- **进阶加分**（近年评阅鼓励）：多模型对照 + 灵敏度分析 + 复杂约束处理
- **常用工具**：Python scipy.optimize、光线追迹

### 2.2 「连续力学/振动」家族

- **家族成员**：2016 A 系泊系统 + 2019 A 高压油管 + 2022 A 波浪能
- **基础方法**：力学平衡建模 + ODE/PDE + 数值求解
- **进阶加分**：参数反演验证 + 多工况仿真

### 2.3 「热传导/温度场」家族

- **家族成员**：2018 A 高温防护服 + 2020 A 炉温曲线
- **基础方法**：热传导方程 + 边界条件设定 + 数值求解
- **进阶加分**：反问题参数估计 + 灵敏度分析

### 2.4 「数据+评价+决策」家族（C 题主流）

- **家族成员**：2015 B 出租车 + 2017 B 拍照赚钱 + 2018 C 会员画像 + 2020 C 信贷 + 2023 C 蔬菜定价 + 2025 C NIPT
- **命题趋势**：纯统计 → 统计+评价 → 统计+优化+机理融合（2023-2025 明显倾向机理+数据混合）
- **基础方法**：数据清洗 + 特征工程 + 回归/分类/聚类 + 灵敏度
- **进阶加分**（2023-2025 评阅鼓励）：混合效应模型 + 机理分析 + 多方案对照 + 结果现实解释性
- **避档警告**：2023 C、2025 C 明确批评「直接聚类不作为好方法」「未做正态性检验直接用 Pearson」

### 2.5 「离散调度/博弈」家族

- **家族成员**：2018 B RGV + 2020 B 穿越沙漠 + 2022 B 无人机定位 + 2024 B 生产决策
- **基础方法**：0-1 规划/动态规划/概率决策 + 仿真
- **进阶加分**：多策略对照 + 灵敏度分析

### 2.6 「交通/网络」家族

- **家族成员**：2016 B 小区开放 + 2019 C 出租车 + 2024 E 交通管控
- **基础方法**：交通流建模 + 网络流 + 排队论 + 优化
- **进阶加分**：多目标 + 仿真验证

## 三、近三年评阅口味演进（2023-2025）

> 供 type-classifier 和 method-matcher 参考——评阅口味直接影响 bonus_methods 推荐。

### 3.1 明确鼓励的

1. **多模型/多方案结果对比**（2023 C 出题人评阅原文）
2. **机理分析与数据建模融合**（2023 C 出题人评阅原文）
3. **结果落于现实合理区间**（可泛化规则 8）
4. **灵敏度分析 + 稳定性验证**（多道评阅共同要求）
5. **摘要独立成页 + 附录注明程序**（2024 A 评阅备注）

### 3.2 明确批评/降档的

1. **直接套用聚类作为分组/评价方法**（2025 C 评阅明确）
2. **未验证统计方法前提条件**（Pearson 未做正态性检验、重复测量数据直接视为独立）
3. **结果脱离现实区间**（日利润偏离合理范围、检测成功率超出 [0,1]）
4. **启发式算法滥用且未说明理由**（直接宣称全局最优、未做灵敏度分析）
5. **AHP 单独使用**（评阅已从首选方法降为"须搭配客观赋权"）
6. **灰色预测单独使用**（精度无法保障，须搭配 ML 方法）

### 3.3 隐性加分信号

1. **出题人评阅综述中给出的「参考结果」** —— 论文中答案落在参考值附近会获得「模型可信」印象
2. **出题人给出的「关键公式/关键步骤提示」** —— 评阅时会重点检查这些点是否正确
3. **「特色加分」项 5-10 分** —— 模型/算法/检验有自主创新时由组长遴选推荐全国评阅

## 四、使用规范

type-classifier 在 Step 2.5（出题人追溯）和 Step 2.6（真题家族映射）中调用本文件。使用流程：

1. 提取赛题核心实体 → 在「命题追踪」表中匹配命题单位
2. 在「赛题家族」中定位当前题所属家族
3. 读取该家族的「基础方法」+「进阶加分」→ 写入 `recommended_directions.methodology`
4. 对照「评阅口味演进」判断有无加分项或避档项
