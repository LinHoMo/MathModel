# 数值结果呈现规范

## 概述

数值结果是论文的核心内容，必须规范呈现。本文详解数值精度、表格、图表引用、误差分析和灵敏度分析的写法。

---

## 数值精度规范

### 基本规则

| 数据类型 | 精度要求 | 示例 |
|---------|---------|------|
| 整数结果 | 保留整数 | 1234 |
| 小数结果 | 小数点后4位 | 3.1416 |
| 百分比 | 小数点后2位 | 95.23% |
| 误差 | 小数点后4位 | 0.0023 |
| 相关系数 | 小数点后4位 | 0.9876 |
| P值 | 小数点后4位 | 0.0023 |
| 标准差 | 小数点后4位 | 1.2345 |

### 精度示例

**正确写法**：
- 模型准确率为92.3456%
- 均方根误差为12.3456
- 相关系数为0.9876
- P值为0.0023

**错误写法**：
- ❌ 模型准确率约为92%（精度不够）
- ❌ 模型准确率为92.34567%（精度太高）
- ❌ 均方根误差很小（无数值）

### 特殊情况

1. **整数结果**：如果结果恰好是整数，保留整数
   - 正确：最优解为1234
   - 错误：最优解为1234.0000

2. **大数值**：使用科学计数法
   - 正确：$1.2345 \times 10^6$
   - 错误：1234500（精度丢失）

3. **小数值**：确保有效数字
   - 正确：0.0001
   - 错误：0.0（精度丢失）

## 表格呈现规范

### 表格结构

```
表1 问题一求解结果
┌──────┬──────────┬──────────┬──────┐
│ 方案  │ 目标函数值 │ 约束违反  │ 时间  │
├──────┼──────────┼──────────┼──────┤
│ 方案1 │ 1234.5678 │ 0.0000   │ 1.23 │
│ 方案2 │ 1345.6789 │ 0.0000   │ 1.45 │
│ 方案3 │ 1456.7890 │ 0.0012   │ 1.67 │
└──────┴──────────┴──────────┴──────┘
```

### 表格要素

1. **表号**：按出现顺序编号（表1、表2、表3...）
2. **表题**：简洁明了，说明表格内容
3. **表头**：变量名+单位
4. **数据**：按规范精度呈现
5. **注释**：必要时添加脚注

### 表格格式要求

- 三线表格式（顶线、表头线、底线）
- 数值右对齐
- 文字左对齐
- 单位放在表头
- 无竖线

### 表格示例

```
表2 灵敏度分析结果
┌──────────┬──────────┬──────────┐
│ 参数变化  │ 目标函数值 │ 变化率   │
├──────────┼──────────┼──────────┤
│ -20%     │ 1234.5678 │ -5.43%   │
│ -10%     │ 1234.5678 │ -2.34%   │
│ 基准     │ 1234.5678 │ 0.00%    │
│ +10%     │ 1234.5678 │ +2.34%   │
│ +20%     │ 1234.5678 │ +5.43%   │
└──────────┴──────────┴──────────┘
```

## 图表引用规范

### 引用原则

1. **先见文，后见图**：图表前必须有引导文字
2. **文图对应**：图表中的内容必须在文字中分析
3. **连续图表**：连续两张图表之间必须有至少一个完整段落

### 引用格式

**正确写法**：
```
图1展示了问题一的求解结果。从图1可以看出，
方案1的目标函数值最小，为1234.5678。

表2列出了灵敏度分析结果。从表2可以看出，
当参数变化±20%时，目标函数值变化不超过5.43%。
```

**错误写法**：
```
如图1所示。（无分析）
结果如图所示。（无图表编号）
```

### 图表前后文字要求

**图表前**：1-2句引导文字
```
为分析模型的稳健性，本文对关键参数进行灵敏度分析，
结果如表2所示。
```

**图表后**：3-5句分析文字
```
从表2可以看出，当参数变化±20%时，目标函数值变化
不超过5.43%，说明模型对参数变化不敏感。
这表明模型具有良好的稳健性，能够在参数波动情况下
保持稳定的性能。
```

## 误差分析呈现

### 误差类型

| 误差类型 | 计算公式 | 适用场景 |
|---------|---------|---------|
| 绝对误差 | $|x_{pred} - x_{true}|$ | 单点预测 |
| 相对误差 | $\frac{|x_{pred} - x_{true}|}{x_{true}} \times 100\%$ | 比较不同量级 |
| 均方根误差 | $\sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_{pred} - x_{true})^2}$ | 整体评估 |
| 平均绝对误差 | $\frac{1}{n}\sum_{i=1}^{n}|x_{pred} - x_{true}|$ | 整体评估 |

### 误差分析模板

```
5.2 结果检验

为验证模型的正确性，本文从以下两个方面进行检验：

（1）与实际数据对比
将模型预测值与实际值进行对比，结果如表3所示。
从表3可以看出，预测误差均小于5%，平均误差为2.3456%，
在可接受范围内。

（2）极端情况分析
当输入取极端值时，模型仍能给出合理结果，
说明模型具有良好的鲁棒性。
```

### 误差表格示例

```
表3 预测误差分析
┌──────┬──────────┬──────────┬──────────┐
│ 样本  │ 实际值    │ 预测值    │ 相对误差  │
├──────┼──────────┼──────────┼──────────┤
│ 1    │ 123.4567 │ 125.6789 │ 1.80%    │
│ 2    │ 234.5678 │ 231.2345 │ 1.42%    │
│ 3    │ 345.6789 │ 352.3456 │ 1.93%    │
│ 平均  │ 234.5678 │ 236.4197 │ 1.72%    │
└──────┴──────────┴──────────┴──────────┘
```

## 灵敏度分析呈现

### 分析方法

1. **参数扰动**：对关键参数进行±10%、±20%扰动
2. **结果观察**：观察目标函数值的变化
3. **稳健性判断**：变化率<10%为稳健，10%-20%为一般，>20%为敏感

### 灵敏度分析模板

```
6. 灵敏度分析

为检验模型的稳健性，对关键参数$\alpha$进行灵敏度分析。
分别取$\alpha$变化±10%、±20%，观察目标函数值的变化。

表4展示了灵敏度分析结果。从表4可以看出，
当$\alpha$变化±20%时，目标函数值变化不超过5.43%，
说明模型对参数$\alpha$的变化不敏感，具有良好的稳健性。
```

### 灵敏度表格示例

```
表4 灵敏度分析结果
┌──────────┬──────────┬──────────┐
│ $\alpha$ │ 目标函数值 │ 变化率   │
├──────────┼──────────┼──────────┤
│ 0.8      │ 1234.5678 │ -5.43%   │
│ 0.9      │ 1234.5678 │ -2.34%   │
│ 1.0      │ 1234.5678 │ 基准     │
│ 1.1      │ 1234.5678 │ +2.34%   │
│ 1.2      │ 1234.5678 │ +5.43%   │
└──────────┴──────────┴──────────┘
```

## 常见错误

### 错误1：精度不一致

**错误**：同一表格中数值精度不统一
**正确**：同一列数值精度保持一致

### 错误2：无数值结果

**错误**：只说"结果很好"，无具体数值
**正确**：给出具体数值和误差

### 错误3：图表无分析

**错误**：只放图表，无分析文字
**正确**：图表前后必须有分析文字

### 错误4：误差未量化

**错误**：只说"误差很小"
**正确**：给出具体误差数值

### 错误5：灵敏度分析缺失

**错误**：未进行灵敏度分析
**正确**：对关键参数进行灵敏度分析

### 错误6：对比无基准

**错误**：只说"提高了"
**正确**：给出具体对比基准和数值
