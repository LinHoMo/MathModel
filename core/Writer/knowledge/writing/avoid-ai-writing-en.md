# 英文 AI 痕迹词汇规避手册

> 避免在英文学术写作中使用 AI 常用表达，使用更自然、专业的替代方案。

## 1. 过渡词汇（避免使用 → 推荐替代）

| 避免使用 | 推荐替代 | 说明 |
|---------|---------|------|

## 2. 句式结构（避免使用 → 推荐替代）

| 避免使用 | 推荐替代 |
|---------|---------|
| This paper aims to... | This paper presents/develops/proposes... |
| The purpose of this paper is to... | This paper focuses on... / We examine... |
| In this paper, we will... | This paper examines... / We analyze... |
| The main contribution of this paper is... | This paper contributes... / We demonstrate... |
| It can be clearly seen that... | (直接陈述观察结果) |
| As can be seen from... | Figure X shows... / (直接陈述) |
| It is well known that... | (直接陈述，引用文献) |
| There is no doubt that... | (直接陈述) |

| Needless to say... | (直接陈述) |

| In light of this... | Therefore... / Thus... / Consequently... |
| With this in mind... | (直接陈述) |
| Taking into account... | Considering... / Given... |

## 3. 量化替代（避免模糊表达）

| 避免使用 | 推荐替代 |
|---------|---------|
| a significant amount | 15.3% / 2.5 times / 1000 samples |
| a large number of | 500+ / over 500 |
| a small number of | 3 / 5 / fewer than 10 |
| approximately | 95.2% / 10.3 (精确数值) |
| roughly | 10.3 ± 0.5 (带误差) |
| very high | 98.7% / 1000 Hz (精确值) |
| very low | 0.3% / 0.01 Hz (精确值) |
| improved significantly | improved from 78.3% to 92.1% |
| better performance | accuracy of 95.2% vs. 87.6% |
| state-of-the-art | (引用具体方法和基准) |

## 4. 学术写作检查清单

- [ ] 无 "Furthermore/Moreover/Additionally" 连续使用
- [ ] 无 "It is important/worth noting that"
- [ ] 无 "In this day and age"
- [ ] 无 "Basically/Simply/Really/Very"
- [ ] 无 "Crucial/Vital/Integral/Pivotal" 过度使用
- [ ] 无 "Game-changing/Cutting-edge/Seamless"
- [ ] 无模糊量化（"a significant amount"）
- [ ] 每个结论都有数据支撑
- [ ] 无第一人称主观判断（"I believe"）
- [ ] 句式多样，无重复模式

## 5. 执行步骤

1. 全文搜索本手册中的"避免使用"词汇
2. 替换为"推荐替代"中的表达
3. 检查量化表达是否具体
4. 检查句式是否多样
5. 运行 AI 检测工具验证
