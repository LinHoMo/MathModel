# LaTeX 转义字符速查表

> 在 LaTeX 中，以下字符有特殊含义，需要转义才能正常显示。

## 1. 必须转义的字符

| 字符 | LaTeX 转义 | 说明 |
|------|-----------|------|
| `%` | `\%` | 百分号 |
| `$` | `\$` | 美元符号 |
| `&` | `\&` | 和号 |
| `#` | `\#` | 井号 |
| `_` | `\_` | 下划线 |
| `{` | `\{` | 左花括号 |
| `}` | `\}` | 右花括号 |
| `~` | `\textasciitilde` | 波浪号 |
| `^` | `\textasciicircum` | 脱字符 |
| `\` | `\textbackslash` | 反斜杠 |
| `<` | `$<$` | 小于号 |
| `>` | `$>$` | 大于号 |
| `\|` | `$\|$` | 竖线 |

## 2. 中文标点转义

| 字符 | LaTeX 写法 | 说明 |
|------|-----------|------|
| `，` | `，` | 直接使用（在CJK环境中） |
| `。` | `。` | 直接使用 |
| `；` | `；` | 直接使用 |
| `：` | `：` | 直接使用 |
| `（` | `（` | 直接使用 |
| `）` | `）` | 直接使用 |
| `"` | `"` 或 `\textquotedblleft` `\textquotedblright` | 左右双引号 |
| `'` | `'` 或 `\textquotesingle` | 单引号 |

## 4. 常见错误

```latex
% 错误：下划线未转义
error_rate_1

% 正确：下划线已转义
error\_rate\_1

% 错误：百分号未转义
95%

% 正确：百分号已转义
95\%

% 错误：波浪号未转义
a~b

% 正确：使用间距
a~b（非断行空格）
或
$a \sim b$（数学模式相似符号）
```

## 5. CJK 环境注意事项

在使用 `ctex` 或 `xeCJK` 包时：
- 中文标点通常不需要转义
- 英文标点仍需转义
- 混合中英文时注意空格处理
- 使用 `\text{}` 包裹中文文本（在数学模式中）
