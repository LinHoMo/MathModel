# 论文结构完整指南

## 概述

数学建模竞赛论文（CUMCM/ICM）采用标准化结构。掌握此结构是写作基础，本文详解每一节的写法。

---

## 正文段落式铁律（最高优先级写作禁令）

> 来源：MathModelAgent writer.py（竞争分析 A-1）。分点式论述是应用型 AI 生成文本最典型的痕迹，也是评委一眼识别"套模板"的依据。

**严格禁止在论文正文出现分点式论述**（bullet points / numbered lists）。所有 `（1）（2）（3）`、`① ② ③`、`- `、`1. 2. 3.` 式的列举，都必须改写为流畅通顺的段落式学术语言。

**重要澄清**：本文文末各节模板中的 `（1）（2）（3）`、`假设1：` 等编号，**仅用于组织你的思路**（提示要写哪几个要点），**不是最终成文的排版形式**。落笔时必须把它们"融化"成连续段落。

**唯一例外**：
- **公式编号**用半角括号 `(1) (2)`（如 `$$\min f(x)=... \tag{1}$$`），不是全角 `（1）`。
- **符号说明表、结果表**是 LaTeX 的 `table` / `tabular` 环境，本就允许表格形式，不属于"分点式正文"。

**反例（禁止，典型 AI 痕迹）**：

```
模型优点：
（1）考虑了 XX 因素；
（2）算法求解效率高；
（3）结构清晰。
```

**正例（段落式）**：

```
本文模型在理想点假设之外引入了 XX 因素，更贴近实际工况；求解层面，
采用 YY 算法将单次迭代复杂度降至 O(n log n)，可扩展到大规模实例；
模型整体结构分层清晰，便于向 ZZ 领域迁移。
```

**落地约束**：`guardrails-checker` / `validate_project.py` 的 `check_body_chinese_list` 会把正文中的全角 `（1）（2）`、圈数字 `①②③` 分点式记为风险点，提示改写为段落式。

## 标准6-7节结构

```
摘要                          ← 最后撰写，全文精华
├── 1. 问题重述与分析          ← 1-2页
├── 2. 模型假设                ← 1页
├── 3. 符号说明                ← 半页
├── 4. 模型建立与求解          ← 主体，8-15页
├── 5. 结果分析与检验          ← 2-3页
├── 6. 灵敏度分析              ← 1-2页
├── 7. 模型评价与推广          ← 1-2页
├── 参考文献                  ← 0.5页
└── 附录（代码）              ← 可选
```

## 第0节：摘要

### 写作模板

```
针对问题一，本文建立了XX模型。首先，对原始数据进行预处理...
通过求解，得到XX值为XXX.XXXX，YY为YYY.YYYY。

针对问题二，本文提出了XX方法。在问题一的基础上...
结果表明，该方法的准确率达到XX.XX%。

针对问题三，本文设计了XX方案。利用XX算法...
最优解为ZZZ.ZZZZ。

关键词：关键词1；关键词2；关键词3；关键词4；关键词5
```

### 注意事项
- 每问独立一段，结构平行
- 必须包含具体数值结果
- 最后撰写，内容全部确定后
- 不出现复杂公式和表格

## 第1节：问题重述与分析

### 写作模板

#### 1.1 问题重述

```
题目要求解决以下三个问题：
（1）问题一：...
（2）问题二：...
（3）问题三：...
```

#### 1.2 问题分析

```
针对问题一，需要解决的核心是...。考虑到...的特点，本文采用...
方法进行建模。

针对问题二，在问题一的基础上，进一步考虑...因素。本文拟采用...
算法求解。

针对问题三，需要综合前两问的结果，设计...方案。本文将建立...
优化模型。
```

### 写作要点
- 问题重述：用自己的语言重新表述题目，不是照抄
- 问题分析：简述解题思路，每问1-2句话
- 总篇幅控制在1-2页
- 不出现具体数值和计算过程

## 第2节：模型假设

### 写作模板

```
为使问题简化，便于建模，本文作出如下假设：

假设1：忽略XX因素的影响。
理由：根据题目条件，XX对结果的影响较小（<X%），忽略后不影响模型准确性。

假设2：假设XX为理想状态。
理由：在实际问题中，XX的波动范围有限，理想化处理可简化模型。

假设3：假设数据来源可靠且具有代表性。
理由：题目给定的数据为标准数据，无需验证。
```

### 注意事项
- 每条假设必须有必要性说明
- 假设数量建议3-6条
- 假设应与后文建模呼应
- 常见假设类型：理想化、质点、线性、数据、环境

---

## 第3节：符号说明

### 写作模板

```
本文主要符号及其含义如表1所示。

表1 符号说明
┌──────┬──────────┬──────┐
│ 符号  │ 含义      │ 单位  │
├──────┼──────────┼──────┤
│ $x$  │ 自变量    │ m    │
│ $y$  │ 因变量    │ kg   │
│ $\alpha$ │ 系数  │ -    │
└──────┴──────────┴──────┘
```

### 写作要点
- 表格形式，含量纲
- 符号按出现顺序或字母顺序排列
- 所有符号必须在后文使用
- 首次出现的符号必须在此说明

## 第4节：模型建立与求解（主体）

### 子节编号规范

```
4. 问题一的模型建立与求解
  4.1 问题分析
  4.2 模型建立
    4.2.1 目标函数
    4.2.2 约束条件
  4.3 模型求解
  4.4 结果分析

5. 问题二的模型建立与求解
  5.1 问题分析
  5.2 模型建立
  5.3 模型求解
  5.4 结果分析

6. 问题三的模型建立与求解
  ...
```

### 写作模板

#### 4.1 问题分析

```
问题一要求...。根据题目条件，需要建立...模型，
目标是在...约束下，使...最优。
```

#### 4.2 模型建立

```
根据问题分析，本文建立如下数学模型：

（1）目标函数
$$\min f(x) = \sum_{i=1}^{n} c_i x_i$$

（2）约束条件
$$\text{s.t.} \begin{cases} \sum_{i=1}^{n} a_{ij} x_i \leq b_j, & j=1,2,...,m \\ x_i \geq 0, & i=1,2,...,n \end{cases}$$
```

#### 4.3 模型求解

```
采用XX算法对上述模型进行求解。算法步骤如下：
（1）...
（2）...
（3）...

经过XX次迭代，得到最优解为$X^* = (x_1^*, x_2^*, ..., x_n^*)$。
```

### 写作要点
- 每个子问题独立成节
- 模型建立必须有公式推导
- 求解过程必须清晰
- 每个图表前后必须有分析文字

## 第5节：结果分析与检验

### 写作模板

```
5.1 结果分析

表2展示了问题一的求解结果。
[表格]

从表2可以看出，XX的最优值为XXX.XXXX，对应的YY为YYY.YYYY。
这表明...

5.2 结果检验

为验证模型的正确性，本文从以下两个方面进行检验：

（1）与实际数据对比
将模型结果与题目给定的参考数据进行对比，相对误差为X.XX%，
在可接受范围内。

（2）极端情况分析
当XX取极端值时，模型仍能给出合理结果，说明模型具有良好的鲁棒性。
```

## 节间过渡技巧

### 第1节→第2节
```
基于上述分析，为简化建模过程，本文作出如下假设。
```

### 第2节→第3节
```
根据假设和模型需要，定义本文主要符号如下。
```

### 第3节→第4节
```
在上述假设和符号定义的基础上，本文针对问题一建立模型。
```

### 第4节→第5节
```
基于上述模型求解结果，本文对结果进行分析和检验。
```

### 第5节→第6节
```
为检验模型的稳健性，本文对关键参数进行灵敏度分析。
```

### 第6节→第7节
```
综合以上分析，本文对模型进行评价并讨论其推广应用。
```

## 常见错误

1. 摘要过长：超过一页，应控制在半页内
2. 问题重述照抄题目：应用自己的语言重新表述
3. 假设无必要性说明：每条假设必须说明理由
4. 图表无分析文字：每张图表前后必须有文字说明
5. 灵敏度分析缺失：这是必查项，不可省略
6. 模型评价空泛：必须诚实讨论缺点
