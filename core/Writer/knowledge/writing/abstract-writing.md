# 摘要写作完全指南

## 概述

摘要是论文的门面，评委第一眼看的就是摘要。本文详解摘要的写作公式、模板和技巧。

---

## 摘要五段式公式

```
第一段：背景引入（1句话）
第二段：问题一（方法+模型+结果）
第三段：问题二（方法+模型+结果）
第四段：问题三（方法+模型+结果）
第五段：模型评价与总结（含方法对比/鲁棒性/工程价值）
```

> 注：以上为"正文段落"结构。关键词**不是**第五段，而是单独一行，必须写入 LaTeX 摘要环境末尾（见下）。

## 关键词（必须写入 LaTeX 摘要）

- 数量：3-5 个，用中文分号 `；` 分隔
- 顺序：从大到小、从宽到窄（问题类型 → 方法 → 领域）
- **必须在 `paper/main.tex` 的摘要环境中、`\end{abstract}` 之前写入**，形式：

```latex
\begin{abstract}
...（五段式正文，每段含方法+模型+关键数值）...

\noindent\textbf{关键词：} 等距螺线；链式约束递推；碰撞几何判据；S形掉头；运动学建模
\end{abstract}
```

- `ctexart` 默认不提供 `\keywords` 命令，统一用 `\noindent\textbf{关键词：}` 手动排版（国赛/华为杯通用，避免模板差异）
- 缺失关键词属于排版硬伤，final-validator 与 validate_project.py 会告警

## 第一段：背景引入

### 写作模板

```
本文针对XX问题，研究了...
```

### 常见开头方式

1. 针对XX问题，本文研究了...
2. XX问题是...领域的重要问题，本文针对...
3. 在...背景下，本文研究了...
4. 针对...中的XX问题，本文建立了...

### 注意事项
- 只用1句话
- 不写具体方法和结果
- 不超过30个字
- 点明研究对象即可

## 第二段：问题一的写作模板

### 标准模板

```
针对问题一，本文建立了XX模型。首先，对原始数据进行预处理，
包括...。然后，采用XX方法，建立了...数学模型。
通过求解，得到XX值为XXX.XXXX，YY为YYY.YYYY，
表明...
```

### 变体模板（优化问题）

```
针对问题一，本文建立了XX优化模型。以...为目标函数，
以...为约束条件，采用XX算法求解。
最优解为XXX.XXXX，此时目标函数值为YYY.YYYY。
```

### 变体模板（预测问题）

```
针对问题一，本文建立了XX预测模型。首先，对数据进行...
处理。然后，采用XX方法建立预测模型。
预测结果显示，未来XX的值为XXX.XXXX，误差为X.XX%。
```

## 数值结果的呈现规范

### 精度要求

| 数据类型 | 精度要求 | 示例 |
|---------|---------|------|
| 整数结果 | 保留整数 | 1234 |
| 小数结果 | 小数点后4位 | 3.1416 |
| 百分比 | 小数点后2位 | 95.23% |
| 误差 | 小数点后4位 | 0.0023 |
| 相关系数 | 小数点后4位 | 0.9876 |

### 呈现方式

1. **精确数值**：XX值为3.1416
2. **范围值**：误差在0.01-0.05之间
3. **对比值**：比XX方法提高了12.34%
4. **百分比**：准确率达到95.23%

### 避免的写法

- ❌ XX值约为3（精度不够）
- ❌ XX值为3.1415926535（精度太高）
- ❌ 结果非常好（没有数值）
- ❌ 误差很小（没有具体数值）

## 关键词选择技巧

### 选择原则

1. 数量：3-5个
2. 顺序：从大到小，从宽到窄
3. 类型：问题类型+方法+领域

### 关键词类型

| 类型 | 示例 |
|------|------|
| 问题类型 | 优化问题、预测问题、分类问题 |
| 方法类型 | 遗传算法、神经网络、多元回归 |
| 领域类型 | 交通规划、资源调度、风险管理 |
| 模型类型 | 多目标优化、动态规划、马尔可夫链 |

### 关键词模板

```
关键词：问题类型；方法类型；模型类型；领域类型；其他
```

### 示例

```
关键词：多目标优化；遗传算法；帕累托最优；交通规划；路径选择
关键词：时间序列预测；LSTM神经网络；数据预处理；股票价格；均方根误差
关键词：聚类分析；K-means算法；客户细分；精准营销；轮廓系数
```

## 优秀摘要范例

### 范例1：优化问题

```
本文针对应急物资调度问题，研究了多目标优化调度方法。

针对问题一，本文建立了多目标优化模型。以总调度时间和总成本
为优化目标，以车辆容量和时间为约束条件，采用NSGA-II算法求解。
得到Pareto最优解集，其中最优方案的调度时间为12.3456小时，
总成本为7890.1234元。

针对问题二，在问题一的基础上，本文考虑了道路中断因素。
建立了鲁棒优化模型，采用自适应遗传算法求解。
得到稳健方案的调度时间为15.6789小时，总成本为8234.5678元，
比原方案增加了13.45%，但抗风险能力提高了25.67%。

针对问题三，本文设计了动态调度方案。建立了随机动态规划模型，
采用蒙特卡洛模拟求解。
期望调度时间为13.4567小时，期望成本为8012.3456元。

关键词：应急物资调度；多目标优化；NSGA-II算法；鲁棒优化；动态规划
```

### 范例2：预测问题

```
本文针对PM2.5浓度预测问题，研究了多模型融合预测方法。

针对问题一，本文建立了LSTM神经网络预测模型。首先对数据进行
预处理和特征工程。然后构建3层LSTM网络进行训练。
预测结果的均方根误差为12.3456，平均绝对误差为8.9012，
相关系数为0.9234。

针对问题二，在问题一的基础上，本文引入了注意力机制。
建立了Attention-LSTM模型，考虑了气象因素的影响。
预测精度提高了15.67%，均方根误差降低为10.4132。

针对问题三，本文设计了多模型融合方案。采用Stacking方法
将LSTM、GRU和XGBoost模型进行融合。
最终预测误差为8.7654，比单一模型降低了25.43%。

关键词：PM2.5预测；LSTM神经网络；注意力机制；模型融合；时间序列分析
```

### 范例3：分类问题

```
本文针对客户信用评估问题，研究了不平衡数据分类方法。

针对问题一，本文建立了XGBoost分类模型。首先对数据进行
预处理和特征选择。然后采用SMOTE方法处理不平衡数据。
分类准确率达到92.34%，AUC值为0.9567。

针对问题二，在问题一的基础上，本文提出了集成学习方法。

准确率提高到94.56%，AUC值为0.9789。

针对问题三，本文设计了在线学习方案。采用流式学习算法，
实现了实时信用评估。在线准确率为91.23%，
延迟控制在100毫秒以内。

关键词：信用评估；XGBoost；不平衡数据；集成学习；在线学习
```

## 常见错误与修正

### 错误1：背景过长

**错误写法**：
```
随着经济社会的快速发展，XX问题日益突出。近年来，
专家学者对XX问题进行了大量研究，提出了多种方法...
本文针对XX问题...
```

**正确写法**：
```
本文针对XX问题，研究了...
```

### 错误2：方法描述不清

**错误写法**：
```
针对问题一，本文采用了某种方法进行求解，得到了较好的结果。
```

**正确写法**：
```
针对问题一，本文建立了XX模型。采用XX算法求解，
得到XX值为XXX.XXXX。
```

### 错误3：无数值结果

**错误写法**：
```
针对问题一，本文建立了XX模型，结果表明该模型效果良好。
```

**正确写法**：
```
针对问题一，本文建立了XX模型。求解得到XX值为XXX.XXXX，
准确率为XX.XX%。
```

### 错误4：关键词不当

**错误写法**：
```
关键词：数学建模；论文；研究；方法；结果
```

**正确写法**：
```
关键词：多目标优化；遗传算法；帕累托最优；交通规划；路径选择
```

### 错误5：摘要过长

**错误**：摘要超过一页
**正确**：控制在半页内，每问一段

## 摘要检查清单

- [ ] 每问独立一段
- [ ] 每段包含：方法+模型+数值结果
- [ ] 数值结果精度正确（小数点后4位）
- [ ] 关键词3-5个，从大到小排列
- [ ] 无复杂公式和表格
- [ ] 无"我们认为"等空泛表述
- [ ] 总长度控制在半页内
- [ ] 最后撰写，内容全部确定后
