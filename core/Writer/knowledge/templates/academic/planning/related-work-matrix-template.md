# 相关工作矩阵表格模板（related-work-matrix-template.md）

> **来源**：R4-W3 调研发现 + Beacon/PaperPip 工程实践。
> **交叉验证**：见 [knowledge/laws/cross-validation-record.md](../../../knowledge/laws/cross-validation-record.md) P1-9 / C4-W6。
> **适用范围**：通用学术路径（`academic/`）Stage 2 文献综述与 Stage 5 写作中"Related Work"章节。
>
> **使用方法**：复制本模板到论文项目的 `paper/` 或 `literature/` 目录，重命名为 `related_work_matrix.md`，按文献逐行填写。完成后的矩阵表格可作为 Related Work 章节的对比骨架，避免堆砌式叙述。
>
> **写作原则**：
> - **5 列对比维度**：方法 / 数据 / 指标 / 优势 / 劣势（缺一不可）
> - **覆盖度**：至少 5 篇核心文献，含经典奠基 + 最新进展
> - **客观性**：优势与劣势均需给具体证据（数值 / 场景 / 引用编号），避免空话
> - **不重复**：每篇文献的"方法"列必须给出可识别特征（避免"基于深度学习"这种泛化描述）

## 2. 维度说明

### 2.1 方法列（Method）

填写规范：
- 给出方法的核心算法名（如 GCN、模拟退火、SAT 求解器）
- 标注关键参数或变体（如 GCN + 强化学习）
- 避免泛化描述（如"基于深度学习"应具体化为"基于 GCN + RL"）

### 2.2 数据列（Dataset）

填写规范：
- 数据集名称 + 规模（如"PeMSD4, 10,784 sensors, 8 weeks"）
- 标注是否公开（"公开" / "自构"）
- 标注是否含标注（"含解" / "无标注"）

### 2.3 指标列（Metric）

填写规范：
- 主指标 + 数值（如"MAE = 18.3"）
- 次指标 + 数值（如"推理时间 < 10ms"）
- 评估方式（如"k-fold 交叉验证"、"测试集 1K 例"）

### 2.4 优势列（Strengths）

填写规范：
- 给具体数值或场景（如"准确率 87.3%"、"推理 < 10ms"）
- 避免空话（如"效果好"应具体化为"准确率 87.3%"）
- 优势需可验证（来自原文或本文复现）

### 2.5 劣势列（Weaknesses）

填写规范：
- 给具体边界（如"n > 25 时超时"、"准确率 87.3%，未达 100%"）
- 标注是否影响核心结论（如"不保证最优"影响可用性）
- 劣势需客观（不刻意贬低竞争方法）

## 4. 研究空白（Research Gap）总结

基于上述 5 列矩阵对比，本文的研究空白为：

> 现有精确求解方法 [1][4] 在大规模（n ≥ 16）场景下超时（> 3600s）；学习型方法 [2] 准确率不足（87.3%）；大语言模型 [5] 不可复现且准确率仅 42.1%。**本文方法填补了"高准确率（≥ 95%）+ 大规模可用（n = 16）+ 可复现（开源代码）"这一组合空白**，与已有工作的具体差异为：
>
> - 与 [2] 相比：引入约束传播模块，准确率从 87.3% 提升至 95.6%（+8.3pp）
> - 与 [3] 相比：在 n = 16 实例上求解时间从 4.7s 降至 0.3s（-93.6%）
> - 与 [5] 相比：完全开源可复现，无 API 依赖

## 5. 写作建议

### 5.1 矩阵表格在论文中的呈现方式

- **期刊论文**：Related Work 章节末尾以 Table 1 形式呈现，正文 1-2 段总结
- **会议论文**：Introduction 末尾或 Related Work 章节以紧凑表格呈现
- **学位论文**：独立"文献综述"章节，每类方法 1 小节 + 矩阵表格汇总

### 5.2 避免的写作模式

- ❌ 堆砌式叙述："Smith et al. (2023) did X. Wang & Liu (2024) did Y. Chen et al. (2023) did Z."（无对比）
- ✅ 对比式叙述："Smith et al. (2023) 的暴力枚举保证最优但 n > 25 超时；Wang & Liu (2024) 的 GCN 推理快但准确率仅 87.3%。本文结合两者优势..."
