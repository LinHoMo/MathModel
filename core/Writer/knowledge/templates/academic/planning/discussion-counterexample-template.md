# 讨论反例段模板（discussion-counterexample-template.md）

> **来源**：R4-W4 调研发现 + forbidden-words.md §7.3 加法层"限定化"策略落地。
> **交叉验证**：见 [knowledge/laws/cross-validation-record.md](../../../knowledge/laws/cross-validation-record.md) P1-10 / C4-W7。
> **适用范围**：通用学术路径（`academic/`）Stage 5 写作中"Discussion"章节。
>
> **使用方法**：复制本模板到论文项目的 `paper/` 或 `discussion/` 目录，重命名为 `discussion_counterexample.md`，按"方法失败条件 + 数据支撑 + 局限解释"三段式填写。完成后的内容应作为论文 Discussion 章节中"Limitations & Boundaries"小节。
>
> **写作原则**：
> - **三段式结构**：方法失败条件（明确边界）+ 数据支撑（量化证据）+ 局限解释（合理的局限性说明）
> - **主动声明**：主动指出方法的失败场景，体现学术诚信（优于审稿人指出）
> - **量化证据**：每个失败条件配具体数值或场景（避免"在某些情况下表现不好"）
> - **不夸大局限**：局限需与核心结论匹配（不把次要局限说成致命）

## 1. 三段式结构骨架

> 每个反例段必须包含以下三段，缺一不可：

### 1.1 第一段：方法失败条件（明确边界）

> **填写要点**：
> - 给出具体的失败触发条件（如"样本量 < 50"、"噪声 > 30%"、"n > 1000"）
> - 避免模糊描述（如"在某些情况下"应具体化为"当 n > 1000 时"）
> - 标注是"完全失效"还是"精度下降"

**示例（第一段）**：

> 本文方法在样本量 n < 50 时精度显著下降。具体而言，当 n = 30 时，模型的 F1 分数从 n = 1000 时的 0.92 降至 0.68（降幅 26.1%）；当 n < 20 时，模型无法收敛（损失函数在 1000 轮后仍 > 1.5）。

### 1.2 第二段：数据支撑（量化证据）

> **填写要点**：
> - 给出具体的实验数据（表格或图引用）
> - 标注统计显著性（p 值 / 置信区间）
> - 与正常情况对比（如"n = 1000 时 F1 = 0.92"）

**示例（第二段）**：

> 这一现象在消融实验中得到验证（见表 4）：在 MIMIC-III 数据集上，n = 1000 / 500 / 100 / 50 / 30 / 20 对应的 F1 分数分别为 0.92 / 0.91 / 0.85 / 0.74 / 0.68 / N/A。Cochran-Armitage 趋势检验显示 F1 分数随 n 下降的趋势显著（Z = -5.43, p < 0.001）。失败原因在于模型的注意力机制在小样本下出现过拟合：n = 30 时训练集 loss = 0.12，验证集 loss = 1.87（差距 15.6 倍）。

### 1.3 第三段：局限解释（合理的局限性说明）

> **填写要点**：
> - 解释失败的根本原因（机制层面）
> - 给出可能的改进方向（不空话，给具体方法）
> - 标注该局限是否影响核心结论

**示例（第三段）**：

> 该局限的根本原因在于注意力机制参数量（约 12.4M）相对小样本（n < 50）过剩，导致过拟合。本文核心结论（"在大规模电子病历数据上，注意力机制优于 RNN 基线"）不受此局限影响，因为核心实验均在 n ≥ 5000 的数据上进行。针对小样本场景，未来可考虑引入预训练 + 微调范式（如 ClinicalBERT 初始化），或采用参数高效微调（LoRA, rank = 8）将可训练参数降至 0.1M 以下。

## 2. 完整示例段（可直接套用）

### 2.1 示例：机器学习方法在小样本下的失败

> **方法失败条件**：本文的图神经网络方法在样本量 n < 50 时精度显著下降。具体而言，当 n = 30 时，F1 分数从 n = 1000 时的 0.92 降至 0.68（降幅 26.1%）；当 n < 20 时，模型无法收敛（loss > 1.5 持续 1000 轮）。
>
> **数据支撑**：在 MIMIC-III 数据集上的消融实验（表 4）显示，n = 1000 / 500 / 100 / 50 / 30 / 20 对应 F1 分别为 0.92 / 0.91 / 0.85 / 0.74 / 0.68 / N/A。趋势检验 Z = -5.43, p < 0.001。训练集 loss = 0.12 vs 验证集 loss = 1.87 表明典型过拟合。
>
> **局限解释**：根本原因为注意力机制参数量（12.4M）相对小样本过剩。该局限不影响本文核心结论（核心实验在 n ≥ 5000 上进行）。改进方向：预训练 + 微调（ClinicalBERT 初始化）或参数高效微调（LoRA rank = 8，可训练参数 < 0.1M）。

### 2.2 示例：物理模型在极端参数下的失效

> **方法失败条件**：本文的扩散模型在扩散系数 D > 10⁻³ m²/s 时数值不稳定。具体而言，当 D = 10⁻³ 时，相对误差从 D = 10⁻⁵ 时的 0.8% 跃升至 23.7%；当 D > 10⁻² 时，求解器发散（NaN）。
>
> **数据支撑**：表 5 列出 D = 10⁻⁵ / 10⁻⁴ / 10⁻³ / 10⁻² 对应的相对误差 0.8% / 1.2% / 23.7% / NaN。CFL 条件分析显示，当 D > 10⁻³ 时 CFL > 1（违反稳定性条件），与数值发散一致。
>
> **局限解释**：根本原因为显式 Euler 时间步长 Δt = 0.01s 在大 D 下违反 CFL 稳定性条件（CFL = D·Δt/Δx² > 1）。该局限不影响本文核心结论（核心实验在 D ≤ 10⁻⁴ 范围内）。改进方向：改用隐式求解器（Backward Euler 或 Crank-Nicolson），可将稳定范围扩展至 D ≤ 10⁻¹（理论分析见附录 C）。

### 2.3 示例：统计方法在数据偏离假设时的退化

> **方法失败条件**：本文的贝叶斯推断方法在数据偏离正态假设时精度下降。具体而言，当数据偏度 |γ₁| > 2 时，95% 置信区间覆盖率从 |γ₁| < 0.5 时的 94.8% 降至 78.3%。
>
> **数据支撑**：模拟实验（图 6）显示，|γ₁| = 0 / 0.5 / 1.0 / 2.0 / 3.0 对应覆盖率 94.8% / 94.2% / 91.5% / 78.3% / 62.1%。Kolmogorov-Smirnov 检验在 |γ₁| > 2 时拒绝正态假设（D = 0.18, p < 0.001）。
>
> **局限解释**：根本原因为方法的正态性假设在重尾分布下不成立。该局限影响范围限于"数据偏度 |γ₁| > 2"的场景（在本文核心应用——气温数据中，|γ₁| 的 95% 分位数为 0.8，未受影响）。改进方向：采用 t 分布替代正态假设（自由度 ν = 5），或非参数 Bootstrap 方法（10,000 次重采样），可将覆盖率恢复至 92% 以上。

## 3. 写作检查清单

### 3.1 三段式完整性

- [ ] 每个反例段均含"方法失败条件"段
- [ ] 每个反例段均含"数据支撑"段
- [ ] 每个反例段均含"局限解释"段
- [ ] 三段顺序不可调换（先条件，再证据，后解释）

### 3.2 量化证据要求

- [ ] 每个失败条件配具体数值（如"n < 50"、"F1 = 0.68"）
- [ ] 数据支撑段引用具体表/图编号（如"见表 4"）
- [ ] 标注统计显著性（p 值 / 置信区间 / 效应量）

### 3.3 局限解释要求

- [ ] 解释根本原因（机制层面，非表面现象）
- [ ] 标注是否影响核心结论（影响 / 不影响 + 说明）
- [ ] 给出具体改进方向（不空话，给方法名 + 参数）

## 4. 与既有资源的关联

### 4.1 与 forbidden-words.md §7.3 加法层"限定化"策略的关系

本模板是 [forbidden-words.md](../../../knowledge/writing/forbidden-words.md) §7.3 加法层"限定化"策略的落地实现：

### 4.2 与 limitations-statement-template.md 的关系

| 模板 | 路径 | 用途 |
|------|------|------|
| limitations-statement-template.md | `core/Writer/knowledge/templates/academic/planning/` | 论文级 Limitations 章节整体框架（含 8 节） |
