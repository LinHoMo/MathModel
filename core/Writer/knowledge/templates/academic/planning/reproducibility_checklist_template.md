# Reproducibility Checklist Template

> **来源**：AI-Scientist 项目的 `reproducibility_checklist.md`（R10 调研发现）+ NeurIPS Checklist。
> **交叉验证**：见 [knowledge/laws/cross-validation-record.md](../../../knowledge/laws/cross-validation-record.md) X-11。
> **适用范围**：通用学术路径（`academic/`）所有论文产出。数模路径（72-96 小时强约束）使用简化版复现性清单。
>
> **使用方法**：复制本模板到论文项目根目录，重命名为 `reproducibility_checklist.md`，逐项填写并打勾。所有"必填"项必须填写；"选填"项按需填写。任一"必填"项空缺 = 不可投稿。

- [ ] **Level 1 - Reusable**：完整代码 + 数据 + 模型 + 详细文档；他人可一键复现所有结果
- [ ] **Level 2 - Functional**：完整代码 + 关键数据 + 文档；他人可复现主要结果
- [ ] **Level 3 - Runnable**：部分代码/数据；他人可运行部分实验
