# 图表决策指南

> 选择图表类型前，先分析数据特征，再用下表匹配。优先匹配数据形态，而非视觉新奇度。

---

## 选择优先级

1. 先查"按数据形态"表 — 匹配数据特征到推荐图表
2. 多个选项时，优先选目标受众（评委/审稿人）能立刻理解的
3. 用高级图表（棒棒糖、哑铃、瀑布、SHAP）时，确保它们能展示基础图表无法展示的信息
4. 一篇论文需要视觉多样性 — 混合基础和高级图表

**硬性规则**：同一种图表类型不要在一篇论文中使用超过 3 次。

---

## 按数据形态选择

| 数据特征 | 推荐图表 | 避免 |
|---------|---------|------|
| ≤3 方法 × 1-2 指标 | 三线表 | 任何图表（数据点太少） |
| 4+ 方法 × 1 指标 | 棒棒糖图或分组柱状图 | — |
| A vs B（2 方法，多指标） | 哑铃图 | 热力图（2 行像红绿灯） |
| A vs B vs C（3-5 方法，多指标） | 分组柱状图或雷达图 | — |
| 方法 × 指标矩阵（≤5×5） | 方法对比热力图或分组柱状图 | — |
| 方法 × 指标（展示趋势） | 平行坐标 | 多个独立图表 |
| 方法 × 指标矩阵（>5×5） | 带数值的热力图 | — |
| 方法 × 数据集排名 | Bump 图或分组柱状图 | — |
| 前后对比 | 哑铃图或分组柱状图 | — |
| 前后对比（配对样本） | 配对点图 | 分组柱状图（隐藏个体差异） |
| 相对于基线（±%） | 发散柱状图 | 分组柱状图（不清晰展示方向） |
| 多模型统计对比 | Taylor 图 | 分开的 RMSE/R²/StdDev 柱状图 |
| 分布对比（5-15 组） | 山脊图 | 多个直方图（浪费空间） |
| 分布对比（2-4 组 × 类别） | 分组小提琴图 | 箱线图（隐藏分布形状） |
| 模块贡献（消融） | 瀑布图 | 柱状图 |
| 时间序列（1-3 条线） | 带置信区间的折线图 | — |
| 时间序列（4+ 条线） | 小多图（子图网格） | 意面图 |
| 分布（1 组） | 小提琴图 + 散点 | 直方图 |
| 分布（2-5 组） | 雨云图 | 箱线图 |
| 占比/组成 | 环形图或堆叠面积图 | 饼图 |
| 相关矩阵 | 热力图 + 树状图 | 普通热力图 |
| 2D 散点 + 关系 | 散点 + 回归 + R² | — |
| 高维特征 | t-SNE/UMAP 散点 | — |
| 多准则评价 | 雷达图 | — |
| 特征重要性 | SHAP Summary Plot | 水平柱状图 |
| 分类结果 | 混淆矩阵 | — |
| 二分类器对比 | ROC + AUC | — |

## 按问题域选择（竞赛）

| 题型 | 推荐图表 |
|------|---------|
| 优化（GA/PSO/SA） | 收敛曲线 + 3D 曲面 + Pareto 前沿 |
| 调度/路径 | 甘特图 + 网络路径图 |
| 分类/聚类 | 混淆矩阵 + ROC + 3D 聚类散点 |
| 回归/预测 | 预测 vs 真实（带置信区间）+ 误差雨云图 |
| 灵敏度分析 | 龙卷风图 + 等高线图 + 3D 曲面 |
| 空间数据 | 省级 choropleth + 时空矩阵 |
| 多目标 | 2D Pareto + 3D Pareto 曲面 |
| 因素分解 | 瀑布图 |

## 按问题域选择（学术）

| 论文类型 | 推荐图表 |
|---------|---------|
| DID/因果推断 | 平行趋势 + 事件研究 + 安慰剂 |
| 回归分析 | 森林图 + 异质性森林图 + 边际效应 |
| 预测/时序 | 带置信区间的预测 + 误差分布 + 模型热力图 |
| 深度学习 | 训练曲线 + 注意力图 + t-SNE |
| 模型对比 | 分组柱状图 + 方法对比热力图 + 雷达图 |
| 超参数调优 | 灵敏度网格 + 3D 损失曲面 |

## 反模式检查

| ❌ 原本要用 | ✅ 考虑替代 | 原因 |
|------------|-----------|------|
| 单指标柱状图排名 | 棒棒糖图 | 视觉噪音更少 |
| 水平柱状图特征重要性 | SHAP Summary Plot | 同时展示方向和大小 |
| 柱状图消融实验 | 瀑布图 | 展示增量贡献 |
| 柱状图前后对比（2 组） | 哑铃图 | 展示变化方向和幅度 |
| 普通箱线图 | 雨云图 | 分布形状 + 箱线统计 + 原始数据 |
| 饼图 | 环形图 | 更现代，视觉扭曲更少 |
| 普通热力图 | 热力图 + 树状图 | 添加聚类结构 |
| RdYlGn 配色 | coolwarm 或 YlOrRd | 红黄绿 = 交通灯 |

---

## 配色通用规则

- 数据颜色（柱子、线条、散点）：用 `PALETTE[i]`，不要硬编码 hex
- 语义颜色（上升/下降）：用 `COLORS['up']`、`COLORS['down']`
- 装饰颜色（网格线/文字）：用 `COLORS['grid']`、`COLORS['text']`
- 同类图表风格统一，颜色要能灰度区分
- 避免过度装饰、阴影和无意义渐变
- 色盲友好：避免红绿同时作为对比色
