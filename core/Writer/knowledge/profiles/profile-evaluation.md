# 评价类问题配置文件

## 适用题型
- 综合评价问题："谁更好"类问题
- 方案选择问题：多方案对比决策
- 绩效评估问题：多指标综合评估
- 质量评价问题：多维度质量评估

## 核心方法推荐
### 主观赋权法
- 层次分析法（AHP）
- 专家打分法
- 德尔菲法

### 客观赋权法
- 熵权法
- 变异系数法
- 主成分分析法

### 综合评价法
- TOPSIS法（逼近理想解排序法）
- 模糊综合评价法
- 灰色关联分析法
- 数据包络分析（DEA）

### 组合赋权法
- AHP-熵权法组合
- 主客观组合赋权

## 论文结构建议
1. **问题分析**：明确评价目标和要求
2. **指标体系构建**：
   - 指标选取原则
   - 指标层次结构
   - 指标筛选方法
3. **数据标准化**：
   - 正向化处理
   - 无量纲化处理
4. **权重确定**：
   - 主观赋权
   - 客观赋权
   - 组合赋权
5. **评价模型建立**：
   - 评价方法选择
   - 模型构建
6. **结果分析**：
   - 评价结果排序
   - 稳定性分析
   - 敏感性分析
7. **结论与建议**

## 评分要点
### 必须包含的图表
- **指标体系图**：展示指标层次结构
- **权重分布图**：展示各指标权重
- **评价结果对比图**：展示不同方法结果
- **敏感性分析图**：展示参数变化影响
- **雷达图**：展示多维度评价结果

### 必须包含的表格
- **指标体系表**：详细指标说明
- **权重计算表**：展示权重计算过程
- **评价结果表**：展示最终评价结果
- **对比分析表**：不同方法结果对比

### 方法选择要求
- 至少2种baseline对比方法
- 主观与客观方法结合
- 敏感性分析必须进行

### 创新性要求
- 指标体系创新
- 赋权方法创新
- 评价方法创新

## 常见陷阱
### 指标体系问题
- 指标选取主观随意
- 指标层次结构不合理
- 未考虑指标相关性

### 权重确定问题
- 仅用单一赋权方法
- 未进行一致性检验
- 权重解释不合理

### 结果分析问题
- 未进行敏感性分析
- 结论过度宣称
- 未与简单方法对比

### 论文写作问题
- 评价过程描述不清
- 图表质量差
- 参考文献不足

## 特殊注意事项
1. **指标体系科学性**：指标选取必须有理论依据
2. **赋权方法合理性**：必须说明权重确定理由
3. **结果稳健性**：必须进行敏感性分析
4. **可解释性**：评价结果必须有合理解释
5. **实用性**：评价结果必须有实际应用价值
