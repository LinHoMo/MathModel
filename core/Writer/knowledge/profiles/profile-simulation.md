# 仿真类问题配置文件

## 适用题型
- 不确定演化问题：随机过程模拟
- 复杂系统仿真：系统动力学模拟
- 蒙特卡洛模拟：概率分布模拟
- 离散事件仿真：排队系统、调度系统
- Agent-based仿真：个体行为模拟

## 核心方法推荐
### 蒙特卡洛方法
- 简单蒙特卡洛模拟
- 重要性采样
- 马尔可夫链蒙特卡洛（MCMC）
- 拉丁超立方采样

### 离散事件仿真
- 事件调度法
- 活动扫描法
- 进程交互法
- 排队网络仿真

### 系统动力学
- 因果回路图
- 存量流量图
- 系统动力学方程
- 灵敏度分析

### Agent-based建模
- 个体行为规则
- 交互规则
- 环境建模
- 涌现现象分析

## 论文结构建议
1. **问题分析**：明确仿真目标和要求
2. **系统描述**：
   - 系统边界定义
   - 关键要素识别
   - 假设条件说明
3. **模型建立**：
   - 仿真模型选择
   - 参数设定
   - 随机分布拟合
4. **仿真设计**：
   - 仿真流程设计
   - 随机数生成
   - 统计收集设计
5. **仿真实施**：
   - 编程实现
   - 验证与确认
   - 运行控制
6. **结果分析**：
   - 统计结果分析
   - 灵敏度分析
   - 置信区间估计
7. **结论与建议**

## 评分要点
### 必须包含的图表
- **系统框图**：展示系统结构
- **仿真流程图**：展示仿真逻辑
- **演化曲线图**：展示系统动态行为
- **分布直方图**：展示随机变量分布
- **灵敏度分析图**：展示参数影响

### 必须包含的表格
- **参数说明表**：详细参数定义和取值
- **随机分布表**：展示随机变量分布
- **统计结果表**：展示关键统计结果
- **置信区间表**：展示结果置信区间

### 方法选择要求
- 至少2种baseline对比方法
- 灵敏度分析必须
- 置信区间估计

### 创新性要求
- 仿真模型创新
- 算法实现创新
- 应用场景创新

## 常见陷阱
### 模型问题
- 系统边界定义不清
- 随机分布选择不当
- 参数设定不合理
- 假设条件过多

### 仿真设计问题
- 仿真流程错误
- 随机数生成不当
- 统计收集不足
- 运行次数不够

### 结果分析问题
- 统计分析不足
- 灵敏度分析缺失
- 置信区间缺失
- 与实际数据对比不足

### 论文写作问题
- 仿真过程描述不清
- 图表质量差
- 参考文献不足

## 特殊注意事项
1. **模型验证**：必须进行模型验证和确认
2. **随机性处理**：必须正确处理随机性
3. **统计分析**：必须进行充分的统计分析
4. **灵敏度分析**：必须进行参数灵敏度分析
5. **实际应用**：仿真结果必须有实际应用价值
