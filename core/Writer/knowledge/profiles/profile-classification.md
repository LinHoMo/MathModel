# 分类与聚类配置文件

## 适用题型
- 分类问题：将数据划分为预定义类别
- 聚类问题：发现数据中的自然分组
- 识别问题：识别特定模式或特征
- 判定问题：判断数据属于哪个类别

## 核心方法推荐
### 分类方法
- 逻辑回归（Logistic Regression）
- 支持向量机（SVM）
- 决策树（Decision Tree）
- 随机森林（Random Forest）
- 梯度提升（XGBoost, LightGBM）
- 神经网络（Neural Networks）

### 聚类方法
- K-means聚类
- 层次聚类（Hierarchical Clustering）
- DBSCAN密度聚类
- 高斯混合模型（GMM）

### 降维方法
- 主成分分析（PCA）
- t-SNE可视化
- 线性判别分析（LDA）

## 论文结构建议
1. **问题分析**：明确分类/聚类目标
2. **数据预处理**：
   - 缺失值处理
   - 异常值检测
   - 特征标准化
3. **特征工程**：
   - 特征选择
   - 特征构造
   - 降维处理
4. **模型建立**：
   - 算法选择与理由
   - 参数设置
   - 训练过程
5. **结果评估**：
   - 评估指标计算
   - 混淆矩阵
   - ROC曲线
6. **结论与建议**

## 评分要点
### 必须包含的图表
- **混淆矩阵**：展示分类结果
- **ROC曲线**：评估分类器性能
- **PR曲线**：类别不平衡时必须
- **特征重要性图**：展示关键特征
- **聚类可视化**：展示聚类效果

### 必须包含的表格
- **分类报告**：precision/recall/F1
- **算法对比表**：不同方法性能对比
- **混淆矩阵表格**：详细分类结果

### 必须报告的指标
- 准确率（Accuracy）
- 精确率（Precision）
- 召回率（Recall）
- F1分数
- AUC值

### 统计检验
- McNemar检验（对比两分类器）
- 5折或10折交叉验证
- 置信区间估计

## 常见陷阱
### 数据问题
- 仅用准确率评价类别不平衡数据
- 未处理缺失值和异常值
- 特征未标准化

### 模型问题
- 未做交叉验证
- 训练集泄漏到测试集
- 未报告baseline方法
- 参数调优不充分

### 结果问题
- 混淆矩阵未显示
- ROC曲线未绘制
- 误差分析缺失
- 结论过度宣称

## 特殊注意事项
1. **类别不平衡处理**：使用过采样（SMOTE）、欠采样或调整类别权重
2. **特征选择**：高维数据必须进行特征选择
3. **模型可解释性**：优先选择可解释性强的模型
4. **业务理解**：分类结果必须结合业务场景解释
5. **鲁棒性验证**：使用交叉验证确保模型稳定性
