# MDS 工具协议

## 真实能力边界

Syslab 当前通过内置 `syslab-search` MCP 暴露 `mdsSearch`。该工具查询 MWORKS 知识库，适合教程、概念、原理、排障和最佳实践，不是函数参数手册。

工具是否可见取决于运行环境：

- 需要有效的同元账号访问令牌。
- 只有自定义大模型 API Key、没有门户登录时通常不可用。
- 华为运行环境当前不注册该内置搜索。
- 工具可能以裸名或带 MCP 命名空间的名称出现。

不要把上述实现细节当作永恒契约；每次以当前会话的工具列表和 schema 为准。

## 当前输入契约

当前 `mdsSearch` 的输入只有：

```json
{
  "query": "约 100 字的连贯假设性答案"
}
```

`query` 必须是根据用户问题构造的 HyDE（Hypothetical Document Embedding）文本：写成一段可能出现在目标帮助文档中的答案，而不是搜索词。

### 好的查询

用户问“Syslab 里怎么提高 Julia 程序性能”时，可以构造：

> 在 Syslab 中优化 Julia 程序时，应先通过性能分析定位耗时和内存分配，再检查类型稳定性、全局变量、容器元素类型与循环中的临时对象。优先使用预分配、就地操作和适合的 Ty 工具箱接口，并在 Syslab 自带 Julia 运行时中对优化前后进行基准验证。

### 不好的查询

- `Syslab Julia 性能 优化 类型稳定`
- `怎么提高 Syslab Julia 程序性能？`
- 把用户整段问题不加改写地复制到 `query`
- 传入 `top_k`、`scope`、`column` 等当前 schema 没有的字段

## 结果契约

当前结果是一个数组，每项通常包含：

- `content`：命中文档片段。
- `score`：相关度。
- `metadata.title`：标题，可选。
- `metadata.location`：来源位置或链接，可选。

宿主当前会过滤带图片的条目、按 `location` 去重并限制结果数。Agent 不需要在答案中复述这些内部处理，也不要直接倾倒 JSON。

## 重写与失败处理

| 情况 | 处理 |
|---|---|
| 工具未出现在会话中 | 立即降级，不猜名字、不循环探测 |
| 未登录或缺少令牌 | 说明需要同元账号登录，进入降级链 |
| 查询为空 | 修正为非空的假设性答案后调用 |
| 首次无结果或结果偏题 | 换角度重写一次，不能复用原参数 |
| 第二次仍无结果 | 停止 MDS，使用本地文档或谨慎回答 |
| 网络、超时或服务错误 | 不连续重试；说明失败并降级 |
| 结果薄弱或冲突 | 限定结论并说明证据不足 |

不要把工作区源码、用户文件内容、令牌或其他敏感信息拼进查询。
